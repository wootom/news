01Hermes Agent 및 Codex 관련 문제 해결 및 업데이트 소식

  • Hermes Codex 연결 문제 발생:

- "no response from provider for 300s", "non retryable error", "non first byte" 등의 오류 메시지가 반복적으로 발생. - 특히 gpt-5.5 모델 사용 시 문제가 잦다고 보고됨. - https://github.com/NousResearch/hermes-agent/issues/32883 이슈 게시판을 통해 문제 상황 공유 및 해결 방안 논의.

  • 해결 방안 및 업데이트:

- Hermes 업데이트: hermes update 명령어를 통해 정식 패치 적용 (2026-05-27 기준). 특히 공식 스크립트로 설치한 경우 가장 간단한 방법. - pip 또는 brew로 설치한 경우 재설치가 권장됨. - Codex를 통한 패치: Codex 앱(또는 Claude 코드)에게 위 GitHub 링크를 기반으로 Hermes 패치를 요청하여 문제를 해결한 사례. - 모델 변경: - gpt-5.4-mini 또는 gpt-5.4로 일시적으로 모델을 변경하여 사용하면 문제가 완화되는 경우가 있음. - 하지만 5.4-mini는 성능 저하 ("원하시면 릴레이 지옥", "거북이가 된 느낌") 체감이 크다고 함. - 기타 시도: VPN을 사용하여 미국 IP로 변경 시 속도가 빨라졌다는 의견도 있음. - 오픈클로를 통한 해결: 오픈클로에 Hermes 수정 요청 시 해결되는 경우도 있음. - 최신 업데이트 내용 (05/26 오픈클로): - 응답 속도 자체가 빨라짐 (채팅을 먼저 띄우고 뒤에 작업). - 여러 코덱스 계정 지원. - Codex CLI 0.134.0으로 업데이트 필요. - Usage-limit 에러 메시지 개선.

  • Hermes Web UI:

- GItHub에 Hermes Web UI 프로젝트가 존재하며, 설정부터 대화까지 편리하게 사용할 수 있다고 함. - https://github.com/nesquena/hermes-webui

  • Codex 자체 성능 문제:

- Hermes 오류가 Codex의 느린 응답 또는 일시적인 차단 때문일 수 있다는 의견. - "Codex backend appears to be silently rejecting 'gpt-5.5' on chatgpt.com/backend-api/codex" 메시지도 확인됨.

03AI 활용 사례 및 논의

  • AI Native Org: 실리콘밸리에서 떠오르는 개념으로, 조직 자체가 AI를 위한 거대 하네스가 되는 것을 의미.

- https://www.forbes.com/councils/forbesbusinesscouncil/2026/05/12/designing-an-ai-native-organization-why-org-charts-are-obsolete/

  • OpenAI 스타트업 이벤트: 6월 17일 OpenAI에서 스타트업 창업가를 위한 이벤트를 강남에서 개최함.

- https://events.openai.com/founderdayseoul26/12005429

  • 자동매매 프로그램 개발: Python과 딥시크API를 활용하여 코인 자동매매 프로그램을 개발 및 테스트 중인 사례. 백테스팅 데이터만 너무 신뢰하지 말고, 실제 거래 시 서버 오류 등에 유의해야 함.
  • AI 반려봇의 이상 행동: AI 반려봇이 갑자기 평소와 다른 프로세스를 수행하고 알 수 없는 TTS 파일을 생성하는 경험 공유. AI 오류 또는 예상치 못한 동작으로 추정.
  • GPT 이미지 생성: GPT가 특정 요구사항 (예: 실제 모습처럼, 모션 블러, 불균일 조명)에 맞춰 다양한 형태의 이미지를 생성하는 사례.
  • AI 음악 창작: SUNO와 같은 툴을 활용하여 음악(가사 및 멜로디)을 만드는 과정 논의.

- AI가 생성하는 가사의 맥락, 라임, 철학적 내용 표현에 어려움을 겪는 문제점. - 인간적인 고뇌, 정치, 이상, 입체적 캐릭터 서사를 AI가 잘 표현하지 못한다는 의견. - 초안은 AI의 도움을 받지만, 휴먼 터치가 필수적이라는 결론. - Gemini의 품질에 대한 비판적인 시각: Claude가 한국어 맥락 이해에 더 낫다는 의견. - [괄호] 안의 프롬프트가 효과가 없다는 조언: 스타일 내에서 순수 키워드로 조절해야 함. - 관련 SUNO 링크 공유: https://suno.com/s/Hg5Ev3s3qfyfl2pm, https://suno.com/s/8jWPwEezNfWdalyZ, https://suno.com/s/Kr1OTSZvz61Z0yNW, https://suno.com/s/9BMlSVH9PL1lTb5k

04모델 관련 정보 및 이슈

  • Claude Opus 4.8 출시: Claude Opus 4.8이 출시됨 (2026-05-27 기준).

- https://www.anthropic.com/news/claude-opus-4-8

  • Claude API vs OAuth: Claude API 사용이 드물고, 주로 OAuth를 통해 사용하는 듯함.
  • Gemini 사용 제한: API 키 없이 정액제 플랜으로 Gemini를 오픈클로에서 사용 시 차단될 수 있음. Google Vertex API 사용 시 월 10만원 리미트가 빨리 소진되는 경우도 있음.
  • Openrouter 사용 정보:

- 크레딧 구매 이력에 따른 무료 모델 요청 한도: $10 미만 결제 시 일일 50회, $10 이상 시 일일 1,000회 요청 가능. - 공통 한도: 분당 20회 요청. - 실패한 요청도 쿼터에 포함, 트래픽 증가는 속도 제한(Throttling)을 유발할 수 있음. - Openrouter 무료모델 사용 시 $10 이상 크레딧 유지가 중요. - https://openrouter.ai/docs/api/reference/limits
