K-디자인 하네스, PRD 기반 UI 생성과 모델별 최적화로 30분 내 앱 디자인 완성

K-디자인 하네스, PRD 기반 30분 내 UI 생성과 모델별 최적화로 K-스타일 앱 완성

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

분석 범위: 원문 전체 69,655자 · 12개 구간. 원문 대조한 핵심 인용 16개를 바탕으로 요약했습니다.

01핵심 개요

  • K-디자인 하네스는 오픈소스 디자인 내핵으로, PRD 명세 기반의 K-스타일 UI/UX를 자동 생성하는 도구다.
  • 하네스 실행 시간은 약 30분 미만이며, 'Go'와 'Max' 두 단계로 서비스 디자인을 빠르게 마무리한다.
  • 색상 토큰은 설렘 중심의 웜톤과 믿음 중심의 쿨톤으로 분류되며, 도메인 스토리텔링은 PRD 작성 전 단계로 운영된다.
  • AI 디자인은 HTML 기반 에이전트로 Figma MCP보다 수정이 빠르고, 사진 탐색은 하이쿠, 최종 선택은 쏘넷으로 모델별 최적화된다.
  • K-스타일 앱은 실리콘밸리 미니멀리즘과 달리 핵심 기능 직관성과 한눈에 보이는 레이아웃에 집중한다.

02핵심 주장 / 논점 구조

  • K-디자인 하네스는 오픈소스 디자인 생태계 내 K-스타일 UI/UX를 구현하는 핵심 도구로 소개된다.
  • PRD 원문의 디테일한 명세를 기반으로 JSON 스펙과 사용자 흐름을 자동 생성하는 워크플로우를 제시한다.
  • 하네스 실행 시간은 30분 미만으로, 서비스 디자인의 빠른 완성을 목표로 하는 'Go' 단계와 심화 단계인 'Max'로 구성된다.
  • AI 디자인은 HTML 기반 에이전트 방식이 Figma MCP보다 수정이 빠르고 효율적이라고 평가된다.
  • K-스타일 앱은 실리콘밸리 미니멀리즘과 달리 핵심 기능의 직관적 도달과 시각적 명확성을 우선시한다.

03K-스타일 UI/UX 원칙과 색상 체계

  • K-스타일 UI/UX는 'Go'와 'Max' 두 가지 키워드로, 서비스 디자인의 빠른 마무리와 심화 작업을 구분한다.
  • 색상 토큰은 제품 핵심 가치에 따라 설렘 중심의 웜톤과 믿음 중심의 쿨톤으로 명확히 분류된다.
  • 금융·의료 등 신뢰가 중요한 도메인은 쿨톤, 축하·결혼 선물 등 설렘이 핵심인 도메인은 웜톤을 적용한다.
  • 도메인 스토리텔링은 하네스 실행 전 단계로, PRD 작성 이전에 수행되는 과정으로 정의된다.
  • K-스타일 앱은 실리콘밸리 미니멀리즘(Clubhouse 등)과 달리 기능 중심의 직관적 레이아웃을 지향한다.

04PRD 기반 자동화 워크플로우와 실행 시간

  • 하네스는 PRD 원문의 디테일한 명세를 입력받아 JSON 스펙과 사용자 흐름을 자동 생성한다.
  • 실제 실행 시간은 약 30분 미만으로, 10.7.1 버전 기준 빠른 디자인 생성이 가능하다.
  • PRD 명세가 디테일할수록 하네스가 생성하는 스펙의 정확도와 완성도가 높아진다.
  • 워크플로우는 서비스 디자인의 빠른 마무리(Go)와 심화(Max) 단계로 나뉘어 운영된다.
  • AI 디자인 에이전트는 HTML 기반이라 Figma MCP보다 수정이 빠르고 오류 해결이 용이하다.

05모델별 최적화와 사진 처리 전략

  • 사진 탐색 작업은 빠른 모델인 하이쿠(Haiku)가 담당하고, 최종 선택은 쏘넷(Sonnet)이 수행한다.
  • 모델별 역할 분담을 통해 사진 처리 테스트는 10분 만에 완료되며, 스크립트 실행은 1초 내 끝난다.
  • 파이썬 스크립트를 다수 구축해 이미지 처리와 디자인 생성 과정을 자동화한다.
  • AI 디자인은 HTML 기반 에이전트로, Figma MCP보다 수정이 빠르고 효율적이라는 평가다.
  • 모델별 최적화는 디자인 생성 속도와 품질을 동시에 확보하는 핵심 전략으로 제시된다.

06K-스타일 vs 실리콘밸리 미니멀리즘 비교

  • 실리콘밸리 스타일(Clubhouse 등)은 미니멀 디자인을 매우 아름답게 표현하는 특징이 있다.
  • K-스타일 앱은 미니멀리즘과 달리 핵심 기능에 직관적으로 도달할 수 있는 레이아웃을 우선시한다.
  • K-스타일은 헷갈리는 포인트를 최소화하고, 한눈에 보이도록 만드는 데 집중한다.
  • K-스타일 앱은 실리콘밸리 미니멀리즘이 제공하지 않는 기능 중심의 직관성을 강조한다.
  • 두 스타일은 디자인 철학이 달라, 제품 성격과 사용자 경험 목표에 따라 선택이 달라진다.

07로컬 LLM과 오프라인 운영 전망

  • 하네스 시대가 지나가고 로컬 LLM이 중요한 관심사로 부상하고 있다.
  • 오프라인 이벤트로 로컬 LLM 기반 디자인 생성을 수행할 수 있을 것으로 기대된다.
  • 로컬 LLM을 위해 Mac Studio와 GPU를 구매하는 계획이 언급된다.
  • 그래픽 카드는 100만 원대 수준으로, 로컬 LLM 구동에 적합한 하드웨어로 평가된다.
  • 로컬 LLM은 데이터 프라이버시와 오프라인 운영 측면에서 하네스의 미래 방향성으로 제시된다.
