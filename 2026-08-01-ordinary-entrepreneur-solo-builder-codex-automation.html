코덱스로 회사를 굴리는 1인 빌더 — 자동화·콘텐츠·고객관리까지 혼자 하는 법

스모어톡 공동창업자 출신 1인 빌더 이정민이 '평범한 사업가' 채널과 나눈 90분 대담. 왜 코덱스(Codex) 데스크톱 앱이 비개발자·개발자 모두에게 엑셀급 필수 도구가 됐는지, GLM·그록·클로드를 실제로 얼마씩 결제하며 무엇에 쓰는지, 사모펀드 AX 입찰과 자체 SaaS 4종 개발 등 혼자서 회사를 운영하는 실제 워크플로우, 그리고 '믹스처 오브 에이전트'라는 다음 흐름까지 구체적 수치와 도구명을 곁들여 풀어낸다.

01핵심 개요

항목내용
게스트이정민, 1인 빌더 (전 스모어톡 공동창업자, AI 콘텐츠 크리에이터 스타트업, 4년 재직 후 2026년 4월 퇴사)
핵심 주제코덱스(Codex) 데스크톱 앱이 왜 개발자·비개발자 모두에게 필수 도구가 됐는가
현재 사업금융권 AX 컨설팅(사모펀드 ERP 에이전틱화, 20인 규모 SI사와 경쟁 입찰 중) + GLM으로 개발한 자체 SaaS 4종
SNS 성과링크드인 팔로워 6개월 만에 1만 명 달성, 글 작성은 클로드에 초안 위임
구독 현황코덱스 프로 3개, 클로드 20달러(메인 아님, 비용·안정성·한국어 저하 이유로 축소), 그록 10→100달러 예정
다음 트렌드 예측에이전트 비용 상승으로 여러 모델을 엮어 쓰는 '믹스처 오브 에이전트'가 다음 화두가 될 것

02핵심 내용 구조 — 코덱스가 좋은 이유와 1인 빌더의 현실

이정민은 4년간 몸담았던 AI 콘텐츠 스타트업 스모어톡(이미지 생성 모델 '플라멜' 담당)을 2026년 4월 퇴사했다. 재작년 말 커서(Cursor), 작년 3~4월 클로드 코드 등장을 계기로 스스로 웹 개발을 익히기 시작했고, 이 경험이 1인 빌더 전환의 출발점이 됐다고 말한다. 그가 코덱스를 반복해서 추천하는 이유는 셋으로 정리된다. 첫째, 데스크톱 앱의 사용성 자체가 개발자·비개발자를 동시에 만족시키는 수준으로, "사무직의 엑셀"급 필수 도구가 될 것이라 전망한다. 둘째, GPT 이미지 2가 현재 가장 지시 반영도가 높은 이미지 생성 모델이라 슬라이드·카드뉴스 등 콘텐츠 제작에 바로 쓸 수 있다. 셋째, 크레딧이 넉넉하고 GPU 부족으로 인한 중단이 적어 장시간 작업을 믿고 맡길 수 있다. 반면 코덱스 모델 자체의 의도 파악력("눈치")과 프론트엔드 디자인 능력은 아직 약하다고 인정한다.

'토큰 맥싱(token maxing)'이라는 개념도 소개한다 — 모델을 여러 번 반복 실행해 슬롯머신처럼 잭팟(좋은 결과물)을 뽑아내는 방식으로, 프롬프트를 정교하게 다듬는 것보다 결과적으로 유용하다는 것. 클로드 코드가 초기 인기를 끈 이유도 구독 계정으로 대량의 API 사용이 가능했기 때문이었으나, 지금은 사용자 급증으로 제한이 걸려(예: 200달러 요금제도 1시간 만에 리밋) 코덱스가 상대적으로 유리해졌다고 설명한다.

인간의 역할론에 대해서는 "3인분을 해내는 설계자"가 돼야 한다고 강조한다. 예전에 팀장·부장급이 부하 직원을 관리하며 검토·수정·결재를 했다면, 이제 그 부하 직원 역할을 AI가 대신하고 개인은 AI 환경을 설계·관리하는 팀장 역할을 맡아야 한다는 것. 소비자 마인드가 아니라 생산자 마인드로 전환해야 살아남는다고 강조한다.

AI로 인한 고용 시장 재편에 대해서는 "디스토피아 시나리오가 실현될 것"이라 전망하며, 미국은 이미 컴퓨터공학·데이터엔지니어 등 선망 직업군에서 대규모 해고가 벌어지고 있고, 안드레센 호로위츠가 1인 개발자 사업자 등록 급증을 통계로 발표했다는 점을 근거로 든다. 한국은 아직 체감이 적지만, 내수 중심 기업일수록 위험하다고 본다.

03핵심 워크플로우 — 혼자서 회사를 굴리는 법

  • 일정/메일 자동화: 코덱스에 Gmail·구글 캘린더 플러그인을 버튼 클릭 한 번으로 연결. "어떤 고객사 메일에 아직 답장을 안 했는지" 음성으로 물으면 바로 답이 나오는 수준이면 충분하며, 별도의 복잡한 세팅은 불필요하다고 강조("연결만 해두고 안 쓰면 못 쓰는 사람인 것"이니 3일간 강제로 써보고 판단하라).
  • 원격 서버 작업: 맥미니-맥북을 SSH로 연결해두고, 코덱스 앱이 모바일에서 자동으로 원격 접속되도록 세팅. 화면이 잠겨 있어도 외부 요청 시 깨어나는 기능 덕분에, 이동 중에도 영상 편집 플러그인에 "파일 찾아서 편집해줘"라고 명령해 기존 2~3일 걸리던 편집 작업을 20~30분 만에 끝낸 경험을 공유했다.
  • 콘텐츠 자동화: 링크드인 글쓰기를 초안 단계부터 클로드에 전적으로 위임 — 자신의 과거 글 패턴을 학습시켜 AI가 오히려 "본인보다 본인 같은" 글을 쓰게 만든 것. 단, 완전 자동화 티가 나면 플랫폼 알고리즘이 노출을 억제하므로 반드시 사람의 검토·수정을 거쳐야 한다고 경고한다.
  • 자체 SaaS 개발: GLM 출시 이후 저렴한 API 비용 덕분에 24시간 풀가동으로 개발, 서비스 4종을 완성했으나 "서비스명과 결과를 동시에 공개하는 순간 카피 앱이 바로 나온다"는 이유로 공개하지 않고 있다.
  • 금융권 AX 컨설팅: 사모펀드·증권사를 상대로 파일럿 프로그램 진행 중이며, 한 사모펀드 건에서는 20인 규모 SI 회사와 경쟁 입찰 중 — 이를 수주하면 "1인 빌더로서의 가능성을 인정받는 계기"가 될 것이라 말한다.
  • 초기 세팅 우선순위: 무작정 일부터 벌이지 말고, 계약서 양식·이메일 포맷·슬라이드 템플릿(예: "제목은 항상 한 줄로 배치" 같은 규칙)을 스크립트 파일로 검증 가능하게 미리 구축해야 진짜 위임이 가능해진다고 조언한다.

04코덱스 프론트엔드 디자인 보완 팁

  • 무료: 코덱스 내장 "Product Design" 플러그인을 @ 호출해서 사용 — 가장 쉬운 방법으로 추천.
  • 고급(무료): design.md 같은 규칙 파일 + 규칙 위반을 검증하는 스크립트 + 이를 강제 호출하는 프론트엔드 스킬/훅 조합.
  • 유료: GLM 5.2를 API로 연결해 디자인 생성을 맡기고, 코덱스가 결과물을 검증하는 방식. GLM은 LM 아레나 벤치마크에서 프론트엔드 디자인 부문 Opus 4.8보다 우위로 나타났지만, 이미지 인식 자체가 안 되는 모델이라 화면 배치를 코덱스와 함께 검증해야 한다고 설명한다. 제미나이도 프론트엔드에 강해 대안으로 언급.
  • 헤드리스 CLI 오케스트레이션: 클로드는 -p, 코덱스는 exec 명령으로 커맨드 호출이 가능해, 코덱스 사이드 패널에서 클로드·제미나이를 동시에 띄워 작업시키는 방식도 소개됐다. 이런 조합이 바로 '믹스처 오브 에이전트'의 기초라고 설명한다.

05구독/모델 사용 현황 (실사용 공개)

  • 코덱스: 프로 3계정 (일부는 선물/할인 구매)
  • 클로드: 페이블(Fable) 출시 시 맥스 요금제로 잠깐 올렸다가 환불, 현재 20달러 요금제만 메인 아닌 보조용. 이유: 비용·장애가 많고, Opus 4.7 이후 한국어 생성 품질 저하 체감 — Opus 4.6만 사용 중.
  • 그록(Grok): 트위터 구독 연장선에서 월 10달러 프로모션 이용 중, 곧 100달러로 상향 예정. 이미지·영상 생성은 그록 "빌드"에서 컴포저(Composer) 2.5 모델을 호출해 사용 — 커서에서는 이미지 생성이 안 되므로 그록 빌드를 선호한다고 밝힘.
  • GLM 5.2: 프론트엔드 디자인과 자체 SaaS 개발에 저비용으로 24시간 가동.
  • 하네스: 서드파티 하네스는 세션 로그가 지저분하게 쌓이는 문제로 사용하지 않으며, 슬라이드 전용 자체 하네스와 "UGC 콘텐츠 팩토리"(에이전트가 코덱스로 이미지, 그록으로 영상을 생성해 대량의 AI UGC 영상을 뽑아내는 자체 파이프라인)를 비공개로 구축해 사용 중.

06활용 시나리오

  • 1인 빌더 준비생: 첫 1개월은 가볍게 시작하되, 2개월 차부터는 과감히 최소 200~300달러급 요금제 2개(합산 약 60~70만 원)를 "투자"라 생각하고 한도까지 써보는 '토큰 맥싱' 경험을 추천 — 시행착오를 통해 어디를 아껴야 할지 아는 안목이 생긴다는 논리.
  • 직장인이 퇴사 전 준비할 것: 회사 안에서는 세일즈·가격 책정 감각이 생기지 않으므로, SNS 반응을 스스로 만들어보거나 소액 광고 테스트로 도달 지표를 미리 확인해볼 것을 권한다.
  • 1인 기업 자동화 필요 여부 자가진단: 순수 개발/서비스 판매형 빌더는 태스크 관리만으로 충분하고 별도 메일/캘린더 자동화가 불필요하나, 기업 대상 컨택 포인트가 쌓이는 유형(컨설팅·외주)은 Gmail/캘린더 자동화가 필수라고 구분한다.

07현황 및 전망

이정민은 올해 말을 1인 빌더 활동의 자체 마감 기한으로 설정해두었으며, 목표(월 매출 1억 원 달성 경험)를 이루지 못하면 회사 복귀도 고려 중이라고 밝혔다. 외부 행사는 축소하고 국내 주요 IT 기업·글로벌 빅테크 지사와의 내부 미팅·전략 수립에 집중할 예정이며, 향후 화이트보드(엑스칼리드로우) 스타일의 유튜브/인스타그램 콘텐츠 제작을 검토 중이다. 그는 에이전트를 한 번도 안 써본 사람과 이미 앞서가는 사람 사이의 격차가 "넘어설 수 없는 수준"으로 벌어지고 있다고 우려하며, 오픈AI·구글·앤트로픽 외 오픈소스/중국 모델(GLM 등)을 결합하는 '믹스처 오브 에이전트'가 API 비용 절감을 위해 필수가 되는 흐름이 이미 시작됐다고 진단한다. 다만 개발에만 매몰돼 최신 흐름(하네스, 앱 업데이트 등)을 놓치는 것도 경계해야 하며, 특정 소수 인플루언서를 팔로우해 흐름만 꾸준히 따라가는 것으로도 충분하다고 조언한다. 마지막으로 번아웃 방지를 위한 건강 관리의 중요성을 강조하며 대담을 마무리했다.

08용어 사전

용어한줄설명비유/예시
토큰 맥싱모델을 여러 번 반복 실행해 최고 결과물을 뽑아내는 방식슬롯머신을 여러 번 돌려 잭팟을 노리는 것
믹스처 오브 에이전트(MoA)여러 AI 에이전트·모델을 조합해 비용 대비 성능을 최적화하는 구성한 사람이 다 하지 않고 각 분야 전문가를 팀으로 엮는 것
헤드리스 CLI 콜링에이전트를 대화창 없이 커맨드(예: exec, -p)로 직접 호출하는 방식사람이 채팅으로 묻는 대신 스크립트로 바로 명령 전달
AX(AI Transformation)기업의 업무 시스템을 AI 에이전틱 구조로 전환하는 작업ERP를 사람 대신 AI가 운영하도록 재설계하는 것
