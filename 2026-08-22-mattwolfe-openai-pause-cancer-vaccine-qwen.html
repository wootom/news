항목내용

02핵심 기능/내용 구조

  1. Trippo 2.0 — 3D 에셋 생성 도구: 이미지를 입력하면 3D 프린팅·블렌더·언리얼 엔진에 바로 쓸 수 있는 3D 메쉬를 생성하는 도구. Matt은 본인 사진으로 3D 아바타를 만들었으나, 메쉬(형태) 자체는 정확했지만 텍스처(스킨)를 입히는 과정에서 입술·코 등 얼굴 부위가 왜곡되는 문제를 발견했다. 반면 Nano Banana로 생성한 늑대 인간형 판타지 캐릭터 이미지를 입력했을 때는 텍스처까지 완성도 높게 나왔는데, 이는 실사 인물보다 AI 생성 판타지 캐릭터 쪽이 결과물이 더 낫다는 관찰로 이어졌다. 추가로 조명 없는 버전(만화 스타일 아웃라인, 스케치 스타일, 홀로그램 스타일)을 내보낼 수 있어 게임 에셋(예: 캐릭터가 피해를 입으면 날개가 파괴된 버전)으로 활용 가능성을 시연했다. 녹화 시점 기준 무료로 2개 생성 가능.
  2. mRNA 흑색종 백신 3상 성공과 AI의 역할: 모더나의 mRNA4157 흑색종 백신이 2B~4기 흑색종 환자 1,137명 대상 3상 임상시험에서 암 재발까지의 기간을 연장시키는 성과를 냈다. Ars Technica 보도에는 AI 언급이 없어 "AI를 안 썼다"는 온라인 논쟁이 있었지만, Matt은 2023년 12월 기사를 근거로 이 백신이 완전히 통합된 AI 알고리즘으로 종양·혈액 샘플의 차세대 시퀀싱 데이터를 분석해 면역 반응을 유발할 가능성이 높은 신생 항원(neoantigen)을 최대 34개까지 예측하며, 임상·면역원성 데이터를 결합해 시간이 지날수록 정확도가 개선되는 머신러닝·신경망 기반 예측 엔진이라는 점을 확인했다. 생성형 AI가 직접 치료법을 찾아낸 것은 아니지만, 오늘날 대규모 언어 모델과 유사한 예측 엔진이 실제 의료 성과에 기여한 사례로 소개된다.
  3. Hyper Agent (협찬): 하나의 AI에 모든 일을 맡기는 대신 각기 다른 역할을 수행하는 전문 에이전트 팀을 구성해 사람과 에이전트가 함께 협업하는 플랫폼. OpenClaw·Hermes·Claude Code 같은 도구가 개인 로컬 환경에 묶여 협업이 어려운 점을 보완한다고 소개되며, Matt은 스크립트 일부를 입력하면 실사 B-roll 영상·모션그래픽을 생성하는 B-roll 생성기를 직접 만들어 팀과 공유한 사례를 언급했다. 마켓플레이스에서 다양한 스킬을 사용하거나 직접 에이전트 팀을 구축할 수 있다.
  4. Qwen3.8 27B — 로컬 실행 가능한 오픈웨이트 모델: 알리바바가 공개한 270억 파라미터 오픈웨이트 모델로, 지난주 소개된 2.4조 파라미터 버전과 달리 24~32GB VRAM의 소비자용 GPU(RTX 3090/4090/5090급 또는 대용량 통합 메모리 Mac)에서 로컬 실행이 가능하다. Artificial Analysis 에이전트 지수에서 GPT-5.6 Turbo·Luna보다 높고 Kimi K3보다는 약간 낮은 성능을, 전체 지능 지수에서는 52점으로 GPT-5.6 Luna Max·DeepSeek V4·Gemini 3.7 Flash 바로 아래 수준을 기록했다. LM Studio(무료 앱)로 4/5/6/8비트 양자화 버전을 다운로드해 실행할 수 있고, 검열 없는(uncensored) 버전도 존재한다. LM Studio 자체는 단일 채팅형이라 에이전트형 작업에는 한계가 있어, Matt은 에이전틱 하네스로 Hermes를 연결해 사용했다. Hermes로 Mega Bonk 게임 클론을 시도했으나 로컬 GPU로 약 2시간이 걸리고 결과물도 실행되지 않아 실패했고, 별도로 클라우드(OpenRouter) 경유 Beautybench 테스트에서는 7만 토큰·74분·25센트가 소요됐다.
  5. OpenAI 차세대 모델 개발 일시중단 및 ChatGPT 신기능: OpenAI가 "사이버 보안 핵심 역량 시대의 모델 개발 속도 조절"이라는 제목으로, GPT-6/Project Astra로 추정되는 차세대 모델의 강화학습(RLHF 단계) 훈련과 최대 규모 프론티어 강화학습 실행을 일시 중단하고 레드팀 테스트를 강화한다고 발표했다. 이는 모델 사전학습 자체는 끝나고 최종 조정 단계만 남은 상태로 해석되며, 과거 모델들이 샌드박스를 탈출하거나 웹사이트를 해킹한 사례가 있어 배포 시점은 불확실하다. 대신 이번 주 실제로 출시된 것은 ChatGPT의 "컴퓨터 사용 기록(Computer History)" 기능으로, 사용자가 활성화한 앱·웹사이트 활동을 타임라인으로 기록해 ChatGPT/Codex가 이를 참조하고 반복 워크플로우를 스킬·자동화로 제안할 수 있게 한다. 사용자가 직접 켜야 하며 앱별 선택, 일시중지, 기록 삭제가 가능하다. 추가로 Mac용 ChatGPT 앱에 Apple Messages 플러그인이 추가되어 앱 내에서 메시지 검색·확인·답장이 가능해졌다.
  6. 기타 단신: Meta가 Codex·Claude Code와 유사한 UI의 전용 Mac 앱을 출시(예약 작업·아티팩트·미디어·채팅 기록 지원). Perplexity가 Andrej Karpathy의 "위키" 개념을 구현한 지식 그래프형 두뇌 기능을 출시. 구글이 AI 생성 이미지·영상·음악의 워터마크를 사용자가 끌 수 있게 해 가짜 콘텐츠 확산 우려가 제기됨(비가시 합성 ID 워터마크는 유지). Claude가 Gmail 발송 및 Google Drive 파일 관리 기능을 추가(승인 시점 설정 가능). OpenAI가 대화 패턴으로 성인/청소년을 추정해 청소년으로 판단되면 자동으로 제한된 버전을 제공하는 기능을 출시. 구글이 전 세계 대학생에게 Google AI 플랜 1년 무료 제공. 알리바바가 음악 생성 모델 "Happy Shrimp 1.0"을 출시(Suno 대비 완성도는 낮다는 평). Cursor가 GitHub 유사 플랫폼 "Origin"을 개발 중. Salesforce가 Slack에 에이전트 코딩 협업 기능을 도입(Codex/Claude Code 등 기존 도구를 Slack 채널에서 호출). Pew 리서치 조사에 따르면 ChatGPT 출시 이후 게시된 인터넷 페이지의 35%가 AI로 작성됨. Unitree 로봇 "슈퍼맨"이 제자리에서 2m 점프, 초속 12.66m 주행 속도를 기록.

03기술적 맥락

이번 주 뉴스의 공통 축은 "모델 크기 대비 성능"과 "AI 활용의 실질적 증거"다. Qwen3.8 27B는 파라미터 수를 줄이면서도 지능 지수 52점으로 프론티어 모델에 근접한 성능을 보여, 로컬 실행 가능한 오픈웨이트 모델의 벤치마크 격차가 빠르게 좁혀지고 있음을 시사한다. LM Studio(단일 채팅 인터페이스)와 Hermes(에이전틱 하네스)의 조합은 로컬 모델을 Codex·Claude Code 같은 에이전트형 워크플로우로 확장하는 현재의 표준 패턴을 보여주지만, 실제 코딩 작업(Mega Bonk 클론)에서는 시간·안정성 면에서 클라우드 프론티어 모델 대비 여전히 열세임이 드러났다. 한편 mRNA 백신 사례는 "AI"라는 단어가 언론에 명시되지 않아도 머신러닝 기반 예측 엔진이 실제 신약 개발 파이프라인(신생 항원 예측)에 이미 깊이 통합되어 있음을 보여주며, 이는 생성형 AI·LLM 담론과는 별개로 진행되어 온 응용 머신러닝의 성과라는 점이 중요한 구분이다. OpenAI의 강화학습 훈련 중단은 사전학습 이후 안전성 조정 단계에서 조직적으로 속도를 늦추는 사례로, 모델 배포 파이프라인에서 RLHF·레드팀 테스트가 병목이 되고 있음을 보여준다.

04전략적 의미

첫째, 로컬 실행 가능한 오픈웨이트 모델(Qwen3.8 27B)이 소비자용 GPU 수준에서도 프론티어 모델에 근접한 성능을 내면서, 향후 데이터·프라이버시 민감 워크로드나 비용 절감을 위한 로컬 AI 인프라 채택이 가속화될 가능성이 있다. 둘째, 파운데이션 랩들이 사이버 보안·안전성 우려로 최신 모델 공개를 늦추는 경향이 강화되면서, 당분간 "제품 기능 업데이트"(컴퓨터 사용 기록, 앱 통합 등) 중심의 점진적 개선이 대형 모델 출시보다 두드러질 것으로 예상된다. Matt은 메타 커넥트와 OpenAI 개발자 데이(다음 달)에 맞춰 차기 모델이 공개될 가능성을 추측성으로 언급했다. 셋째, mRNA 백신 사례처럼 AI가 실제 성과에 기여했음에도 언론이 이를 명시하지 않는 경향은, "AI 워싱"에 대한 반작용으로 AI 언급 자체를 회피하는 새로운 트렌드를 시사하며, 이는 향후 AI 기여도를 검증할 때 표면적 언급 여부가 아니라 기술적 실체(알고리즘 구조, 데이터 파이프라인)를 확인해야 한다는 방법론적 함의를 준다. 넷째, ChatGPT 컴퓨터 사용 기록·Slack 에이전트 코딩 등은 AI 에이전트가 사용자의 실제 작업 맥락(과거 행동 이력, 협업 채널)에 점점 더 깊이 통합되는 방향을 보여주며, 이는 편의성 증가와 동시에 지속적인 활동 모니터링에 대한 프라이버시 트레이드오프를 수반한다.

06활용 시나리오

  1. 로컬 AI 인프라를 검토하는 개발자/기업: 데이터 프라이버시나 비용 문제로 클라우드 LLM 대신 로컬 실행을 고려할 때, Qwen3.8 27B를 LM Studio로 다운로드해 24~32GB VRAM급 GPU에서 성능·속도를 직접 벤치마크하고, Hermes 같은 에이전틱 하네스와 연결해 실제 코딩 워크플로우에 적용 가능한지 검증하는 데 참고할 수 있다.
  2. 게임/3D 콘텐츠 제작자: Trippo 같은 이미지-투-3D 도구를 파이프라인에 도입할 때, 실사 인물 사진보다 Nano Banana 등으로 먼저 생성한 판타지 캐릭터 이미지를 입력하면 텍스처 품질이 더 높다는 관찰을 참고해 워크플로우 순서를 설계할 수 있다.
  3. AI 리터러시 교육 담당자/미디어 종사자: mRNA 백신 사례처럼 "AI 언급 여부"만으로 AI 기여도를 판단하는 온라인 논쟁을 접했을 때, 기술 문서(알고리즘 구조, 데이터 파이프라인)를 직접 확인해 실제 AI 활용 여부를 검증하는 방법론을 적용할 수 있다.
  4. 생산성 도구 관리자: ChatGPT 컴퓨터 사용 기록이나 Apple Messages 통합 같은 맥락 인지 기능을 팀에 도입할 때, 프라이버시 설정(앱별 선택, 일시중지, 기록 삭제)을 사전에 검토해 반복 워크플로우 자동화와 데이터 노출 리스크 사이의 균형을 설계하는 데 참고할 수 있다.

07현황 및 전망

OpenAI는 GPT-6/Project Astra로 추정되는 차세대 모델의 강화학습 훈련을 안전성 검증을 이유로 일시 중단한 상태이며, Matt은 다음 달 메타 커넥트·OpenAI 개발자 데이 일정에 맞춰 각사의 차기 모델이 공개될 가능성이 있다고 추측하되 확실한 정보는 없다고 밝혔다. 로컬 실행 가능한 오픈웨이트 모델(Qwen3.8 27B)이 파라미터 규모를 줄이면서도 벤치마크 성능을 유지하는 추세가 이어지고 있어, Matt은 Opus/GPT급 모델을 소비자용 GPU에서 돌릴 수 있는 날이 머지않았다고 전망했다. 전반적으로 이번 주는 뉴스량은 많았으나 하나하나는 소규모 개선에 가까웠고, 프론티어 랩들이 사이버 보안 우려로 대형 모델 공개를 미루는 경향이 강해지면서 당분간 이런 점진적 흐름이 지속될 것으로 예상된다.

08용어 사전

용어한줄설명비유
오픈웨이트 모델(Open-weight model)모델 가중치 파일을 공개해 누구나 다운로드·로컬 실행할 수 있는 모델소스코드는 아니지만 완성된 프로그램 실행파일을 무료 배포하는 것
신생 항원(Neoantigen)암세포에만 나타나는 변이 단백질 조각으로, 면역세포가 이를 표적 삼아 암을 공격하도록 유도하는 백신의 핵심 성분암세포에만 붙어있는 "지명수배 전단지"
양자화(Quantization)모델 파라미터의 정밀도를 낮춰 파일 크기와 연산량을 줄이는 압축 기법고화질 사진을 용량 줄이려 압축하면 화질이 살짝 떨어지는 것과 유사
에이전틱 하네스(Agentic harness)LLM에 작업 체크리스트 생성·순차 실행 기능을 얹어 자율적으로 다단계 작업을 수행하게 하는 프레임워크단순 채팅봇에 "할 일 목록 관리 비서"를 얹은 것
강화학습(RLHF, 이 영상 맥락)사전학습이 끝난 모델을 사람의 선호도·안전 기준에 맞춰 미세조정하는 후처리 훈련 단계원석을 다 깎은 뒤 마지막으로 광택을 내는 마무리 공정
VRAMGPU에 내장된 전용 메모리로, 로컬에서 실행 가능한 AI 모델 크기를 좌우하는 핵심 제약 조건모델이라는 짐을 실을 수 있는 트럭 적재함 크기
