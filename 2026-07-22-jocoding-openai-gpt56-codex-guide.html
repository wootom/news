02핵심 내용 구조

이번 데모의 두 축은 (1) 실시간 음성 통번역(GPT 보이스)과 (2) 강력해진 코딩 에이전트 Codex다. 에어팟과 챗GPT 보이스 모드만으로 실시간 통역기가 되며, Codex로 유튜브 채팅을 실시간 번역하는 크롬 익스텐션을 즉석에서 만들어낸다. (0:00 딥링크)

03기술적 맥락 — 음성 처리의 3세대 진화

1세대는 음성→텍스트→LLM→텍스트→음성의 단계별 처리로 느렸다. 2세대 GPT-4o는 턴 기반이라 대화가 다소 부자연스러웠다. 이제 GPT-Live-1은 말하는 동안 바로 응답하는 진짜 실시간이며, 더 높은 지능이 필요하면 GPT-5.5 같은 모델에 작업을 '위임'해 검색 등을 처리한다. 무료 버전 포함 Go·Plus·Pro 전부에서 사용 가능. (3:02 딥링크)

04전략적 의미 — 접근성과 속도

실시간 통역·미니 모델·API 제공으로 누구나 활용 가능해졌고, Cerebras 칩 위의 GPT-5.6 Sol은 초당 750토큰의 전례 없는 속도를 낸다. 5.3 Spark는 연구 프리뷰였고, 이를 최신 5.6 Sol로 정식화했다(초기 접근 제한 후 용량 확대 예정).

05핵심 워크플로우 — Codex 신기능

  1. 플랜모드 불필요: 사람에게 말하듯 자연스럽게 요청하면 됨. 질문이 더 길고 자연스러워짐.
  2. 자동 리뷰: 모든 명령 승인(한쪽 끝)과 YOLO 모드(다른 끝) 사이의 중간 지점. 서브 에이전트를 생성해 검토.
  3. Goal(목표): Codex에게 스스로 목표를 정하게 하는 에이전트 기능.
  4. 사이드챗: 작업 중인 에이전트를 방해하지 않고 옆에서 지시(이름 변경·핀 고정 등)를 대신 전달.
  5. 스크린샷/맥락 전달: 커맨드+스크린샷으로 텍스트·데이터까지 포함해 전달(단순 이미지 아님). 이메일 캡처로 답장 요청, CSV 분석·PPT 생성, 이미지 생성까지. (8:58 딥링크)

06활용 시나리오

  • 실시간 라이브 번역: 크롬 익스텐션으로 유튜브 채팅을 실시간 영↔한 번역, 이모지 디자인까지 적용.
  • 데이터→산출물: 18MB ICML 논문 CSV를 분석해 트렌드 프레젠테이션·초록 기준 분류 PPT를 Codex 안에서 바로 생성·편집·전송.
  • 클라우드 실행: DigitalOcean 플러그인으로 원격 droplet 생성, SSH 자동 발급 후 노트북을 닫아도 클라우드에서 작업 지속. 스마트폰 연동으로 이동 중에도 확인·새 작업 지시.

07현황 및 전망

플러그인(OpenAI Developers)으로 API 키 발급·로테이트까지 자동화되고, Computer Use로 브라우저·앱 제어, 5분마다 서버 준비를 확인하는 '하트비트' 자동화, 이메일/Slack 처리·자동 PR 등이 시연됐다. 이 모든 데모가 5.5 기준이며 5.6은 더 좋아질 것이라 예고했다.
