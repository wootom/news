OpenAI GPT-6 Soul·Luna는 Astra급 성능 일부를 절반 이하 비용으로 겨냥한다.

GPT-6 Soul·Luna는 Astra보다 낮은 복잡도 작업을 절반 이하 비용으로 겨냥한다.

01핵심 개요

  • GPT-6 제품군은 상위 모델 Astra 아래에 Soul과 Luna를 배치해, 덜 복잡한 작업을 저비용으로 처리하도록 설계됐다.
  • Frontier Code에서 Soul은 49.3%, 작업당 2.14달러를 기록해 Astra의 53.3% 대비 성능 차이를 좁혔다.
  • Luna는 Frontier Code 42.4%와 작업당 11센트를 제시했으며, GPT-5.6 Luna와 성능은 비슷하지만 비용 차이가 크다고 설명했다.
  • GPT-6 전환으로 입력·출력 비용이 모두 50% 줄었고, Luna 가격은 입력 10센트·출력 50센트로 제시됐다.
  • Soul과 Luna는 사실 오류율, 캐시 유지 방식, API 프롬프트 캐싱 대시보드 측면에서도 개선 사항을 포함한다.

02핵심 주장 / 논점 구조

  • OpenAI는 GPT-6 Astra보다 낮은 등급의 Soul과 Luna를 통해 성능과 비용의 균형점을 제공하려 한다.
  • Soul과 Luna는 Astra를 능가하기 위한 모델이 아니라, 복잡도가 낮은 작업을 더 저렴하게 처리하는 용도다.
  • 영상은 Anthropic의 Opus 5.5와 GPT-6 Astra가 고성능 영역을 맡는 반면, Soul·Luna는 효율 영역을 겨냥한다고 비교한다.
  • 발표자는 많은 사용자가 Astra·Opus급보다 한 단계 낮은 문제를 다루므로 비용이 핵심 변수라고 강조한다.

03Frontier Code 성능과 작업당 비용

  • Frontier Code에서 GPT-6 Astra의 최대 점수는 53.3%, Soul의 점수는 49.3%로 소개됐다.
  • Soul의 작업당 비용은 2.14달러로, Astra와 비교해 절반 이하 비용이라는 점이 강조됐다.
  • Luna는 같은 벤치마크에서 42.4%를 기록했고 작업당 비용은 11센트로 제시됐다.
  • Soul을 중간 노력 수준으로 설정하면 점수는 46%, 비용은 80센트라고 설명했다.

04Claude Opus 5.5와의 비용 대비 비교

  • Claude Opus 5.5는 Frontier Code에서 54.4%, 작업당 6.19달러로 소개됐다.
  • 영상은 Soul이 Opus 5.5보다 약 5% 낮은 점수이지만 비용은 약 3분의 1 수준이라고 비교했다.
  • Opus와 Fable은 매우 우수하지만 비용이 높은 반면, Anthropic은 저렴하고 효율적인 모델 제공에 어려움이 있다고 평가했다.
  • Soul과 Luna는 복잡하지 않은 작업에서 Anthropic 모델군의 비용 공백을 채울 수 있다는 것이 영상의 관점이다.

05GPT-5.6 대비 가격 효율 변화

  • GPT-6 Soul은 GPT-5.6 Soul 대비 성능 향상은 작지만 비용 효율성 증가는 유의미하다고 설명됐다.
  • GPT-6 Luna는 GPT-5.6 Luna와 성능이 대체로 비슷하지만 비용 차이가 특히 크다고 언급됐다.
  • 영상은 GPT-6 Luna의 작업당 비용을 15센트, GPT-5.6 Luna의 비용을 2.57달러로 제시했다.
  • GPT-6는 일부 경우 Claude Fable 5.1과 저노력 GPT-6 Astra를 앞서는 사례가 있다고 소개됐다.

06사실 오류율 개선 수치

  • GPT-5.6 Luna의 최대 노력 수준 사실 오류율은 12%였으나, GPT-6 Luna에서는 7.6%로 제시됐다.
  • 저노력 Luna의 사실 오류율은 36%에서 27%로 낮아졌다고 설명됐다.
  • Soul의 사실 오류율은 8.5%에서 4.6%로 개선됐으며, Astra의 3.9%에 근접한다고 평가됐다.
  • 영상은 GPT-6 Soul의 정확도가 Astra와 비교 가능한 수준에 가까워졌다고 주장했다.

07캐시 유지와 API 사용성 변화

  • 웜 캐시는 OpenAI 에이전트와 대화를 이어 가는 상태이며, 영상은 이 상태에서 90% 할인이 적용된다고 설명했다.
  • 하루 뒤 같은 대화로 돌아오면 전체 대화 입력 비용이 청구될 수 있어 비용이 커질 수 있다고 언급했다.
  • 기존에는 추론 노력 수준을 낮음에서 높음으로 바꾸면 캐시가 초기화됐지만, 이제는 캐시가 유지된다고 소개됐다.
  • OpenAI는 API 사용자가 캐시 구간을 최적화할 수 있도록 프롬프트 캐싱 대시보드도 추가했다.
  • GPT-6 Soul과 Luna는 사실상 모든 곳에서 사용할 수 있으며, 영상은 GPT-6 Terra 출시 가능성도 언급했다.
