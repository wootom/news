클로드 코드 서브에이전트로 카드뉴스 마케팅 팀 만들기 (빌더 조쉬)

빌더 조쉬가 신간 '클로드 에이전트 협업의 기술'(한빛미디어) 16장 실습을 라이브로 시연했다. IDE 도구 오르카(Orca) 위에서 클로드 코드 서브에이전트로 마케팅 디렉터(오케스트레이터)+카드뉴스·블로그·SNS 작성 에이전트+검수 에이전트를 구성하고, 순정 클로드의 저품질 이미지를 GPT 이미지 2.0 API로 끌어올린 뒤 힉스필드(익스필드) MCP로 영상까지 자동화한다. 카드뉴스 1건 생성 비용은 수백 원 수준, 영상은 15~30초에 2~3천 원대다.

02핵심 내용 구조 — 감도 싸움과 멀티에이전트 구성

조쉬는 모두가 빌더가 되어 결과물을 만들 수 있는 시대에는 디자인·카피라이팅·전달력 같은 '감도'가 차별점이라 강조한다. 실습 목표는 통일된 톤앤매너의 마케팅 팀을 만들어 카드뉴스·블로그·뉴스레터·SNS를 한꺼번에 뽑는 것. 클로드 코드에 "마케팅 에이전트 팀을 추천해 줘"라고 요청하면 오케스트레이터(마케팅 디렉터) 아래 카드뉴스 크리에이터, 블로그 라이터, 소셜 미디어 라이터와 브랜드 가디언·카피라이터·리뷰어 같은 검수 에이전트를 자동 제안한다.

03기술적 맥락 — 컨텍스트와 클로드.md의 역할

첫 스텝은 컨텍스트 폴더에 캐릭터(claude.png)와 레퍼런스 카드뉴스 이미지를 넣어 브랜드 맥락을 충분히 입히는 것이다. 서브에이전트는 "워크플로우가 담긴 마크다운 프롬프트 모음집"으로 정의되며, 이를 만든 뒤 반드시 CLAUDE.md(작업 순서·SOP)를 별도로 작성해야 에이전트가 업무 순서를 잊지 않는다. 대량·복잡 작업에서 핵심 정보 누락(할루시네이션)이 생기면 1M 컨텍스트 모델을 선택해 토큰 여유를 확보하라고 조언한다.

04핵심 워크플로우 — 순정→GPT 이미지→영상 3단계

순정 클로드는 이미지를 HTML로만 밀어내 품질이 낮으므로, .env에 OpenAI API 키를 넣고 GPT 이미지 2.0(또는 코덱스 CLI 기본 제공)으로 카드뉴스 6장 세트를 생성해 퀄리티를 크게 끌어올린다. 오르카 브라우저의 '페이지 요소 주석 달기'로 결과물에 직접 피드백을 찍어 에이전트에 일괄 전송할 수 있다. 마지막으로 힉스필드 MCP를 URL만 붙여 연결한 뒤 카드 이미지를 5초짜리 움직이는 영상으로 변환하고, 전체 팀을 구동하는 웹 스튜디오 페이지까지 루프로 완성한다.

05활용 시나리오

1인 소셜 미디어 운영이나 콘텐츠 마케팅 에이전시가 일관된 브랜드 톤의 카드뉴스·블로그·영상을 반복 생산·자동 발행하는 데 적용할 수 있다. 버퍼 API를 연동하면 매일 오전 정해진 시각에 인스타·쓰레드·X로 자동 배포가 가능하다(단, 티스토리·네이버 블로그 직접 발행은 까다롭다).

06현황 및 전망

조쉬는 순정 모델(GPT-5.6 계열 등)이 워낙 강해 하네스 무용론이 도는 시대에도, 카피라이팅·정확도에서는 클로드가 여전히 우위이며 약점은 이미지·미디어 엔진 부재라고 진단한다. 노출된 API 키가 탈취돼 약 270만 원이 청구된 경험을 공유하며 .env·gitignore를 통한 키 보안을 거듭 강조한다.
