ChatGPT Work의 'Sites' 기능, 대화를 실제 웹앱으로 바꾸다

Futurepedia가 소개하는 ChatGPT Work의 숨은 기능 Sites — 채팅 결과를 지속형 웹사이트·자동화 도구로 전환

01핵심 개요

  • ChatGPT Work·Codex 전용 기능 "Sites", @sites 태그만으로 9분 만에 게임 사이트 "Capybara Protocol" 생성
  • 라이브 URL, 지속 데이터 저장, 파일 스토리지, 인증, 애널리틱스가 자동으로 제공됨
  • GitHub 무료 스킬 "Last 30 Days"와 결합해 필터 가능한 트렌드 리서치 대시보드 구축
  • Gmail 다중 연동으로 뉴스레터 2,000통 이상 백필, 레코드 2,081건→2,094건 자동 증가 시연
  • "Scheduled tasks" 자동화로 매일 정오 새 뉴스레터 처리, 사람 개입 없는 상시 갱신 데이터베이스 완성

02핵심 주장 / 논점 구조

  • Sites는 "채팅에 묻히는 결과물"을 "계속 쓸 수 있는 인터페이스"로 바꾸는 것이 핵심 가치라는 것이 발표자의 중심 주장
  • 단순 요약본이 아니라 대화·파일·리서치·의사결정 과정 전체를 인터랙티브 사이트로 압축할 수 있다는 점을 강조
  • 지속적 데이터 저장(persistent storage) + 스케줄 자동화(scheduled tasks)가 결합되는 순간 "장난감"이 아니라 "진짜 도구"가 된다고 규정
  • 정교한 게임 개발 등 고난도 코딩에는 Codex나 Claude Code가 더 적합하다며 Sites의 적용 범위를 스스로 한정

03기능 상세 설명

  • 웹 앱에서 상단 메뉴를 Chat에서 Work로 전환해야 Sites 사용 가능(Work는 codex 능력을 일반 사용자도 쓰게 만든 에이전틱 모드)
  • 채팅에 원하는 내용을 쓰고 @sites를 태그하면 도구가 호출되어 사이트를 빌드·배포
  • Share 메뉴에서 Public/Private 전환 가능, Private면 ChatGPT 계정 로그인 필요
  • Settings에서 URL 앞부분 커스터마이징, 커스텀 도메인 연결, 환경 변수 추가, 방문자 애널리틱스 탭 확인 가능
  • 사이트 수정은 채팅으로 요청 후 새로고침하면 즉시 반영되는 방식으로 반복 편집

04실전 활용 단계

  1. 이미 쌓인 프로젝트 대화(예: 디즈니랜드 여행 계획 — 호텔 선택, 놀이기구 우선순위 등)에서 새 채팅을 열고 "지금까지 논의한 내용을 인터랙티브 사이트로 정리해줘"라고 요청
  2. 기존에 만든 사이트가 있으면 ChatGPT가 중복 생성 대신 자동 인식해 새 대화 내용으로 업데이트
  3. 외부 스킬(Last 30 Days) 설치 시 "skill creator로 이 GitHub URL 스킬을 추가해줘"라고만 요청하면 자동 패키징
  4. 스킬 실행 결과(예: "Grok bot" 리서치)를 받은 뒤 "요약과 함께 유즈케이스, 특이 의견을 따로 정리하고 원본 게시물을 임베드해서 볼 수 있게 해줘"처럼 구체적으로 요구해 사이트 초안 생성
  5. "새 리서치를 추가하고 히스토리를 저장하는 기능도 필요하다"고 요청 → 처음엔 JSON 수동 입력 방식이 제안되나 "스킬이 끝나면 자동으로 사이트에 반영되게 해달라"고 재요청해 자동화 완성
  6. 뉴스레터 통합처럼 대규모 백필이 필요하면 별도 구독용 Gmail을 ChatGPT 계정에 연결해 전체 카탈로그(2,000통 이상)를 한 번에 가져오게 지시
  7. 마지막으로 "매일 정오에 새 뉴스레터를 처리하는 태스크를 만들어줘"라고 요청하면 Scheduled tasks가 사이드바에 등록되어 자동 반복 실행

05타 도구 대비 장점

  • 기존에는 결론을 "긴 요약 텍스트"로만 받아야 했지만 Sites는 필터·검색·임베드가 가능한 구조화된 인터페이스로 변환
  • 호스팅, 인증, 데이터베이스, 분석 도구를 사용자가 직접 구축할 필요 없이 ChatGPT가 통합 제공(발표자는 "hosted by ChatGPT, all built in and taken care of already"라고 표현)
  • 코드를 몰라도 자연어 요청만으로 URL 변경, 버그 진단(하드코딩된 URL 문제를 스스로 발견), 기능 추가가 가능
  • 다만 복잡한 게임·고성능 앱 개발에는 한계가 있어 Codex·Claude Code와 역할이 구분됨

06핵심 워크플로우 또는 비교표

사례입력 소스사이트 결과물자동화 여부
게임 프로토타입단순 프롬프트Capybara Protocol (9분 완성)없음
여행 계획 정리다중 대화 스레드디즈니랜드 인터랙티브 가이드없음(수동 재요청 시 갱신)
RV 구매 가이드리서치 데이터예산·가족규모·견인력 등 조건별 추천 도구없음
트렌드 리서치Last 30 Days 스킬(Reddit·YouTube·TikTok 등)필터형 유즈케이스·특이의견 대시보드스킬 실행 후 수동 트리거
뉴스레터 아카이브전용 Gmail 2,000통+중복제거·검색 가능 데이터베이스Scheduled tasks로 매일 정오 완전 자동

07활용 시나리오

  • 팀 프로젝트의 여러 대화·데이터 분석 결과를 하나의 대시보드로 통합해 팀원과 공유
  • 개인 리서치(트렌드, 뉴스레터, 경쟁 도구 분석)를 자동으로 축적되는 "리서치 라이브러리"로 전환
  • 반복적으로 발생하는 정보(뉴스레터, 리포트, 알림)를 매일 자동 처리해 큐레이션된 개인 데이터베이스 구축
  • 의사결정 보조 도구(예: RV 구매 가이드처럼 조건 입력 시 결과가 바뀌는 계산기형 사이트) 제작

08현황 및 전망

  • Sites는 ChatGPT Work/Codex에서만 제공되는 최신 기능으로, 발표자는 "가장 간과되었지만 유용한 기능"으로 소개
  • 다중 Gmail 계정 연동은 "최근에 추가된" 기능이라고 언급되어, ChatGPT Work가 빠르게 기능을 확장 중임을 시사
  • 텍스트 기반 레코드는 수천 건 단위로 문제없이 저장되었으나, OpenAI가 공식적으로 저장 용량 한도를 공개하지 않아 대용량 파일(영상 등) 저장 시 한계는 불확실
  • 발표자는 Sites·지속 저장·Scheduled tasks 세 가지가 결합되면 ChatGPT가 단순 챗봇을 넘어 "실제 도구(actual tools)"를 만드는 플랫폼으로 진화한다고 전망

09용어 사전

  • Sites: ChatGPT Work/Codex에서 대화 기반으로 실제 웹사이트·앱을 빌드·배포하는 기능. 라이브 URL, 인증, 데이터 저장, 애널리틱스 포함
  • ChatGPT Work: Codex의 능력을 일반 사용자도 쉽게 쓰도록 만든 에이전틱 모드. 장시간 작업·도구 사용·다단계 작업 수행 가능
  • Scheduled tasks: 정해진 시간(예: 매일 정오)에 특정 작업(뉴스레터 처리 등)을 자동 반복 실행하는 자동화 기능
  • Last 30 Days: GitHub에 공개된 무료 에이전트 스킬로, YouTube 자막·Reddit·Polymarket·Instagram·TikTok 등에서 특정 주제에 대한 실시간 반응을 수집·점수화·요약
  • Skill Creator: GitHub 저장소를 ChatGPT가 사용할 수 있는 스킬 패키지로 자동 변환해주는 내장 도구
