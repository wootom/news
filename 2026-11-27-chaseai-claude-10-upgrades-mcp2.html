Claude의 데스크톱 앱 전환, MCP 2.0, 코드 모드 등 최근 2주간의 10가지 주요 업데이트 정리

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

아티팩트를 독립 데스크톱 앱으로 전환

  • Claude Code 데스크톱 앱에서 만든 아티팩트를 Mac과 Windows에서 독립적인 애플리케이션으로 설치할 수 있게 되었다.
  • 설치된 앱은 Claude Code 외부에서도 작동하며 기존처럼 Claude API를 호출하여 사용량을 소모한다.
  • 문서, 슬라이드, 시트는 데스크톱 앱으로 전환할 수 없으며 나머지 아티팩트는 모두 대상이 된다.
  • 공유 버튼에서 '앱으로 설치'를 선택하고 권한을 허용하면 모든 요금제(무료 포함)에서 즉시 사용 가능하다.

MCP 2.0의 네 가지 핵심 기능 강화

  • MCP에 스킬을 포함하여 AI가 해당 MCP를 가장 효율적으로 사용하는 방법을 학습할 수 있게 되었다.
  • 태스크 기능을 통해 MCP 서비스가 대형 작업을 백그라운드에서 실행하여 AI의 다른 작업 처리를 방해하지 않는다.
  • 엘리시테이션(elicitation)은 위험한 작업 실행 전 명시적인 사용자 권한 확인을 요구하여 안전 가드레일을 제공한다.
  • 파일 업로드 기능으로 서버에 파일을 직접 전달하여 채팅 컨텍스트를 절약하고 비용 및 성능을 최적화한다.

코드 모드(CLI)를 통한 토큰 효율성 향상

  • CLI 전용 실험적 기능으로, 도구 호출을 하나씩 순차적으로 처리하는 대신 JavaScript 프로그램을 작성해 동시에 실행한다.
  • JavaScript가 모든 도구 출력을 수집하고 Claude가 필요한 정보만 필터링하여 전달함으로써 컨텍스트 윈도우를 절약한다.
  • 이 방식은 토큰 비용을 크게 절감하고 컨텍스트 로트(context rot) 문제를 방지한다.

Slash Ship을 통한 자동 코드 배포 및 모니터링

  • Slash Ship 명령어 실행 시 Claude가 코드를 커밋하고 GitHub에 푸시한 뒤 사용자 이름으로 PR을 자동으로 생성한다.
  • 생성된 PR은 Slash Code Review로 검토되며 7일간 모니터링되어 오류 발생 시 수정 사항을 자동으로 제출한다.
  • Slash Steward 명령어는 이미 열린 PR에 동일한 자동화 과정을 적용하며, 최종 병합은 사용자가 직접 결정한다.

화이트보드 및 시트(Excel 대체) 기능 도입

  • Excalidraw와 유사한 무한 캔버스 화이트보드에서 팀원들과 협업하며 Claude가 코멘트에 응답하거나 시각 요소를 생성한다.
  • 시트(Sheets)는 250개 이상의 함수를 갖춘 초보적인 Excel 대체재로, 복잡한 모델링이나 VBA/매크로는 지원하지 않는다.
  • 대용량 CSV 데이터 정렬이나 단순한 스프레드시트 작업에 적합하며, Claude가 데이터를 채우고 편집하는 과정을 지원한다.

Claude Data와 Google Meet 회의 통합

  • Claude Data는 실시간 데이터 업데이트가 가능한 대시보드로, Redshift, Snowflake, Salesforce 등 주요 비즈니스 데이터 소스와 연결된다.
  • 데이터를 스프레드시트, 내레이션 스토리, 스크롤텔러 등 다양한 형태로 시각화하여 비즈니스 인사이트를 제시한다.
  • Claude Meetings는 Google Meet 회의에 자동 참여하여 회의록을 작성하고, 회의 중 실시간으로 대시보드나 시트 등 아티팩트를 생성해 공유한다.

Fable Advisor와 월간 사용량 리포트

  • Fable Advisor는 Fable 5.2를 오케스트레이터로 활용하여 Opus나 Sonnet 등 저비용 모델이 작업을 실행하도록 지시한다.
  • 작업 중 문제가 발생하면 Fable 5.2에게 조언을 구하는 방식으로 상위 모델의 지능과 하위 모델의 속도·비용 효율을 결합한다.
  • 월간 리포트는 채팅 및 Claude Code 로그를 분석하여 사용자의 시간 배분과 앱 사용 패턴을 시각적으로 보여준다.
