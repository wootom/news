VPS에 Claude Code를 설치하고 Telegram으로 원격 제어하는 방법

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

분석 범위: 원문 전체 14,356자 · 3개 구간. 원문 대조한 핵심 인용 15개를 바탕으로 요약했습니다.

VPS 환경 구축 및 Claude Code 설치

  • VPS는 가상 사설 서버로, Claude Code를 24시간 구동시켜 Telegram을 통해 언제 어디서나 접속할 수 있게 하는 역할을 한다.
  • 클라우드코드 설치된 VPS를 제공하거나 10% 할인 쿠폰으로 연간 100달러에 368달러 상당의 리소스를 확보하는 방법을 소개한다.
  • SSH 접속 시 root 비밀번호를 설정하고, 이는 비밀번호 관리자나 .env 파일에 안전하게 저장할 것을 권장한다.
  • VPS 내부에서 Claude가 설치되어 있는지 확인하고, 부재 시 Bun과 Tmux 등 필수 의존성 패키지의 설치 상태를 점검한다.

Telegram 봇 연동 및 보안 설정

  • Telegram의 BotFather를 통해 새 봇을 생성하고, 발급받은 토큰을 VPS의 Claude Code 설정에 입력하여 계정을 페어링한다.
  • 팀 플랜 사용 시 조직 내 채널 활성화 및 관리자 권한 설정이 선행되어야 하며, 오류 발생 시 트러블슈팅을 안내한다.
  • Claude Code가 VPS의 root 권한으로 접근하여 시스템 상태를 탐색하고, 문제가 발생하는 원인을 스스로 진단하도록 구성한다.
  • Telegram 페어링 후 본인만 접근할 수 있도록 보안 설정을 적용하여 외부 무단 접근을 차단한다.

자동화 구성 및 개인 AIOS 연동

  • VPS 재부팅 시에도 Claude Code가 Tmux 세션에서 자동으로 실행되도록 시스템 부팅 스크립트를 설정한다.
  • 메모리 효율성을 위해 자동 압축(auto compact) 임계값을 기본 960K에서 400K로 변경하는 환경 변수를 설정한다.
  • GitHub의 개인 저장소(Herc2)를 VPS에 클론하여, 일상적으로 사용하는 스킬과 운영체제(AIOS) 구성 요소를 동기화한다.
