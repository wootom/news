SpaceXAI 팀이 GrokBot으로 72시간 내 운영 회사 구축에 도전한다.

GrokBot 팀이 시장 조사부터 봇 조직·개발·출시까지 72시간 창업에 도전한다.

01핵심 개요

  • 맷 파머·로샨·로런은 샌프란시스코 모스코니 센터 인근 스튜디오에서 72시간 창업 과정을 생중계한다.
  • 팀은 첫날 시장 조사를 통해 아이디어를 정하고, 사람들이 원하면서도 직접 사용할 수 있는 제품을 목표로 삼는다.
  • 코드는 Cursor로 작성하고 수작업은 GrokBot으로 자동화하며, Slack·Notion·GitHub 조직을 협업 기반으로 준비한다.
  • 새 GitHub 조직 ‘Ship by Thursday’와 빈 GrokBot 계정에서 출발해 봇 팀, 사용자 조사 봇, 창업 엔지니어 봇을 구성한다.
  • GrokBot Galaxy 챌린지는 9월 29일까지 진행되며, Starbase Starship 발사 여행과 호손 공장 견학을 경품으로 내건다.

02핵심 주장 / 논점 구조

  • 도전의 목표는 아무것도 없는 상태에서 72시간 안에 실제로 운영되는 회사를 만드는 것이다.
  • 팀은 사업을 사람들이 원하고 직접 써볼 수 있으며, 수익도 낼 수 있는 유용한 제품으로 정의했다.
  • AI의 가치는 엑셀·메시지 탐색·수작업 자동화 같은 반복 업무를 줄여 중요한 일에 집중하게 하는 데 있다고 설명했다.
  • 제품은 사람에게 가치를 제공해야 하며, 구매자는 사람뿐 아니라 신용카드를 연결한 에이전트가 될 가능성도 언급됐다.

03참가 팀과 각자의 GrokBot 활용

  • 맷 파머는 개발자 경험·개발자 관계를 맡으며 사용자에게 GrokBot과 새 기술의 사용법을 알리고 코드와 문서 작업도 한다.
  • 로샨은 SpaceXAI 제품 담당자로 고객 피드백과 AI 도구 수요를 제품에 반영하고 GrokBot 커넥터 및 마켓플레이스를 고민한다.
  • 로런(poteto)은 GrokBot 엔지니어링과 성능 개선을 맡고, X 멘션이 너무 많아 답변 작업을 GrokBot으로 자동화했다.
  • 로런은 PM과 디자이너도 좋은 코드를 기여할 수 있게 GrokBot 코드베이스를 정비했다고 밝혔다.

04아이디어 탐색과 시장 조사 계획

  • 시청자와 SpaceX 직원에게 무엇을 만들면 좋을지 물었고, 수천 개의 답변을 GrokBot으로 먼저 살펴볼 계획이다.
  • 팀은 시장 조사 뒤 첫날 오전쯤 만들 제품을 발표하는 방안을 제시했으며, 사흘뿐이라 첫날 아이디어 결정이 목표라고 말했다.
  • 사용자 조사와 인터뷰 일정 잡기, 세상의 반응 확인을 포함한 제품 개발 전 과정을 0에서 1로 진행하려 한다.
  • Dreamforce로 샌프란시스코에 평소보다 5만 명이 더 온 상황을 언급하며, 디지털 결과물을 현실에서 경험하게 하는 가능성도 검토했다.

05개발 도구와 자동화 사례

  • 맷은 X 북마크의 npm 패키지 등을 찾아 Cursor 클라우드 에이전트로 직접 구현하고, 미리보기 배포까지 설정하는 GrokBot 데모를 만들었다.
  • 해당 데모는 매일 아침 북마크한 기술과 직접 만들어 배포한 버전을 알려주는 방식으로 설명됐다.
  • 팀은 코드는 Cursor로 쓰고 번거로운 수작업은 GrokBot으로 해결하며, 필요에 따라 Slack·Notion·Linear를 사용할 계획이다.
  • 배포는 PR 대신 main 브랜치에 바로 합치는 방식도 언급됐으며, 데이터베이스와 Stripe·Link 결제 인프라도 필요 요소로 거론됐다.

06PStack과 빠른 개발 방식

  • 로런은 PStack을 자신이 수행하던 꼼꼼한 엔지니어링 작업용 스킬과 작업 방식을 모아 공개한 무료 오픈소스 플러그인이라고 소개했다.
  • PStack은 GrokBot 마켓플레이스에서 검색할 수 있으며, 로런은 지난달 이를 통해 PR 2,500개를 프로덕션에 반영했다고 말했다.
  • 월간 PR 2,500개는 하루 약 83개라는 계산이 나왔고, 팀은 3일 동안 250개 이상의 PR 또는 커밋을 목표처럼 언급했다.
  • 방송에서는 SpaceX 직원들이 이런 도구로 빠르게 제품을 개선하는 과정을 아이디어 단계부터 출시까지 보여주겠다고 밝혔다.

07Ship by Thursday와 봇 조직 설계

  • 팀은 이번 사흘 동안만 사용할 새 GrokBot 팀과 빈 GitHub 조직을 만들었고, 조직 이름은 ‘Ship by Thursday’다.
  • 시작 시점에는 저장소와 봇이 없는 상태이며, 개발 준비는 PStack 설치부터 보여주겠다고 했다.
  • 사용자 조사 봇과 마켓플레이스의 봇 템플릿을 활용하고, 창업 엔지니어 봇을 한두 명 고용하는 구상을 제시했다.
  • 회사 문서를 읽어 업무 방식과 원칙을 전달하는 온보딩 봇, 직원 봇을 만드는 GrokBot 공장, 공유 지식 저장소 구상도 나왔다.

08용어 사전

용어뜻
GrokBot팀이 코드 작성 보조, 수작업 자동화, 시장 조사, 봇 구성 등에 활용하겠다고 밝힌 AI 도구다.
PStack로런이 엔지니어링 작업용 스킬과 작업 방식을 모아 공개한 무료 오픈소스 플러그인이다.
Ship by Thursday‘목요일까지 출시’라는 뜻으로 만든, 이번 72시간 도전용 빈 GitHub 조직 이름이다.
Cursor 클라우드 에이전트맷의 데모에서 X 북마크로 찾은 기술을 실제로 구현하는 데 사용된 도구다.
Stripe LinkGrokBot에 신용카드를 연결해 사람이나 봇이 구매하는 실험 가능성을 말하며 언급된 결제 수단이다.
