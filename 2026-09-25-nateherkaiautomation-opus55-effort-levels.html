Opus 5.5는 노력 수준별 비용과 품질이 비례하지 않는 3D 행사장을 만들었다.

Opus 5.5의 6개 노력 수준 비교에서 Extra가 가장 선호됐고, Max는 가장 비쌌다.

01핵심 개요

  • 동일 프롬프트로 AIS Live의 105GB 녹화 자산을 3인칭 3D 컨퍼런스 세계로 만드는 작업을 6개 노력 수준에서 비교했다.
  • Low는 16분 43초, API 기준 3.91달러, 19만1,000토큰, 22회 점검으로 기본 행사장을 구현했다.
  • Extra는 1시간 30분, 25.92달러, 73만2,300토큰, 34회 점검으로 좌석·대화·VIP 기능을 포함한 결과를 냈다.
  • Max는 2시간 28분과 50.38달러로 가장 비쌌지만 보행·좌석·맵·공간 이동에서 버그가 관찰됐다.
  • 제작자는 Extra를 가장 선호했으며, Ultra Code는 18.69달러로 Max보다 저렴했지만 기대한 동적 워크플로가 보이지 않았다고 말했다.

02핵심 주장 / 논점 구조

  • 동일한 /goal 프롬프트를 Low, Medium, High, Extra, Max, Ultra Code에 각각 실행해 결과물을 비교했다.
  • 평가 기준은 3D 세계의 창의성, 디자인, 물리감, 탐험 시 전반적 느낌과 함께 실행 시간·비용·토큰·점검 횟수였다.
  • 노력 수준이 높아질수록 대체로 토큰과 비용은 증가했지만, 결과 품질과 사용성은 일관되게 상승하지 않았다.
  • 제작자는 6개 실행 가운데 Extra 결과물을 가장 선호한다고 밝혔고, Max와 Ultra Code에서는 기능 및 완성도 문제를 지적했다.

03공통 프롬프트와 AIS Live 제작 목표

  • 프롬프트는 AIS Live의 Frame.io 폴더에 있는 105GB 영상 녹화물을 활용하도록 지시했다.
  • 목표는 가상으로 기록된 행사를 여러 방·트랙·무대를 갖춘 현실적 오프라인 컨퍼런스형 3D 세계로 바꾸는 것이었다.
  • 사용자는 3인칭 시점으로 공간을 걸어 다니며 탐험할 수 있어야 했고, 필요하면 key.ai 이미지·영상 생성도 허용됐다.
  • 행사 자산 외에 Herk 2 프로젝트의 AI 운영체제 내부 자료도 활용할 수 있도록 설정됐다.

04Low와 Medium의 기본 구현 차이

  • Low는 AIS Live 로고와 색상을 충분히 반영하지 못했고, 화면이 과도하게 밝거나 인물이 사라지는 문제가 나타났다.
  • Low는 일정 정보와 Glido 등 실제 부스는 찾아냈지만, 워크숍 화면 대부분은 움직이지 않는 이미지로 표시됐다.
  • Medium은 Nate Herk 배지와 AIS Live 색상 체계, Day One Build·Day Two Earn·VIP 표기를 적용했다.
  • Medium에서는 Tangy Frederick 세션, Glido 소개, 커뮤니티 스포트라이트 등이 실제 영상 재생으로 구현됐고 인물 글리치도 줄었다.

05High와 Extra에서 강화된 행사 경험

  • High는 발표자 깃발, 자동 슬라이딩 유리문, 방문 장소를 기록하는 패스포트와 실제 재생 영상을 제공했다.
  • High의 VIP 구역은 손목밴드를 받아야 열리며, VIP 브레이크아웃룸·애프터파티·메인 스테이지 자막도 포함했다.
  • Extra는 NPC와 대화할 수 있었고, 고급 트랙에서 좌석에 앉아 영상을 시청하는 기능을 보여줬다.
  • Extra는 발표자·일정·리소스 라이브러리와 사진 촬영 기능을 제공했으며, 제작자는 앞선 결과보다 낫다고 평가했다.

06Max 결과의 높은 비용과 관찰된 결함

  • Max는 2시간 28분, 50.38달러, 118만 토큰, 51회 점검으로 6개 실행 중 가장 긴 시간과 높은 비용을 기록했다.
  • Max는 토큰 한도에서 자동 compaction을 수행했으며, 제작자는 이 실행이 compaction에 도달했다고 설명했다.
  • 엑스포 부스 디자인과 VIP용 에스컬레이터, 메인 스테이지 콘텐츠 전환 기능은 긍정적으로 평가됐다.
  • 반면 보행 애니메이션, 그림자 전환, 워크숍 공간 이동에서 문제를 보였고 좌석에 앉을 수 없는 경우도 있었다.

07Ultra Code의 비용·검증 수치와 워크플로 의문

  • Ultra Code는 1시간 35분, 18.69달러, 6만6,000토큰, 42회 점검, 사용자 질문 0회로 기록됐다.
  • VIP 손목밴드 스캔, 위치 안내, 방 진입 시 시작되는 영상과 자막, 리소스 열람 및 사진 저장 기능을 구현했다.
  • 제작자는 Ultra Code의 보행 감각과 라벨이 있는 맵, 프리미엄한 공간 분위기를 긍정적으로 평가했다.
  • 그러나 NPC 대화와 좌석 기능이 빠졌고 보행 글리치도 관찰됐으며, 로그에서 기대한 동적 워크플로가 실행되지 않았다고 말했다.
  • 비용·시간·점검 비교와 실행 방식: Low와 Max의 비용은 3.98달러 대 50.38달러로, 제작자는 가장 저렴한 실행과 가장 비싼 실행의 차이를 12.9배라고 제시했다.
  • 비용·시간·점검 비교와 실행 방식: Max와 Low의 점검 횟수 차이는 2.3배였으며, 6개 실행의 API 기준 총비용은 127달러라고 집계했다.
  • 비용·시간·점검 비교와 실행 방식: 산점도에서 Low는 빠르고 저렴했으며 Max는 느리고 비쌌고, 노력 수준 상승에 따른 비용·실행 시간 증가는 대체로 예상과 맞았다.
  • 비용·시간·점검 비교와 실행 방식: 제작자가 세션 로그를 확인한 결과 6개 실행 모두 서브 에이전트를 사용하지 않았고, High만 사용자에게 질문 1개를 했다.
