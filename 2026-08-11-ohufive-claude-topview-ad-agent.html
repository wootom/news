클로드 코드 + 탑뷰 MCP로 광고 영상 자동 제작 — 오후다섯씨

오후다섯씨 실전 데모. 클로드 코드에 탑뷰(Topview) MCP를 연결해 데이터→인사이트→전략→비주얼 4단계로 광고 영상을 자동 제작하는 워크플로우. 틱톡샵·아마존 판매 데이터를 실시간 조회해 바이럴 패턴 기반으로 기획하고, 이미지·8초 영상·자막·보이스·립싱크까지 에이전트가 스스로 생성하는 과정이 핵심.

01MCP 개념과 연결 구조

MCP(Model Context Protocol)는 클로드 바깥 서비스를 클로드가 직접 불러 쓰게 연결하는 규격. 클로드를 베이스로 MCP를 하나씩 붙이는 구조로, 광고 영상 제작에 특화된 탑뷰 MCP를 연결해 클로드가 영상을 만들 수 있게 한다.

02설치·인증 절차

VS Code의 클로드 코드에서 프롬프트로 "MCP 설치·로그인 방법 알려줘" + 탑뷰 MCP 주소를 붙여 HTTP 방식으로 등록. 새 세션에서 MCP 목록 확인 후 터미널에서 authenticate 실행, 브라우저 인증(successful) 완료. 데모 시점 크레딧 260 잔여로 시장조사·이미지·영상 생성 진행 가능.

03광고 제작 4단계 방법론

단순 영상 생성 도구만으로는 부족하며 데이터→인사이트→전략→비주얼 4단계가 필요. 데이터를 모으고, 왜 중요한지 인사이트를 뽑고, 어떻게 만들지 전략을 정한 뒤 실제 제작. 영상을 먼저 만들고 이유를 붙이는 게 아니라 수요를 파악한 뒤 제작하는 순서.

04실시간 시장조사

"틱톡샵에서 잘 팔리는 제품 + 아마존 데이터" 요청에 두 플랫폼을 동시 조회. 틱톡샵 미국 최근 7일 판매 1위 로디드 티믹스(주간 6만 판매), 아마존 상위에 키친타월·네스프레소 캡슐 등. 겹치는 트렌드로 로디드 티 계열·K뷰티 멀티밤을 데모 후보로 제안.

05데이터 기반 광고 기획

K뷰티 멀티밤 선택 시 에이전트가 제품 컨텐츠 데이터를 먼저 확인. 최근 30일 405만 달러 매출 중 72.9%가 숏폼 영상에서 발생, 라이브는 5.5%뿐. 비포애프터·비용비교·다크서클 컨실러 대체가 상위 패턴이며, 8초 초단편이 920만 조회 사례. 트랜스포메이션·비용대체·루틴 단순화 3방향과 훅·대본·스토리보드까지 자동 생성.

06이미지·영상·립싱크 자동 생성

루틴 단순화(8~15초 초단편) 선택 후 이미지 생성→시댄스 2.0으로 8초 영상 제작→자막·보이스오버(탑뷰 Generate Voice)까지 에이전트가 모니터링하며 완성. 크레딧 8.2 소모. 립싱크 컷(카메라 응시 발화)을 영상 앞에 붙이는 구성도 자동 처리.

07캔버스 협업과 활용처

탑뷰 캔버스에 이미지·영상·프롬프트·제작 과정이 모두 기록돼 한눈에 확인·재편집 가능. 다양한 각도의 영상 재생성, 타임라인 편집, 수동 도구를 통한 사람-에이전트 협업 지원. 제품·콘텐츠 마케팅은 물론 기존 제품 광고 제작을 통한 제휴 마케팅 수익화에도 활용 가능.

08용어 사전

  • MCP(Model Context Protocol): 외부 서비스를 LLM에 연결하는 표준 인터페이스.
  • 탑뷰(Topview): 데이터·인사이트·전략·비주얼을 지원하는 광고 영상 제작 MCP 서비스.
  • 숏폼 바이럴 패턴: 조회수 상위 영상의 훅·구성 패턴을 데이터로 추출해 기획에 반영.
  • 립싱크 컷: 인물이 카메라를 보고 말하는 입모양 동기화 장면.
