AX 도입이 실패하는 이유 = 터미널

메이커 에반 · 비개발자 수백 명 AI 교육 현장 경험 요약

목차핵심 개요비개발자가 이탈하는 2단계핵심 방법론 — 눈높이 전달해결책 — 코워크 GUI활용 시나리오현황 및 전망용어 사전

01핵심 개요

항목내용
핵심 주장AX(AI 전환) 성공은 기술이 아니라 사람 적응 문제
실패 트리거강의 중 터미널(까만 화면) 노출 → 즉시 이탈
결과 비교터미널 교육 잔존율 ~10% vs GUI 교육 잔존율 ~80~90%
권장안클로드 데스크탑 앱 코워크 등 GUI 환경에서 전부 처리
비권장오픈클로·헤르메스 등 설치 난도 높은 터미널 도구

02비개발자가 이탈하는 2단계

  • 1차 이탈(50%): 터미널 까만 화면 등장 순간 → "이건 내 영역 아니구나" 심리적 포기 (0:07 딥링크)
  • 2차 이탈(40%): "마우스 안 되고 키보드 명령어만" → 평생 마우스 쓰던 사용자 추가 이탈 (1:42 딥링크)
  • 결과: 100명 중 90명이 내용 배우기도 전에 도구 화면만으로 이탈

03핵심 방법론 — 눈높이 전달

  • 비개발자 교육 1순위 역량 = 기술 지식 아님 → 눈높이 전달 능력
  • 원칙: 무조건 눈에 보이고(GUI) 마우스로 누를 수 있어야 함 (3:37 딥링크)
  • 비유: 외국어 모르는 사람에게 문법책 X → 손으로 가리키기 O

04해결책 — 코워크 GUI

  • 클로드 데스크탑 앱 코워크 성능 향상 → 과거 명령어 세팅이 마우스 클릭 몇 번으로 단축 (4:09 딥링크)
  • MCP 연결도 검색 후 클릭만으로 가능 → 키보드 명령어 암기 불필요
  • 비유: 핸드폰 앱 설정 만지는 수준 / 거의 완성된 가구 몇 군데만 끼우기

05활용 시나리오

  • 회사 AI 도입 교육: 터미널 대신 코워크 화면 안에서 세팅·작업·결과 확인 일원화
  • 비개발자 직원 자율 세팅: 개발자 없이 직접 AI 업무 환경 구성
  • 정착률 관리: "집에 가서도 다시 켜는지"가 실제 활용도 좌우

06현황 및 전망

  • 문턱 거의 소멸 → 비개발자 직접 AI 세팅 시대 진입
  • 화자(에반)는 VRL에서 기업 AI 도입 컨설팅 제공 (영상 말미 홍보)
  • 결론: "기술 도입"이 아니라 "사람 적응"이 AX 성공식

용어한줄 설명비유/예시
