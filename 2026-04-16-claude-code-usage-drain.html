근본 원인 3가지
백그라운드 과잉 파일 탐색
맥락 파악을 위해 이미 읽은 파일을 재탐색하고, 주변 파일까지 불필요하게 읽어들여 사용자 모르게 막대한 토큰 소모
시스템 프롬프트 캐시 만료
수 시간 방치된 세션 재진입 시 캐시 만료 → 전체 컨텍스트 재로딩 → 짧은 메시지 한 줄이라도 재로딩 트리거
대화 길이 누적 + 규칙 파일 비대
긴 대화 → 이전 기록 매번 재읽기 / CLAUDE.md 등 규칙 파일이 길면 매 턴 고정 비용 발생
3
즉시 적용 대처법
가장 효과적
프롬프트로 행동 제한
작업 지시 마지막에 아래 문구를 추가하여 과도한 파일 탐색을 강제 차단
"Minimize tool calls. Don't re-read files you've already read this session. Don't read files for context unless I explicitly ask. Batch all changes into as few operations as possible."
세션 관리
/clear 와 /compact 활용
태스크 전환 시 /clear로 초기화
맥락 유지 필요 시 /compact로 대화 요약
방치 세션은 재진입 대신 새 세션 열기
대화 패턴
긴 대화 대신 새 세션
한 세션에서 반복 수정 요청 지양
오류/코드를 복사 후 새 세션에서 재질문이 사용량 절약에 유리
규칙 파일
CLAUDE.md 간소화
프로젝트 규칙 파일이 길면 매 턴 고정 토큰 비용 발생
핵심만 남기고 간소화 권장
4

Before
  • 간단한 작업에 40% 소진
  • 1시간 내 100% 도달
  • 방치 세션 재진입 → 22% 급증
  • 불필요한 파일 재탐색
  • 긴 대화로 토큰 누적 폭증

  • CLAUDE.md 핵심만 유지
