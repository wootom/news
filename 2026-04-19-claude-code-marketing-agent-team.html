Claude Code 마케팅 에이전트 팀 서브에이전트 + 스킬 + MCP로 100% 자동화하는 방법

하네스 세팅에 95%의 시간을 투자하고, 실행은 5%만 쓴다. 빌더 조쉬가 Claude Code 위에 마케팅 에이전트 팀을 구축하는 전 과정을 보여준다. 맥락 주입, 스킬 설치, MCP 연결, 서브에이전트 팀 구성, Buffer API 배포까지 5단계 파이프라인으로 카드 뉴스, PPT, 뉴스레터, 썸네일을 단일 대화에서 생산한다.

Overview
핵심 주장하네스 세팅 95% + 실행 5% = 고품질 결과물
산출물카드 뉴스, PPT, 뉴스레터, 유튜브 썸네일, SNS 예약 게시
도구 체인Claude Code + Anthropic 스킬 + NanoBanana MCP + Buffer API
대상1인 마케터, AX(AI Transformation) 도입 기업
Core Insight
95% : 5%
하네스 세팅(맥락 폴더, 템플릿, CLAUDE.md, 에이전트 정의)에 95%의 시간을 투자해야 실행 단계에서 일관된 고품질 결과물이 나온다. 이 비율을 무시하면 매번 다른 품질의 산출물이 생산되며, AI가 폴더를 재해석하는 데 시간을 낭비한다.
Pipeline

5단계 구축 파이프라인

1
폴더 구조 + 맥락 주입
context/ 폴더에 브랜드 가이드라인, 디자인 스타일, 비즈니스 맥락을 MD 파일로 작성. templates/ 폴더에 카드 뉴스, PPT, 뉴스레터 레퍼런스 저장.
Tip: 이미지 템플릿을 MD 파일로 변환해 두면 토큰 소모를 대폭 줄일 수 있다.
2
CLAUDE.md + 공식 스킬 설치
CLAUDE.md는 프로젝트의 SOP(표준 업무 규약). 폴더 구조, 에이전트 규칙, 작업 흐름을 정의한다. Anthropic 공식 스킬(PPTX, PDF, DOCX)을 Marketplace에서 설치.
핵심: CLAUDE.md가 없으면 AI가 매번 폴더를 재해석 — 시간 낭비 + 일관성 붕괴
3
MCP 연결 (이미지 생성)
NanoBanana MCP로 Gemini 이미지 API를 Claude Code에 직접 연결. Google AI Studio에서 API 키 발급 후 설치 명령어에 삽입.
검증: /mcp 명령어로 서버 연결 상태 확인 필수
4
서브 에이전트 팀 구성
.claude/agents/ 폴더에 MD 파일로 4개 에이전트 정의. CLAUDE.md에 라우팅 룰을 추가하여 작업별 에이전트 자동 선택.
5
자동 배포 (Buffer API)
.env에 Buffer API 키 저장. Claude Code가 카드 뉴스 + 텍스트를 SNS에 예약 게시. LinkedIn, Threads, X 동시 관리.
Agent Team

4개 서브 에이전트

Step 1
리서치 에이전트
웹 검색 + 컨텍스트 문서를 참조하여 주제별 핵심 팩트 보고서를 생성한다. 회사 맥락에 맞는 범위로 리서치를 좁혀 품질을 높인다.
Step 2
콘텐츠 에이전트
리서치 결과를 기반으로 뉴스레터 원고, 블로그 포스트, SNS 카피를 브랜드 보이스에 맞춰 작성한다.
Step 3
디자인 에이전트
NanoBanana MCP를 활용하여 카드 뉴스, 유튜브 썸네일, PPT를 디자인 가이드라인에 맞춰 제작한다.
Step 4
검수 에이전트
모든 산출물의 브랜드 가이드라인 준수 여부, 팩트 정확성, 디자인 일관성을 자동으로 검증한다.
"하네스 세팅에 95%의 시간을 써야 된다. 5%는 실행 시간에 쓰는 것이죠." 빌더 조쉬 (Builder Josh)

Takeaway

전략적 시사점

1인 마케터가 팀급 산출물을 생산하는 구조가 현실화되고 있다. 핵심은 AI 도구 자체가 아니라 맥락의 구조화에 있다. 브랜드 가이드라인, 디자인 시스템, 작업 규칙을 MD 파일로 정의하는 하네스 세팅이 결과물의 품질을 결정한다.

NanoBanana MCP 등 커뮤니티 기반 MCP 생태계가 빠르게 성장하면서, Claude Code의 마케팅 자동화 도구 체인 완성도가 높아지고 있다. Buffer API의 정식 출시와 함께 리서치부터 배포까지 전 과정의 자동화가 가능해지는 시점이 가까워지고 있다.
