초파리 뇌지도 활용부터 AI 난제·안전 논쟁까지 주요 흐름을 짚었다.

초파리 뇌지도 실험부터 OpenAI·Anthropic·Kimi 논란까지 정리했다.

01핵심 개요

  • 구글이 9월 3일 공개한 수컷 초파리 뇌지도는 16만6,000개 뉴런과 연결 관계 데이터를 담아 다양한 실험의 기반이 됐다.
  • 영상은 초파리 커넥텀을 둠·비트세이버·비트코인 트레이딩·로봇 제어 등에 활용했다는 사례와 진위 불명 사례를 함께 언급했다.
  • OpenAI는 1만 개 에이전트가 88시간 협업해 나비에-스토크스 관련 문제를 풀었다고 소개했으나, 비공개 대화 활용 의혹도 제기됐다.
  • ChatGPT Images 2.5, 라이브 음성 API, 에이전트 API가 공개됐고 Anthropic의 AI 감속론과 Kimi API 논란도 다뤘다.

02핵심 주장 / 논점 구조

  • 영상은 초파리 뇌지도 공개가 게임·학습·로봇 제어 실험으로 이어진 흐름을 이번 주 가장 뜨거운 AI 사례로 제시했다.
  • OpenAI의 수학 난제 해결 주장은 형식 검증 공개와 함께, 연구자 대화가 모델 개선에 쓰였을 가능성 논쟁을 동반했다.
  • Anthropic CEO와 주요 AI 기업 CEO들의 감속론은 안전 필요성과 선도 기업의 경제적 이해관계라는 두 관점에서 다뤄졌다.
  • AI 모델·에이전트의 성능 향상은 이미지 편집, 음성 대화, 코딩 에이전트 API 확장과 함께 보안·안전 우려도 키웠다.

03초파리 뇌지도와 활용 실험 확산

  • 구글은 9월 3일 수컷 초파리 뇌지도를 공개했으며, 영상은 16만6,000개 뉴런의 연결 관계 데이터가 공개됐다고 설명했다.
  • 커넥텀은 뉴런 A에서 B로 신호가 가는 방향성 연결을 담은 그래프로 소개됐고, 컴퓨터에서 신경 신호 전달을 시뮬레이션할 수 있다.
  • 공개 뒤 초파리 뇌를 마인크래프트와 둠 플레이에 연결하거나 비트세이버·비트코인 트레이딩에 활용했다는 사례가 확산됐다.
  • 영상은 히라가나 10만 글자를 8시간 학습시켜 약 85% 정답률을 냈다는 사례를 소개하면서도, 온라인 사례 일부의 진위는 불명확하다고 밝혔다.
  • AwesomeFly GitHub 저장소에는 게임·통제·언어·예술 등 소스 코드 기반 실험 사례가 모여 있어 참고할 수 있다고 소개했다.

04조코딩의 24시간 둠플라이 실험

  • 조코딩은 초파리 커넥텀 자체를 바꾸는 대신, 신경 활동 신호를 게임 조작으로 바꾸는 별도 컨트롤러를 구성했다고 설명했다.
  • 시각 입력을 받은 초파리 모델의 신호가 컨트롤러를 거쳐 둠 조작으로 이어지도록 만들고, 컨트롤러 파라미터를 강화학습했다.
  • 약 24시간 동안 둠플라이를 구동했으며, 강화학습이 진행될수록 평균 생존 시간이 늘어난 것으로 보인다고 말했다.
  • 실험 중 최고 기록으로 20여 킬을 언급했으며, 실험 구조와 해석은 추가로 파악·정리할 필요가 있다고 밝혔다.

05나비에-스토크스 해결 주장과 공로 논쟁

  • 영상은 나비에-스토크스 문제를 유체의 속도와 압력이 시간에 따라 어떻게 변하는지 다루는 밀레니엄 난제 중 하나로 설명했다.
  • OpenAI 측 사례에서는 1만 개 에이전트가 88시간 협업해 특이점이 생길 수 있다는 결론을 내고 린 형식 검증을 공개했다고 소개됐다.
  • 해당 난제의 상금은 100만 달러지만, 영상은 일반 요금 기준 계산 비용이 약 600만 달러였고 OpenAI가 상금은 받지 않았다고 전했다.
  • 연구자 버크마스터는 자신이 Codex와 논의한 비공개 연구 내용이 풀이와 유사하다며 데이터 활용 가능성을 의심했다고 소개됐다.
  • OpenAI는 직접 사용을 부인했지만 비식별 데이터의 모델 개선 기여 가능성은 배제할 수 없다는 취지의 논쟁이 언급됐다.

06ChatGPT Images 2.5와 에이전트 API

  • ChatGPT Images 2.5는 더 선명한 디테일, 빠른 생성, 정밀 편집과 제작·공유 도구 향상을 내세우며 공개됐다.
  • 영상은 Images 2.5가 인물·배경 등 나머지 요소를 유지하면서 요청한 부분만 바꾸는 편집 능력이 이전 이미지 2보다 좋아졌다고 비교했다.
  • GPT 라이브 1은 실시간 음성 대화 API로 소개됐으며, 대화 중 끼어들기와 자연스러운 왕복 대화를 앱에 도입할 수 있다고 설명됐다.
  • OpenAI 에이전트 API는 Codex 하니스를 클라우드 에이전트로 구축·실행하는 방식으로, 샌드박스 또는 온프레미스 환경을 지정할 수 있다고 소개됐다.
  • OpenAI는 사용자 수요와 용량 문제를 이유로 200달러 프로 플랜 구독을 일시 중단하고 용량 확충에 노력 중이라고 밝혔다.

07AI 감속론과 Kimi의 Claude API 전달 논란

  • Dario Amodei는 안전 투자만으로 부족하며 최첨단 AI 역량 발전 속도를 늦춰야 한다고 제안했고, 영상은 Sam Altman·Elon Musk 등의 동의를 언급했다.
  • 감속론에는 에이전트 집단이 6~12개월 안에 지속적 봇넷을 구축해 수천억 달러 피해를 낼 수 있다는 위험 주장이 근거로 제시됐다.
  • 반대 관점에서는 규제·외부 감사 비용이 후발 기업 진입을 어렵게 하고, Anthropic의 IPO 및 선도 지위에 유리할 수 있다는 비판이 소개됐다.
  • Anthropic 연구원 Jay Koenig는 AI 기업들이 자기개선형 초지능으로 향하며 생명을 도박으로 삼고 있다고 말한 것으로 영상에서 인용됐다.
  • Anthropic 보고서에 따르면 Moonshot AI의 Kimi가 일부 요청을 Claude에 전달해 응답을 반환했으며, 중국 감시 영상 데이터 전달 문제도 제기됐다.
