클로드 코워크로 업무 자동화 끝내기

메이커 에반 · 코딩 지식 없이 자연어만으로 루틴 업무 자동화 티칭

목차핵심 개요사전 세팅 절차핵심 워크플로우 — 스케줄 자동화활용 시나리오 (실제 데모)기술적 맥락현황 및 전망용어 사전

01핵심 개요

항목내용
코워크 강점클로드 코드보다 자유도 높고 챗보다 편리, 스케줄 업무를 자연어로 생성
필수 세팅플레이(Play) MCP + 클로드 인 크롬 확장 프로그램
사용 도구단 2개(플레이 MCP·클로드 인 크롬)만으로 자동화 구현
권장 구독Pro로도 가능하나 대량 작업 시 Max($100) 권장
핵심 가치프롬프트 몇 줄 = 매일 반복 업무 자동 실행

02사전 세팅 절차

  • 설정 → 커넥터 → 맞춤 설정 → 플레이 MCP 연결 → 카카오톡 로그인 → "나와의 채팅방" 도구함 추가 (1:42 딥링크)
  • 앱 재시작 후 카카오톡 도구 "항상 허용" 설정
  • 브라우저 확장 클로드 인 크롬 설치 → 크롬 창 제어 권한 부여 (0:48 딥링크)

03핵심 워크플로우 — 스케줄 자동화

  • 코워크 → 스케줄 → 새 작업 → "질문 대신 묻지 않고 실행" 설정 (0:29 딥링크)
  • 프롬프트로 업무 정의 → 매일 지정 시각 자동 트리거 → 결과 카카오톡 전송
  • 편집에서 "묻지 않고 실행" 저장 후 테스트 실행 권장

04활용 시나리오 (실제 데모)

사례동작
인스타 모니터링매일 9시 특정 계정 신규 게시물 확인 → 요약·링크 카카오톡 발송 (3:31 딥링크)
마케팅 트렌드매일 SNS 마케팅 트렌드 웹검색 → 요약 카카오톡 전송
쓰레드 자동포스팅X(엑스) 최신 글 크롤링 → 한글 번역 → 쓰레드 자동 게시 (10:27 딥링크)
이커머스 리뷰 이전자사몰 리뷰 → 에이블리 등 타 플랫폼 이전

05기술적 맥락

  • 클로드 인 크롬 MCP가 브라우저를 직접 크롤링·제어 → 스냅샷 기반 페이지 조작
  • 플레이 MCP가 카카오톡 "나와의 채팅방" 알림 채널 역할
  • 모든 작업이 자연어 프롬프트로 구성 → 코딩 불필요

06현황 및 전망

  • 코워크 = 루틴 업무 자동화 필수 요소로 자리매김
  • "코워크 쓸 수 있는 사람과 없는 사람의 격차 확대" 전망
  • 라이브 아티팩트·디스패치·커스터마이즈·스킬·프로젝트 등 추가 기능 후속 강의 예고

07용어 사전

용어한줄 설명비유/예시
코워크클로드 데스크탑 앱의 업무 자동화 모드화면으로 일 시키는 AI 비서
플레이 MCP카카오톡 등과 연결해 주는 커넥터알림 보내는 전용 우체통
클로드 인 크롬크롬을 AI가 제어하는 확장 프로그램AI에게 마우스 쥐여 주기
스케줄정해진 시각에 반복 실행되는 작업매일 울리는 알람
크롤링웹페이지 정보를 자동 수집하는 것도서관에서 자료 긁어 모으기
