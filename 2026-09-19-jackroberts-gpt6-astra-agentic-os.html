GPT-6 Astra 기반 에이전틱 OS로 개인 데이터와 업무 도구를 통합하는 과정을 소개한다.

GPT-6 Astra 기반 에이전틱 OS의 메모리 통합, 업무 실행, 생성 API 연결 시연.

01핵심 개요

  • 영상은 GPT-6 Astra가 구축했다는 에이전틱 OS를 통해 메모리·대시보드·캘린더·생성 도구를 한 화면에 통합하는 모습을 시연한다.
  • 시스템은 Claude, Codex, ChatGPT, Gmail, Outlook, Slack, Notion, Obsidian, 사진 및 금융 정보를 연결 대상으로 제시한다.
  • 사용자와 사업체 정보를 담는 라이프 프로필·비즈니스 프로필을 먼저 만들고, 목표·전략·일일 브리프에 활용하는 구성을 설명한다.
  • Higgsfield API 키를 연결해 이미지와 영상을 생성하고, 컴퓨터 사진을 키워드로 색인하는 ‘매직 서치’ 기능을 소개한다.
  • Zapier를 연결 계층으로 활용하면 School, YouTube, Microsoft 등 여러 앱을 에이전틱 OS와 연결할 수 있다고 안내한다.

02핵심 주장 / 논점 구조

  • 영상의 핵심은 단순 채팅형 AI가 아니라 개인·사업 데이터의 맥락을 바탕으로 실제 작업을 수행하는 에이전틱 OS라는 주장이다.
  • 제작자는 이 OS가 사용자의 정보와 사업 정보를 연결하고, 이를 정리·추론해 목표 달성에 필요한 행동을 돕는다고 설명한다.
  • 구성은 메모리 코어, 목표와 전략, 일일 브리프, 대시보드, 캘린더 작업, 이미지·영상 생성 기능으로 제시된다.
  • 기존 Claude, Codex, ChatGPT의 연결을 활용해 별도의 복잡한 재연결 없이 통합하는 방식을 강조한다.

03프로필과 목표 중심의 운영체제 설정

  • 운영체제에 이름을 부여하고 사용자 자신을 설명하는 라이프 프로필과 사업체 정보를 담는 비즈니스 프로필을 설정한다.
  • 비즈니스 프로필에는 고객과 사업의 형태 등이 포함되며, GPT-6 Astra가 인터뷰를 통해 필요한 맥락을 제공한다고 설명한다.
  • 목표와 전략을 설정하면 시스템이 이번 주 업무, 이번 달 목표, 분기별 도달 지점을 반영한 일일 브리프를 제공하는 구조다.
  • 제작자는 에이전틱 OS가 개인 및 사업 성과 달성에 도움을 주지 못하면 가치가 없다고 말한다.

04메모리 코어의 데이터 통합과 질의

  • 메모리 코어는 ChatGPT와 Claude 등의 정보를 포함하는 시스템 전체 메모리로 소개되며, 백그라운드에서 새 메모리가 추가되는 화면이 나온다.
  • Codex, Claude, OpenClaw 등의 코딩 도구를 선택하고 Granola, Notion, Obsidian, 사진을 메모리 소스로 가져올 수 있다고 제시한다.
  • Claude 또는 Codex의 채팅과 이메일이 발생할 때 로컬 컴퓨터에서 실행 중인 OS에 자동 반영될 수 있다고 설명한다.
  • 회의 참석자나 최근 회의 제목을 묻는 질의를 예시로 들며, 저장한 ‘좋아하는 색은 green, 동물은 English Springer Spaniel’ 정보를 다시 검색해 답한다.
  • 유튜브 영상, 파일, 사진 등을 메모리에 넣고 이후 채팅에서 활용할 수 있다고 시연한다.

05대시보드와 음성 캘린더 작업

  • 대시보드는 연결된 시스템의 주요 지표, 일일 브리프, 목표 진행도, 재무 현황, 오디언스 성장 정보를 한눈에 보는 공간으로 제시된다.
  • 화면의 수치는 데모 수치라고 밝히며, 캘린더 접근 권한을 바탕으로 우선순위를 확인할 수 있다고 설명한다.
  • 재무 영역에서는 월별 수입, 사업 상태, 재무 구성과 관련한 정보를 볼 수 있다고 소개한다.
  • 음성으로 ‘내일 11시부터 12시까지 Budapest 시간, Jack Brunch Lockin’ 일정을 요청하자 이벤트가 추가되는 시연이 나온다.

06Higgsfield API 기반 이미지·영상 생성

  • 디자인 시스템은 Higgsfield API를 연결해 이미지와 비디오 생성을 사용할 수 있는 기능으로 소개된다.
  • Higgsfield에서 API keys 메뉴로 이동해 키를 입력하면 OS 안에서 생성 기능을 쓸 수 있다고 안내한다.
  • 예시로 Soul 2 모델, 16:9 비율, 이미지 4장을 선택하고 English Springer Spaniel이 체육관에서 단백질 셰이크를 마시는 이미지를 생성한다.
  • 생성 화면에서는 모델별 선택지와 이미지당 비용이 표시되며, 제작자는 이미지뿐 아니라 영상도 생성할 수 있다고 말한다.
  • 라이브러리의 모든 컴퓨터 사진을 AI가 설명 키워드로 색인해 ‘burger’ 같은 검색어로 찾는 ‘매직 서치’를 소개한다.

07웹사이트 편집과 외부 앱 연결

  • 웹사이트 디자인 시스템에서는 localhost 주소를 입력해 웹사이트를 열고 태블릿·모바일 화면 형태로 미리 볼 수 있다고 시연한다.
  • 제작자는 Astra에 지시해 웹사이트를 만들었다고 말하며, 디자인·그래픽·카피를 확인하고 일부 요소를 편집하는 화면을 보여준다.
  • 카피는 ‘slop monster’를 거쳐 수정할 수 있고, 그래픽 생성 기능도 사용할 수 있다고 언급한다.
  • Zapier는 여러 앱 연결을 위한 연결 계층으로 소개되며, School, YouTube, Microsoft 등이 예시로 언급된다.
  • OS 안에서 Claude와 Codex에 명령을 내릴 수 있으며, Zapier 연결은 skills를 선택해 설정하는 방식으로 설명된다.

08용어 사전

용어뜻
에이전틱 OS개인·사업 데이터와 여러 AI 및 앱 연결을 통합해 질의와 작업 실행을 지원하도록 영상에서 소개한 운영체제다.

라이프 프로필사용자가 집중하는 일과 개인 정보를 담아 운영체제에 맥락을 제공하는 프로필이다.
