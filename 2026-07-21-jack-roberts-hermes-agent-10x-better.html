Hermes 에이전트 5단계 업그레이드

01핵심 개요

항목내용
채널Jack Roberts
길이약 20분
대상Hermes agent(에이전트형 OS, 기업가치 15억 달러) 최신 5단계 기능 강화
요지모델 선택·병렬 실행·초고속 웹검색·자동 브리핑·완료 검증 + 옵시디언 메모리 연동으로 생산성 극대화

02레벨 1 — 두뇌 교체(멀티모델)

모델연결특징
GPT 5.6ChatGPT 구독기본 모델, Max 플랜은 medium/high, $20 플랜은 낮은 레벨
Grok 4.5X 구독매우 빠르고 저렴, X 데이터 실시간 조회 가능
Kimi K3OpenRouter디자인 파워하우스, Opus에서 증류 추정, Fable 5의 약 30% 가격, 다만 응답 느림
토큰 트래커(우하단)로 컨텍스트 사용률 실시간 확인. 10M 토큰 기준 비용: Kimi K3 $54 · Opus 4.8 $90 · Fable 5 $180.

03레벨 2 — 속도(병렬 도구 호출)

구분내용
이전Gmail→캘린더→날씨 순차 호출(하나씩)
변경여러 도구 동시 호출 → 텔레그램 프롬프트 4건(업데이트·미읽음메일·다음일정·두바이기온)을 한 번에 처리

04레벨 3 — 웹검색 + Firecrawl

항목수치·내용
속도기존 대비 60배 빠름(15초 vs 약 3분)
비용49배 저렴
FirecrawlHTML 잡음(H1·광고) 제거, 핵심 텍스트만 전달 → 토큰 93% 절감
브랜드 추출로고·OG 이미지·컬러·타이포그래피·폰트까지 스크랩 → 디자인 자동 반영

05레벨 4 — 인텔리전스 브리프

구분내용
연결mcp.zapy(Zapier)로 Gmail·캘린더 등 앱 연동
권한 원칙발송 금지, 읽기·초안(draft)만 허용 — quick draft·labels·find emails
모닝 브리프날씨·수신 메일·오늘의 포커스 자동 요약, 매주 자가 인터뷰로 브리프 품질 개선

06레벨 5 — 완료 계약(Completion Contracts)

요소설명
목표/g + 프롬프트로 작업 지시(예: 다운로드 폴더 유형별 정리)
검증verify 조건·제약(constraints)·경계(boundaries) 명시
증거판정자가 완료 여부를 확인할 수 있도록 실제 수행 증거 제출

07보너스 — 복리형 메모리(옵시디언 연동)

항목내용
옵시디언 브레인컴퓨터에 저장된 개인 지식을 Hermes가 접근
Glider 플러그인음성 받아쓰기 스타트업(베타), 웹/유튜브 URL을 하이라이트→옵시디언 볼트에 저장
/learn유튜브 URL을 직접 학습·요약(3~5개 불릿), 스킬 마켓플레이스 지향

08용어 사전

용어설명
Hermes agent여러 모델·도구를 오케스트레이션하는 에이전트형 운영체제
OpenRouter다양한 모델을 단일 API로 호출하는 라우팅 서비스
Firecrawl웹페이지에서 핵심 텍스트·브랜드 자산만 추출하는 스크래핑 도구
Completion Contract목표·검증·제약을 명시해 에이전트 작업 완료를 증명하는 방식
