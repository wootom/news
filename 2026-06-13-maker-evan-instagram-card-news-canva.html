클로드 코드로 인스타 카드뉴스 자동 생성 — 캔바에서 바로 편집까지

메이커 에반 · 2026-06-13 · 업무 자동화 3강. 클로드 코드 스킬로 인스타그램 카드뉴스를 자동 생성하고, 캔바 MCP로 업로드해 편집 가능한 형태로 만드는 실습. GitHub CLI·Replicate API 셋업부터 스킬 트리거·캔바 연동까지 단계별 안내.

목차핵심 개요사전 셋업 — 계정·도구 준비핵심 워크플로우 — 프로젝트 초기화스킬 트리거 — 카드뉴스 생성동작 방식 — 생성에서 캔바 업로드까지활용 시나리오현황 및 전망용어 사전

01핵심 개요

항목내용
목표클로드 코드로 인스타 카드뉴스 자동 생성 → 캔바에서 편집 가능하게
사전 셋업GitHub 가입·CLI 로그인, Replicate API 키(선택), 캔바 MCP 연결
핵심 스킬인스타 카드뉴스 제너레이터 스킬
이미지 옵션Replicate API 사용(고퀄, $5 충전) / 미사용(무료, 기본 품질)
산출PPT 포맷 카드 → 캔바 업로드 → 표·편집 가능한 슬라이드

02사전 셋업 — 계정·도구 준비

  • GitHub: 가입·로그인
  • GitHub CLI: OS별(맥/윈도우) 버전 다운로드·설치 → 클로드 코드에게 "GitHub CLI로 로그인, 웹 브라우저로 할 거야" 요청
  • Replicate(선택): 계정 설정에서 API 토큰 발급 + 빌링에 $5 크레딧 충전(고퀄 이미지용, 없어도 동작)
  • 캔바 MCP: 설정 → 커넥터 → 맞춤 설정에서 캔바 MCP 연결·로그인 필수

03핵심 워크플로우 — 프로젝트 초기화

  • 작업 폴더 추가: 워크스페이스에 "인스타 카드뉴스" 폴더 생성·열기
  • GitHub 연동: "이 프로젝트 GitHub 연동해줘, 깃 레포지토리 초기화 먼저" 명령 → 권한 건너뛰고 git status 확인 후 퍼블릭 레포로 업로드
  • 이 초기화가 후속 작업의 전제 (맨 처음 필수 단계)

04스킬 트리거 — 카드뉴스 생성

  • 인스타 카드뉴스 제너레이터 스킬 호출
  • 명령 예: "메이커 에반이고 바이브 코딩 주제로 카드뉴스 만들어줘. 클로드 코드 스킬이면 더 좋아. 카드 8장 만들어줘"
  • 동작: 웹에서 적절한 내용 조사 → 걸맞는 이미지 검색·수집 → 이미지 밸리데이션 자동 수행

05동작 방식 — 생성에서 캔바 업로드까지

  • 1) 웹에서 주제 관련 내용·이미지 소싱(디스크립션 읽고 관련 이미지 수집)
  • 2) PPT 스킬로 카드 합성(8장)
  • 3) 캔바 MCP로 업로드 → 캔바에서 표·이미지 편집 가능한 슬라이드로 전환
  • 결과 확인: 아웃풋 폴더 슬라이드 → 캔바 업로드 완료 후 편집

06활용 시나리오

  • 1인 콘텐츠 운영: 주제만 주면 카드뉴스 8장 자동 제작 → 캔바에서 미세 조정
  • 채널 일관성: 동일 스킬로 반복 생성해 톤·포맷 통일
  • 비용 최적화: Replicate API 미사용 시 이미지 비용 0, 캔바 구독료만 소요

07현황 및 전망

  • 핵심 메시지: 콘텐츠 제작이 "디자인 노동" → "주제 지정 + 검수"로 단순화
  • 한계·선택: 고퀄 이미지는 Replicate 유료가 유리하나, 기본 무료로도 충분히 동작
  • 확장: 캔바 편집 가능 산출이라 자동 생성 후에도 사람 손질 자유로움

08용어 사전

용어한줄 설명비유/예시
MCP클로드가 외부 앱(캔바 등)과 연결되는 표준 커넥터앱끼리 끼우는 공용 어댑터
GitHub CLI터미널에서 깃허브를 다루는 명령줄 도구마우스 없이 키보드로 쓰는 깃허브
ReplicateAI 이미지 생성 모델을 API로 빌려 쓰는 서비스종량제로 그림 그려주는 외주
카드뉴스 제너레이터주제로 카드뉴스를 자동 생성하는 스킬한 줄 주문하면 나오는 카드 공장
밸리데이션가져온 이미지가 적절한지 자동 검증납품 전 불량품 골라내기
