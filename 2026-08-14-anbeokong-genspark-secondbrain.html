AI로 두 번째 뇌 만드는 가장 빠른 방법 — 젠스파크 SecondBrain 체험

01핵심 개요

항목내용

02핵심 기능/내용 구조

젠스파크 워크스페이스 6.0은 기억 문제를 해결하기 위해 4개 층(4 layers)으로 설계되었다.

  1. 레이어 1 — 메모리(세컨드 브레인): 사용자가 작업한 모든 것을 기억하는 최하위 층
  2. 레이어 2 — 브레인(슈퍼 에이전트): 기억을 읽고 일을 계획하는 층
  3. 레이어 3 — 아웃풋(슬라이즈·닥스·시트 등 스위트): 실제 결과물을 만들어내는 층
  4. 레이어 4 — 젠 팀: 사람과 AI 에이전트가 같은 채널에서 함께 작업하는 최상위 협업 층

세컨드 브레인이 담당하는 기억 프로세스는 세 단계로 구성된다.

  • 연결: 이메일, 캘린더, 문서, 회의 노트, 젠스파크 내 프로젝트 등 흩어진 정보를 가져옴
  • 정리: 자료를 그대로 쌓지 않고 사람·회사·프로젝트·타임라인·지식 단위로 구조화
  • 재사용: 슈퍼 에이전트가 새 작업을 수행할 때 이 기억을 다시 검색해 활용

03기술적 맥락

  • AI 활용 방식의 변화 흐름: (1) 초기 생성형 AI = 질문-답 챗봇 → (2) 코파일럿(문서·코드 작업 보조) → (3) 자율형 에이전트(자료 탐색·도구 사용·결과물 생성까지 자율 수행)
  • 에이전트가 많은 일을 맡을수록 "기억"의 중요성이 커짐. 발표자는 이를 "매우 똑똑하지만 회사 맥락을 전혀 모르는 신입사원"에 비유
  • 세컨드 브레인은 일반적인 자료 보관(개인 위키) 서비스와 다름: 위키는 사용자가 파일을 직접 찾아 열어야 하지만, 세컨드 브레인은 AI가 현재 작업과 관련된 과거 맥락을 능동적으로 검색해 반영
  • 연동 가능한 앱: Gmail, 구글 드라이브, 구글 캘린더 등 개인이 실제 사용하는 앱과 직접 연결 가능
  • 보안: SOC 2 Type, ISO 27001 인증 공개. 세컨드 브레인 노트의 녹음 파일은 전송 과정에서 암호화

04전략적 의미

  • 기존 AI 경쟁은 "더 큰 모델, 더 높은 성능, 더 복잡한 작업 수행 능력"에 집중되어 있었음
  • 발표자는 비슷한 성능의 AI가 여러 곳에 보급되면, 다음 경쟁 축은 "사용자의 자료와 판단을 얼마나 오랫동안 이어서 이해하는가"가 될 것이라고 전망
  • 하드웨어(세컨드 브레인 노트)를 통해 오프라인 정보(현장 대화, 발표, 순간 생각)까지 온라인 기억 체계로 연결하는 서비스는 현재로서는 젠스파크가 유일하다는 평가
  • 크리에이터 업무 관점에서 세컨드 브레인의 가치는 "AI가 콘텐츠를 대신 만들어주는 것"이 아니라 "과거 자료·판단을 다시 찾고 확인하는 부담을 줄여주는 것"에 있다고 강조

05핵심 워크플로우·방법론

실제 시연에서 사용된 프롬프트·절차는 다음과 같다.

  1. 콘텐츠 소재 정리 요청: "세컨드 브레인에 저장된 최근 안될공학 콘텐츠 관련 기록을 참고해서, 현재 검토 중인 항목 중 반복된 소재나 추가 확인이 필요한 팩트를 정리하고 각각 어떤 기록을 참고했는지 표시해줘" → 슈퍼 에이전트가 주제별 정리, 반복 소재(예: 메모리 쇼티지·D램 등 반도체 관련) 분석, 유사 주제 간 차이점 분석, 크로스체크 필요 팩트 나열까지 수행
  2. 제작진 공유용 브리핑 작성: "세컨드 브레인에 저장된 이번 영상 기획안·고객사 피드백·조사 기록을 참고해서 제작진 공유용 브리핑을 정리해줘. 총 5장, 각 장마다 핵심 문장·공식 근거·재해석·추가 확인 항목·추천 시각자료로 구성하고, 슬라이드는 아직 생성하지 말고 내용과 순서만 작성해줘" → 사람이 먼저 순서·핵심 메시지를 검토 후 실제 슬라이드 제작 단계로 진행
  3. AI 슬라이즈 제작: 프로페셔널 모드 + 16:9 화면비 선택, 5장 아웃라인 확인 후 전체 슬라이드 생성. 완료 후 "베리파이 컨텐트" 기능으로 수치·주장 재검증(단, 최종 확인은 사람이 공식 자료와 재대조)
  4. 슬라이드 세부 편집: 완성된 슬라이드에서 특정 요소를 클릭·지정한 뒤 프롬프트로 한 번에 반영해 세부 조정
  5. 스킬스(Skills) 활용: 반복 작업 방식을 저장하는 기능. "기술 콘텐츠 자료 검수" 스킬을 만들어 "자료에 없는 주장 추가 금지", "사실과 해석 구분", "최신 여부 불분명한 수치는 재확인 항목으로 분류" 같은 규칙을 등록 → 이후 다른 주제 자료에도 동일 검수 기준 자동 적용

06활용 시나리오

  1. 콘텐츠 제작자의 소재 관리: 영상 기획안, 고객사 피드백, 조사 기록을 세컨드 브레인에 축적해두면 다음 영상 제작 시 반복 소재나 미확인 팩트를 자동으로 크로스체크
  2. 제작진 공유 브리핑 자동화: 기획 배경과 근거를 정리한 브리핑 자료를 프롬프트 한 번으로 초안 생성, 이후 AI 슬라이즈로 시각 자료까지 완성
  3. 현장 취재·행사 기록: 세컨드 브레인 노트로 발표 녹음과 현장 소감을 음성으로 남기면 자동 전사·요약되어 세컨드 브레인에 새 기억으로 축적
  4. 업무 연속성이 중요한 직군: 이메일·미팅·프로젝트가 계속 이어지고 과거 결정이 다음 업무에 영향을 주는 경우(발표자는 일회성 질문 위주 사용자는 효용이 크지 않을 수 있다고 언급)
  5. 반복 검수 기준 적용: 스킬스에 등록한 검수 규칙을 여러 콘텐츠(예: 키미 K3 영상, 애플 관련 대본 등)에 동일하게 적용해 사실과 해석을 일관되게 분리

07현황 및 전망

  • 세컨드 브레인 노트는 온디바이스로 AI가 모든 걸 분석하는 제품이 아니라, 현장 음성을 먼저 녹음하고 앱을 통해 젠스파크 서버의 기억으로 전달하는 구조(온디바이스보다 강력한 AI를 활용하기 위한 설계)
  • 사용법: 버튼 3초 눌러 전원 켜기 → 젠스파크 모바일 앱 AI 노츠 메뉴에서 페어링 → 버튼 2초 길게 눌러 녹음 시작 → 짧게 누르면 북마크(하이라이트) 표시 → 다시 2초 길게 눌러 녹음 종료
  • 녹음 종료 후 자동으로 앱에 파일 전송, 전사·AI 요약·하이라이트 구간이 생성됨(단, 1분 미만 녹음은 전사만 생성될 수 있음)
  • 가격: 정가 199달러에서 179달러로 할인 판매 중. 기기 구매 시 구독 없이도 월 300분 전사·요약 제공, 플러스·프로 플랜 사용자는 하루 최대 24시간 범위 무제한 전사 지원
  • 발표자는 "AI가 콘텐츠를 얼마나 빠르고 쉽게 만드는가"보다 "더 좋은 판단을 내리는 데 AI가 어떤 부분을 도와줄 수 있는가"를 계속 살펴보겠다고 마무리
