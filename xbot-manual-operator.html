xbot 운영자 매뉴얼

xbot 실행·설정·게시·장애 대응을 위한 운영자 전용 문서. 카톡 사용법은 [[xbot-사용자-매뉴얼]] 참고. 본 문서는 형상 변화 시 갱신합니다.

목차시스템 구성봇 실행·종료·재시작설정: hot-reload vs 재시작방별 에이전트 = Hermes profile모델 설정 (자주 혼동)관리자 웹 (Flask :5001)출판 파이프라인 (슬라이드/웹 리포트)MCP 서버 (Hermes 등록)Watchdog / 자동 복구주요 데이터·로그 경로트러블슈팅자주 쓰는 진단 명령

01시스템 구성

카카오톡 → kakaocli 동기화(Swift) → 웹훅 수신(FastAPI :8766) → MessageRouter(방별 페르소나 lookup, !명령 정규화) → 분기:

  • !주가/!도움말 → CommandHandler 전단 직답(K-dexter 직접 호출, 1–2초)
  • 그 외 → AIEngine.ask → 방별 Hermes profile(kakao_<chatid>)로 라우팅 → Hermes(LLM)가 MCP 도구 자동 호출(kdexter·dart·macro·brave·gmail) → 응답 → kakaocli send(AX UI 자동화)

병렬 백그라운드: Telegram→KakaoTalk 포워더 · Flask 관리자 웹(:5001) · watchdog(무응답 자동 재기동) · daily_report 스케줄러.

02봇 실행·종료·재시작

  • 실행(중요): 반드시 plain Terminal.app에서 cd ~/xbot && python3 main.py

- 이유: kakaocli send는 macOS 접근성(AX)으로 카톡 UI를 자동화 → Terminal.app에서 띄운 프로세스만 AX 권한을 상속. tmux/SSH/원격 셸에서 띄우면 전송 실패.

  • 정상 종료: kill -INT $(lsof -ti:8766 | head -1) 또는 봇 띄운 터미널에서 Ctrl+C
  • 재시작이 필요한 경우: .py 코드 변경 시 반드시 재시작(모듈 import 시점에 값 캡처). 설정(settings.json)만 바꿨으면 재시작 대신 hot-reload.
  • 헬스 체크: 봇 curl http://127.0.0.1:8766/healthz · 관리자 curl http://127.0.0.1:5001/ · K-dexter curl http://localhost:3000/health · Hermes hermes status

03설정: hot-reload vs 재시작

변경 대상반영 방법
settings.json(포워딩·페르소나·정책)curl -X POST http://127.0.0.1:5001/apply 또는 SIGHUP (재시작 불필요)
.py 코드봇 재시작 필수
방 Hermes profile(config.yaml·SOUL·AGENTS)다음 호출부터 자동 반영(재시작 불필요)

04방별 에이전트 = Hermes profile

  • 방마다 독립 profile kakao_<chatid> — 자체 config.yaml(모델)·SOUL.md(정체성)·AGENTS.md(공통 규칙)·기억. 미존재 방은 첫 메시지에 kakao_base 복제로 생성.
  • 공통 동작 규칙은 ~/.hermes/profiles/kakao_base/AGENTS.md가 소유(Hermes 자동 주입). 갱신은 거기 + 이미 생성된 방 profile의 AGENTS.md.
  • 안정 키는 chat_id (chat_name은 UI rename으로 바뀜). 페르소나·세션 매핑은 항상 chat_id 기반.

05모델 설정 (자주 혼동)

  • 방 대화 모델 = 단일 진실원천 = 그 방 profile config.yaml: ~/.hermes/profiles/kakao_<chatid>/config.yaml 의 model.provider / model.default. 모델명을 단언할 때는 메모리·문서가 아니라 이 파일을 직접 읽을 것(값이 표류함).

- 예) vaax-test(469041369346893) = openai-codex / gpt-5.5 + fallback(openrouter deepseek/deepseek-v4-flash).

  • 관리자 웹의 "폴백"은 두 종류 — 헷갈리지 말 것:
위치저장처의미올바른 값 형식
운영설정 탭 "폴백 모델"(ai_model)settings.json policyHermes 실패 시 OpenRouter 직호출 모델OpenRouter id (예 anthropic/claude-sonnet-4.6)
에이전트설정 탭 방별 "폴백"방 config.yaml fallback_providers방 모델 실패 시 Hermes 내부 폴백provider/model (예 openai-codex/gpt-5.4-mini)

⚠️ 운영설정 폴백칸에 openai-codex/... 같은 Hermes 모델명을 넣으면 OpenRouter가 그 모델을 못 찾아 폴백이 깨집니다.

06관리자 웹 (Flask :5001)

  • 4탭: ① 포워딩 ② 방 관리 ③ 에이전트 설정(방별 모델·폴백·페르소나 모달 편집) ④ 운영설정(정책).
  • 외부 접근: Tailscale로 노출(예 https://macmini.tail*.ts.net:10000/). 사내망 합류는 Tailscale 클라이언트.
  • 페르소나 라벨은 SOUL 내용 기반 자동 분류(soul_personas.classify_soul).

07출판 파이프라인 (슬라이드/웹 리포트)

흐름: 콘텐츠 원고 생성 → 렌더 → 경량 검수 → git push → 공개 URL.

  1. 원고: 대화/주제/URL → ai_engine.compose_report(방 모델이 마크다운 원고 생성). 유튜브는 자막/전사(transcribe.py 스킬)를 source로 주입. ⏱줄 🤖에 실사용 모델 노출.
  2. 영상 출처: 유튜브 URL이면 yt-dlp로 제목·채널·게시일을 가져와 ## 영상 출처 섹션으로 본문에 자동 삽입(메타 조회 실패해도 링크는 들어감).
  3. 인포그래픽: 원고에 펜스 블록(bars/kpi/donut/timeline)이 있으면 공용 렌더러가 막대·카드·도넛·타임라인으로 변환. 색상은 스타일가이드 팔레트(녹/적)만 사용.
  4. 렌더: 공용 생성기 — 웹=~/Documents/Claude/Scheduled/_shared/md_to_deck.py(스크롤 리포트), 덱=md_to_deck_16x9.py(16:9). morning-digest 등과 공유되므로 수정 시 회귀 주의.
  5. 검수(self_review): 경량 lint(색상·테두리·구조) + LLM 자가검토. 검수 프롬프트에 현재 KST 날짜를 주입해 과거 날짜를 "미래"로 오탐하지 않게 함.
  6. 게시: ~/Sites/ai-infographic 로컬 → git push(origin, PAT 내장) → wootom.github.io/news/slides/.... 충돌 시 untracked 백업-비키기 self-heal.
주의: 원고 생성 모델이 openai-codex(gpt-5.x)인 방은 간헐적 stall로 빈 원고(2슬라이드)가 나올 수 있음 — 재생성하면 대개 정상. (참고: 주가 응답 지연과 동일 원인)

서버도구

  • MCP에 API 키 전달은 ~/.hermes/config.yaml의 mcp_servers.<name>.env에 명시(Hermes는 기본적으로 환경변수 미상속).

09Watchdog / 자동 복구

  • kakaocli silent-dead(30분 웹훅 0건) + Telethon silent-dead(30분 이벤트 0건) 감시 → 자동 재기동.
  • 포워딩 부분 실패 시 실패한 방만 지연 재전송 큐(기본 30/90/300초).

10주요 데이터·로그 경로

  • ~/.xbot/xbot.log — 메인 로그
  • ~/.xbot/user_tickers.json — 사용자 종목 매핑(xbot + kdexter-mcp 공유)
  • ~/.hermes-xbot/sessions.json — chat_id ↔ hermes 세션 캐시
  • ~/xbot/settings.json — 포워딩/페르소나/정책/일일리포트
  • ~/xbot/.env — API 키(OPENROUTER, TELEGRAM, KAKAO, TAVILY, FIRECRAWL, OPENDART, FRED, FINNHUB, BRAVE)

12자주 쓰는 진단 명령

  • 전체 회귀: python3 -m pytest tests/ -q (인터프리터 /usr/bin/python3)

  • 합성 웹훅(디버그): :8766/kakao에 메시지 JSON 배열 POST (chat_id·log_id·text·is_from_me 포함)
