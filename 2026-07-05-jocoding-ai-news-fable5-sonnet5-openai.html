02Fable 5 재개방 — 왜 지금 "특가"인가

  • 미국이 Fable 5·MS-5(미소스) 수출통제 해제 → 액세스 복원, 7/7까지만 구독제로 이용 가능
  • 제약: 주간 사용량 한도 최대 50%까지만. 7/7 이후엔 사용량 크레딧(고가) 전환
  • 가치 비교: Claude Max($200) 구독이 Opus 기준 약 $8,000어치 API 값 → 구독제가 압도적으로 저렴
  • API 단가: Fable $50/100만 토큰(출력) = 이전 Opus($25)의 2배. Artificial Analysis "cost per intelligence" 기준 GPT-5.5의 약 2.75배
  • 결론: 7/7 전까지 구독제로 "팍팍" 쓰는 게 유일한 가성비 창구 → 다계정 결제 러시 발생

03Fable 5 실사용 — 한계와 절약 팁

구분내용
부작용새 안전 분류기가 코딩·디버깅 중 정상 요청을 악성으로 오탐 → 일부 Opus로 다운그레이드
성능 유지아레나 점수는 재배포 전후 큰 변화 없음(프론트엔드만 소폭↓, 오차범위)
미리 시킬 일7/7 전에 "Opus 4.8용 스킬 작성" 등 어려운 작업을 최강 모델로 선점
이미지 토큰 꿀팁이미지 내 텍스트는 토큰 미산정 → 코드를 이미지로 변환해 입력 시 최대 60~70% 토큰 절감(패치 가능성 有)
프롬프트 원칙앤트로픽 직원 팁 "지도는 영토가 아니다" — 프롬프트·스킬을 과하게 빡세게 X. 저비용 브레인스토밍·프로토타이핑으로 오류를 미리 잡는 게 핵심 스킬

04신규 모델 지형 — Sonnet 5 / OpenAI / Google

  • Claude Sonnet 5: 벤치는 Sonnet 6↑·Opus↓의 애매한 중간. 문제는 "해결 문제당 비용"이 오히려 Opus보다 비쌈. 전체 벤치 실행 비용이 Fable 5보다도 비쌀 만큼 토큰 효율이 나쁨 → "그 돈이면 GPT-5.5나 Opus 4.8을 쓰지" (사실상 쓸 이유 없음)
  • OpenAI: GPT-5.6 임박 루머. 미국 정부에 회사 지분 5%(약 $426억) 기부 검토 → Fable 사태처럼 정부 규제 한 번이면 사업 마비, 정치적 압력 완화용 로비성 조치로 해석. Codex 전용 단축키 하드웨어(승인/거절 버튼 중심, 음성+버튼 바이브코딩) 출시 예고
  • Google: Gemini 3.6 혹은 4 임박 — 7/17 목표(폴리마켓 62%), 2M 컨텍스트, 딥싱크 추론, SVG·프론트엔드·UI 강점(데모 품질 Fable 5 이상 평가). Nano Banana 2 Lite(1분 21장 vs 기존 3장, 반값), Gemini Omni Flash(영상→영상), NotebookLM 숏폼 비디오 개요, Cerebras Gemma 4(1851 tok/s), Ollama+MLX Gemma 4 90%↑

05메타 — 광고·뇌·클라우드 3대 이슈

  • 초개인화 광고 논란: 인스타 릴스 광고가 사용자 프로필 사진을 끌어와 "여자친구에게 전화해줘" 식 타깃팅 → 마이크 도청 불안과 결합돼 거부감 확산(조작 가능성도 거론)
  • Brain2Qwerty v2: 비침습 뇌-텍스트 디코더. 학습 데이터 확대로 평균 단어정확도 61%, 최고 참가자 78% → 생각만으로 타이핑·바이브코딩 가능성
  • 클라우드 진출 검토: 과잉 투자로 남는 GPU 연산 자원을 외부 판매하는 클라우드 사업 검토 보도 → "GPU 남아도나" 우려로 반도체·데이터센터주 출렁, 메타 주가는 약 10%↑ (진행자 해석: 메타 특유의 과대투자일 뿐 타 기업은 여전히 GPU 부족)

06중국·오픈소스·로봇 — 확산 신호

  • 중국 Longcat 2.0: 배달 플랫폼 메이투안(중국판 배민)이 공개. 엔비디아 없이 중국산 AI 칩(5만 개 클러스터)만으로 학습·추론한 1조 파라미터 오픈웨이트 모델, 100만 컨텍스트. 일부 벤치서 Gemini 3.1 Pro 상회 → 자국 칩 자립 신호
  • 오픈소스 이미지: MR Flow(저해상도 먼저 생성→고해상 정제, Flux 8.25배·Z-Image Turbo 21배·조합 시 최대 25배 가속). ComfyUI MCP 공식 출시 → 에이전트가 워크플로우 자동 구성·이미지/영상 생성
  • 유비테크 U1(바이오닉 휴머노이드): 실리콘 피부·표정·감성 대화·IP 캐릭터 커스터마이징. 공개 직후 누적 예약 1.1만 대 돌파, 가격 2~3천만 원(최고 2억 원대). 1인 가구 정서적 동반자 타깃 → 휴머노이드 초기 실수요 입증 사례
