OpenAI Dots는 음성 통화와 클라우드·로컬 제어로 여러 작업을 맡기는 개인 에이전트다.

음성으로 여러 일을 맡기는 OpenAI Dots, 편리함과 한계를 직접 시험했다.

01핵심 개요

  • OpenAI Dots는 ChatGPT 데스크톱 앱에서 이름과 캐릭터를 정해 만들고, 대화가 끝난 뒤에도 일을 이어가는 개인 에이전트다.
  • 통화 중 말을 끊어 요청을 수정할 수 있고, 영상 제작 같은 작업을 백그라운드로 진행하며 중간 상황과 산출물을 보고한다.
  • 전용 클라우드 컴퓨터와 브라우저를 이용하고, Space에서는 페이지·이미지·사이트 등 작업 결과물과 에셋을 모아 볼 수 있다.
  • 매일 오전 7시에 최근 3일간의 중요 메일을 요약해 채팅과 Slack으로 보내는 예약 작업을 설정하는 과정을 시연했다.
  • 영상 제작은 20초·1920×1080·30fps MP4로 완료됐지만 Space 저장은 확인되지 않았고, 쿠팡 상품 조사도 성공하지 못했다.

02핵심 주장 / 논점 구조

  • 진행자는 Dots를 세션이나 프로젝트를 직접 관리하기보다, 개인화된 봇에게 대화로 일을 맡기는 방식으로 소개했다.
  • Grok봇·Buzz·Hermes Agent Bot Mode와 비슷한 점은 이름과 캐릭터를 가진 AI 동료라는 것이고, Dots는 클라우드 컴퓨터와 음성 통화를 결합했다.
  • 여러 작업을 병렬로 맡기고 전체 진행을 챙기는 오케스트레이터나 팀장처럼 활용하는 방식이 유용하다는 것이 영상의 핵심 평가다.

03음성 통화로 맡긴 모션 그래픽 제작

  • 진행자는 Dots 소개용 20초 모션 그래픽을 요청하고, 처음 제안된 네온 스타일 대신 Vox식 종이 콜라주로 방향을 바꿨다.
  • 실제 이미지 검색과 필요한 이미지 생성, 종이 질감과 찢긴 가장자리를 활용하는 구성을 요청했으며 봇은 중간 산출물도 공유했다.
  • 통화 도중 사용자가 말을 끊고 수정 요청을 할 수 있었고, 봇은 작업 방향 변경과 진행 상황을 음성으로 안내했다.
  • 완성 영상은 20초, 1920×1080, 30fps로 렌더링·재생 검수를 마쳐 채팅에 전달됐고, 진행자는 슬라이드형 결과물이라고 평가했다.

04클라우드 컴퓨터와 Space 결과물 관리

  • Dots의 클라우드 컴퓨터 화면에서 브라우저와 프로그램을 열고, 터미널·파일 관리 등을 제어할 수 있는 모습을 소개했다.
  • 진행자는 앱을 닫아도 클라우드 작업을 이어갈 수 있고 다른 기기에서 다시 연결할 수 있다고 설명했다.
  • Space에는 페이지, 이미지, 사이트와 작업 에셋이 모였으며, 진행자는 이를 Notion이나 Claude Artifacts와 닮은 공간으로 보았다.
  • 최종 MP4는 채팅에 첨부됐지만 Space 페이지에는 저장되지 않았고, 움직이는 진돗개 아바타의 프레임 이미지 등은 에셋으로 확인됐다.

05예약 작업과 병렬 진행

  • 최근 3일간의 메일에서 광고를 제외한 중요 메일을 매일 오전 7시에 요약해 채팅과 Slack DM으로 보내도록 예약했다.
  • 예약 설정에는 중복 메일을 피하고 새 소식이나 미처리 중요 건을 중심으로 다루는 조건이 포함됐다.
  • 영상 제작과 메일 요약을 동시에 진행했고, 화면의 활동 목록에서 작업별 상태를 확인하는 모습을 보여줬다.
  • 진행자는 순서대로 하나씩 기다리기보다 여러 일을 맡겨 병렬로 진행시키고 전체를 관리하는 방식이 편리하다고 말했다.

06플러그인·로컬 Claude Code·쿠팡 조사

  • Canva 연결은 이미 설치·연결된 상태였지만, Bright Data는 계정 플러그인 목록에서 찾지 못했고 Firecrawl은 사용자가 직접 설치와 계정 연결을 해야 했다.
  • 로컬 Claude Code에 Bright Data를 이용한 쿠팡 미니 PC 조사를 요청했지만, 인증이 완료되지 않아 상품 조사까지 진행되지 않았다.
  • 원격 컴퓨터에서도 쿠팡 페이지를 시험했으나 사용 권한이 없다는 안내가 떠 상품 목록과 판매 지표, 상위 3개 제품을 확인하지 못했다.
  • 진행자는 로컬 Claude Code와 원격 컴퓨터를 제어할 수 있음을 확인했지만, 쿠팡 접근 실패 원인은 확정할 수 없다고 봇이 보고했다.

07사용 소감·제약·제공 조건

  • 진행자는 통화 경험과 여러 작업을 맡기는 편의성을 긍정적으로 평가했지만, 한국어 음성이 다소 어색하고 진행 상황 보고가 정정된 사례도 언급했다.
  • 완성 영상은 무음이었으며, 진행자는 음성이나 효과음을 추가하고 결과물을 더 발전시킬 여지가 있다고 말했다.
  • 영상 말미에 소개된 제공 대상은 Pro와 Business Premium이며, 무료와 Plus 구독자는 아직 사용할 수 없다고 설명했다.
  • 대화·음성 추론은 사용량 차감이 없지만 Codex를 연동한 작업은 기존과 같이 토큰 할당량을 차감한다고 안내했다.

08용어 사전

용어뜻
DotsChatGPT 안에서 이름과 캐릭터를 붙여 만들고, 클라우드 컴퓨터와 브라우저로 대화 밖에서도 작업을 이어가는 개인 에이전트다.
Space페이지·이미지·사이트와 같은 작업 결과물 및 에셋을 모아 확인하는 공간으로 영상에서 소개됐다.
Computer Use봇이 브라우저와 컴퓨터 화면을 이용해 원격 또는 로컬 작업을 수행하는 기능으로 영상에서 설명됐다.
예약 작업정해진 시간과 조건에 따라 반복 실행하도록 설정하는 기능으로, 매일 오전 7시 중요 메일 요약 사례가 시연됐다.
Claude Code CLI진행자가 로컬 Claude Code 작업을 터미널 방식으로 요청하려고 시도한 경로이며, Bright Data 인증 문제로 쿠팡 조사는 진행되지 않았다.
