Anthropic의 Claude Code 워크플로우 변화와 자동화 관리 전략

Claude Code의 Auto Mode, Deny Rule, Projects 기능으로 효율적인 AI 개발 워크플로우 구축법

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

Claude Code 사용량 급증과 세션 매니저 역할 전환

  • Anthropic은 5월 하루 2,500건의 코드 변경에서 9월 30,000건 이상으로 처리량이 크게 증가했다.
  • Claude Code 팀의 Lydia Halley는 현재 사용자들이 수십 개의 세션을 관리하는 매니저 역할을 수행한다고 설명했다.
  • 강연에서는 사용자가 직접 수행해야 하는 5가지 핵심 작업과 이를 자동화하는 설정 방법을 다루었다.

Claude.md 파일 최적화와 모델별 지시어 조정

  • Opus 5.5와 같은 최신 모델에서는 대문자 강조나 '절대 금지' 같은 과도한 지시어가 오히려 모델의 성능을 저하시킨다.
  • Claude.md 파일에는 코드를 읽으면 알 수 없는 비즈니스 위키, 브랜드 자산, 재무 정보 등 라우팅 맵 정보만 포함해야 한다.
  • 슬래시 도क्टर 프롬프트 오딧 명령어를 실행하면 현재 모델에 더 이상 필요하지 않은 지시어와 공간을 차지하는 항목을 자동 식별한다.

Auto Mode 권한 분류기와 위험 명령 차단

  • Auto Mode는 별도 분류기를 통해 테스트와 설치 명령을 허용하되, 불확실한 명령만 사용자에게 승인 요청을 보낸다.
  • 기본적으로 현재 폴더와 저장소만 신뢰하며, 배포 저장소로의 푸시 등 위험한 작업은 차단하여 안전한 승인을 유도한다.
  • 8월 연구에서 Auto Mode는 인간이 놓친 위험 명령의 89%를 차단했지만, 여전히 10%는 통과하는 한계가 있다.

Deny List 하드 블록과 샌드박스 환경 구성

  • 되돌릴 수 없는 작업(예: API 키 읽기, 파일 삭제)은 프롬프트가 아닌 설정 파일의 Deny Rule로 하드 블록 처리해야 한다.
  • Deny Rule은 명령어 자체만 확인하므로, 악성 패키지가 키를 탈취하는 행위는 샌드박스 환경으로 제한해야 한다.
  • 슬래시 샌드박스 명령어는 컴퓨터가 명령어가 열 수 있는 파일과 접속 가능한 웹사이트를 제한하여 보안성을 높인다.

중간 체크포인트와 Exit Code 기반 피드백 루프

  • 장시간 실행되는 작업은 중간에 테스트나 스크린샷 등 통과/실패 기준이 되는 체크포인트를 설정하여 오류를 조기에 잡는다.
  • Claude Code의 훅 스크립트는 실패 시 Exit Code 2를 반환해야 모델이 작업을 완료 처리하지 않고 수정하도록 강제한다.
  • Exit Code 1은 대부분의 도구에서 실패를 의미하지만 Claude Code에서는 작업을 완료로 처리하므로 주의가 필요하다.

Claude Code Projects 베타와 오케스트레이터 모델 활용

  • Claude Code Projects는 주간 작업 목록을 주 세션에 주면 각 태스크별 별도 세션을 자동 생성하고 결과를 검증한다.
  • 주 세션은 코드 작성 대신 판단과 검증에 특화된 Fable 5.2 모델을 오케스트레이터로 사용하도록 설정할 수 있다.
  • 실제 작업은 Opus 5.5 등 작업 특화 모델이 수행하며, PR은 작성 세션이 아닌 새로운 컨텍스트의 Claude가 먼저 리뷰한다.

용어 사전

용어뜻
Claude.mdClaude Code가 프로젝트 컨텍스트를 이해하기 위해 읽는 마크다운 파일로, 코드에서 추론할 수 없는 비즈니스 정보만 포함해야 한다.
Auto ModeClaude Code의 기본 권한 관리 모드로, 별도 분류기가 명령어의 위험성을 판단하여 안전한 작업은 자동 실행하고 위험한 작업은 차단한다.
Deny Rule설정 파일에 하드코딩된 차단 규칙으로, Auto Mode보다 우선하여 특정 명령어가 실행되는 것을 물리적으로 방지한다.
HooksClaude Code가 편집이나 작업 완료 시점에 자동으로 실행하는 스크립트로, Exit Code에 따라 모델의 다음 행동을 제어한다.
Claude Code Projects주 세션이 여러 하위 세션을 오케스트레이션하는 베타 기능으로, 복잡한 프로젝트 작업을 병렬로 처리하고 결과를 검증한다.
