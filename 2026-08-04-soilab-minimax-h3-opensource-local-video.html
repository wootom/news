무료 오픈소스로 풀린 시덴스급 영상모델 — 미니맥스 H3 로컬 생성 실습 (소이랩)

중국 AI 기업 미니맥스(MiniMax)가 영상 생성 모델 H3(하일로 3)를 오픈웨이트로 무료 공개했다. 유료 API·자사 하일로 사이트 서비스와 별개로 허깅페이스에서 가중치를 내려받아 컴피UI(ComfyUI)에서 로컬 구동할 수 있다. RTX 3060급 그래픽카드만 있으면 텍스트 기반 영상, 레퍼런스·옴니 참조 영상을 직접 생성할 수 있음을 실습으로 보여준 튜토리얼 영상이다.

01핵심 개요

항목내용

02핵심 내용 구조 — '로컬에서 돌리는 시덴스급 모델'의 등장

현시점 영상 생성 모델의 최강자로 꼽히는 시덴스(Seedance)의 대항마로 미니맥스의 H3가 급부상했다. 발표자는 영상 도입부에 나온 장면이 촬영본도 시덴스 결과물도 아닌 H3로 만든 영상이라고 밝히며, 감정·움직임이 매우 자연스럽게 표현된다고 강조한다. 핵심 메시지는 "시덴스급 모델을 로컬에서 무료로 쓰는 날이 코앞으로 왔다"는 것이다.

03기술적 맥락 — 넥스트젠 멀티모델과 오픈웨이트 공개

미니맥스는 중국의 대형 AI 개발사로, 축적한 기술을 바탕으로 H3를 공개했다. H3는 텍스트 기반 비디오, 스타트·엔드 프레임, 옴니 레퍼런스를 모두 처리하는 멀티모델 비디오 생성 모델로, 시덴스와 동일한 기능군을 제공한다고 소개된다. 놀라운 지점은 유료 API와 자사 하일로 사이트 서비스가 이미 있음에도, 모델을 오픈소스 소프트웨어(무료 다운로드)로 함께 공개했다는 점이다. 사양은 초당 24프레임·최대 1080p FHD이며, RTX 3060 VRAM GPU에서도 작동한다고 홍보한다. 다만 공개 초기라 1080p는 아직 어렵고 720p 사용을 권장한다.

04전략적 의미 — 로컬·무제한 생성 시대의 개막

지금까지 고품질 캐릭터 교체·모션그래픽은 상당한 비용을 들여야 했지만, 오픈웨이트 공개로 RTX 그래픽카드만 있으면 사실상 무제한으로 영상을 뽑을 수 있는 환경이 열렸다. 유료 상용 모델(시덴스 등)과 대등한 기능을 로컬에서 무료로 쓸 수 있다는 점은, 영상·모션그래픽 제작 비용 구조와 진입 장벽을 근본적으로 낮춘다. 이는 상용 영상 모델 진영에 직접적인 경쟁 압력이 된다.

05핵심 워크플로우·방법론 — 설치부터 옴니 참조까지

  • 설치 준비: ① 컴피UI(ComfyUI)를 최신으로 업데이트해 H3 지원·워크플로우 확보 → ② 허깅페이스 페이지에서 디퓨전 모델·텍스트 인코더·VAE를 내려받는다. 처음에는 FP8 스케일드 디퓨전 모델 + MVFP4 텍스트 인코더로 시작할 것을 권장한다. 업데이트 후 컴피UI에 H3 워크플로우 템플릿 4종이 나타난다.
  • 프롬프트 작성: H3는 프롬프트 양식이 매우 정교해, 별도의 프롬프트 가이드(허깅페이스의 base·RF 마크다운 파일)가 제공된다. 이 MD 규칙 파일을 챗GPT·코덱스 같은 LLM에 넣고 원하는 방향만 지시하면 복잡한 H3 프롬프트를 깔끔하게 자동 생성할 수 있다.
  • 텍스트→비디오: 감정 연기 레퍼런스를 넣어 프롬프트를 만들고, 시드·듀레이션(15초)·메가픽셀(1M)을 조정해 실행하면 발음·표정까지 자연스러운 결과물이 나온다. 한글·세종 테마의 타이틀 모션그래픽도 인상적인 글자 이펙트로 생성된다.
  • 옴니 레퍼런스(참조 기반): 다크나이트 조커 장면 등 소스 영상에 교체할 인물 이미지를 넣고, 비디오·오디오 레퍼런스를 각 노드에 연결한 뒤 듀레이션(예: 7초)을 맞춰 실행하면 캐릭터가 교체된 영상이 나온다. 스토리보드 이미지를 입력해 프롬프트화하면 스토리보드 기반 영상도 생성된다.
  • 속도 최적화: 세이지 어텐션(Sage Attention, KJ 노드)을 워크플로우에 연결하고 오토로 설정하면 생성 시간이 26분(또는 24분)에서 16분으로 단축된다(퀄리티 하락 없음). 설치가 복잡하므로 코덱스에 전체 권한을 열고 그래픽카드 드라이버에 맞춰 설치를 맡기면 자동으로 처리된다.

06활용 시나리오

로컬 GPU만으로 광고·단편의 캐릭터 교체 영상 제작, 한글 타이틀·모션그래픽 생성, 스토리보드 기반 프리비주얼 영상화, API 비용 없이 반복 실험이 필요한 크리에이터의 대량 영상 프로토타이핑에 활용할 수 있다.

07현황 및 전망

H3는 공개 초기라 720p 권장 등 제약이 있으나, RTX 3060급에서도 상용급 결과가 나오는 점이 확인됐다. 발표자는 후속 콘텐츠로 H3의 다양한 기능을 계속 소개하겠다고 예고했다. 오픈웨이트 공개로 로컬 영상 생성 생태계(컴피UI·워크플로우·최적화 노드)가 빠르게 확장될 전망이다.
