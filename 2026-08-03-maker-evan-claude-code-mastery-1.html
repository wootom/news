클로드 코드 완전정복 1부 (왕초보용)

01핵심 개요

터미널(검은 화면)이나 명령어 없이, 데스크톱 앱만으로 클로드 코드를 처음 켜 보는 완전 왕초보를 위한 튜토리얼이다. 개발·코딩 지식이 전혀 없어도 되고, 카카오톡 켜듯 앱 아이콘을 더블 클릭한 뒤 말풍선 입력창에 한국어로 요청만 쓰면 된다. 핵심 전환점은 예전엔 개발자 도구였던 클로드 코드가 클로드 데스크톱 앱 안에 통째로 들어왔다는 점이다. 강사(메이커 에반)는 "터미널 열어라는 말을 한 번도 안 한다", "아는 척하고 넘어가는 부분이 없다"는 두 가지 약속으로 시작한다. 영상은 크게 여섯 덩어리로 구성된다: (1) 클로드 코드가 무엇이며 챗봇과 뭐가 다른지, (2) 설치·첫 화면·버튼 뜯어보기, (3) 안전하게 쓰는 법, (4) 잘 시키는 법, (5) 기억하게 만드는 법, (6) 스킬즈. 강사가 꼽는 오늘의 가장 중요한 단어는 스킬즈(Skills)다.

02클로드 코드의 정체 — 챗봇과의 결정적 차이

  • 정의: 내 컴퓨터 안에 앉아 진짜로 일하는 만능 조수. 보고서 초안, 자료 조사, 엑셀 정리, 파일 폴더 분류, 웹사이트 직접 확인까지 한다.
  • 결정적 차이: 챗봇은 말로 답만 한다. 클로드 코드는 진짜 폴더의 진짜 파일을 열고 읽고 만들고 고친다.
  • 예시: "월간 보고서 양식 만들어 줘" → 챗봇은 예시를 글로 보여주고 복사·붙여넣기는 사용자 몫. 클로드 코드는 월간보고서양식.md 파일을 실제로 만들어 지정 폴더에 저장한다. 폴더를 열면 파일이 진짜 있다.
  • 의미: 업무 대부분은 결국 파일 하나(보고서·엑셀·기획서 초안·회의록)가 남는 일이므로, 말이 아니라 손에 잡히는 결과물이 중요하다.
  • 에이전틱(agentic): "스스로 판단해서 여러 단계를 밟는"이라는 뜻. 챗봇은 한 번 주고받고 끝. 클로드 코드는 목표만 던지면 거기까지 가는 단계를 스스로 설계한다. 챗봇이 상담 창구라면 클로드 코드는 일을 맡길 수 있는 동료다.

03작동 원리 — 파악·행동·검증 루프와 도구

  • 루프의 3박자: (1) 맥락 파악(파일 읽고 폴더 살피고 필요하면 웹 조사) → (2) 행동(파일 생성·수정, 실행) → (3) 검증(결과가 맞는지 확인, 틀리면 1번으로 복귀). 이 루프가 한 요청 안에서 수십 번 돌 수 있다.
  • 사용자도 루프 안에 있음: 방향이 틀렸으면 "멈춰"라고 하면 되고, 진행 중 "그거 말고 이거로"를 던지면 현재 동작을 끝내고 반영한다. 위험한 작업 앞에서는 클로드가 먼저 멈추고 물어본다. 깜깜이로 진행되지 않는 것이 핵심.
  • 화면 표시: "읽기 회의록 3월" 식으로 진행 상황이 계속 뜨고, 클릭하면 상세 내역이 펼쳐지며, 이상하면 그 자리에서 세울 수 있다.
  • 도구(Tools) 때문에 파일을 다룸: AI 모델 혼자서는 글만 쓴다. 실제 작업엔 도구가 필요하고, 클로드 코드는 파일 작업·검색·실행·웹·브라우저·위임·질문 등 도구 세트를 갖췄다. 어떤 도구를 쓸지는 사용자가 고를 필요 없이 자동 선택된다.
  • 도구는 모두에게 동일하게 주어진다. 그럼 결과 차이는 어디서? → 클로드가 "나의 방식"을 아느냐이고, 그 지식을 넣어주는 장치가 스킬즈다. 클로드 코드는 코딩 전용 도구가 아니라 컴퓨터로 할 수 있는 일 대부분을 돕는다(자료 조사, 발표자료 초안, 문서 작성, 긴 문서 요약, 데이터 정리, 파일 정리, 웹 확인).

04안전하게 쓰는 법 — 한계와 권한 모드

  1. 회사 사정(사내 규칙·승인 절차·팀 사정)을 모른다 → 알려줘야 하며, 안 알려주면 일반론으로 답한다.
  2. 사실을 틀릴 수 있다 → 특히 숫자·날짜·인용문은 사람이 검증.
  3. 권한 밖은 안 건드린다(단점 아닌 장점) → 지정 폴더 바깥은 함부로 안 만짐.
  4. 되돌릴 수 없는 일(메일 발송·결제·배포)은 반드시 물어본다.
  5. 최종 판단은 사람 몫.
  1. 수동: 파일 수정·명령 실행 때마다 물어봄. 초보자 강력 추천. 미리보기 후 승인/거부.
  2. 편집 자동 수락: 파일·폴더 편집은 알아서, 나머지는 물어봄. 빠르지만 나중에 한꺼번에 검토 필요.
  3. 계획(Plan) 모드: 아무것도 안 고치고 "이렇게 하겠습니다" 계획만 세움. 읽기·조사는 되지만 수정은 안 됨. "진짜 좋다"고 강조.
  4. 자동: 대부분 스스로 판단, 배경 안전 검사 상시 작동, 위험 판정 시 무조건 사람에게 질문.
  5. 건너뛰기(무시): 배우는 동안은 쓰지 말 것.

05설치·화면·세션 이해

  • 준비물 3개: 맥/윈도우 컴퓨터, 클로드 계정+유료 구독, 인터넷.
  • 설치 순서: (1) 브라우저에서 claude.ai 다운로드 → OS에 맞는 파일 받기, (2) 실행(맥은 아이콘을 응용 프로그램 폴더로 드래그, 윈도우는 안내대로), (3) 로그인. 윈도우는 로컬 세션용으로 Git for Windows 필요, 맥은 대부분 기본 포함. 클로드 코드는 데스크톱 앱에 이미 들어 있어 따로 설치할 것 없음.
  • 3개 탭 구분: 챗(일반 대화형 AI, 파일 접근 안 함), 코워크(격리된 가상 환경에서 스스로 오래 일하는 자율 모드, 오늘 다루지 않음), 코드(내 컴퓨터의 지정 폴더 파일을 직접 다루는 작업 공간, 오늘의 주인공). 판단 기준 한 줄: 작업 끝났을 때 내 컴퓨터에 파일이 남아야 하면 코드.
  • 세션: 하나의 작업 단위(대화 하나). 4가지 성질 — 각자 대화 기록/작업 폴더/프로젝트/변경 내역을 가지며 서로 방해하지 않고 여러 개 동시에 띄울 수 있다.
  • 세션 시작 전 확인 4가지: 환경, 작업 폴더, 모델, 권한 모드. 이 중 작업 폴더가 첫 단추 — 어느 폴더에서 일할지 지정("서랍" 지정 비유). 지정 폴더 안은 읽고 쓸 수 있고 바깥은 안 건드림(안전 장치). 바탕화면/문서에 'AI 작업실' 폴더를 만들어 프로젝트로 지정 권장.
  • 입력 조작: 보내기=엔터, 줄바꿈=Shift+엔터, 즉시 중단=ESC. 중단하지 않고 방향 바꾸려면 그냥 새 메시지를 입력하면 된다.
  • 특수문자 3개: /(슬래시)=명령어 목록(모델·유세지·컨텍스트·컨피그·스케줄·이닛·닥터·콤팩트·클리어 등, 아래에 설치된 스킬즈도 표시), @(골뱅이)=에이전트·스킬즈 및 파일·폴더 목록, +(플러스)=파일/사진 추가·폴더 추가·커넥터(Gmail·드라이브 등)·플러그인. 비개발자는 파일/사진 추가를 많이 쓰며, 화면 캡처를 붙여 "여기 이 부분 이상해"라고 하는 게 말보다 정확.
  • 모델: 오른쪽 아래에서 언제든 변경. 페이블 5(가장 똑똑) > 오퍼스(옵스, 그다음) > 소넷(균형, 일상 업무 대부분 충분) > 하이쿠(가장 빠르고 가벼움, 요약·형식 변환·반복 작업 특화). 옆의 사고 강도는 얼마나 깊게 생각할지(낮음=빠르고 저렴, 보통=균형, 높음=꼼꼼, 매우 높음=가장 깊게). 실전 규칙: 기본값으로 쓰다가 결과가 얇을 때만 한 단계 올려라(사용량 절약).
  • 요금제 4종: 프로(개인·가볍게·입문용 충분), 맥스(개인이지만 많이 쓰는 사람·사용량 한도 훨씬 큼) 등. 처음엔 프로로 시작하고 한도가 자주 걸리면 맥스로. 실행 환경은 처음엔 로컬(내 컴퓨터·내 폴더·눈앞에서 작업)만 알면 됨.

06활용 시나리오

  • 회의록 요약: "이 폴더 회의록 20개에서 결정 사항 뽑아서 표로 정리해 줘" → 폴더 목록 확인 → 파일 하나씩 읽기 → 결정 사항 추출·정리 → 빠진 회의록 재확인·추가 → 보고. 앱 켜고 한국어 한 문장만 쓰면 됨.
  • 첫 실습 3단계: (1) "이 폴더에 뭐가 있는지 살펴보고 어떤 작업을 도와줄 수 있는지 알려줘"(빈 폴더면 비었다고 답), (2) "이 폴더에 테스트.md 파일 만들고 안에 '안녕하세요. 첫 파일입니다'라고 써 줘"(수동 모드면 승인 요청 → 승인 시 실제 생성, 폴더 열어 확인 권장), (3) "우리 팀 주간 회의록 양식 만들어 줘 — 참석자·안건·결정 사항·담당자·마감일 항목, 표 형태"(마음에 안 들면 이어서 말로 수정).
  • 데이터 점검: "지난달 매출 데이터에서 이상한 숫자 좀 찾아줘" → 파일 검색·읽기·계산·결과 문서화까지 한 문장으로.
  • 웹 확인: 브라우저를 실제로 열어 페이지 확인, 화면 캡처로 검증, 문제 발견 시 수정 후 재확인.

07현황 및 전망

  • 예전엔 개발자 전용이던 클로드 코드가 데스크톱 앱에 통합되어 기획자·마케터·디자이너·대표 등 비개발 직군도 터미널 없이 쓸 수 있게 됨.
  • 데스크톱 앱을 고르는 이유 5가지: 터미널 몰라도 됨, 변경 사항을 눈으로 확인, 여러 작업 병렬 실행, 미리보기 내장, 나중에 확장 쉬움.
  • 로그인 시 반복되는 "로그" 안내는 버그로, 껐다 켜면 해결. 신규 기능 안내 팝업은 X/ESC로 닫으면 됨.
  • 좋은 요청의 4요소: 목적·대상·형식·제약, 그리고 맥락(배경)은 아낌없이 세세하게. 잘 만든 요청은 "이 요청 방식을 스킬로 만들어 줘"라고 하면 재사용 가능 → 매번 반복 설명 없이 스킬즈로 '딸깍' 실행.
  • 강사는 무료 전자책(왕초보용 클로드 코드 입문서)을 댓글로 배포하며, 2부에서 이어진다.

08용어 사전

용어설명
클로드 코드내 컴퓨터의 진짜 파일·폴더를 열고 읽고 만들고 고치는, 데스크톱 앱 안의 AI 조수
에이전틱(agentic)스스로 판단해 여러 단계를 밟는 성질. 목표만 주면 단계를 자체 설계
파악·행동·검증 루프맥락 파악 → 행동(생성·수정) → 결과 검증, 틀리면 반복하는 작동 사이클
도구(Tools)파일·검색·실행·웹·브라우저 등, AI가 실제 작업을 하게 해주는 기능 세트(자동 선택)
스킬즈(Skills)클로드에게 '나의 방식/지식'을 주입해 재사용하게 만드는 장치. 영상의 핵심 단어
세션하나의 작업 단위(대화 하나). 각자 기록·폴더·변경 내역을 가지며 병렬 가능
작업 폴더클로드가 일할 범위로 지정한 폴더. 안은 읽고 쓰지만 바깥은 안 건드림(안전 장치)
권한 모드얼마나 자주 사람에게 물어볼지 정하는 설정(수동·편집 자동·계획·자동·건너뛰기)
계획(Plan) 모드아무것도 안 고치고 조사·계획만 세우는 모드. 큰 작업 시작 시 권장
코워크 탭격리된 가상 환경에서 스스로 오래 일하는 자율 모드(오늘 미다룸)
프롬프트 인젝션외부 프롬프트를 심어 원치 않는 동작·보안 키 탈취를 노리는 공격
사고 강도모델이 얼마나 깊게 생각할지 정하는 값(낮음·보통·높음·매우 높음)
