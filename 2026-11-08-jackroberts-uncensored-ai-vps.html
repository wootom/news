검열 제한 모델로 앱을 만들고 로컬·음성·VPS 운용을 살펴본다.

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

분석 범위: 원문 전체 28,982자 · 5개 구간. 원문 대조한 핵심 인용 30개를 바탕으로 요약했습니다.

거부 응답을 제거한 ‘obliterated’ 모델의 작동 방식과 이용

  • 영상은 사용자가 모델 자체를 소유하는 것은 아니라고 설명한다. ‘obliterated’ 모델은 모델의 가중치에서 답변 거부와 관련된 부분을 식별해 제한을 없앤 방식으로 소개된다.
  • obliterated large V2를 선택해 이용하는 장면을 보여주며, 계정을 만들고 5달러를 예치하면 질문할 수 있다고 말한다.

Jarvis로 Granola·Linear·Screen Studio 재현 작업

  • 진행자는 Jarvis에 obliterated 모델을 사용해 회의 앱 Granola를 역설계해 달라고 요청한다. Linear와 Screen Studio를 재현한 결과도 예시로 보여준다.
  • 영상에서 Linear 작업 비용은 63달러, Granola는 32달러로 제시된다. Opus 5.5를 사용했다면 각각 281달러와 152달러였을 것이라고 비교한다.

로컬 실행의 데이터·비용과 모델 성능 간격

  • 로컬에서 실행하는 경우 파일이 사용자 기기에 남고 API 요금이 들지 않는다고 설명한다. 진행자는 자신의 대화 데이터가 OpenAI나 Anthropic으로 가지 않는다고 말한다.
  • DeepSeek V4.1 Flash가 2026년 3월의 프런티어 모델만큼 좋다는 평가를 제시한다. 일반적으로 최고 수준 오픈 모델은 프런티어보다 약 4개월, Mac에서 실행 가능한 모델은 약 9개월 뒤처진다고 설명한다.
  • 영상은 모델 선택의 기준을 컴퓨터에서 직접 실행할지 클라우드에서 쓸지, 검열된 모델과 검열되지 않은 모델 중 무엇을 택할지로 정리한다.

Fish Audio 음성 복제와 API 연동

  • Fish Audio로 1분 이내에 음성을 복제하거나 직접 음성을 설계할 수 있고, 음성 라이브러리에서 목소리를 고를 수도 있다고 소개한다.
  • API 키를 만든 뒤 Claude나 사용하는 운영체제에 전달해 시스템에 연결하는 과정을 설명한다.

Hostinger VPS로 원격 접속 환경 구성

  • 노트북을 끄면 실행이 멈추고 책상에 묶인다는 점을 한계로 들며, 지속적으로 작동시키기 위해 소형 서버가 필요하다고 말한다. Hostinger에서 VPS를 설정하는 과정을 보여준다.
  • VPS는 노트북 대신 빌린 서버 공간에서 작업을 실행하는 방식으로 설명된다. Tailscale로 노트북·데스크톱·휴대전화와 VPS 사이에 사설 터널을 연결한다.
