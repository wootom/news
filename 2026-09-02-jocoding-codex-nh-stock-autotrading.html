프롬프트 한 번으로 AI가 주식 자동매매까지

코덱스와 NH증권 API로 상담부터 매매·텔레그램 승인까지 자동화

01핵심 내용

  • NH투자증권 API 서비스 나무플러그와 오픈AI 코덱스를 연결해 코드를 몰라도 미리 준비된 한글 프롬프트만 붙여넣으면 자동 매매 프로그램이 만들어진다.
  • 코덱스가 저장소 다운로드, 파이썬 설치, API 키 연결, 투자 성향 상담, 전략 수립까지 순차적으로 자동 진행하며 기본값은 한 시간마다 시장을 확인해 매매한다.
  • 실전 투자로 전환하면 텔레그램 봇이 연동돼 매 주문마다 알림이 오고 3분 안에 사람이 승인해야 체결되며 미승인 시 자동 취소되지만, 손절·익절 주문은 예외적으로 즉시 처리된다.
  • 컴퓨터를 계속 켜둘 수 없을 때는 디지털오션 클라우드 서버(월 24달러)에 원격 연결하면 컴퓨터를 꺼도 예약된 자동 매매가 계속 돌아간다.

02왜 중요한가

  • API 문서를 사람이 직접 읽고 코드를 짜던 방식에서 AI 에이전트가 문서를 이해해 자동 구현하는 바이브 코딩으로 개발 문턱이 크게 낮아졌다.
  • AI에 전권을 넘기지 않고 텔레그램 승인이라는 사람의 최종 확인 절차를 넣어 실전 투자의 위험을 통제하는 안전장치 설계를 보여준다.
