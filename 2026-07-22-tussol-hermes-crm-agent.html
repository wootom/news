헤르메스 에이전트로 업무 위임 — 슬랙·솔라피 CRM 자동화

01핵심 개요

항목내용
주제AI 에이전트 '헤르메스'에게 CRM(알림톡 발송) 업무를 통째로 위임
채널투쏠ㅣAI 에이전트
만든 것슬랙 채널에 리드가 올라오면 5일간 자동 예약 발송하는 CRM 에이전트
스택실습폼 → n8n(웹훅·정제) → 슬랙 → 헤르메스 에이전트 → 솔라피 MCP
변화기존 n8n 수동 노드 배치 → 자연어 지시 한 번으로 에이전트가 설계·구현

02핵심 내용 구조

기존에는 CRM(고객 알림톡) 작업을 n8n으로 노드마다 사람이 배치하고, API 인증 파라미터를 일일이 세팅하며, 조건 하나만 바뀌어도 전체를 다시 만들어야 했다. 이를 헤르메스 에이전트에게 솔라피 MCP 주소·템플릿 정보만 주고 "만들어 달라"고 말로 지시하는 방식으로 대체한다.

03기술적 맥락 — 데이터 흐름 구성

실습폼 제출 데이터를 n8n 웹훅(POST)으로 받아 Edit Fields로 이름·이메일·연락처·취미를 깔끔하게 정제한다. 정제된 리드를 슬랙 'CRM 에이전트' 채널로 '리드 발생' 메시지로 전송한다. 슬랙과 헤르메스를 연결해 채널에 메시지가 올라오면 멘션(@) 없이도 에이전트가 자동 호출되도록 게이트웨이를 설정한다.

04핵심 워크플로우 — 자연어 에이전트 설계

헤르메스 뉴챗에서 "솔라피 MCP로 1~5일차 알림을 순차 발송하는 CRM을 설계·구현해줘"라고 지시한다. 에이전트에게 필요한 맥락은 (1) 솔라피 MCP 문서 주소, (2) 솔라피 API 키·시크릿, (3) 카카오 브랜드 템플릿(Day1~Day5) ID와 연결 채널 정보다. 에이전트는 아키텍처·메시지 포맷·발송 후 피드백까지 스스로 설계하고, 확인이 필요한 항목(채널 ID 등)을 되물으며 구현을 완성한다.

05실행 결과 — 자동 예약 발송

실습폼 입력이 슬랙에 '리드 발생'으로 올라오면, 헤르메스가 리드 정보(전화번호 등)를 추출해 솔라피로 신청 다음날부터 5일간 매일 오전 10시 예약 발송을 자동 처리한다. 솔라피 대시보드에서 1~5일차 메시지가 정상 예약된 것을 확인할 수 있다(데모의 가상 번호 1234-5678은 없는 번호라 발송 실패로 처리).

06활용 시나리오

리드가 들어올 때마다 사람이 개입하지 않고 에이전트가 정보 추출·암호화·예약·백업 피드백까지 처리한다. 자는 동안에도 에이전트가 알아서 발송하고 결과를 슬랙에 알려주므로, 반복적 CRM 운영 인력을 대체할 수 있다.

07전망 및 함의

핵심 메시지는 "n8n처럼 노드를 수동으로 세팅하지 않고 에이전트 하나로 대체"한다는 것이다. 워크플로우 자동화 도구(n8n)를 '설계 대상'에서 'AI가 알아서 구성하는 대상'으로 올리는 흐름이며, MCP(솔라피)·슬랙·브랜드 템플릿을 조합하면 비개발자도 대화만으로 실무 CRM을 구축할 수 있음을 보여준다. 다음 편에서 다른 유형 에이전트를 예고했다.
