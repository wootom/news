다음은 'GPTers x 뽀짝이' 오픈채팅방에서 논의된 주요 화두들을 주제별로 요약한 내용입니다.

01AI 모델 사용량 및 비용 관련 질문

  • Claude Max 20x 플랜에서 사용량을 추가 구매하여 Fable을 더 사용할 수 있는지에 대한 질문이 있었습니다.
  • 이에 대해 API 요금제로 사용하는 것과 같아 사용량이 매우 빠르게 소모될 수 있으므로 권장하지 않는다는 답변이 있었습니다.
  • 빅테크 기업들이 AI 투자 재원 마련을 위해 인력을 감축하는 '흑자형 구조조정'이 고착화되고 있다는 뉴스가 공유되었습니다. 이는 인건비를 아껴 AI 토큰값과 GPU값을 벌기 위함이라는 분석이 이어졌습니다.
  • GPU 가격과 관련하여 "가격이 개깡패네요", "Input $2 / Output $6" 등의 언급이 있었습니다.

02에이전트 관리 도구 및 기술 관련 논의

  • 여러 PC의 Hermes(Claude, Codex) 대화 이력 및 활성 상태 등을 관리하는 데 어떤 도구를 사용하는지에 대한 질문이 있었습니다. 'mission-control'이라는 오픈소스가 언급되었습니다.
  • 자연어 명령으로도 상당 부분 관리가 가능하며, 토큰을 아끼기 위해 코드로 만들어 사용하기도 한다는 경험 공유가 있었습니다.
  • GUI 부재로 인한 관리의 어려움이 언급되었습니다.
  • 에이전트 관리 도구로 'Orca'가 추천되었으며 "개지립니다 진짜"라는 긍정적인 평가가 있었습니다.
  • 모바일 앱으로도 개발이 가능하다고 언급되었습니다.
  • Orca GitHub 링크: https://github.com/stablyai/orca
  • orca에 대해 "wnux 고도화 버전 같은 느낌", "물건인거 같은 느낌이 스물스물 드네요" 와 같은 호평이 있었습니다.

03AI 모델 성능 및 특징 비교 (Groq, Gemini, Claude 등)

  • GroqBuild를 사용해본 경험을 공유하며 GPT, Claude보다 완전히 똑똑하다고는 할 수 없지만 "커서가 만나서 덜 멍청해졌다", "빠르다"와 같은 평가가 있었습니다.
  • Gemini가 빠르다는 점이 언급되었으나, 사용정지 위험이 있어서 "제미니는 저를 밴할뻔했으므로 저는 제미니를 밴합니다", "-p(프롬프트)로 될까요?", "-p 막아둬서 힘들 거에요" 와 같은 의견이 있었습니다.
  • 계정 블록만 없으면 좋겠다는 아쉬움을 표현했으며, 무료로 검색엔진이나 이메일 번역기로 사용된다는 언급도 있었습니다.
  • Claude Opus 4.8에서 오류가 증가하고 있다는 안내가 공유되었습니다.
  • Claude Status 페이지 링크: https://status.claude.com/incidents/t5kjpnysf4vp
  • GPT-5.6 출시 여부에 대한 질문과 함께 관련된 이미지(합성)가 공유되었습니다.
  • "합성입니다", "이제는 이미지로 믿을만한 시대가 아니네요"와 같이 AI로 생성된 이미지 정보의 신뢰도에 대한 논의가 있었습니다.
  • 5.5와 5.6의 차이에 대한 질문이 있었고, 영상 제작 품질에서 Fable과 Codex의 차이를 언급하며 Fable의 영상 퀄리티가 더 좋다는 의견이 있었습니다.
  • Fable이 ffmpeg와 Swift 조합으로 영상을 만들어주며, Codex는 그렇게 해주지 못했다고 언급했습니다.

04로컬 AI 모델 실행 경험 공유 (GLM-5.2 on Mac Studio)

  • Mac Studio M3 Ultra(512GB 통합 메모리)에서 GLM-5.2 모델(368GB)을 완전 로컬/오프라인으로 실행한 성공 사례와 상세한 과정, 장단점이 공유되었습니다.
  • 장점: 데이터 외부 유출 없음, 클라우드 API 비용 없음, 토큰당 과금 없음.
  • 난관: 368GB 모델 크기, macOS GPU 메모리 한계(전체 RAM의 75%인 약 384GB), LM Studio 로드 실패(아키텍처 지원 문제), 아직 병합되지 않은 mlx-lm의 특정 PR 버전 사용.
  • 메모리 및 컨텍스트 문제: KV 캐시 증가로 인한 GPU 메모리 부족, 긴 컨텍스트(약 74,500토큰) 세션 시 서버 크래시 발생(재시작 시 prefill에 약 9분 소요).
  • 해결책: macOS GPU 메모리 한도 조정, HTTP 타임아웃 회피.
  • 성능 체감: 12 tokens/s 수준으로 실시간 채팅에는 답답하지만 배치/코딩 작업에는 사용 가능. 코딩 품질은 Fable 5보다 실망스러웠다는 평가.
  • 결론: 초대형 AI 모델의 개인 장비 로컬 실행이 기술적으로는 가능하나, 아직은 매우 까다롭고 실험적인 영역.
  • 관련 블로그 글: https://blog.workingmodels.ai/p/glm-5-2-local-mac-studio
