02

핵심 워크플로우 구조 (5단계)

STEP 1 · 플랜 선택
Hostinger 가입 → KVM 2 플랜 + 12개월 · 무료 도메인 1년 · 쿠폰 "Astro"로 10% 할인.
STEP 2 · 원클릭 템플릿
애플리케이션 선택 화면에서 "Claude Code" 체크 → 결제 시점에 사전 설치 완료.
STEP 3 · 터미널 접속
hPanel의 Terminal 버튼(웹 터미널) 또는 SSH로 접속. claude --version → 2.1.143 확인.
STEP 4 · 헤드리스 인증
터미널이 보여주는 인증 URL을 로컬 브라우저에 붙여넣기 → Authorize → 발급된 코드를 다시 터미널에 붙여 넣어 페어링.
STEP 5 · 실행 & 모델 전환
claude 실행 → /model 명령으로 Sonnet 4.6 ↔ Opus 4.7 전환 → 프롬프트 입력.
데모 1: [05:00] 터미널 날씨 대시보드 (386 라인 bash) · 데모 2: [07:36] 포트폴리오 페이지 HTTPS 공개 URL 자동 발급
03

기술적 맥락

구성요소설명
VPS (Virtual Private Server)클라우드 위 24/7 가상 머신, 사용자당 독립 OS 환경
KVM 가상화리눅스 표준 하드웨어 가상화. KVM 1/2/4/8은 vCPU·RAM 등급
원클릭 템플릿VPS 생성 시 Claude Code가 사전 설치된 이미지
Claude CodeAnthropic의 터미널 기반 AI 코딩 에이전트, 파일 생성·명령 실행 직접 수행
Sonnet 4.6 / Opus 4.7Claude 모델 등급, /model로 전환 (Opus가 상위)
Termux안드로이드 리눅스 터미널 — 폰에서 VPS SSH 접속용
root 실행 주의영상은 시연 편의로 root 사용 — 운영 시 user + sudo 권장
04

전략적 의미

로컬 의존 탈피
노트북 전원·네트워크에 더 이상 묶이지 않음. 비행 중에도 폰만으로 코드 작업.
백그라운드 작업의 일상화
긴 빌드·테스트·스크래핑·크론잡을 VPS의 Claude 세션이 대신 끌고 간다.
입력기 vs 컴퓨팅 분리
폰/태블릿(입력기) + VPS(연산) — 모바일 우선 개발 워크플로우의 시작점.
에이전트 호스팅 카테고리
클라우드 IDE가 아닌 "AI 에이전트 자체를 호스팅"하는 새로운 인프라 영역.
비용 구조 단순화
월정액 VPS + Claude 구독 두 가지로 끝. AWS 종량제 학습곡선 불필요.
리스크
AI가 임의로 외부 공개 URL을 발급하는 행위는 보안·비용 폭발 위험. 영상 발표자도 경고.

항목로컬 노트북VPS + Claude Code클라우드 IDE

AI 에이전트 호스팅OFF 시 중단핵심 강점대화 단위만 제한적
외부 포트 노출NAT 우회 필요즉시 가능 (공인 IP)자동 터널
진입 장벽낮음중간 (SSH·sudo)낮음
06

활용 시나리오

A · 출장 중 폰으로 핫픽스
공항에서 GitHub 이슈 발견 → Termux로 VPS SSH → "이 리포 클론해서 X 버그 고치고 PR 올려" 한 줄로 처리.
B · 24시간 데이터 수집 봇
VPS에 Claude Code 상주 + 크론으로 매일 새벽 3시 뉴스 크롤링·요약·텔레그램 알림. 노트북 OFF 무관.
C · 프로토타입 즉시 공유
"포트폴리오 만들고 인터넷에 공개해줘" → HTTPS URL 자동 발급 → 클라이언트 공유. ngrok 셋업 불필요(단, 보안 검토 필수).
D · 팀 공용 AI 게이트웨이
팀 VPS에 Claude Code + 표준 도구·MCP 사전 구성 → 모든 팀원이 동일 컨텍스트로 작업.
07

현황 및 전망

  • 현황 Hostinger가 Claude Code 원클릭 템플릿 공식 제공 — VPS 업체들이 AI 에이전트 호스팅을 마케팅 포인트로 채택.
  • 확산 신호 Peter Levels(@levelsio) 등 인플루언서가 "노트북 없는 코딩" 워크플로우를 X에서 시연 → 모방 확산.
  • 전망 1 에이전트 친화 OS 이미지가 별도 카테고리로 성장 가능.
  • 전망 2 폰 + VPS 조합이 코딩 신규 진입자의 표준 환경이 될 가능성 (특히 신흥국).
  • 전망 3 AI의 자율 포트 개방·공개 URL 발급에 대응한 권한 가드레일·감사 로그가 필수 인프라화.
  • 주의 root 실행, 자동 공개 URL 발급 같은 시연 패턴을 운영에 그대로 옮기면 위험.
