02Fable 5 핵심 특성

  • Mythos급 모델: 사이버보안·생물학·화학 niche 영역 고성능 — 양날의 검(악용 위험)
  • Mythos 비공개 사유: 무검열 접근은 'glassing 프로젝트' 파트너 기업만, 일반 악용 차단
  • 안전 폴백: 보안·생물·화학 민감 질문 시 Fable 5 미응답 → Opus 4.8로 폴백 응답 (신규 메커니즘)
  • 과거 사례: Mythos 모델이 20년간 숨겨진 코드베이스 보안 취약점 발견 — 위험성 방증

03성능 — 벤치마크 / 비용

  • 벤치마크 우위: SWE-bench Pro, Frontier Code, Terminal Bench 2.1, HealthBench Professional 등에서 Opus 4.8·GPT 5.5·Gemini 3.1 Pro 상회 (Fable 5 preview·Mythos 5)
  • Cursor 벤치 1위: 현재 차트 톱
  • 가격 구조: Fable 5 입력 $10/출력 $50, Mythos 5 입력 $20/출력 $100 (100만 토큰당)
  • 사용 비용: Opus 대비 사용량 2배 빠르게 소진, 단일 시뮬레이션에 $30+ / 누적 $300~400 지출

04실사용 데모 — 단일 프롬프트 생성물

  • 3D 거실 시뮬레이션: Three.js 기반 단일 HTML, 실시간 이동·충돌·조명/그림자/반사(선풍기·에어컨·TV·사운드바) 구현
  • 애니메이션 랜딩페이지: 3D 회사용, 로딩·패럴랙스 줌·입자 산란·끈적이는 호버·스무스 스크롤·WebGL 제품 시각화 — "AI 티 안 남" 수준
  • ENSO 기후 시뮬레이션: 엘니뇨/라니냐 결합 해양-대기 모델, 물리 정확성 요구. Fable 5 단독 실패 → cursor에서 27분 연산으로 완성, CFL 조건 위반 시 물리 검증 에러 표시

05핵심 워크플로우 — 강점과 한계

  • 단일 패스 강점: Opus 4.8이 다중 인간개입으로도 어려운 문제를 Fable 5는 단일 패스로 해결
  • 롱러닝·에이전틱 우수: 장시간 작업(예: 시뮬레이션 27분, 대부분 thinking)에서 진가
  • 결정적 한계: 극도로 느림(Opus 4.8 대비), 인기 급증·과부하 가능성
  • 비용 부담: 재미 프로젝트엔 부적합, 실무·SaaS·내부도구 개발에 적합

06활용 시나리오

  • 복잡 시뮬레이션·물리 모델: 정확성 검증 내장된 인터랙티브 생성
  • 프로덕션급 프런트엔드: 고품질 3D·애니메이션 랜딩페이지 단일 프롬프트 생성
  • SaaS·내부 도구 개발: 발표자 실사용 — 장기 에이전틱 작업 위주
  • 보안·생화학 민감 작업: 폴백으로 차단, 일반 사용자 접근 불가

07현황 및 전망

  • 안전-역량 긴장: "속도 줄이자"는 공개 메시지와 최강 모델 출시의 모순, 안전장치(폴백)로 절충
  • 위치: 코딩·에이전틱 영역 최상위, cursor 등 도구 생태계 즉시 통합
  • 트레이드오프: 역량 최고 ↔ 속도·비용 최악, 용도에 따라 Opus 4.8과 선택
  • 발표자 계획: Fable 5 활용 후속 영상 예고
