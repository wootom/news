편집을 손이 아니라 말로 시킨다 — 클로드 코드 + 리모션 자동 편집 (메이커 에반)

영상 편집 프로그램을 한 번도 켜지 않고 컷·자막·모션 그래픽까지 '말로' 만드는 워크플로우를 공개한 영상. 핵심은 리모션(코드로 영상을 만드는 도구)에 클로드 코드로 지시하고, Whisper로 단어별 타이밍 자막을 자동 생성하는 것. 편집 시간을 4~6시간에서 20분 안팎으로 줄였고, 디자인·모션 원칙과 '편집 매뉴얼' 표준화로 채널 일관성까지 확보한다.

01핵심 개요

항목내용
도구리모션(코드 기반 영상) + 클로드 코드 + Whisper
개념영상을 '설계도(코드)'로 지어 수정·재사용 용이
자막Whisper 단어별 타이밍 → 싱크·카라오케 자동
디자인 원칙레퍼런스 제시·색 3개 제한·진짜 로고 사용
성과편집 4~6시간 → 20분 안팎, 대부분 검수 시간

02핵심 내용 구조 — 영상을 코드로 만든다

편집의 대부분은 반복 작업(같은 폰트·인트로·전환)이라는 문제의식에서 출발한다. 리모션은 웹 제작 기술로 영상을 만드는 도구로, "자막을 화면 아래 120px 위, 3.2초에 등장해 5초에 소멸"처럼 글로 적으면 그대로 렌더된다. 설계도(글)이므로 숫자 하나만 바꾸면 자막 100개가 한 번에 수정되고, 글은 AI가 잘 쓰므로 클로드에 말로 지시해 코드 한 줄 없이 제작한다.

03기술적 맥락 — Whisper 단어별 타이밍 자막

Whisper는 음성을 글자로 옮기면서 각 단어의 시작·종료 초를 기록한다. 이 기록을 설계도에 붙이면 10분 영상 자막이 몇 분 만에 싱크되고, 단어별 시간이 있으니 색이 순차로 바뀌는 카라오케 자막도 자동으로 구현된다. 발음이 뭉개진 몇 단어만 수정하면 되며, 수백 개 타이밍을 손으로 맞추던 작업과 차원이 다르다.

04핵심 워크플로우 — 디자인·모션 원칙

디자인은 "이쁘게"라는 모호한 지시 대신 ①해외 영상 캡처 레퍼런스 제시 ②색 3개로 제한(배경 흰·글자 회·강조 보라) ③가짜 아이콘 대신 진짜 로고 사용이 핵심이다. 모션은 ①등장은 스프링·퇴장은 페이드 ②한 화면에 움직이는 요소는 하나 ③장면 전환은 부드럽게(디졸브)라는 3원칙으로 촌스러움을 막는다.

05활용 시나리오

디자인·모션·자막 규칙을 문서 하나('편집 매뉴얼')로 표준화하면 AI가 늘 같은 스타일로 찍어내 채널 일관성이 유지된다. 긴 영상 재료로 "하이라이트 쇼츠 뽑아줘" 한 마디면 쇼츠도 자동 생성돼, 세팅 후 반복 재사용이 가능하다.

06현황 및 전망

발표자는 이 워크플로우를 석 달간의 시행착오로 매뉴얼화했고 지금도 개선 중이라고 밝힌다. 처음부터 완벽을 노리기보다 '자막 자동화' 하나부터 도입하라는 조언으로, 실제 제작 시간의 대부분이 손작업이 아닌 검수로 이동한 점이 핵심 변화다.

07용어 사전

용어한줄 설명비유/예시
리모션(Remotion)코드로 영상을 만드는 도구웹페이지 짓듯 영상을 설계도로 지음
클로드 코드자연어 지시로 코드·작업을 수행하는 AI말로 시키면 설계도를 대신 써줌
Whisper음성을 단어별 타이밍까지 받아쓰는 AI초 단위 기록까지 하는 속기사
카라오케 자막말하는 단어마다 색이 바뀌는 자막노래방 가사처럼 색이 따라감
스프링/페이드튕기며 등장/서서히 사라지는 모션용수철처럼 등장, 조용히 퇴장
