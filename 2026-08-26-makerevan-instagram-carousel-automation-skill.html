02핵심 기능/내용 구조

  1. 스킬은 프로그램이 아니라 매뉴얼: 스킬은 설치되는 앱이 아니라 AI에게 주는 업무 매뉴얼(인수인계 문서) 묶음으로, 카드 규격·글자 크기·로고 위치·사진 선정 기준이 문서로 고정되어 매번 같은 결과가 나온다 (01:48).
  2. 계정 스타일 선학습: 카드 제작 전 인스타 계정 주소를 받아 소개글과 최근 게시물 12장을 훑어 로고 문구·계정 아이디·주제를 추출하며, 이 정보는 최초 1회만 확인하고 이후 재사용한다 (03:02).
  3. 8장 뼈대 설계: 표지(시선)→본문 6장(근거)→마지막 장(행동 요청)의 광고 전단지형 구조를 고정 적용해 계정 피드 전체의 통일감을 만든다 (03:24).
  4. AI 생성 이미지 회피, 실제 화면 채택: 한글 깨짐 문제 때문에 AI 이미지 대신 소개 대상의 공식 홈페이지 영상·화면을 그대로 가져오며, 움직이는 영상 카드를 세트당 4~7장 기본 배치한다 (04:14).
  5. 소재 부족 시 주제 폐기 규칙: 공식 영상이 4개 미만이면 해당 주제를 자동으로 버리고 다른 주제로 전환하며, 일반 주제는 저작권이 풀린 공개 이미지 저장소(박물관 소장품 등)에서 수급한다 (04:42).
  6. 브라우저 자동 업로드, 확인은 사람: 파일 8장을 순서대로 넣고 비율을 4:5로 맞추며 캡션을 문단별로 나눠 붙여 줄바꿈을 보존하지만, 공유 버튼 직전에서 멈춰 사람의 최종 확인을 거치도록 설계했다 (06:47, 07:09).

03기술적 맥락

이 도구는 생성형 이미지(예: 이미지 생성 AI) 대신 실제 존재하는 화면 캡처·공식 영상을 소재로 쓰는 점이 핵심 기술적 선택이다. AI 이미지 생성 시 한글 텍스트가 깨지는 고질적 문제를 우회하기 위한 결정이며, 이미지 출처는 로컬 컴퓨터에 기록만 남기고 게시물에는 노출하지 않는다. 업로드 단계는 사람이 인스타를 조작하듯 브라우저를 직접 제어하는 방식(RPA형 자동화)으로 구현되어, API 연동이 아닌 화면 조작을 모사한다.

04전략적 의미

카드뉴스 제작의 5단계(주제 선정·사진 탐색·레이아웃 정렬·캡션 작성·업로드) 중 창의적 판단이 필요한 것은 주제 선정 1단계뿐이며, 나머지 4단계는 반복노동이라는 진단이 이 도구의 존재 이유다. 외주는 건별 비용이, 직원 고용은 고정 인건비가 발생하는 두 선택지 사이에서, "반복 구간만 기계에 위임"하는 제3의 대안을 제시한다. 매주 여러 세트를 지속 발행해야 하는 계정에는 외주 단가 대비 비교 우위가 있을 수 있으나, 월 2~3세트 수준의 저빈도 운영자에게는 실익이 낮다는 점도 영상에서 명시한다.

05핵심 워크플로우 또는 비교표

단계사람이 하는 일(기존 방식)도구 적용 후
1. 주제 선정5분, 창의적 판단동일하게 사람이 담당
2. 사진 탐색무료 이미지 사이트 순회, 1시간+공식 영상/공개 이미지 자동 수집, 소재 부족 시 주제 자동 폐기
3. 레이아웃 정렬캔바 등에서 8장 수동 정렬고정 매뉴얼 기준으로 8장 일괄 렌더링(1080×1350)
4. 캡션 작성길이 조정 반복자동 생성(카피 재작성 여부는 사람 판단)
5. 업로드순서·비율·줄바꿈 수동 처리브라우저 자동 조작, 공유 직전 사람 최종 확인

06활용 시나리오

  1. 주 2~3회 발행하는 브랜드 계정: 매번 동일한 톤앤매너(검은 띠+굵은 제목+로고 위치)를 유지해야 하는 계정이 반복 작업 부담 없이 발행 주기를 지킬 수 있다.
  2. 해외 AI/서비스 소개 계정: 공식 소개 영상 자료가 풍부한 해외 도구·서비스 주제는 소재 확보가 쉬워 이 도구와 궁합이 좋다.
  3. 1인 운영자의 외주 대체: 건당 외주비가 부담되는 소규모 계정 운영자가 초기 투자(29만 9천 원)로 반복 제작 비용을 대체하는 시나리오.
  4. 다인 협업 계정의 톤 일관성 확보: 여러 사람이 번갈아 카드를 만들면 스타일이 어긋나기 쉬운데, 매뉴얼화된 스킬로 협업자 간 결과물 편차를 줄일 수 있다.

07현황 및 전망

  • 이 도구로 만든 카드는 현재도 실제 계정에 지속 게시 중이며, 다음 영상에서 실제 조회수·반응 데이터를 공개할 예정이라고 예고했다.
  • 국내의 좁은 지역 소식이나 속보성 주제는 공식 영상 소재가 부족해 이 도구로는 잘 나오지 않는 한계가 명확하다.
  • AI 이미지 생성의 한글 깨짐 문제가 해결되지 않는 한, 실제 화면 캡처 기반 접근이 당분간 대안으로 유지될 가능성이 크다.
  • 첫 사용 시 계정 확인(온보딩) 절차가 필수라 완전 무인화는 아니며, 사람의 개입 지점(주제 선정, 최종 업로드 확인)이 설계상 의도적으로 남아 있다.
