외주 개발이 사라진다 — 똑똑한개발자의 AI 네이티브 전환과 '똑빌더'

빌더 조쉬 × 똑똑한개발자 서장원 대표 · 2026-06-12 · 10년차 IT 에이전시(30명)가 AI 네이티브 선언 후 직무 통합·내부 시스템 '똑빌더' 구축. "에이전시업 자체가 사라질 것"이라는 단언과 AX 실천 방법론.

목차핵심 개요AI 네이티브 전환 — 조직 변화똑빌더 — 워크플로우 구조기획·개발 자동화 — 휴먼 인 더 루프만족도 트래킹 — 커뮤니케이션 자산화활용 시나리오 / 교훈현황 및 전망용어 사전

01핵심 개요

항목내용
출연서장원 (똑똑한개발자 대표, 10년차 IT 에이전시·약 30명)
사업 구조B2B 외주(캐시카우) + B2B SaaS '플러그'(CRM, 월 BEP 돌파)
핵심 선언AI 네이티브 전환 → 직무 통합, 장기적 '에이전시업 소멸' 전망
핵심 산출내부 시스템 '똑빌더' — 프로젝트 전과정 AI 프렌들리 워크 대시보드
도구 전환2026년 2월 Opus 모델 이후 전사 클로드 전환, 헤르메스 에이전트

02AI 네이티브 전환 — 조직 변화

  • 직무 통합: 기획·디자인·프런트·백엔드 분리 → 'AI 빌더(프로덕트 빌더)'로 통합
  • 고객사별 유연 대응: 진보 기업은 피그마 없이 산출물 위임, 보수 기업은 피그마·엑셀 API 명세 요구
  • 전환 부작용: 급격하게 느낀 일부 팀원, 팀 전체 퇴사 사례 발생 (민감한 영역)
  • PM 팀 소멸 → 에이전트 대체: 슬랙에 에이전트 투입, 회의 내용 수집·투두 작성. 단 100% 대체 불가, 사람 검수 병존
  • 직무 경계 소멸: 마케터도 AI 학습해 강의자료·브랜딩 확장 참여, DRI(Direct Responsible Individual) 지향

03똑빌더 — 워크플로우 구조

  • 목적: 판매용 아닌 내부용, 프로젝트 전과정(투입검토→기획→디자인→개발→인수인계→자산화) AI 화
  • 인력 배정: 플러그 CRM 영업 히스토리 → '계약 인박(구두계약 단계)' 전환 시 슬랙 자동 알림 → AI가 과거 프로젝트 데이터 기반 적임자 추천
  • 채널 자동 생성: 내부·외부 슬랙 채널 동시 생성, 실무자·재무·리드 자동 초대 (기존 PM 역할 디지털화)
  • 데이터 수집: 클라이언트·팀 데일리 대화 로우데이터 → DB 적재 → 헤르메스 에이전트가 DB 조회(쿼리 조건값 스킬화)
  • 안정성 설계: 확률적 동작 최소화 위해 에이전트보다 API·웹훅 기반 연동 우선

04기획·개발 자동화 — 휴먼 인 더 루프

  • 자료 수집: 이메일·마크다운·RFP·기획서 데이터 전량 수집
  • PRD 생성: 수집 자료 기반 초안 → AI가 미결사항 질문 추출 → 사람 확인(휴먼 인 더 루프)
  • 화면 구조: IA·페이지·권한별 구성 자동 생성, 디자인 시스템 기반 MD 파일 산출 (바이브 코딩)
  • 빌드 자동: Supabase·Git·Vercel 자동 연동, AI 태스크 / 휴먼 태스크(토큰 발급 등) 자동 분류
  • 클로드 코드 연계: 웹 빌드 명령 복사 → 로컬 설치 → 기획·디자인 자료 탑재 상태로 투두 생성, 스킬로 태스크 반영
  • 규모 기준: 약 30페이지 프로젝트 빌드까지 무개발 환경 세팅, 이후 사람이 퀄리티 향상

05만족도 트래킹 — 커뮤니케이션 자산화

  • 핵심 통찰: 기능 완성도는 디폴트, 진짜 중요한 건 커뮤니케이션
  • 감정 상태 추적: "화가 난 클라이언트 있나" 등 커뮤니케이션 내역 기반 LLM 만족도 점수화
  • 이슈 감지: 실무자도 놓치거나 인지 못하는 불만 지점 자동 감지·알림
  • 자산화: 프로젝트별 데이터·실무자 이력(연차·경력) 기록, 추가 계약 시 맥락 전달. RAG·벡터DB 미사용, MD 기반 운영

06활용 시나리오 / 교훈

  • 스킬 공유 실패 교훈: 웹 대시보드로 스킬 공유 시도했으나 미사용 — 클로드 코드 터미널이 더 편하면 우회 안 함. "유저가 원하지 않는 기능은 안 쓴다"는 프로덕트 원칙 적용
  • AX 조언 ①: 팀원 AI 활용 수준 먼저 파악 (GPT 채팅 수준 vs 클로드 코드), 수준 맞춰 도입 시도
  • AX 조언 ②: 잘 쓰는 개개인 조기 발굴, 전문성 소멸 우려 케어
  • AX 조언 ③: DX 선행 필수 — 데이터가 개인기로 흩어지면 AX 불가, 회의록 무조건 녹음(Carrot)·프로젝트별 API 수집
  • 핵심 메시지: AI 도입 = 기술 도입 아닌 환경 변화, 조직 리듬 전체 전환 필요

07현황 및 전망

  • 에이전시업 소멸 전망: AI 네이티브 가속 이유 = "우리가 그 업을 없애기 위함", 남는 자산 = IT 전문성 가진 실무자의 산업 해체·생산성 극대화 경험을 타 조직 적용
  • 똑빌더 방향: 1차 PM 역할 자동화 → 실무자(빌더)가 빌딩 집중 환경 제공, 디자이너 출신 빌더의 기술 공백 보완
  • 대상 규모: 예비 창업자 첫 프로덕트 수준, 프리랜서 협업 구조
  • 데이터 철학: 데이터 多 ≠ 좋음, 핵심 지표만 사람 검수 후 적재, 최종 의사결정은 사람
