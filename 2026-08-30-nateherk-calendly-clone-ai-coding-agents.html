I Cloned Calendly and Now It's Free Forever

AI 코딩 에이전트만으로 1주일 만에 Calendly 핵심 기능을 복제한 'Snag Time'을 무료 공개하며, 실제 구축·운영 비용과 과정을 보여준다.

01무엇을 만들었나

  • 'Snag Time'이라는 셀프호스팅 예약(스케줄링) 앱 — Calendly(기업가치 약 30억달러), cal.com(약 1.5억달러, 수천만달러 투자유치)과 핵심 기능이 동등.
  • 워크스페이스 대시보드, 예약 현황, 이벤트 타입별 링크, 브랜딩·팀원 초대·권한 관리, 스트라이프 연동 유료 예약까지 구현.

02실제 동작 — 예약 흐름

  • 예약 링크에서 날짜·시간 선택 시 실제 구글 캘린더와 실시간 동기화 — 캘린더에 새 일정을 넣으면 예약 페이지에도 즉시 반영됨을 시연.
  • 예약 확정 시 예약자에게 확인 메일과 캘린더 초대가 발송되고, 호스트 쪽 캘린더에도 자동 등록.
  • 유료 이벤트는 스트라이프 결제 페이지로 연결 — 샌드박스 카드로 결제 테스트, 실제 API 키로 교체하면 바로 실사용 가능.

03에이전트가 놓친 것 — 사람의 손길

  • AI 에이전트들이 반복 테스트로 버그는 잘 잡았지만, "리뷰 단계에서 진행바를 클릭하면 이전 단계로 돌아갈 것"이라는 사용자의 직관적 기대는 놓쳤다(원래는 화살표만 클릭 가능하게 설계됨).
  • 명시적으로 UX를 고려하라고 프롬프트했음에도 이런 지점을 놓쳐, 결국 사람이 직접 재설계에 개입해야 했다는 점을 강조.

04비용과 접근 방법

  • 로컬(localhost)에서 전부 구현 완료, 실제 배포하려면 Vercel 등에 올리고 구글 계정·백엔드 DB·스트라이프 계정만 연결하면 끝.
  • 무료 스쿨 커뮤니티(설명란 링크)에서 전체 셋업 가이드를 받아 하루 만에 설정 가능. 자동화 기능 등 Calendly의 일부 부가기능은 아직 없지만, 코덱스·클로드 코드가 이 앱 구조를 이미 파악하고 있어 추가 기능 구현이 쉽다고 설명.
