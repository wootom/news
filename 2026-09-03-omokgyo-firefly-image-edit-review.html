어도비 파이어플라이 이미지 편집으로 촬영 불가능한 배경까지 만든 실전 후기

오목교 전자상가가 그린 스크린 촬영에 파이어플라이 이미지 편집 기능을 적용해 지하철·사무실 뷰·가상 박물관 배경을 직접 제작한 과정

01핵심 개요

  • 월요일 아침 지하철 맞은편 승객 시점은 실촬영이 불가능해 그린 스크린 촬영 후 파이어플라이로 배경만 생성·합성
  • 마크업 도구의 텍스트·브러시·박스 3가지 방식으로 광고판 제거, 빈 좌석 생성, 창문 밖 도시 풍경 교체를 각각 수행
  • 디테일 조절 기능으로 "골든 아워" 프롬프트 적용 후 슬라이더로 분위기 강도를 0.4 등 수치로 직접 선택 가능
  • 회사 19층 창밖 뷰가 앞 건물 신축으로 곧 사라질 것을 우려해 선택 영역 제거·경도 조절·21:9 배경 확장·업스케일까지 적용해 스튜디오 배경으로 박제
  • 프롬프트 이미지 생성으로 "오목 기술사 박물관"이라는 가상 공간을 만들고 3종 이미지(참조 이미지) 기능으로 전시물의 일관성을 유지

02핵심 주장 / 논점 구조

  • 영상 생성 AI로 배경째 만드는 방식은 주인공(피사체)의 정확한 행동·표정을 그대로 유지하기 어려워, 배경만 따로 만들어 합성하는 그린 스크린 방식이 여전히 실무적으로 우월하다
  • "이미지를 만드는 것"보다 "뽑힌 이미지를 의도대로 정교하게 고치는 것"이 실제 영상 활용 여부를 가른다는 게 영상의 중심 주장
  • 파이어플라이는 이미지·비디오·오디오를 한 공간에서 만드는 올인원 크리에이티브 AI 스튜디오이며, 이번 영상은 그중 이미지 편집 메뉴에 집중
  • 어도비 파이어플라이 모델은 상업적으로 안전한 데이터로 학습되어 자유롭게 상업적 용도로 사용 가능하다는 점을 실무자 관점에서 강조

03지하철 배경 제작 워크플로우

  • 참조 이미지에 지하철 스케치를 그려 넣고 "지하철 실내 좌석에 앉은 사람들이 전부 고개를 숙이고 휴대폰을 보고 있음. 앵글은 정면 유지, 실사 이미지처럼" 프롬프트로 1차 생성
  • 1차 결과물의 문제 3가지: 좌석이 꽉 차 주인공 앉힐 자리 없음, 위쪽 광고판이 어색함, 지하철 톤이 스튜디오와 불일치
  • 텍스트 도구로 광고판 위에 "광고판을 아예 지울 것"이라 적어 바로 제거, 브러시 도구로 크기를 줄여 좌석 한 칸만 정밀 선택 후 "빈 좌석으로" 적용해 옆자리 승객은 그대로 유지
  • 박스로 창문 영역만 잡고 "아침에 도시 풍경"을 입력해 창밖 배경 교체, 이후 비디오 생성 단계에서 "지하철 안 풍경 창문 뒤쪽으로 도시 풍경이 지나감, 카메라 무빙 없이" 프롬프트로 영상화까지 확인

04색상판·디테일 조절: 정밀 제어의 차별점

  • 좌석 색상을 바꿀 때 텍스트 도구로 색상명(예: 옐로우)을 적으면 화면에 색상판이 떠서 정확한 색상값을 직접 선택 가능 — 말로 "조금 더 차분한 노랑"을 반복 설명하는 비효율을 제거
  • 디테일 조절 기능은 분위기(퇴근길 특유의 노곤한 느낌 등)를 브러시로 지정한 영역에만 적용하며, "골든 아워" 같은 짧은 프롬프트 입력 후 강도별 베리에이션을 미리보기로 제공
  • 슬라이더를 좌우로 밀며 수정 강도가 약하게 들어간 버전부터 강하게 들어간 버전까지 눈으로 비교해 원하는 지점을 직접 선택 — "적당히 해달라"는 말 대신 수치로 통제

05사무실 실사 배경 리터치 파이프라인

  • 회사 19층에서 보이는 실제 뷰를 촬영했으나 유리에 사무실 형광등이 비쳐 그대로 사용 불가
  • 선택 영역 제거 기능은 단순히 지우는 게 아니라 브러시로 칠한 부분을 주변 배경 정보를 읽어 자연스럽게 메꾸며, 브러시의 경도(edge hardness)까지 조절 가능 — 유리 반사처럼 경계가 흐린 대상은 경도를 낮춰 블렌딩, 형체가 명확한 대상은 경도를 높여 딱 떨어지게 처리
  • 정면·측면 2대의 카메라 촬영을 고려해 21:9 와이드 비율로 배경 확장 기능을 적용, 프롬프트 입력 없이 확장 버튼만 눌러도 원본 분위기를 읽어 자연스럽게 이어 그림
  • 향후 몇 년간 방송에 반복 사용할 배경이므로 업스케일 도구로 모델과 배율(2배/4배)을 선택해 고해상도화 — 업스케일 후 멀리 있는 아파트 창문까지 디테일이 살아남을 확인

06가상 배경 생성: 오목 기술사 박물관 사례

  • 오래된 기술 역사를 다루는 채널 코너를 위해 실존하지 않는 "오목 기술사 박물관"을 프롬프트 이미지 생성으로 제작
  • 파이어플라이 자체 모델 외에 구글 제미나이, 클링, 플럭스 등 파트너 모델도 같은 화면에서 선택 가능하며 모델별 강점이 다르므로 용도에 맞게 선택 권장
  • 일상 언어 프롬프트("밝은 박물관 전시실 정면 벽 좌측 위에 가상의 옛날 기계들") 입력 후에도 결과 이미지 위에서 "왼쪽 좌대의 유물을 다이얼이 큰 기계로", "바닥을 밝은 원목으로" 등 부분 수정을 반복 적용해 통이미지 재생성 시 발생하는 복불복 문제를 회피
  • 3종 이미지(참조 이미지 고정) 기능으로 박물관을 여러 각도·장면에서 재생성해도 동일한 유물 형태를 유지시켜 배경 시리즈의 일관성 확보

07전략적 의미

  • 영상 제작 워크플로우에서 "생성"과 "편집"의 역할이 분리되고 있으며, 실무 채택의 관건은 생성 품질이 아니라 뽑힌 결과물을 얼마나 정밀하게 국소 수정할 수 있는가로 이동
  • 텍스트·브러시·박스 3방식의 마크업, 색상판 직접 선택, 디테일 조절 슬라이더 등은 모두 "말로 설명"에서 "수치·좌표로 직접 지정"으로 제어 방식을 전환하는 흐름을 보여줌
  • 상업적으로 안전한 학습 데이터 기반이라는 점은 방송·유튜브처럼 저작권 리스크에 민감한 콘텐츠 제작자에게 실질적 채택 장벽을 낮추는 요인

08활용 시나리오

  • 촬영이 물리적·현실적으로 불가능한 장면(출근길 지하철 맞은편 시점 등)을 그린 스크린과 AI 배경 생성으로 대체
  • 사라질 위기의 실제 촬영 장소(재건축 예정 뷰 등)를 미리 촬영해 업스케일·배경 확장으로 영구 보존하고 반복 사용
  • 채널 특성에 맞는 가상 세트(박물관, 스튜디오 등)를 만들어 매번 같은 흰 벽 배경에서 탈피, 참조 이미지 기능으로 시리즈 전반의 시각적 일관성 유지
  • 색상판·강도 슬라이더 기반 정밀 조정이 필요한 브랜드 컬러 매칭, 미세한 분위기 톤 조정 작업

09현황 및 전망

  • 파이어플라이는 이미지 편집을 포함해 비디오·오디오·웹·모바일까지 아우르는 올인원 방향으로 확장 중이며, 이번 영상은 그중 이미지 편집 기능에 초점을 맞춤
  • 구글 제미나이, 클링, 플럭스 등 경쟁 모델을 파트너로 같은 인터페이스에서 통합 제공하는 방식은 개별 생성 성능보다 편집·제어 툴체인의 통합성이 경쟁 우위가 될 것임을 시사
  • 제작자는 "아무리 다른 툴이 나와도 정교한 편집 단계에서는 여전히 어도비를 쓸 수밖에 없다"는 실무 판단을 제시, 향후 배경 시리즈를 지속 확장할 계획을 밝힘

10용어 사전

  • 마크업(Markup): 파이어플라이 이미지 편집의 핵심 도구 모음으로 텍스트·브러시·박스 선택 방식을 통해 이미지의 특정 영역을 지시·수정하는 기능
  • 디테일 조절: 선택 영역의 전반적 분위기·톤을 프롬프트와 강도 슬라이더로 미세 조정하는 기능
  • 선택 영역 제거: 브러시로 표시한 부분을 주변 배경을 참조해 자연스럽게 채워 삭제하는 기능, 경도 조절로 경계 처리 방식 선택 가능
  • 배경 확장(Generative Expand 개념): 원본 이미지의 화각을 벗어난 영역을 별도 프롬프트 없이 원본 분위기에 맞춰 자동으로 그려 넓히는 기능
  • 3종 이미지(참조 이미지): 특정 피사체나 오브젝트의 생김새를 고정해 이후 생성물에서도 동일하게 유지시키는 참조 기능
  • 울트라키(Ultra Key): 프리미어 프로의 크로마키 합성 기능, 그린 스크린 촬영본과 생성 배경을 합성할 때 사용
