헤르메스 데스크톱으로 개인 업무 에이전트를 만들고 반복 작업을 자동화하는 방법을 소개한다.

헤르메스 데스크톱으로 뉴스·콘텐츠 업무를 에이전트화하는 구성과 운영 사례.

01핵심 개요

  • 김민정 HRX랩 부대표는 오픈소스 헤르메스의 데스크톱 버전으로 비개발자도 로컬 에이전트를 바로 쓸 수 있다고 설명했다.
  • 헤르메스는 대화 과정의 피드백을 기록해 산출물 방식과 스킬 파일을 점진적으로 업데이트하는 점을 핵심 차이로 제시했다.
  • AI·AX 뉴스 봇은 매일 오픈AI·구글·클로드 공식 사이트를 탐색해 블로그용 HTML, 링크드인 글, 카드뉴스를 만든다.
  • 뉴스 제작에는 치프 에이전트와 리서치·인사이트·작성·검수 역할의 서브 에이전트 4명이 함께 배치됐다.
  • 완전 자동 발행도 가능하지만, AI·AX 관점의 시사점은 오류나 의도 차이를 고려해 본인이 리뷰한 뒤 게시한다고 밝혔다.

02핵심 주장 / 논점 구조

  • 일반 채팅형 AI는 질문에 답하지만, 에이전트는 지정된 폴더의 파일을 읽고 정리하며 메일 발송 같은 행동을 수행한다고 설명했다.
  • 클로드 코드, 코덱스, 클로드 코워크도 파일 접근과 문서·코드 작성 기능을 가진 에이전트로 분류했다.
  • 헤르메스는 사용자가 매번 스킬 파일 수정을 요청하지 않아도 대화 속 작업 기준을 반영해 산출물을 개선한다고 말했다.
  • 에이전트 설계는 업무를 가장 잘 아는 본인이 세부 업무 단위와 사람의 검토 지점까지 정해야 한다고 강조했다.

03헤르메스 데스크톱 설치와 로컬 구동

  • 발표자는 5월 초 헤르메스 설치가 어려웠지만, 최근 데스크톱 버전이 나와 로컬에 설치하면 바로 사용할 수 있다고 말했다.
  • 헤르메스는 맥·윈도우·리눅스 버전 다운로드를 제공하며, 일반 프로그램처럼 설치할 수 있다고 안내했다.
  • 별도 VPS 대신 우선 로컬에서 작동을 시험해 보기를 권했고, VPS 비용은 월 약 9달러였다고 언급했다.
  • 노트북을 껐다 켠 뒤 재가동이 원활하지 않을 때는 코덱스에 상태 점검과 구동을 요청해 해결한다고 설명했다.

04메인봇과 분리된 업무 봇 운영

  • 메인봇 헤르메스는 5월부터 뉴스, 강의안, 도서 기획 등 여러 작업을 함께 수행하며 사용자의 업무 방식을 축적했다.
  • 콘텐츠 헤라 봇은 뉴스 기반 링크드인 글, 인스타그램·블로그 글, X용 카드뉴스 자동화를 시험하기 위해 만들었다.
  • AI·AX 뉴스 봇은 일정 수준으로 작업이 안정된 뒤 메인봇에서 분리했으며, 매일 아침 뉴스 선별 업무를 수행한다.
  • 초기부터 많은 봇을 만들면 관리 지점과 혼란이 늘 수 있으므로 개인이나 기업 모두 꼭 필요한 에이전트 중심으로 시작하라고 조언했다.

05AI·AX 뉴스 자동화 산출물과 검토 방식

  • AI·AX 뉴스 봇은 오픈AI, 구글, 클로드 공식 사이트의 소식 가운데 업무 관련 AI·AX 키 메시지를 골라 뉴스 형태로 정리한다.
  • 산출물에는 핵심 요약, AI·AX 관점에서 중요한 이유, FAQ, 추가 링크 태그와 블로그 게시용 HTML 파일이 포함된다.
  • 링크드인용 문구와 해시태그, 헤드라인 이미지가 포함된 카드뉴스도 만들며, 카드뉴스 스타일은 피드백 후 수정됐다.
  • 버퍼를 통해 인스타그램 등으로 승인 후 게시하거나 API 연동으로 티스토리 등에 자동 발행할 수 있지만, 발표자는 직접 리뷰 후 올린다.

06크론 작업과 서브 에이전트 협업 구조

  • AI 뉴스 치프 봇에는 뉴스 리뷰, 리서치, 인사이트 도출, 글 작성·검수에 관여하는 서브 에이전트 4명이 배치됐다.
  • 오전 10시 등 지정된 시간에 작동하는 스케줄 잡은 크론 잡으로 설정하며, 반복 업무를 예약 실행하는 방식이라고 설명했다.
  • 뉴 그룹 챗을 열면 치프와 서브 에이전트의 역할 소개 및 의견 교환을 확인할 수 있지만, 정기 작업 자체는 채팅방과 별개로 수행된다.
  • 결과물이 기대에 못 미치면 메인봇에 제목 최신성이나 카드뉴스 방식 등을 재검토하도록 지시하고, 이후 작업 기준에 반영할 수 있다.

07모델 연동과 업무별 활용 범위

  • 헤르메스는 무료 오픈소스이며, 무료 모델이나 올라마로 설치한 로컬 LLM을 연결해 사용할 수 있다고 소개했다.
  • 사용자는 보트별로 모델을 다르게 설정할 수 있어 글쓰기 역할에는 GPT, 분석 역할에는 클로드를 연결하는 예를 들었다.
  • 텔레그램 연동은 BotFather에서 봇을 만들고 API 토큰을 설정하는 방식으로 가능했으나, 현재는 데스크톱에서 바로 쓸 수 있다고 말했다.
  • 발표자는 헤르메스로 리서치와 초안을 설계한 뒤, 기존 PPT 스타일 스킬이 설정된 클로드로 MD 인수인계 파일을 넘겨 PPT를 만든다고 밝혔다.

08용어 사전

용어뜻
헤르메스대화와 작업 과정의 피드백을 기록하고, 메인봇·서브 에이전트·스케줄 작업을 구성할 수 있다고 소개된 오픈소스 에이전트 도구다.
스킬 파일에이전트가 수행할 업무, 주의사항, 산출물 형태, 참조 대상 등을 담는 업무 매뉴얼 성격의 설정 파일이다.
소울 MD봇의 정체성, 역할, 작업 방식 등을 설정하는 파일로 영상에서 에이전트 프로필 구성 요소로 언급됐다.
크론 잡오전 10시처럼 지정된 시간에 봇의 반복 작업을 실행하도록 예약하는 스케줄 작업이다.
서브 에이전트치프 봇 아래에서 리서치, 인사이트, 작성, 검수처럼 세분화된 역할을 맡도록 만든 보조 에이전트다.
올라마발표자가 로컬 LLM을 설치해 헤르메스에서 무료로 사용할 수 있는 방법으로 언급한 도구다.
