옵시디언에서 AI 딥리서치 자동화 — NotebookLM + Tavily 무료 플러그인

title: 옵시디언에서 AI 딥리서치 자동화 — NotebookLM + Tavily 무료 플러그인

01핵심 개요

항목내용
채널배움의 달인 (AI·자동화) · 김문정
주제자체 개발 옵시디언 플러그인 "RealyGood Research" 소개·설치·시연

결과물마크다운(.md) + HTML 두 형식 동시 생성

02핵심 기능 구조

옵시디언 볼트 내부에서 질문 하나를 던지면 두 종류의 리서치 리포트가 동시에 생성된다. 첫째는 Tavily API 기반 딥리서치, 둘째는 NotebookLM 기반 리서치이며, 각각 수십 개(40~50개) 소스를 활용한다. 결과는 지정 폴더(기본 00-리서치)에 마크다운과 HTML로 저장되어, 리서치 데이터가 자동으로 개인 지식관리(볼트) 안에 축적된다.

두 프로바이더(Tavily·NotebookLM)는 개별 또는 동시 사용이 가능하며, 토글로 선택한다. 실행은 모달(진행 창)로 표시되고 창을 내려도 백그라운드로 계속 진행된다. 통상 10분 내외 소요.

03기술적 맥락

플러그인은 외부 CLI 코딩 에이전트를 백엔드로 활용한다. Codex CLI, Claude Code CLI, Gemini CLI, Antigravity 중 하나를 프로바이더로 지정하면, 그 CLI가 NotebookLM MCP와 Tavily API를 연결해 리포트를 작성한다. NotebookLM MCP는 오픈소스를 차용했고, 설치는 제공된 커맨드를 터미널(옵시디언 내장 터미널 가능)에 붙여넣어 진행한다.

NotebookLM은 로그인이 필요하며, 작업 대기 한도는 기본 900초(약 15분)로 설정된다. Tavily API 키는 클라우드가 아닌 로컬에 .env 형태로 저장되어 보안 우려가 낮다. 딥리서치 1회당 약 20크레딧 차감(무료 1,000크레딧으로 충분).

04전략적 의미

기존에는 NotebookLM·Gemini·ChatGPT 딥리서치를 각 웹서비스에서 따로 수행하고 결과를 옮겨야 했다. 이 플러그인은 리서치 실행 지점을 옵시디언으로 통합해, "리서치 → 지식 축적"의 흐름을 끊김 없이 만든다. 지식관리 도구(옵시디언)를 단순 저장소가 아닌 리서치 실행 허브로 확장한 사례다.

05핵심 워크플로우

  1. 커뮤니티 플러그인 브라우즈에서 "RealyGood Research" 설치·활성화(BRAT 불필요).
  2. 설정에서 Tavily API 키 저장 + NotebookLM MCP 설치·로그인 + CLI 프로바이더 지정.
  3. 좌측 리본 아이콘 → 토픽 입력 → 프로바이더 토글 → 출력 폴더 지정 → Start.
  4. 10분 내외 후 .md·.html 리포트 자동 생성.
  5. 공유 시: HTML 파일을 Gemini Canvas에 업로드 → "HTML 페이지로 열어줘" → Share로 공유 링크 생성(PDF 인쇄도 가능).

06활용 시나리오

  • 주제 조사 자동화: "AI 챗봇 활용 시 고객 만족도·충성도 영향" 같은 질문으로 40~50개 출처 기반 리포트를 노트로 확보(영상 시연 사례).
  • 개인 지식베이스 강화: 반복 리서치 결과가 옵시디언에 자동 누적되어 이후 검색·연결에 재활용.
  • 외부 공유: 사내 협업·보고 시 Gemini Canvas 공유 링크로 시각화된 리포트 전달.

07현황 및 전망

플러그인은 커뮤니티 플러그인으로 정식 등록되어 누구나 설치 가능하다. 개발자는 생업 병행으로 업데이트에 한계가 있어 카톡방 커뮤니티의 협업(오픈소스)으로 개선·재배포되는 구조라고 밝혔다. Tavily API 퀄리티 만족도가 높아 딥리서치 워크플로우의 표준 도구로 자리 잡을 가능성이 있다.
