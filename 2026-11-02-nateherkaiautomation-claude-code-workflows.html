Claude의 모델·컨텍스트·코드 도구와 자동화 기능을 비개발자 관점에서 설명한다

Claude 모델 선택부터 Claude Code와 반복 업무 자동화까지 핵심 개념을 정리한다.

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

분석 범위: 원문 전체 27,312자 · 5개 구간. 원문 대조한 핵심 인용 30개를 바탕으로 요약했습니다.

01핵심 개요

  • Haiku는 저렴하고 빠른 소형 모델, Sonnet은 일상 작업용, Opus는 큰 과제를 맡기는 모델로 소개된다.
  • 실제 워크플로 7개 비교에서 명확한 지시가 있는 작업은 Sonnet이 대체로 더 빠르고 저렴했고, 모호한 목표는 Opus가 강했다.
  • Claude Code의 컨텍스트 창은 100만 토큰이며, Anthropic은 약 55만 5천 단어에 해당한다고 설명한다.
  • 무료는 월 0달러, Pro는 20달러, Max는 100달러부터이며, 월 200달러 요금제는 Ultra로 불린다.
  • 파일을 다루는 Claude Code부터 아티팩트, 스킬, 플러그인, 권한 설정까지 여러 기능을 실제 업무 흐름과 연결해 설명한다.

02핵심 주장 / 논점 구조

  • 영상은 Claude의 모델 선택부터 Claude Code 사용, 반복 업무 자동화까지 비개발자도 이해하도록 개념을 설명한다.
  • 모델 성능은 작업 조건에 따라 달라진다. 명확한 지시에는 Sonnet, 목표가 모호한 일에는 Opus가 유리했다고 소개한다.
  • 컨텍스트와 사용량 제한을 이해하고, 스킬·플러그인·권한 설정을 조합해 반복 작업을 다루는 흐름을 제시한다.

03Haiku·Sonnet·Opus의 역할과 작업별 비교

  • Haiku는 세 모델 중 작고 저렴하며 빠른 모델, Sonnet은 일상 작업의 주력 모델, Opus는 큰 과제를 맡기는 모델로 설명된다.
  • 진행자는 실제 워크플로 7개에서 Sonnet과 Opus를 비교했으며, 명확한 지시가 필요한 자료 안내서 작업에서는 Sonnet이 이겼다.
  • 자료 안내서 작업에서 Sonnet은 Opus보다 대략 절반 시간에 끝냈고, 보통 비용도 더 적게 들었다고 설명한다.
  • 90일 계획처럼 목표가 모호한 작업에서는 Opus가 우세했다고 비교한다.

04컨텍스트 창과 요금제별 사용 한도

  • 영상은 Claude Code의 현재 모델에 100만 토큰 컨텍스트 창이 있으며, Anthropic 기준 약 55만 5천 단어라고 전한다.
  • 출력 토큰 하나를 쓸 때 약 200개를 읽을 수 있다는 설명을 들어, 불러오는 파일과 지침이 중요하다고 강조한다.
  • 사용량에는 5시간 세션 한도와 주간 한도가 함께 적용되며, Claude 앱 채팅과 Claude Code 작업이 같은 한도를 공유한다.
  • 무료는 월 0달러, Pro는 20달러, Max는 100달러로 Pro의 5배 사용량이며, Ultra는 200달러로 Pro의 주간 사용량 10배라고 설명한다.
  • 검증된 Ultra 계정은 5시간 제한이 없어질 예정이라고 영상에서 안내한다.

05Claude Code의 로컬 파일 작업과 Cowork

  • Claude Code는 컴퓨터의 폴더 안에서 작동해 로컬 파일을 읽고 새로 만들거나 편집하고 이동할 수 있다.
  • 영상은 계약서 폴더를 플레이북과 대조하거나, 여러 자료를 맞춰보는 스프레드시트를 만드는 일을 예로 든다.
  • Anthropic의 에이전트 앱은 연결한 앱 안에서 입력이나 음성으로 요청한 작업을 수행하도록 소개된다.
  • 메시지 전송, 결제, 문서 서명, 삭제 같은 작업 전에는 사용자에게 확인을 요청하며, 당시 연구 미리보기와 대기 목록 단계라고 설명한다.

06아티팩트·메모리와 재사용 가능한 스킬

  • 아티팩트는 문서, 발표 자료, 디자인, 대시보드, 간단한 인터랙티브 도구처럼 채팅 옆에서 열리는 Claude의 결과물이다.
  • 대시보드의 숫자를 클릭하면 그 수치에 사용된 쿼리를 확인할 수 있어 차트의 근거를 살펴볼 수 있다고 설명한다.
  • 메모리는 Claude가 세션이나 날짜가 바뀐 뒤에도 정보를 이어가는 방식이며, 매번 새로 시작하는 세션에서 불러올 내용을 간결하게 유지하라고 조언한다.
  • 같은 영상 처리 요청을 약 15번 반복한 뒤 이를 스킬로 만들었고, Google Sheet의 Master Database와 Wiki에 정리하는 사례를 든다.
  • 플러그인은 스킬·명령·커넥터·에이전트 등을 함께 설치하는 묶음이며, 모드는 Claude Code 자체의 작동 방식을 바꾸는 플러그인 유형이라고 설명한다.

07권한 모드·하위 에이전트와 예약 작업

  • 권한 모드는 Claude가 작업 전에 얼마나 자주 확인할지를 조절하며, 영상은 모두 다섯 가지라고 설명한다.
  • Manual 모드는 파일 편집이나 명령 실행 전에 확인을 요청하며, Auto는 Pro·Max·Team의 새 세션에서 기본값이라고 소개한다.
  • 하위 에이전트는 한 세션 안에서 돕는 빠른 보조 도구이고, 프로젝트는 작업마다 전체 세션을 실행할 수 있다고 구분한다.
  • 하위 작업은 메인 세션에 작은 요약만 돌려줘 컨텍스트 토큰을 아끼는 방식으로 설명된다.
  • 다른 도구의 이벤트를 활용해 매주 일요일 웹사이트 통계를 갱신하거나 4시간마다 캐러셀을 게시하는 자동화 사례를 든다.

스킬반복해서 쓰는 작업 절차를 재사용하도록 만든 것으로, 영상 처리 과정을 스킬로 전환한 사례가 나온다.
