xbot 개요

📊 슬라이드
xbot 개요
  • 카카오톡에서 바로 쓰는 AI 비서
  • 제공 기능: 한국 주식 분석, 웹 검색, 날씨 조회, 대화·링크 요약, 슬라이드·웹 리포트 생성
  • 반응 방식:

그룹방 — 명령어 ! 또는 멘션(@봇이름)에만 반응 1:1 방 — 명령어 없이 말 걸어도 반응

카카오톡사용 플랫폼
한국 주식 분석핵심 기능 #1
웹 검색·날씨핵심 기능 #2
슬라이드·웹 리포트 생성핵심 기능 #3
  • 방마다 성격(페르소나)과 기억이 독립 — 같은 질문도 방마다 톤 다를 수 있음

슬라이드 / 웹 리포트 생성 상세

📊 슬라이드
슬라이드 / 웹 리포트 생성 상세
1. 명령어 입력!슬라이드 [주제] 또는 !웹 [주제]
2. 주제 생략 시직전 대화 내용을 자료로 자동 활용
3. 유튜브 링크 입력자막/음성 분석 → 핵심 정리 (자막 없는 영상도 음성 인식 처리)
4. 생성 완료공개 링크 발행
5. 링크 전달wootom.github.io/news/slides/... 형식 URL → 폰 브라우저에서 열람 가능
  • 게시 반영 소요 시간: 최대 1분
  • 리포트 포함 구성 요소
영상 출처원본 제목·채널·게시일·링크 포함
인포그래픽수치 비교 막대·핵심 지표 카드·비율·시간순 타임라인
전수 정보빠짐없이 빼곡히 담는 것을 목표
  • 인포그래픽 조건: 내용에 수치가 있을 때만 포함

답변 첫 줄 (⏱) 읽는 법 & 알아두면 좋은 점

📊 슬라이드
답변 첫 줄 (⏱) 읽는 법
  • 답변 맨 위 한 줄은 처리 정보 표시
  • 예시: ⏱ 12.4s · Hermes · 🤖 gpt-5.5
항목설명예시
⏱ 시간답변 생성까지 걸린 시간12.4s = 12.4초
주체도구 사용 가능 여부Hermes = 도구 사용 가능
폴백·OpenRouter = 도구 없음, 비상 경로
🤖 모델실제 답변 생성 AI 모델gpt-5.5
Hermes도구 사용 가능 — 정상 상태 (주식·검색·요약·슬라이드 생성)
폴백·OpenRouter도구 없음 — 비상 경로 (제한된 응답만 가능)
알아두면 좋은 점
  • 종목 별칭 인식: 삼전 → 삼성전자 등 흔한 줄임말 자동 인식
  • 정확성 주의

AI가 가끔 틀릴 수 있음 투자·중요 결정은 반드시 직접 확인 필수 종목 코드가 헷갈릴 경우 6자리 코드로 입력하는 것이 가장 정확

  • 시간 소요 안내

슬라이드·웹 리포트: 수십 초~수 분 소요 가능 (특히 긴 영상) 게시 반영: 최대 1분

  • 응답 없을 때

잠시 후 재시도 지속 불가 시 운영자에게 문의
