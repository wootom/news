종교사 3대 변곡점 — 불교 소멸·이슬람 확산·기독교 개혁

목차불교의 인도 소멸 — 성장에서 소멸까지이슬람 급속 확산 배경 — 5대 요인기독교 교회 타락과 개혁 — 독신제 도입십일조의 역사와 영향3대 주제 종합 비교영상 출처

01불교의 인도 소멸 — 성장에서 소멸까지

불교의 성장과 초기 영향력

  • 기원전 6세기 인도 왕자 시다르타의 깨달음에서 시작
  • 브라만교 중심 사회에서 혁명적 종교로 등장
  • 핵심 교리: 카스트 제도 부정, 인간 평등 사상
  • 인도인들의 열광적 지지 획득
  • 아슈카 왕 시대 불교 전성기: 인도 통일 후 인근 국가까지 전파 → 국제 종교화

불교 쇠퇴의 내부 요인

교단 부자화승려들 탁발 중단, 사원 내 틀어박힘
민중 전파 상실설법 활동 중단
형이상학적 이론 추구산스크리트어 경전 사용 → 일반인 이해 불가
철학·학문적 성격지식인층만 이해 가능
수행법의 한계참선·고행 등 → 민초들 실천 불가능
의례 부재가정 의식·종교 의례 없음 → 일상 생활에 뿌리내리지 못함
무소유 교리생존 투쟁하는 민중과 거리 멀음
  • 결과: 민중들 힌두교로 대거 이탈

브라만교의 힌두교 전환

  • 7~8세기 브라만교 → 힌두교로 대혁신
  • 불교의 명상·열반 개념 + 불살생 교리 수용
  • 부처를 힌두의 신 비슈누 환생으로 편입

불교의 자살적 선택

  • 신도 감소 위기 → 힌두교 대폭 수용
  • 여러 보살 신격화 → 소원 기복 신앙 도입
  • 9~10세기부터 불교와 힌두교 구분 불가 → 불교 정체성 상실
  • 신도 이탈 가속화 → 사찰 대신 힌두 신전 선택

이슬람의 결정타

8세기이슬람 본격 인도 영향
무역로 장악인도 왕족·상인 몰락 → 불교 후원자 상실
사원 파괴·승려 살해경전 들고 네팔·티베트 탈출
13세기 초인도에서 불교 완전 소멸

불교 소멸의 근본 원인

  • 불교의 존재 이유: 카스트 제도 부정, 평등주의 실현
  • 이슬람 출현: 불교와 유사한 반카스트·평등 주장 + 무력·경제력 보유
  • 이슬람이 불교의 완벽한 대체제로 등장
  • 힌두 vs 불교 구도 → 힌두 vs 이슬람 구도로 변화
  • 불교도 대거 이슬람 개종: 아프가니스탄·파키스탄·방글라데시 이슬람화
기원전 6세기불교 창시
7~8세기힌두교 대혁신
8세기이슬람 인도 진출
13세기 초인도 불교 완전 소멸

결론

  • 불교 소멸 결정적 이유: 인도 사회 담당 역할을 이슬람에게 상실 → 존재 이유 자체 소멸
  • 교훈: 아무리 오래된 종교도 올바른 정치·사회적 역할 못할 경우 도태 가능

02이슬람 급속 확산 배경 — 5대 요인

요인 ① 페스트와 기존 제국의 약화

40%비잔틴 인구 단기간 사망 (페스트)
25%페르시아 인구 사망 (페스트)
포함페르시아 왕도 사망
  • 페스트가 콘스탄티노플에 퍼져 비잔틴 인구 40% 사망
  • 페르시아에도 페스트 상륙 → 인구 25% 사망, 페르시아 왕 포함
  • 페스트가 두 제국을 동등하게 약화시킴
  • 아라비아 반도: 대부분 사막 → 페스트 매개 곤충 서식 불가 → 이슬람 영향 거의 없음
  • 아라비아 반도 유목민: 사막에 흩어져 거주 → 페스트 회피 유리
  • 비잔틴·페르시아 장기 전쟁 + 페스트로 양강 약화 → 이슬람 급속 전파 가능
  • 비잔틴·페르시아 영향권 약화 → 제3 세력 성장 용인

요인 ② 경제적 토대

  • 페르시아-시리아-요르단-지중해 전통 교역로 단절
  • 대상들이 새로운 루트 개척
  • 아라비아 사막 횡단 및 홍해 연안 루트 개발 → 메카·메디나 도시 발달
  • 중계 무역으로 전례 없는 호황
  • 무함마드도 메카 상인 출신
  • 정복 전쟁의 경제적 토대 마련

요인 ③ 군사력 구성

  • 비잔틴·페르시아의 인력난 → 많은 용병 고용
  • 아랍인들이 두 제국 국경 수비 군사의 대부분 차지
  • 용병 수입이 유목·농사보다 훨씬 우수 → 선망 대상
  • 선진 제국의 전쟁 전술 습득한 아랍인들 → 이슬람 개종 후 최고 전사로 변모

요인 ④ 포용 정책

  • 이슬람 세력 숫자 적음 → 광대한 정복지 직접 통치 불가능
  • 간접 통치 시행: 세금 납부 조건으로 기존 세력의 기득권 인정
  • 종교 자유 보장 → 기독교·유대교 등 모든 종교 허용
  • 지마(Dhimmi) 제도: 무슬림 아닌 국민도 세금만 내면 보호

요인 ⑤ 조세 정책 — 혁명적 우위

비잔틴·페르시아가혹한 수탈 민중 부담 극심
이슬람 지조세25% 토지 소유·경작물 소유 가능
이슬람 인두세10% 개종 불필요, 종교 자유 유지
  • 25% 지조세만 내면 누구든 토지 소유 가능
  • 비잔틴·페르시아의 가혹한 수탈에 신물난 민중에게 혁명적 제도
  • 10% 인두세만 내면 이슬람 개종 불필요 → 다른 종교로부터 거부감 없음
  • 콥트기독교·네스토리우스파·단성론자·유대교도들이 이슬람을 해방군으로 인식

확산 메커니즘

초기 정책개종·세금·죽음 중 선택
세금 납부 시기득권·종교 유지 가능 + 비잔틴·페르시아보다 낮은 세율
결과많은 지역에서 환영 → 전투 없이 도시 통째로 투항
개종 유인이슬람 개종 시 10% 인두세 감면 → 기독교·조로아스터교 대거 개종
역효과세수 급감 → 집단 개종 제한 조치 시행

종교 이념의 역할

  • 이슬람 제국: 사상 처음 종교가 지배 이념인 제국
  • 무함마드 사후에도 정통 칼리프·우마이야 왕조·아바스 왕조로 계승

03기독교 교회 타락과 개혁 — 독신제 도입

중세 교회 성직자 타락 실태

  • 교회 성직자의 타락: 사유와 세습으로 막대한 부 축적
  • 종교개혁 무렵 성직자의 30%가 처를 둠
  • 자녀 상속 필요성 → 세습·부정부패 극성
30%종교개혁 무렵 처를 둔 성직자 비율
1123년1차 라테라노 공회 (전면적 사제 독신제 도입 합의)
1139년2차 라테라노 공회 (예외 없는 독신제 교회법 확정)

11세기 교황들의 개혁 시도

레오 9세성직자 독신제 강화, 성직 매매 금지
그레고리 7세성직자 결혼·축첩 금지
우르바노 2세여자 또는 성직 중 하나만 선택 강요
  • 반복된 대책에도 실패 이유: 강제성 부족 → 변법·뇌물로 회피

전면적 독신제 도입

  • 근본 해법: 교회·성지·재산 상속자 차단 → 결혼·성관계 전면 금지 필요
  • 1123년 라테라노 대성당 공회: 전면적 사제 독신제 도입 합의
  • 1139년 2차 라테라노 공회: 예외 없는 독신제를 교회법으로 확정

- 사제 결혼 불법화·처벌 규정 - 유럽 전역 정착에 수백 년 소요 - 결과: 교회 세습 확연히 감소

  • 현재 가톨릭: 천 년간 성행위 금지 고행 강요 중

04십일조의 역사와 영향

십일조의 기원

  • 십일조(11조)의 역사적 기원
  • 구약성경: 아브라함과 자손들이 수입의 10분의 1을 사제에게 헌납
  • 유대교: 교회 헌납 십일조 의무화
  • 용도: 사제 생활비·의식비용·고아·과부 구호자금

유대교 부패

  • 원문 내용: 십일조와 관련된 유대교 부패 언급 (원문 중단으로 세부 내용 확인 불가)
10%십일조 비율 (수입의 10분의 1)
사제 생활비십일조 주요 용도
고아·과부 구호십일조 사회 복지 기능

053대 주제 종합 비교

불교 소멸13세기 초 인도
이슬람 확산7~8세기 중동·북아프리카
기독교 개혁11~12세기 유럽

공통 패턴

  • 기존 종교·제도의 내부 부패와 타락 → 위기 초래
  • 외부 충격(페스트·이슬람)이 기존 질서 붕괴 가속
  • 포용적 정책과 낮은 진입 장벽이 새로운 체제 확산 촉진
  • 종교의 사회적 역할 상실 시 존재 이유 자체 소멸 가능
