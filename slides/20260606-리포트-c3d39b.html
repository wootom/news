  • 핵심 기술: 성능 저하 최소화 + 모델 크기 대폭 축소

04QAT 기술 설명

  • 양자화(Quantization): AI 모델의 가중치 정밀도를 낮춰 모델 크기를 줄이는 기술
  • PTQ(Post-Training Quantization, 사후 양자화): 학습이 끝난 모델을 압축 — 성능 저하 발생 가능
PTQ 방식학습 완료 → 모델 압축 → 성능 저하 가능
QAT 방식학습 과정에서 양자화 미리 시뮬레이션 → 모델이 정밀도 손실 자체 보정
  • QAT 장점: 동일 크기의 기존 PTQ 모델보다 더 높은 품질 제공
  • 구글 측정 결과: 비양자화 체크포인트 기준 약 5,000 스텝 QAT 학습 추가 진행
5,000 스텝QAT 추가 학습량
54%Q4_0 압축 시 당혹도(Perplexity) 상승 감소율 (기존 대비)
  • Perplexity(당혹도) 상승 = 성능 저하 지표
  • 단, 구체적인 성능 벤치마크 수치는 공개되지 않음

06모바일 QAT 4대 핵심 기술

기술 1정적 활성화(Static Activations) — 학습 단계에서 스케일 값 미리 계산 → 모바일 연산 부담 감소
기술 2채널 단위 양자화(Channel-wise Quantization) — 모바일 AI 가속기에 적합
기술 32비트 압축 — 토큰 생성 계층에만 선택적으로 적용
기술 4임베딩 및 KV 캐시 최적화 — 메모리 사용량 추가 절감
  • 핵심 추론 계층: 상대적으로 높은 정밀도 유지 → 성능 저하 최소화
