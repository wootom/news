Astra와 Codex로 다빈치 리졸브 편집을 말로 지시하고 반복 수정하는 흐름을 시연한다.

Astra·Codex로 러프컷부터 B롤·자막까지 말로 지시하고 반복 수정하는 다빈치 편집 시연.

01핵심 개요

  • 영상 편집을 처음 하는 사람도 Astra가 DaVinci Resolve 안에서 러프컷부터 후속 편집까지 수행하는 흐름을 소개한다.
  • 필요 도구로 295달러인 DaVinci Resolve Studio와 월 200달러 Codex 플랜, Codex와 편집기를 잇는 MCP를 제시한다.
  • 첫 러프컷은 멈춤·공백·잘못 말한 부분을 제거하는 단계이며, 요청 후 결과까지 약 15~40분이 걸린다고 설명한다.
  • 수정은 시간·문제·원하는 변화 순으로 구체화하고, 컷·B롤·자막·효과를 한꺼번에 요청하지 말라고 권한다.
  • AI는 편집을 실행하고 사용자는 결과를 검토하며 방향을 정하며, 작은 저화질 파일로 먼저 확인하는 방식을 사용한다.

02핵심 주장 / 논점 구조

  • Astra가 DaVinci Resolve 내부에서 편집을 수행하고, 사용자는 Codex를 통해 원하는 결과와 수정 방향을 말로 전달한다.
  • 바이브 편집은 ‘전체를 편집해 줘’ 한 번으로 끝나지 않으며, 결과를 보고 오류와 방향을 반복적으로 수정하는 과정이다.
  • 편집 순서는 말의 흐름을 정리한 러프컷, 참고 화면인 B롤, 자막·강조·효과 순으로 나누는 방식이 제시된다.
  • AI가 실행을 맡고 사용자는 이야기 구조, 화면과 말의 일치, 자막 가독성 등을 검토하며 디렉션을 맡는다.

03DaVinci Resolve·Codex·Astra·MCP의 역할

  • DaVinci Resolve는 실제로 영상을 자르는 작업 공간이며, Astra는 Codex 안에서 작업을 판단하는 모델로 설명된다.
  • Codex는 사용자가 요청을 입력하는 곳이고, MCP는 Codex와 DaVinci Resolve를 연결하는 통로로 소개된다.
  • 컴퓨터 사용 기능은 최후의 수단으로 언급되며, 가능하면 Codex가 컴퓨터를 점유하지 않고 프로그램 내부에서 직접 작업하는 편이 좋다고 말한다.
  • 완전 초보자는 Codex에 DaVinci Resolve 최신 버전 설치를 요청할 수 있으며, 영상에서는 MCP 설치를 권한다.

04비용과 작업 준비 방식

  • 영상은 DaVinci Resolve Studio 가격을 295달러, Astra를 충분히 쓰기 위한 Codex 플랜을 월 200달러로 제시한다.
  • Astra 에이전트를 온종일 사용하면 하루 반에서 이틀 만에 한도를 모두 쓸 때가 있다고 말하며, 발표자는 Light 설정을 사용한다.
  • 시연 환경에서는 Codex가 영상 보관 위치와 정리 방식을 이미 알고 있어 짧은 요청만으로 파일을 가져올 수 있다.
  • 처음 사용하는 사람은 파일 위치, 원하는 결과물, 첫 작업을 함께 알려야 하며, 예시로 인터뷰 폴더에서 1분 쇼츠 러프컷을 요청한다.

05러프컷 생성과 첫 검토 기준

  • 첫 프롬프트의 목표는 멈춤, 공백, 잘못 말한 부분을 제거해 말의 흐름을 정리한 러프컷을 만드는 것이다.
  • 러프컷 검토에서는 단어가 잘리지 않았는지, 쉼이 어색하지 않은지, 이야기가 이어지는지를 먼저 확인하라고 제안한다.
  • 시연에서는 Anthropic 관련 쇼츠의 첫 러프컷 생성에 23분이 걸렸고, 단어 사이 공백과 멈춤을 다듬고 컷마다 짧은 전환을 넣었다.
  • 확인용으로 작은 저화질 버전을 렌더한 뒤 받아쓰기를 켜고 영상을 보면서 수정 사항을 실시간으로 말한다.

06시간 기반 피드백과 B롤 수정 사례

  • 수정은 ‘어색하다’처럼 모호하게 말하기보다 시간, 문제, 원하는 변화를 순서대로 전달해야 한다고 설명한다.
  • 예시로 ‘3초에서 단어 앞부분이 잘렸어, 첫 클립을 조금 더 앞에서 시작해 줘’처럼 구체적인 요청을 제시한다.
  • B롤은 말하는 사람 대신 보여주는 참고 화면으로, 기사를 읽을 때 기사 화면을 보이고 직접 설명할 때는 얼굴을 보이는 방식이다.
  • 시연에서는 4초 점프 컷, 22초 잘린 ‘cancer’, 56초 기사 화면 유지 등 시간대를 지정해 수정하며, B롤 작업은 약 20분이 걸렸다.

07스토리 구조·자막·효과를 단계적으로 다듬기

  • 처음부터 컷, 자막, B롤, 효과를 모두 요청하면 오류 원인을 찾기 어려우므로 작업 범위를 나눠 요청하라고 권한다.
  • Anthropic 쇼츠에서는 ‘군 관련 Claude 요청’을 ‘AI 생물무기’로 바꾸고, 도입부를 ‘Anthropic이 보고서를 냈습니다’로 시작하도록 요청한다.
  • 말이 이어져도 이야기의 요점이 없을 수 있으므로, 시작의 궁금증·가운데 설명·끝의 요점이라는 구조를 확인한다.
  • ‘능력을 더 강화’에서 얼굴을 확대하고, 과학자·생물무기·바이러스 B롤과 약한 휙 소리, 배경음악을 추가하는 요청 사례가 나온다.
  • 최종 확인에서는 처음과 끝의 말이 들리는지, 자막이 읽히는지, 화면이 설명과 맞는지를 점검해야 한다고 말한다.

08용어 사전

용어뜻
AstraCodex 안에서 편집 작업을 판단하며 DaVinci Resolve 타임라인 작업을 수행하는 모델로 소개된다.
Codex사용자가 편집 요청을 입력하고 결과물 확인 및 렌더 요청을 하는 작업 창구다.
MCPCodex가 DaVinci Resolve를 제어할 수 있도록 두 프로그램을 연결하는 통로로 설명된다.
러프컷자막과 효과 전에 남길 말과 연결 지점을 정리해 말의 흐름을 만드는 첫 편집 초안이다.
B롤말하는 사람 대신 기사 화면이나 관련 화면을 보여줘 발화 내용과 화면을 맞추는 참고 영상이다.
바이브 편집사용자가 원하는 결과를 말로 지시하고 AI 결과물을 보며 시간대별로 반복 수정하는 편집 방식이다.
