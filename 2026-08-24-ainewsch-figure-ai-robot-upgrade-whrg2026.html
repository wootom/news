02핵심 기능/내용 구조

영상은 크게 두 파트로 구성된다. 전반부는 "휴머노이드 로봇 성과 랭킹 4가지", 후반부는 "무료 스텔스 LLM Ox Alpha 소개"다.

  1. Figure 03 — 사다리를 자율적으로 오르내리는 시연 (0:00)
  2. Galbot — 테니스 로봇 "Astro Tennis"가 130회 이상 무실점 랠리 (2:44)
  3. Tienong·Tangong — 1500m·400m·100m 육상에서 인간 세계기록 경신 (3:16)
  4. Booster Robotics — T2 휴머노이드 80대 동시 군무 시연 (4:48)

03기술적 맥락

  • 시스템 2(느린 추론층): "사다리에 접근 → 그립 확보 → 무게중심 이동 → 다리 전진 → 반복" 같은 상위 지시를 세분화해, 개별 관절 움직임이 아니라 의미론적 목표(semantic goal)를 하위 시스템에 전달한다.
  • 시스템 1(빠른 제어층): 그 목표를 전신 관절 목표값으로 변환해 200Hz로 실행하며, 모든 센서 데이터를 동시에 받아들인다. 머리 카메라는 사다리 발판 간격과 각도를 추적하고, 손바닥에 장착된 카메라는 팔이 시야를 가릴 때도 시각 정보를 보완한다.
  • 시스템 0(균형 보정층): 하강 시 중력 방향으로 체중을 낮추는 힘 프로파일을 매 스텝 관리한다.

하강은 상승보다 어려운 균형 문제로 소개된다. 머리 카메라가 로봇 발밑을 직접 보지 못하므로 손바닥 카메라가 "로봇의 눈" 역할을 대신하고, 손끝 촉각 센서(1kHz 갱신)에 의존해 그립을 확인하는 촉각 중심 제어로 전환된다. 같은 Helix 02 시스템은 설거지, 청소, 계단 오르기 등 다른 작업도 이미 시연한 바 있다.

  • 프로바이더명 "stealth", 모델ID "stealth/oxalpha", 코딩·에이전틱 작업·프로덕션 태스크 지향 추론 모델
  • 컨텍스트 윈도우 100만 토큰, 최대 출력 13만1000 토큰, 텍스트·이미지·비디오 입력 지원
  • 독립 니들인더헤이스택(needle-in-haystack) 테스트: 약 93만4000 토큰 지점까지는 검색 성공, 약 100만5000 토큰 지점부터 실패 — 공식 스펙과 대체로 부합
  • 프리뷰 기간 요금 100만 토큰당 입출력 모두 $0. 오픈코드는 "출시 후 약 1주간 무료" 명시(대략 8월 27일 종료 추정), 오픈라우터 목록에는 명확한 종료일 없음
  • 일일 처리 용량 주장 편차: 오픈코드는 100조 토큰/일, 다른 프로바이더는 1000조(1퀸틸리언) 토큰/일 주장

04전략적 의미

  • 육체 지능 대 소프트웨어 지능의 이중 경쟁: 같은 주에 "몸으로 세계기록을 깨는 로봇"과 "정체를 숨긴 채 등장한 초저가 코딩 모델"이 나란히 보도된다는 것 자체가, AI 경쟁이 물리적 구현(embodiment)과 순수 지능(모델) 두 축에서 동시에 벌어지고 있음을 보여준다.
  • 숫자냐 지능이냐: 영상 도입부의 질문처럼, Booster Robotics의 "80대 동시 군무"는 규모(양적) 접근, Figure 03의 계층형 추론 시스템은 지능(질적) 접근을 대표하는 대비되는 전략으로 제시된다.
  • 벤치마크 신뢰성 문제: Ox Alpha의 "딥 소프트웨어 엔지니어링 벤치마크 80%"라는 초기 확산 수치가 113개 전체 과제가 아닌 10개짜리 선별 세트에서 나온 것이며, 전체 실행 시 실제 해결률은 58.4%였다는 대목은 AI 벤치마크 발표를 곧이곧대로 믿어서는 안 된다는 경고로 읽힌다.
  • 데이터 정책의 플랫폼별 비대칭: 같은 모델이라도 오픈라우터 경유 시 제공자가 학습·평가용으로 데이터를 활용할 수 있는 반면, 오픈코드 경유 시 제로 데이터 보존·학습 미사용이 명시돼 있어, 사용자가 어느 경로로 접근하느냐에 따라 프라이버시 위험이 달라진다.
  • 정체 은폐 자체가 마케팅/실험 전략일 가능성: 오류 메시지 포맷이 Zhipu(智谱)의 GLM 계열과 일치한다는 커뮤니티 분석, 동시에 제미나이 신모델이라는 추측까지 나오는 상황은, 대형 랩들이 "스텔스" 형태로 신모델을 실사용자 트래픽에 노출시켜 검증하는 관행이 확산되고 있음을 시사한다.

05핵심 워크플로우·방법론

  1. 시스템 2가 상위 지시를 세분화: 접근 → 그립 확보 → 체중 이동 → 다리 전진 → 반복
  2. 시스템 2가 각 단계를 "의미론적 목표"로 시스템 1에 전달(개별 관절 명령이 아님)
  3. 시스템 1이 목표를 200Hz 전신 관절 목표값으로 환산, 머리·손바닥 카메라 데이터를 동시 융합
  4. 하강 시 시스템 2가 순서를 역전: 다음 발판 위치를 직접 시야 없이 추정
  5. 시스템 1은 시각 중심에서 촉각(손끝 센서, 1kHz) 중심 제어로 전환
  6. 시스템 0이 매 스텝 중력 방향 힘 프로파일을 보정해 균형 유지
  • 컨텍스트 윈도우: 독립 니들인더헤이스택 테스트로 공식 스펙(100만 토큰) 근접 여부 실측
  • 벤치마크: 초기 확산 수치(선별 10개 과제, 80%)와 전체 과제(113개, 58.4%) 결과를 대조해 과장 여부 검증
  • 출처 추적: 오류 메시지 포맷 핑거프린팅으로 기반 모델 계열 추정(GLM 계열 가능성 vs 제미나이 추측)

06활용 시나리오

  1. 물류·서비스 현장의 다층 지형 이동: Helix 02 같은 계층형 추론 구조는 사다리·계단처럼 시야가 가려지는 환경에서 촉각 센서로 보완하는 로봇에 적용 가능해, 창고 고소 작업이나 재해 현장 접근에 활용될 수 있다.
  2. 스포츠·엔터테인먼트 시연용 로봇: Galbot의 테니스 랠리, Booster의 80대 군무처럼 정밀 제어와 대규모 동기화가 결합된 로봇은 개막식·전시 이벤트용 퍼포먼스 콘텐츠로 상업화될 수 있다.
  3. 저비용 코딩 에이전트 실험: Ox Alpha처럼 한시적 무료 스텔스 모델은 개발자가 프로덕션 배포 전 비용 부담 없이 에이전틱 코딩 워크플로우(자동 PR, 리팩터링)를 벤치마킹하는 용도로 쓸 수 있다.
  4. 모델 출처 검증 실무: 오류 메시지 핑거프린팅, 니들인더헤이스택 재검증 같은 절차는 정체불명 모델을 도입하기 전 사내 AI 거버넌스 팀이 표준 점검 체크리스트로 채택할 수 있다.

07현황 및 전망

  • Figure 03은 현재 저속 사다리 등반만 시연했지만, CEO 브렛 애드콕은 2배 속도까지 가능하다고 언급 — 향후 가속화가 예고된 상태다.
  • 2026년 WHRG는 육상 세계기록(1500m 2분21초, 400m 38.15초, 100m 9.32초로 우사인 볼트 기록 경신)까지 휴머노이드가 갱신하는 단계에 도달했음을 보여준다.
  • Ox Alpha는 무료 프리뷰가 8월 27일경 종료될 가능성이 높아, 이 영상이 다루는 "무료 이용 가능 기간"은 이미 단명 이벤트로 소비되고 있다.
  • 출시 약 3일 만에 오픈코드 기준 16조 토큰 처리, 21만1000명 사용자, 500만 세션 이상을 기록해 해당 플랫폼 내 2위 사용 모델로 부상 — 정체 미상임에도 실사용 채택 속도는 매우 빠르다.
  • 개발사는 여전히 미확인 상태이며, GLM 계열 정황과 제미나이 추측이 공존해 커뮤니티 자체 조사가 계속되는 중이다.
