02스킬이란 — 워크플로우 레시피 카드

스킬은 특정 작업을 매번 동일하게 수행하도록 지시·맥락을 담은 명령서. 이메일 응답·프레젠테이션·리포트처럼 반복 작업에서 톤·형식·포함 항목을 매번 프롬프트로 쓰던 것을, 한 번 작성해두면 이후 자동 트리거. 긴 프롬프트 없이 첫 시도부터 동일 품질 출력. 채팅·Cowork·Code 전반에서 작동하며 Hermes·Codex·Manus 등 외부 도구로도 이식 가능.

내부 구조는 단순한 마크다운(plain text) 파일. 고급 스킬은 추가 마크다운·이미지·PDF를 끌어와 시각 가이드라인·추가 맥락 제공.

03사전 설정 — 필수 1단계

Settings → Capabilities에서 코드 실행(code execution)·파일 생성(file creation) 활성화. 미활성 시 스킬 미작동(대개 기본 켜짐).

04내장 스킬·플러그인 계층

계층내용접근
내장 스킬PowerPoint·스프레드시트·Word·PDF·데이터 분석 자동 트리거"PPT 만들어줘" → 자동 실행
추가 스킬Anthropic 제공 스킬Customize → Skills → Browse → + 버튼
플러그인다수 스킬 + 커넥터 묶음(생산성·세일즈·재무·법률·마케팅)내장/파트너 탭
파트너 플러그인Canva·Zapier·Airtable 등 외부 제품 심층 연동Partners 탭

05스킬 제작 — 권장 방식

"Create a skill" 버튼 직접 기술은 비권장(사전 정제된 프롬프트가 있을 때만). 권장: Claude와 정상적으로 작업을 주고받으며 결과를 원하는 수준까지 다듬은 뒤, "지금 한 작업을 스킬로 패키징해줘" 지시 → 내장 스킬 크리에이터가 전체 대화를 분석·재사용 프로세스로 증류. 이미 완성한 과거 대화도 스킬화 가능.

예시(내 목소리로 쓰는 스킬): ① 글 샘플 붙여넣고 분석 요청 → ② Claude가 사고방식·문장 흐름·금기 표현을 인터뷰 → ③ "스킬로 패키징" → ④ 저장 시 자동 트리거.

06놓치기 쉬운 핵심 — 반복 개선

첫 시도에 완성되지 않음. 어려운 스킬일수록 그렇다. 테스트 → 출력 비평 → 피드백 기반 스킬 업데이트를 반복해야 진정 강력해진다. 출력을 수정할 때마다 변경 내용을 Claude에 알리고 스킬 갱신 지시 → 시간이 지나며 본인이 하듯 처리하는 시스템 완성.

07스킬 공유·다운로드

스킬은 파일/폴더이므로 공유 용이. GitHub·마켓플레이스·유튜브 배포본을 Customize → Skills → Add → Upload skill로 드롭인.

08보안 경고 — 반드시 검증

스킬은 명령서이므로 악의적 스킬은 데이터를 몰래 외부 전송 가능. Cowork·Code에서는 컴퓨터 파일에 직접 접근도 가능. 외부 출처 설치 전 ① 신뢰 가능한 제작자인지 확인 ② 내부 내용 반드시 열람. 본인 제작·Anthropic 제공은 안전, 그 외는 검증 필수.

09실행 조언 — 첫 스킬 만들기

과거 Claude 대화 중 여러 번 주고받아 원하는 결과를 얻은 대화를 열고 "지금 한 작업을 스킬로 패키징해줘". 이것만으로 해당 워크플로우 시간을 영구 절약. 없다면 설명란 리소스 프롬프트 활용 또는 자주 하는 작업 하나를 선정해 완성 후 패키징.
