Claude의 새 인터페이스와 분할 작업·컴퓨터 제어 기능으로 프로젝트 활용 범위가 넓어진다.

Claude의 새 UI부터 분할 작업, 컴퓨터 제어, Motion Studio까지 핵심 기능과 제한을 살펴본다.

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

분석 범위: 원문 전체 32,386자 · 6개 구간. 원문 대조한 핵심 인용 36개를 바탕으로 요약했습니다.

01핵심 개요

  • 영상은 Claude의 새 UI와 프로젝트 정리 기능, Slides·Docs·Motion Studio 등을 포함한 업데이트를 13가지 핵심 항목으로 소개한다.
  • 프로젝트는 대화 기록을 바탕으로 최대 다섯 개로 정리하도록 요청할 수 있고, Split view에서는 창마다 맥락을 분리한다.
  • 작업별 helper를 두고 Claude가 컴퓨터를 조작하게 할 수 있으며, 영상은 helper를 네다섯 개보다 늘리지 말라고 권한다.
  • 고정한 대화에서 프로젝트 현황을 살피고 휴대전화로 메시지를 보내거나 클라우드에서 세션을 실행하는 방식도 다룬다.
  • Remote Control과 Motion Studio의 기능을 소개하는 한편, 베타 제한과 요금제 사용량·파일 접근·모드 안전성도 짚는다.

02핵심 주장 / 논점 구조

  • 영상은 Anthropic이 Claude에 새 UI, 프로젝트 구성 방식, 새 앱을 포함한 대규모 업데이트를 제공했다고 소개한다.
  • 설명은 13가지 핵심 기능을 차례로 살펴보며, 창과 프로젝트를 정리하는 방법에서 컴퓨터 제어와 앱 활용으로 확장된다.
  • 업데이트는 지역별로 순차 제공되므로 사용자마다 기능이 나타나는 시점이 다를 수 있다고 설명한다.

03새 레이아웃과 프로젝트·분할 보기

  • 프로젝트를 정리할 때 Claude에 전체 대화를 바탕으로 최대 다섯 개의 프로젝트를 제안해 달라고 요청하는 방법을 소개한다.
  • Split view에서는 두 개의 창을 동시에 띄우고, 각 창이 서로 독립된 맥락을 유지한다.
  • 영상은 한 번에 한 작업만 처리하는 방식과 여러 창을 병행하는 방식을 비교해 보여준다.

04작업별 helper와 컴퓨터 사용

  • helper를 활용해 팟캐스트 에피소드에서 쇼 노트, 클립, X 게시물, 커뮤니티 게시물을 만드는 사례를 보여준다.
  • 각 helper에는 하나의 역할과 작업을 맡기는 구성을 권하고, helper 수는 네다섯 개를 넘기지 말라고 조언한다.
  • Computer use를 켜면 Claude가 사용자가 계속 작업하는 동안 Mac 앱이나 Windows 환경의 앱을 백그라운드에서 다룰 수 있다고 설명한다.
  • 기능을 켜는 경로로 Settings의 Capabilities에서 Computer use를 활성화하는 과정을 안내한다.

05프로젝트 현황 관리와 클라우드 세션

  • 고정한 대화인 ‘What's happening’에서 여러 프로젝트의 진행 상황을 살피는 구성을 설명한다.
  • 매일 아침 진행 중인 프로젝트와 필요한 조치를 보고하도록 요청하는 활용 예시를 든다.
  • 휴대전화에서 메시지를 보내 작업을 요청하고, 프로젝트 파일을 GitHub 저장소에 넣은 뒤 새 클라우드 세션을 실행하는 흐름을 소개한다.
  • 프로젝트 기능은 베타이며, 클라우드에서 작업할 때 로컬 파일에 접근할 수 없다는 제한을 언급한다.

06Remote Control과 Motion Studio 활용

  • Claude Code 설정의 Remote Control에서 새 세션에 연결하는 과정을 보여준다.
  • 브라우저 안에서 로그인하면 API 키가 없는 서비스도 컴퓨터 제어로 다룰 수 있고, 필요한 내용을 가져오거나 다운로드할 수 있다고 설명한다.
  • Motion Studio로 문서, 슬라이드, 디자인, 대시보드를 만들고 결과물을 편집하거나 질문할 수 있다고 소개한다.
  • 기존 데이터와 연결한 결과물을 팀원과 공유해 실시간 데이터를 함께 볼 수 있는 사례를 제시한다.

07확장 기능과 사용 시 유의점

  • URL을 Bitly 링크로 바꾸는 작업과 ‘Eli 5’, ‘Aerospace’ 같은 응답 스타일 선택 사례를 소개한다.
  • 모드는 신뢰할 수 있는 출처에서 받는 것이 중요하며, GitHub에서 설치할 때 Claude에 안전성을 물을 수 있다고 말한다.
  • Claude Duet은 대기 목록에 참여해 승인을 받아야 사용할 수 있는 기능으로 설명한다.
  • 저가 요금제에서는 사용량이 빠르게 소진될 수 있고, 클라우드 작업은 로컬 파일을 볼 수 없다는 점을 유의사항으로 든다.
