03심화 토픽 A — Kimi K3 (문샷AI)

구분내용
개발사중국 문샷AI, 기업가치 약 200억 달러(20B) — 오픈AI·앤트로픽 대비 소규모
스펙2.8조 파라미터, 100만 토큰 컨텍스트, 27일 오픈웨이트 공개 예정
코드 아레나프론트엔드 코드 아레나에서 Fable 5·GPT 5.6 제치고 1위, 오픈웨이트 최초로 미국 추월
코딩 벤치딥소프트웨어 엔지니어 공식 67.5점 표기(실측 69점), Fable 5는 70점(1% 차), GPT 5.6 Sol 73%
특이 벤치하비랩(법률) 벤치에서 Fable 5 대비 약 2배 점수 → 단순 증류 아님 시사
보안 능력벌셀 CEO "사이버보안 최상위·과적합 아님" 평가, 오픈웨이트라 안전장치 해제 시 악용 위험
가격API 100만 토큰당 입력 3달러·캐시 0.3·출력 15달러(Fable 5 출력 50달러 대비 저렴), 월 39달러 코딩 티어
실측 비용작업당 비용 0.95달러로 GPT 5.6(1.04) 수준, 클라인 실험 시 Fable 대비 1.7배 토큰 사용
사례macOS 스타일 OS, 동물의 숲 유사 게임 등 원샷 구현 데모 공개
투자 관점세미애널리시스 "엔비디아·HBM·D램에 긍정적", 제본스 패러독스로 오히려 수요 증가 전망

04심화 토픽 B — Fable 5 구독제 편입 (클로드)

구분내용
기존 계획7/19까지만 구독제에서 Fable 사용, 이후 API 전용 전환 예정이었음
변경7/20부터 모든 Max·팀 프리미엄 플랜에 Fable 5 포함
한도전체 사용량의 50%까지만 Fable, 나머지는 오퍼스 등 다른 모델
공식 사유"Fable 수요 예측 어려움 + 추가 용량 확보"로 구독 편입
프로 구독크레딧 차감(API) 방식 접근 가능하나 비싸 구독제가 유리
배경 해석GPT 5.6·Kimi K3 등장으로 Fable 제외 시 하드 유저 이탈 우려 → 방어적 선택

05심화 토픽 C — grok-build 보안사고·오픈소스 (XAI)

구분내용
문제grok-build CLI가 질문 시점 파일뿐 아니라 전체 깃 저장소·기 히스토리·미참조 파일까지 업로드
규모필요 데이터 대비 약 26,000배 이상 전송
노출 위험API 키·AWS/GCP 자격증명·DB 비밀번호·SSH 키, 삭제된 비밀정보까지 포함 가능
대응XAI 서버 업로드 기능 비활성화·데이터 삭제 발표, 일론 머스크 직접 삭제 언급
후속grok-build 하네스를 Apache 2.0 오픈소스로 공개(3일 전 깃허브), grok 4.5 기반 동작 투명화
