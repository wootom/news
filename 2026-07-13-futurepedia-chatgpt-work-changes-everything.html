ChatGPT Work — 챗GPT 사용법을 완전히 바꾸는 신규 에이전트 기능

title: ChatGPT Work — 챗GPT 사용법을 완전히 바꾸는 신규 에이전트 기능

01핵심 개요

항목내용
채널Futurepedia
소재OpenAI가 출시한 신규 제품 "ChatGPT Work" — 데스크톱 앱 기반 자율 작업 에이전트
핵심질의응답형 챗봇에서 목표만 주면 파일 정리·문서 생성·웹사이트 제작·자동화까지 스스로 수행하는 에이전트로 전환. Claude의 Cowork와 동일한 개념을 챗GPT에 이식
결론비개발자도 자연어 한 줄로 로컬 파일 시스템 접근, 스프레드시트/사이트 생성, 플러그인 연동, 스킬 패키징, 예약 자동화까지 원스톱으로 처리 가능해짐

02제품 개요 및 포지셔닝

  • ChatGPT Work는 코덱스(Codex)의 자동화 능력을 비개발자용으로 패키징한 제품
  • Claude Cowork와 동일한 콘셉트를 챗GPT 생태계에 이식한 것으로 명시적으로 언급됨
  • 유료 플랜 사용자는 웹·모바일·데스크톱 앱에서 모두 이용 가능
  • 데스크톱 앱에서만 로컬 파일 시스템 접근 및 컴퓨터·브라우저 제어 가능 — 웹/모바일은 클라우드에서만 실행되어 로컬 파일 접근 불가
  • 사이드바 드롭다운에서 Work와 Codex 모드 전환 가능

03핵심 인터페이스 구성

  • Schedule tasks: 워크플로우 전체를 자동화하는 예약 작업 기능
  • Plugins: Gmail, Google Calendar, Drive, Canva, Slack, Asana 등 외부 도구 연동 커넥터, 컴퓨터 사용·크롬 사용 플러그인 포함
  • Sites: 챗GPT 내에서 바로 호스팅되는 웹사이트·경량 앱 제작 기능
  • Chat: 기존 챗GPT 대화 이력 유지, 단발성 질문 창 별도 제공
  • Attach to task: 채팅 스레드 전체를 맥락으로 끌어와 작업·자동화의 기반으로 활용
  • 프로젝트(작업 폴더): Work가 작업할 로컬 폴더를 지정 — 기존 폴더든 신규 폴더든, 파일이 있든 없든 선택 가능

04실제 시연 워크플로우 (카페 운영 데이터 정리)

  1. 파일 정리 및 통합 스프레드시트 생성: 뒤섞인 CSV, PDF 청구서, 판매 로그, 텍스트 파일이 든 폴더를 분석해 11개 폴더로 자동 분류, 모든 데이터를 취합한 합계 포함 스프레드시트를 output 폴더에 생성
  2. 체크리스트 기반 장시간 작업 수행: Work가 스스로 전체 실행 계획(체크리스트)을 세우고 단계별로 완료할 때까지 몇 시간이든 수행 — 기존 챗GPT라면 각 단계마다 별도 프롬프트가 필요했을 작업을 한 번의 지시로 처리
  3. Sites로 대시보드 제작: "@sites"로 오너 대시보드 요청 시 3가지 스타일 시안을 자동 생성, 선택한 시안으로 매출·재고·인건비·우선순위 항목을 포함한 라이브 대시보드(chatgpt.site 도메인) 완성
  4. 예약 자동화 설정: 매일 오전 6시에 폴더의 신규 파일을 정리하고 스프레드시트·대시보드를 갱신하도록 자연어로 지시 — 복잡한 프롬프트 없이 목표만 전달하면 자동 실행되며, 실행을 위해서는 컴퓨터가 켜져 있어야 함
  5. 플러그인·스킬 연계 마케팅 작업: 판매·재고 데이터 분석 → 주말 스페셜 메뉴 기획 → GPT Image 2로 인스타그램 홍보 이미지 생성 → 구글 드라이브에 폴더 생성 및 저장 → Gmail로 링크 전송까지 한 번의 프롬프트로 처리
  6. 브라우저 사용 플러그인의 우회 대응: Gmail 플러그인 연동 실패 시 Work가 스스로 판단해 인앱 브라우저로 전환, 이미 로그인된 세션을 찾아 이메일을 작성하고 전송까지 완료
  7. 스킬 패키징 및 재사용: 방금 수행한 "주말 스페셜" 전체 워크플로우를 하나의 스킬로 패키징 요청 → 이후에는 "스페셜 만들어줘" 한마디로 동일 절차 반복 가능, 나아가 "매주 금요일 아침에 그 스킬 실행"이라고 지시하면 완전 무프롬프트 자동화까지 구현

05기능별 세부 특징

기능세부 내용
로컬 파일 접근데스크톱 앱에서만 가능, 폴더 정리·문서 생성·파일 이동 등 수행
인앱 브라우저생성물 확인 및 일반 브라우저처럼 정보 수집 가능, 결과물에 코멘트 남기면 수정 반영
플러그인사전 구축된 커넥터(도구 연동) + 스킬(사용법 지침) 묶음 패키지
컴퓨터 사용/크롬 사용 플러그인자체 커서로 브라우저·컴퓨터를 자율 조작, 크롬 사용은 별도 확장 프로그램 설치 필요
스킬반복 가능한 작업 지침 세트(레시피 카드 개념), 스프레드시트 생성 스킬 등 내장
웹/모바일 버전클라우드 실행이라 더 길고 맥락이 많은 작업에 적합하나 로컬 파일 접근 불가

06활용 시나리오

  1. 소상공인 운영 데이터 자동화: 매일 쌓이는 판매·재고·청구서 파일을 새벽에 자동 정리하고, 오너용 대시보드를 매일 최신 상태로 갱신
  2. 마케팅 콘텐츠 반복 생산: 데이터 기반 프로모션 기획부터 이미지 생성, 소셜 캡션 작성, 자산 저장, 담당자 메일 발송까지 한 번의 스킬 실행으로 매주 반복
  3. 비개발자의 파일/문서 자동화 진입: 코딩 지식 없이 자연어 한 줄로 폴더 정리, 스프레드시트 통합, 웹 대시보드 제작 등 기존에는 개발자나 복잡한 매크로가 필요했던 작업을 수행
