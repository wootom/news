클로드 커넥터, 제발 쓰세요

title: 클로드 커넥터, 제발 쓰세요 — 실전 추천 커넥터 5선

01핵심 개요

항목내용
채널투쏠ㅣAI 에이전트
대주제Claude Desktop 커넥터(MCP)를 실사용 관점에서 추천·설정 가이드
핵심 메시지구글·크롤링·마인드맵·회의녹음·메시지 5개 커넥터만 붙여도 클로드가 외부 도구를 직접 조작

02커넥터란 — 두 종류

커넥터는 클로드가 Gmail·미로·슬랙·탈리처럼 별개 제품인 외부 도구의 데이터를 확인·작업하게 해주는 확장 기능이다. 설정 진입: 좌하단 계정 → 설정 → 기능 → 커넥터. 추가 버튼을 누르면 두 갈래가 나온다.

  • 커넥터 둘러보기: 클로드와 공식 계약을 맺은 SaaS 모음(노션·드라이브·리니어·헬릭스·MS·그래놀라 등).
  • 커스텀 커넥터 추가: 목록에 없는 도구를 MCP 주소만 있으면 직접 연결.

03커넥터 ① 구글 워크스페이스 — 필수 1순위

클로드에 처음 들어오면 가장 먼저 붙여야 할 커넥터. Google Drive·Gmail·Google Calendar 3종을 붙인다. 실사용 예: "Gmail에서 최신 이메일 1개 가져와 확인해줘" → Gmail 도구 로드 후 내용 요약. Drive는 견적서 시트 링크만 줘도 get file metadata로 소유자·구조·항목(수량·단가 등)을 읽어온다. Calendar는 일정 추가·조회·수정.

04커넥터 ② Firecrawl — 웹·X 스크래핑

웹 크롤링 전용 툴. 클로드가 이중 방벽에 막힌 X(트위터) 포스트를 직접 못 읽는 문제를 해결한다. "이 X 포스트를 Firecrawl로 긁어와줘"로 해외 콘텐츠 수집. Firecrawl은 목록(둘러보기)에 없으므로 커스텀 커넥터로 MCP 주소를 복사·등록해야 한다. 어느 정도 무료 사용이 가능해 부담이 적다.

05커넥터 ③ XMind — 마인드맵 자동 생성

내용을 요약·번역한 뒤 마인드맵 형태로 도식화할 때 사용. "이걸 XMind로 마인드맵 만들어줘" → 클로드가 XMind 맵을 생성해 링크로 열람. 구글에 "XMind MCP"로 검색해 MCP 서버 주소를 얻고, 커스텀 커넥터로 등록 후 XMind 로그인 연결. 상품 기획 등 구조화가 필요한 작업에 유용.

06커넥터 ④ 회의 녹음(플라우드) & ⑤ 솔라피

  • 플라우드(회의 녹음): 회의를 녹음·보관하는 앱. 공식 리모트 MCP 서버 URL을 커스텀 커넥터로 등록하면 "어제 무슨 회의 했는지 알려줘" → 녹음 목록·요약 조회("어제 6개 녹음"처럼).
  • 솔라피(문자·카카오톡): 목록·둘러보기 어디에도 없고 로컬 MCP만 지원. 설정 → 개발자 → 로컬 MCP 서버 → 구성 편집(claude_desktop_config.json) 에 솔라피 MCP 서버와 API 키·시크릿(솔라피 개발 메뉴에서 발급)을 넣고 클로드 데스크탑 재시작. 발송은 항상 승인 필요(세션 한정 '항상 허용'). 예: "내 번호로 '안녕' 문자 보내줘" → 즉시 발송. 알림톡·문구 생성도 가능.

07현황 및 전망

발표자는 원래 M8(n8n)으로 하던 메시지 발송을 이제 대부분 클로드 커넥터로 대체했다. 공식 커넥터(원클릭)와 커스텀 커넥터(MCP 주소), 로컬 MCP(설정 파일 직접 편집) 세 경로를 상황에 맞게 조합하면, 클로드가 이메일·크롤링·마인드맵·회의록·메신저를 하나의 대화창에서 오케스트레이션한다. 발표자는 더 많은 커넥터·CLI 플러그인·클로드 코드 팁을 후속 워크플로우 영상으로 공개할 예정.

08용어 사전

용어한줄 설명비유/예시
커넥터클로드가 외부 도구를 조작하게 하는 확장스마트폰에 앱 설치

로컬 MCP설정 파일에 서버·API키를 직접 넣는 방식앱을 손수 설정
