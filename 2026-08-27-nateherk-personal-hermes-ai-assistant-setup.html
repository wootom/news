02핵심 기능/내용 구조

  1. 관리형 에이전트 vs VPS 에이전트 비교: 영상 초반, 화자는 두 방식의 차이를 정리한다. 관리형 Hermes는 월 6달러 수준으로 VPS보다 약간 저렴하고 서버 구매·유지관리가 불필요하며 원클릭 설치로 끝난다. 반면 VPS는 Docker, SSH, 환경 변수 파일을 직접 다뤄야 하고 설정 항목이 더 많지만, 루트 권한으로 완전한 제어가 가능하고 하나의 서버에 Hermes 외에도 n8n 등 여러 앱을 동시에 설치해 확장할 수 있다는 장점이 있다. 화자는 "대부분(약 98%)의 사용자에게는 관리형 방식으로 충분하다"고 조언한다.
  2. Hostinger 가입 및 Hermes Agent 앱 설치: hostinger.com에서 계정을 만들면 HPanel이라는 UI가 제공되며, 왼쪽 메뉴의 'AI 에이전트' 섹션에서 Open Claw, Hermes, n8n을 선택할 수 있다(02:15). Hermes Agent를 클릭해 새 앱을 다운로드하고 '시작하기'를 누르는 것으로 설치가 시작된다(02:53).
  3. 요금제 선택과 AI 모델 연결: AI 크레딧 옵션은 끄는 것을 권장하며, 웹 스크래핑 크레딧 1,000개와 Agentic Mail(에이전트 전용 이메일) 기능이 기본 제공된다. 연간 플랜 결제 시 쿠폰 코드 'Nate Herc'로 10% 할인을 받을 수 있다. 이후 사용할 AI 모델을 선택하는데, 화자는 API 키 직접 입력 대신 ChatGPT 구독 연동을 추천한다. 더 저렴하면서도 더 강력한 추론 기능을 쓸 수 있기 때문이다. 코드를 복사해 ChatGPT 계정에 로그인하면 약 10초 만에 Codex 연결이 완료된다(04:17).
  4. 텔레그램 봇 생성 및 연동: 텔레그램에서 BotFather를 찾아 /newbot 명령으로 새 봇을 만들고("관리형 Hermes 데모"), 'bot'으로 끝나는 고유 사용자명을 지정한다. 발급된 액세스 토큰을 Hostinger에 붙여넣고, 이어서 텔레그램의 '사용자 정보 봇'에서 사용자 ID를 복사해 입력하면 연동이 완료된다(05:41). 이후 사용할 실제 AI 모델(ChatGPT 구독 기준 GPT 계열)을 다시 한번 선택하면 설정이 마무리된다(06:26).
  5. 대시보드 기능과 텔레그램-대시보드 동기화: '앱 열기'를 누르면 Hostinger 대시보드 안에 내장된 Hermes 대시보드가 나타난다. 이 대시보드와 텔레그램 앱이 서로 다른 스레드로 동작하면서도 대화 내용이 실시간 동기화되어, PC의 대시보드와 휴대폰의 텔레그램 어디서 메시지를 보내도 같은 맥락을 공유한다(07:04, 08:29). 대시보드에서는 예약 작업 생성, 칸반 보드를 통한 작업 상태(누가 할당받았는지, 진행 상태) 확인이 가능하며, Claude Code·Codex·컴퓨터 활용·이메일·GitHub 등 내장 스킬을 켜고 끌 수 있고, YAML 프런트매터 형식으로 커스텀 스킬(예: Excalidraw 다이어그램 작성)을 직접 추가할 수도 있다.
  6. 환경 변수(API 키) 추가와 Tavily 웹 검색 연동, 개인화 스킬: HPanel의 환경 설정에서 Tavily API 키 같은 외부 서비스 키를 환경 변수로 추가할 수 있다. 키를 저장하면 대시보드 세션이 초기화되어 비밀번호로 재로그인해야 하며, 간혹 키가 "보이지 않음"으로 표시되면 Hermes 앱을 재시작하면 해결된다. 재시작 후 실제로 Tavily 검색을 실행하자 Tavily 계정에서 크레딧 5개가 소모된 것이 확인되어 연동이 정상 작동함을 증명했다(11:41 부근). 마지막으로 화자는 무료 커뮤니티에서 제공하는 '그릴 미(Grill Me)' 스킬을 추가해 에이전트가 사용자에 대해 인터뷰하고 그 정보를 메모리에 저장하도록 하는 개인화 과정을 시연한다.

03기술적 맥락

Hermes Agent는 자체 AI 모델을 갖지 않고 Claude, GPT, Gemini 등 기존 LLM을 감싸는 래퍼(wrapper) 형태의 에이전트 플랫폼이다. 사용자는 API 키를 직접 입력하거나, ChatGPT/Codex 같은 기존 구독을 그대로 연결해 추론 능력을 활용할 수 있다. 관리형 버전은 Hostinger가 인프라(컨테이너, 트래픽, 백업 등)를 자동으로 관리해 주는 대신 기본적으로 하나의 에이전트만 제공하고 설정 자유도가 제한적인 반면, VPS 버전은 사용자가 Docker, SSH, 환경 변수, 방화벽 규칙, 컨테이너 상태 관리를 직접 맡아야 하는 대신 여러 에이전트나 n8n 같은 다른 애플리케이션을 동일 서버에 함께 운영할 수 있다. 스킬 시스템은 YAML 프런트매터(이름, 사용 시점 등 메타데이터)와 본문 지침으로 구성되며, Claude Code 등에서 쓰는 스킬 파일을 그대로 복사해 붙여넣는 방식으로 이식할 수 있다. 환경 변수를 통한 외부 API(Tavily 등) 연동은 저장 시 대시보드 세션을 초기화시키는 특성이 있어, 키가 즉시 인식되지 않을 경우 앱 재시작이라는 별도 조치가 필요하다.

이 구조가 의미 있는 이유는, 서버 운영 경험이 없는 일반 사용자도 '개인용 AI 운영체제'를 구축할 수 있게 진입장벽을 낮췄다는 점이다. 텔레그램이라는 이미 익숙한 채널을 인터페이스로 사용하고, 대시보드와 완전히 동기화되므로 PC와 모바일을 오가며 하나의 연속된 대화 맥락을 유지할 수 있다. 또한 예약 작업, 칸반 보드, 다중 하위 에이전트 할당 등 Claude Code나 Codex의 '루틴' 기능과 유사한 기능을 제공해, 코딩 에이전트에 익숙한 사용자가 위화감 없이 전환할 수 있도록 설계되어 있다.

04전략적 의미

이 영상이 보여주는 흐름은 AI 에이전트 인프라가 '개발자 전용 VPS 설정'에서 '누구나 몇 분 안에 쓰는 관리형 서비스'로 이동하고 있다는 신호다. 월 6달러라는 낮은 진입 비용과 원클릭 설치는 그동안 서버·Docker·SSH 지식 부족으로 개인 AI 비서 구축을 미뤄온 잠재 사용자층을 크게 넓힐 수 있다. 동시에 기존 ChatGPT/Codex 구독을 그대로 재사용할 수 있게 한 점은, 사용자가 API 종량 과금 대신 이미 지불 중인 구독을 활용해 추가 비용 부담 없이 에이전트를 운영할 수 있게 해준다는 점에서 실질적인 비용 효율 전략이다.

다만 관리형 방식은 유연성과 맞바꾼 편의성이라는 점도 함께 읽어야 한다. 기본적으로 에이전트 하나만 제공되고 세부 서버 설정에 대한 통제권이 제한되므로, 여러 에이전트를 동시에 운영하거나 n8n 같은 별도 자동화 도구를 한 서버에 얹고 싶은 사용자는 결국 VPS로 이전해야 한다. 즉 이 영상은 '입문 단계에서는 관리형으로 시작하고, 필요에 따라 VPS로 확장한다'는 단계적 채택 전략을 암묵적으로 제시하고 있으며, 이는 개인 AI 인프라를 처음 구축하는 사람들에게 실질적인 의사결정 기준이 된다.

06활용 시나리오

  1. 서버·Docker·SSH 지식이 전혀 없는 1인 사업자나 프리랜서가 월 6달러 수준의 비용으로 텔레그램을 통해 언제 어디서나 접근 가능한 개인 AI 비서를 구축하는 경우.
  2. 이미 GitHub에 개인 파일 구조, 프로젝트, 비즈니스 정보를 정리해 둔 사용자가 Hermes 에이전트에게 저장소를 학습시켜 자신의 맥락을 이해하는 맞춤형 비서로 활용하는 경우.
  3. Tavily 같은 외부 리서치 API를 연동해, 에이전트가 최신 정보(예: 음성 AI 에이전트 시장 동향)를 웹에서 조사하고 출처와 함께 보고하도록 활용하는 경우.
  4. 예약 작업과 칸반 보드 기능을 이용해 여러 하위 에이전트에게 반복 업무를 할당하고 진행 상태를 한 화면에서 관리하는 경우.
  5. Excalidraw 다이어그램 작성처럼 기존에 Claude Code 등에서 쓰던 커스텀 스킬을 YAML 프런트매터 형식으로 그대로 이식해 Hermes에서도 동일하게 활용하는 경우.

07현황 및 전망

현재 Hermes Agent는 Hostinger를 통해 관리형(Managed)과 VPS 두 가지 배포 방식으로 제공되며, 이번 영상은 그중 진입장벽이 가장 낮은 관리형 방식에 초점을 맞췄다. 화자는 명시적으로 "오늘은 기본 설정만 다뤘다"고 밝히며, 시청자 반응에 따라 스킬 심화 활용이나 다양한 설정 방법을 다루는 후속 영상을 제작할 의향을 내비쳤다. 이는 Hermes/Hostinger 생태계가 아직 초기 소개 단계에 있으며, 향후 스킬 마켓플레이스 확장, 다중 에이전트 협업, 메모리·개인화 기능 고도화 등으로 콘텐츠가 이어질 가능성을 시사한다.

전반적으로 이 사례는 개인용 AI 에이전트 인프라 시장이 클라우드 호스팅 업체(Hostinger)와 결합해 '원클릭 SaaS화'되는 흐름을 보여준다. VPS의 유연성과 관리형의 단순함 사이에서 사용자가 자신의 성장 단계에 맞춰 선택할 수 있는 구조가 자리 잡고 있으며, 텔레그램·ChatGPT 구독 등 기존에 널리 쓰이는 도구와의 연동이 채택을 가속하는 핵심 요인으로 작용하고 있다.
