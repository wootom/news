스페이스X는 왜 커서를 샀나 — 토큰 이코노미에서 AI 데이터센터 전쟁으로

채널: 티타임즈TV · 게시: 2026-07-04 · 길이: 약 31분 (박종천 지란지교소프트 CAIO 인터뷰)

01핵심 개요

항목내용
한 줄 요약AI 경쟁의 무게중심이 "모델"에서 "토큰을 만드는 GPU·전기"로 이동 → AI 데이터센터를 쥔 회사가 주도권
핵심 프레임토큰 이코노미의 하부구조 = GPU 개수 + 전력. 수요가 공급을 넘어 토큰 값이 오르는 국면
상징적 사건스페이스X가 상장 직후 첫 인수로 코딩 에이전트 회사 '커서' 매입 → 코딩 에이전트가 최대 전쟁터임을 방증
계층 서열(추정)AI 데이터센터: Azure > AWS > GCP > Colossus(XAI, GPU 22만)
신뢰도 유의GPU 보유량·AI 매출 순위는 대부분 비공개 추정치. 스페이스X-구글 콜로서스 렌트의 실수요/상장용 여부는 불명

02AI 발전의 4단계 — 지금은 '에이전트 전쟁'

  • 2023~25: 모델 전쟁(오픈AI·앤트로픽·제미나이)
  • ~2025: 일반 AI 전쟁(ChatGPT·Claude·Gemini 챗)
  • 2026: 코딩 에이전트 전쟁 — 6개사 격전(GitHub Copilot·Cursor·Claude Code·Codex·Amazon Kiro·Google Antigravity)
  • 병행 진행: 업무 에이전트 전쟁 — M365 Copilot 압도적, Claude Cowork 부상(아직 2파전)
  • 포인트: "코딩"이 아니라 "에이전트"에 방점 — 일을 쪼개 자율 수행하는 프레임워크. 챗에 시키는 것과 근본적으로 다름

03왜 코딩 에이전트가 먼저 터졌나

  • 개발 업무는 스펙·테스트가 명확 → 결과물을 논리적으로 정확히 평가 가능 → 에이전트에 최적
  • 실수요 폭증: 우버가 3개월 만에 1년치 AI 예산 소진, 기업들 억 단위 토큰 소비 → "차라리 사람이 싸다"는 말까지
  • 스페이스X 상장 직후 커서 인수 = 로켓 회사가 코딩 에이전트를 살 만큼 큰 전쟁터

04토큰의 하부구조 — GPU·전기가 병목

  • GPU 가격 두 달 새 2배, "주식 말고 GPU를 사라"는 농담. 돈 있어도 못 구함(엔비디아 물량·전력 제약)
  • 오픈AI·앤트로픽은 자체 DC 없음 → 오픈AI=MS 인프라, 앤트로픽=AWS 학습·서빙 의존
  • 추상화 레이어: AWS Bedrock처럼 클라우드가 모델 위에 캡슐화 → 개발자는 숫자 하나로 모델 교체, 헤게모니는 클라우드로
  • 오케스트레이션: 쉬운 일=싸고 빠른 모델, 어려운 일=비싼 모델, 결과 캐시 재사용 → 에이전트가 모델에 종속 안 되게 설계

05데이터센터 서열과 렌트 사슬

계층상태
AzureGPU 최다 보유·AI 매출 1등 추정(MS가 실적 대비 GPU 투자에 대거 지출)
AWS클라우드 1등, Bedrock으로 오픈소스·중국 모델까지 서빙
GCPTPU 자체 보유하나 제미나이 무료 남발로 자체 물량도 부족
Colossus(XAI)GPU 22만 개, 세계 4위급. 10%만 자가 사용, 나머지를 앤트로픽·구글에 렌트
  • 앤트로픽: AWS+구글 TPU로도 부족해 콜로서스에서 고가 렌트(클로드 코드 수요 못 받는 상태)
  • 구글: TPU 부족으로 콜로서스 렌트(+구글은 스페이스X 투자자라 상장 조력 의혹도)
  • 한국: 엔비디아와 GPU 22만 개 도입 협상 = 콜로서스급, 성사 시 세계 2~3위 보유국

06마진 전쟁 — "본체 무료, 코파일럿이 돈"

  • MS 365 전체가 월 $36인데 Copilot 단독이 $30 → 본체가 사실상 무료로 수렴, 수익은 Copilot
  • 라인업 다양화 흐름($50·$100·$200 등 Claude Code식)
  • 구글은 서비스 전부 무료 + 제미나이 유료 부착 모델 → 점유율은 넓히나 "1등 전장"이 없음(모델·코딩·업무 모두 2~3등)

07현황 및 전망

  • 확정 흐름: 코딩 에이전트 6파전, 업무 에이전트로 확산, GPU·전력이 실질 병목
  • 시그널: 구글 딥마인드 핵심 과학자(노벨상 수상자 존 점퍼) 앤트로픽 이직 → 인재·문화 이동 주시
  • 관전 포인트: ① 최종 수익은 워크 에이전트 vs 모델 vs 데이터센터 중 누구에게 ② Azure 우위의 지속성 ③ 구글의 무료 남발이 '승자의 저주'가 될지 ④ 반도체·전력 공급 탄력성(급증 불가, 위탁생산 의존)
  • 투자 관점: DC를 "건물주"로 비유 — 한 번 세팅하면 이전 곤란, GPU·전력 선확보 기업이 내년~내후년 매출 주도 예상

08용어 사전

용어한줄 설명비유/예시
토큰 이코노미AI가 처리하는 토큰량이 곧 매출·비용이 되는 경제 구조전기요금처럼 쓴 만큼 과금
코딩 에이전트개발 작업을 자율로 쪼개 수행하는 AI스스로 일하는 신입 개발자
업무 에이전트문서·분석 등 일반 업무를 자율 수행하는 AI알아서 보고서까지 만드는 비서
서빙(serving)학습된 모델을 실사용자에게 응답시키는 것완성된 요리를 손님에게 내는 홀
BedrockAWS가 여러 모델을 감싸 제공하는 API 레이어여러 브랜드를 파는 편의점 매대
ColossusXAI의 초대형 AI 데이터센터(GPU 22만)거대한 발전소형 서버창고
오케스트레이션작업 난이도별로 모델을 골라 쓰는 배분일마다 다른 전문가 배치
