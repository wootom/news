오픈AI의 200달러 프로 판매 중단은 아스트라 비용과 정액제 부담을 드러냈다.

아스트라 수요 폭증 뒤 200달러 프로만 막힌 배경을 정액제 비용 구조로 분석했다.

01핵심 개요

  • 오픈AI는 9월 11일 수요 과다를 이유로 200달러 프로 요금제의 신규 구매와 상위 전환을 중단했다.
  • 9월 3일 공개된 GPT-6 아스트라 뒤 플러스·프로 이용자의 사용 한도 소진 보고가 이어졌고, 샘 알트먼은 롤아웃 문제를 인정했다.
  • 200달러 프로는 채팅에서 아스트라를 주간 200회 쓸 수 있어, 아스트라 사용량이 가장 큰 정액 요금제다.
  • 영상은 아스트라 API 출력 가격이 100만 토큰당 50달러라는 점을 근거로 정액제 수익성 문제를 제기한다.
  • 다만 실제 원가, 서비스용 GPU 부족, 판매 중단의 단기성은 확인되지 않은 변수로 함께 제시됐다.

02핵심 주장 / 논점 구조

  • 영상은 200달러 프로 판매 중단이 단순한 용량 부족뿐 아니라 고사용자 정액제의 계산 문제와 연결된다고 본다.
  • 오픈AI 공식 설명은 프로 요금제가 인프라 부담이 가장 커서 많은 이용자에게 서비스를 열기 위한 최소 조치라는 것이다.
  • 영상의 해석에 따르면 GPU가 부족한 상황에서 정액제로 많이 쓰는 이용자보다 사용량 과금 API와 낮은 한도 요금제를 우선한 결정이다.
  • 이 해석은 API 가격이 원가와 다르며, 실제 서비스 GPU가 물리적으로 부족할 가능성도 있다는 단서를 전제로 한다.

03아스트라 출시 뒤 이어진 판매 중단

  • 9월 3일 오픈AI는 자사 최대 학습 모델이라고 소개된 GPT-6 아스트라를 공개했고, 9월 4일부터 유료 이용자에게 본격 배포했다.
  • 배포 당일 플러스 이용자는 5시간 한도를 수분 만에 썼고, 200달러 이용자는 일주일 한도를 하루에 소진했다는 보고가 나왔다.
  • 샘 알트먼은 9월 4일 롤아웃이 지저분했다고 인정했고, 오픈AI는 9월 6일 같은 작업의 사용량을 3~4배 덜 쓰도록 패치했다.
  • 제품 책임자는 9월 9일 아스트라 수요가 전례 없다고 밝혔으며, 이틀 뒤 200달러 프로 신규 판매가 중단됐다.

04차단 범위와 아스트라 접근 요금제

  • 중단 대상은 200달러 프로의 신규 구매와 무료·고·플러스·100달러 프로에서 해당 요금제로 올라가는 전환이다.
  • 기존 200달러 프로 이용자는 계속 이용할 수 있으며, 재판매 시점은 정해지지 않았다고 영상은 설명한다.
  • 플러스는 월 20달러, 프로는 월 100달러, 프로 20배는 월 200달러로 소개되며 200달러 요금제는 플러스의 20배 사용량을 뜻한다.
  • 채팅에서 아스트라를 쓰려면 프로가 필요하고, 100달러 프로는 주 50회, 200달러 프로는 주 200회 아스트라 사용이 가능하다.

05GPT-6 아스트라의 성능과 비용 특성

  • 영상은 아스트라가 텍사스 스타게이트에서 GPU 10만 개 이상을 사용한 오픈AI 역사상 가장 큰 학습 모델이라고 전한다.
  • 그레그 브록먼은 발표에서 AGI 시대에 들어섰다고 말해도 이상하지 않다는 표현을 사용했다고 소개됐다.
  • 아스트라는 스프레드시트 조작, 폼 입력, 웹페이지 탐색 등 컴퓨터 사용과 코딩 능력을 강점으로 내세운 모델로 설명된다.
  • 보안 취약점 탐지 능력으로 오픈AI 내부 기준 최고 위험 등급을 받았고, 보안 파트너와 유료 이용자에게 단계적으로 제공됐다.

06정액제 손익과 API 가격 비교

  • 샘 알트먼은 2025년 1월 X에서 이용자들이 예상보다 많이 써서 프로 구독으로 돈을 잃고 있다고 밝힌 바 있다.
  • 영상에 따르면 아스트라 API 출력 가격은 100만 토큰당 50달러로, 직전 모델 솔보다 2.5배이며 빠른 모드에서는 다시 2배가 붙는다.
  • 영상은 출력 400만 토큰이 API 가격 기준 200달러에 해당하며, 코딩 에이전트 사용 시 하루에 이 정도를 쓸 수 있다고 계산한다.
  • API는 사용량만큼 과금하지만 200달러 프로는 월 정액이어서, 영상은 사용량이 큰 이용자일수록 회사의 손실 가능성이 커진다고 해석한다.

07과거 제한 사례와 향후 요금제 전망

  • 오픈AI는 2023년 11월 DevDay 직후에도 사용량이 용량을 넘었다며 플러스 신규 가입을 막았고, 한 달 뒤 재개했다.
  • 영상은 당시에는 이용자 수 급증이 원인이었지만 이번에는 아스트라로 한 이용자당 사용량이 증가한 점이 다르다고 구분한다.
  • 빠른 모드까지 사용하면 같은 프로 이용자의 자원 사용이 이전보다 6배 가까이 늘 수 있다는 계산이 영상에서 제시됐다.
  • 영상은 200달러 요금제가 재개되더라도 한도가 바뀌거나 아스트라 사용량이 별도로 배정될 수 있다고 전망하며, 이는 해석임을 밝힌다.

08용어 사전

용어뜻
GPT-6 아스트라9월 3일 공개된 오픈AI의 최대 학습 모델로, 채팅·코딩·컴퓨터 사용 능력과 높은 사용 비용이 함께 언급됐다.
프로 20배월 200달러 요금제로 소개되며 플러스 대비 20배 사용량과 채팅 기준 주 200회 아스트라 접근을 제공한다.
코덱스요금제별 사용량 비교가 제시된 오픈AI의 코딩 관련 서비스로, 플러스에서도 아스트라 사용이 가능하다고 설명됐다.
API토큰 사용량만큼 비용을 내는 방식으로, 영상은 정액형 프로 구독과 대비해 손익 구조를 설명했다.
빠른 모드아스트라 API에서 사용 시 가격이 기본 가격의 2배로 붙는 모드로 영상에서 소개됐다.
