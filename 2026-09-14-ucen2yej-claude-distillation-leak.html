중국 AI의 클로드 증류 경로로 고객 민감 정보가 역유출됐다는 주장이다.

클로드 증류용 중계 경로에 키미·딥시크 고객의 CCTV·접속 정보까지 섞였다는 주장이다.

01핵심 개요

  • 앤트로픽은 문샷 AI와 딥시크가 클로드 성능을 가져오기 위한 대규모 증류 작업을 했다고 주장했다.
  • 문샷 AI의 키미 관련 요청은 프록시 계정을 거쳐 Claude Office로 전달됐으며, 열흘간 실제 고객 요청 약 30만 건이 포함됐다.
  • 보고서에는 중국 청두 지역 수백 대 CCTV 감시 자료, 공항국 사건 관리 시스템 개발 요청 등이 클로드로 전송된 사례가 담겼다.
  • 딥시크 관련 사례에서는 러시아 국방부 연관 정부 기관 데이터베이스의 실제 접속 자격 정보가 중계됐다고 설명됐다.
  • 영상은 에이전트형 AI 시대에는 입력 문장뿐 아니라 AI가 열람한 파일과 데이터의 실제 전송 경로를 확인해야 한다고 지적한다.

02핵심 주장 / 논점 구조

  • 앤트로픽 보고서는 문샷 AI와 딥시크가 경쟁 모델 클로드의 출력과 추론 방식을 확보하려 했다고 주장한다.
  • 증류용으로 구축된 중계 경로에 실제 고객 요청이 섞이면서 문서, 코드, CCTV 자료, 접속 정보까지 이동했다는 것이 핵심이다.
  • 사용자는 키미나 딥시크 화면에서 서비스를 이용했지만 일부 요청은 Claude Office로 전달됐다고 보고서는 설명한다.
  • 영상은 모델 학습 재사용 여부와 별개로, 요청 처리 과정에서 데이터가 누구에게 전송되는지가 문제라고 구분한다.

03키미 프록시 중계와 30만 건 고객 요청

  • 앤트로픽이 파악한 구조에서 키미 사용자의 일부 요청은 프록시 계정을 거쳐 Claude Office로 넘어갔다.
  • 클로드의 응답은 다시 키미 사용자에게 전달돼, 사용자는 키미가 직접 답변한 것으로 인식했을 수 있다.
  • 앤트로픽은 열흘 동안 실제 고객 요청 약 30만 건이 이 방식으로 클로드에 전달됐다고 밝혔다.
  • 이 과정에 사용된 프록시 계정은 5,000개 이상이었으며, 문샷 AI는 질문과 클로드 답변을 모델 개발에도 활용한 것으로 설명됐다.

04CCTV와 중국 공항 데이터가 포함된 사례

  • 키미 사용자 사례에서는 중국 청두 지역 수백 대 CCTV 감시 자료로 특정 인물의 행동을 분석하는 요청이 언급됐다.
  • 앤트로픽은 일부 자료에 중국 군시설, 국영기업, 연구 기관 주변 카메라가 포함됐다고 설명했다.
  • 보고서는 여러 정황을 토대로 해당 사용자가 중국 인민해방군과 연관됐을 가능성을 높게 평가했지만, 실제 관계자로 확인된 것은 아니라고 영상은 강조했다.
  • 중국의 한 공항국을 위해 신분증 번호, 이동 내역, 경찰 기록을 대조하는 사건 관리 시스템 개발 요청도 클로드로 전달됐다고 한다.

05딥시크와 러시아 정부 DB 접속 정보

  • 앤트로픽에 따르면 딥시크는 Claude Code나 OpenCode 등 코딩 도구로 자사 모델을 이용한 일부 사용자를 식별해 Claude Office로 요청을 전달했다.
  • 러시아 국방부와 연관된 정부 기관의 데이터를 다루던 IT 담당자 요청에는 실제 사용 중인 정부 데이터베이스 접속 정보가 포함됐다.
  • 영상은 이것이 러시아 군사기밀이나 데이터베이스 내부 자료가 미국으로 넘어갔다는 뜻은 아니라고 선을 그었다.
  • 보고서에는 앤트로픽이 해당 접속 정보로 데이터베이스에 들어가거나 내부 자료를 가져갔다는 내용도 없다고 설명했다.

06추론 흔적 확보와 대규모 증류 규모

  • 증류는 우수 모델의 출력물을 다른 모델 학습 재료로 이용하는 기술이며, 영상은 기술 자체가 AI 업계에서 정상적으로 사용된다고 설명한다.
  • 앤트로픽이 문제 삼은 부분은 서비스 제한을 우회해 클로드를 대규모 호출하고 결과를 경쟁 모델 개발에 활용했다는 점이다.
  • 보고서에 따르면 문샷 AI는 Claude API의 thinking signature 값을 저장한 뒤 다른 세션에서 재사용하는 크로스세션 리플레이를 시도했다.
  • 앤트로픽은 2026년 5월부터 7월까지 문샷 AI 귀속 증류 관련 교환이 2,300만 건 이상, 딥시크는 7월 약 2주간 1,210만 건 이상이었다고 밝혔다.

07기업 업무와 에이전트 시대의 데이터 경로

  • 제약회사 직원이 2026년부터 2028년 해외 생산시설 확장과 지역별 투자 계획이 담긴 내부 CAPEX 자료 분석을 AI에 맡긴 사례가 언급됐다.
  • 다른 개발자는 알림봇 오류를 해결하려고 텔레그램 봇 토큰과 페이스크립트·노션 연동 키가 들어 있는 설정 파일을 제시했다.
  • 영상은 코딩 에이전트가 프로젝트 파일, 설정 파일, 터미널 로그, 저장소 전체를 열람하며 API 키와 서버 주소까지 볼 수 있다고 설명한다.
  • 향후에는 사용자가 입력한 비밀뿐 아니라 AI가 업무 중 무엇을 열람했고 그 정보가 실제 어디까지 갔는지 확인해야 한다고 주장한다.
