2. 카카오톡 봇 개발 및 운영 관련

  • 카카오톡 오픈클로봇 (Openclawbot):

* 카카오톡 오픈클로봇이 중단된 것인지, 혹은 카카오톡 업데이트로 인해 작동이 막힌 것인지에 대한 질문이 있었습니다. * 일부 사용자들은 "비공식이라 한때 잘 썼다가 다 죽은 것 같다"고 언급했지만, 다른 사용자들은 "여전히 잘 작동한다", "업데이트 딱히 영향 없다"며 정상 작동을 보고했습니다. * 문제가 발생할 경우 다시 로그인하고 문제를 찾아 복구하면 된다는 경험 공유도 있었습니다.

  • 카카오톡 봇 계정:

* 오픈클로봇 사용 시 듀얼번호나 별도의 카카오톡 계정이 필요한지에 대한 질문이 있었고, 본계정 사용 시 밴 위험이 있어 듀얼번호나 서브폰 사용이 권장되었습니다. * 해외폰으로는 오픈채팅이 불가능하다는 정보도 공유되었습니다.

  • 카카오톡 봇 활용:

* 오픈채팅을 지식 관리용으로 활용하는 방법(혼자 입장 가능), 지역 모임 활용, 대화 요약/뉴스봇 활용 등 다양한 사용 사례가 언급되었습니다. * 맥 환경에서는 대화 내보내기 자동화도 가능하다고 합니다.

  • 카카오톡 봇 아키텍처:

* kakaocli sync --follow를 이용한 SQLite DB 폴링 방식으로 봇을 구성한 아키텍처 예시가 공유되었습니다. * kakao-math-bridge.py가 트리거 감지 및 허용 채팅방 필터를 통해 openclaw agent로 위임하고 agent-kakaotalk message send로 답장하는 방식이었습니다. * 이 방식의 반응 속도가 즉각적이지 않다는 의견과, 실시간 감지 대신 쿨타임을 주거나 챗아이디를 활용하여 관리자 식별을 하는 등의 팁이 공유되었습니다. * '뽀짝이' 봇의 전체 아키텍처도 공유되었습니다.

  • CLI 툴: kakaocli와 kmsg에 대한 논의와 테스트 결과가 공유되었습니다. kmsg는 작동하지만 좀 느리다는 피드백이 있었습니다.
  • 봇 인증 문제: agent-messenger 사용 시 인증이 자꾸 풀리는 문제와, 이를 해결하기 위해 ID/PW를 직접 던져주거나 주기적으로 재로그인하는 방식 등이 언급되었습니다. 1년짜리 인증 토큰 사용에 대한 언급도 있었습니다.

3. AI 모델 (클로드, 오픈AI, 코덱스 등) 활용 및 정책

  • 클로드 (Claude) API 변경 및 요금제:

* Claude CLI 방식이 6월 15일부터 막힌다는 사실(오피셜)이 공유되었습니다. * Max 20x 플랜 구독자들이 Agent SDK 및 타사 도구 사용 시 매월 $200 크레딧을 받게 되며, 이는 기존 구독 한도와 별개로 처리된다는 내용이 공유되었습니다. * Agent SDK 사용량에 대한 정책 변경이 있었고, 기존 claude -p 사용량과 별개로 Agent 전용 사용량이 할당될 것이라는 내용이 있었습니다. * 추가 크레딧의 제한적인 사용량 ($200으로 1~2일 내 소진 가능성)에 대한 우려와, 오푸스 모델을 꼭 사용해야 할 때만 추가 사용량을 활용하는 구조 설계에 대한 논의가 있었습니다.

  • 오픈클로(Openclaw) vs 헤르메스(Hermes):

* 두 플랫폼 모두 최근 많이 개선되었다는 의견이 있었습니다. * 오픈클로를 계속 사용하는 이유로 기존 구축 기반, 클로드 백엔드 CLI 방식 종료 후 코덱스(GPT 모델) 구독의 안정성, "뽀짝이 소울" (개인적 취향) 등이 언급되었습니다.

  • 클로드 사용량 제한:

* 클로드 3만원 결제 시 하루 5시간 제한이 아니라, 5시간마다 제한량이 리셋되는 방식이며, 사용량에 따라 1시간 만에도 동날 수 있다는 설명이 있었습니다.

  • 크롤링 성능:

* 크롤링 능력에 있어서는 클로드와 안티그래비티(구글)가 우수하고, 코덱스는 요약하는 느낌이 강하다는 사용자 경험이 공유되었습니다.

  • AI 자체 학습 기능:

* 오픈클로가 스스로 시뮬레이션을 통해 문제점을 찾고 개선점을 말하는 자가 학습 기능(RSI와 유사)이 발견되었다는 경험이 공유되었습니다.

  • 국산 AI 모델 (엑사원, 독파모, 솔라 등):

* 엑사원이 높은 수준이지만 아직 갈 길이 멀다는 평가와 함께, 11월에 전국민에게 무료로 제공될 '독파모' 모델에 대한 기대감이 언급되었습니다. * 한국의 AI 기술 현황과 글로벌 기업 AI 도입에 대한 아쉬움도 있었습니다.
