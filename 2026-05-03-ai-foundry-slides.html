Curriculum — Module 01·02

기초 & 엔지니어링

MODULE 01 · AI Fundamentals · 3h
  • Rule-based → Transformer → Agentic AI 4세대 진화
  • 미국 3강 + 글로벌 도전자 모델 시장 비교
  • 요청·응답 파이프라인 8개 구간 — 비용·속도 최적화
핵심: "좋은 모델"보다 "적절한 모델 선택"이 역량이다
MODULE 02 · Engineering · 4h
  • 프롬프트 · 컨텍스트 · 하네스 3대 프레임워크
  • ReAct · Tool Calling · MCP · A2A · Agentic Loop
  • Reflection · Tool Use · Planning · Multi-Agent 4대 패턴 구현
  • 역할별(BizUser/PM/개발자) 에이전트 셋업
핵심: 프레임워크 없이 Raw 구현 → 프레임워크의 존재 이유를 안다

Curriculum — Module 03·04

접점 전략 & Vibe Planning

MODULE 03 · AI 접점 전략 · 3h

Key Takeaways

3가지 핵심 메시지

01
오케스트레이터가 돼라
AI를 하나만 쓰는 것이 아니라 여러 에이전트에게 역할을 분배하고 결과를 통합하는 지휘자가 돼라
02
데이터 품질이 AI 성능이다
AI 성능의 한계는 모델이 아니라 데이터 품질이 결정한다. 지식 자산 구축이 곧 AI 역량이다
03
3일 안에 배포하라
직접 프로토타입을 만들어 보여주는 사람이 기회를 잡는다. 배포 자동화 없이 1인 운영은 지속 불가능하다
