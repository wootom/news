사용 도구클로드 코드(데스크톱 앱), 클로드 프로 구독(약 월 24~28 캐나다달러), Fable 5·Opus 5 모델, GPT 이미지 API(OpenAI), 구글 드라이브·구글 시트, 클라우드 루틴(환경변수+API 키)
강의 성격실시간 빌드 시연 중심(일부 구간 편집 없이 그대로 노출), 세일즈 코스 아님을 명시하되 말미에 저자의 유료 프로그램(Maker School) 홍보 포함

02강의 커리큘럼 구조

  • 0. 인트로 — 코스 개요

- 강사 소개, 코스가 다룰 5가지 마케팅 기능과 전체 흐름 소개

  • 1. 클로드 코드 설치·설정

- claude.com 가입 → 결제(개인 사용 플랜) → 데스크톱 앱 다운로드·설치(Mac 기준 시연) - 인터페이스 투어: Home 탭 vs Code 탭, 아티팩트, 사용량/토큰 대시보드, 승인(Allow/Deny) 팝업, 검색·프로젝트 기능

  • 2. 마케팅 자동화 프레임워크

- 마케팅 성과를 좌우하는 레버 구조(Reach·Speed to Lead·Booking 비율 등) 설명 — 강사가 "RACE"식 모델의 R(Reach) 등을 언급하며 각 단계에서 AI가 개입할 지점을 매핑 - 프롬프트 → 스킬 → 루프 → 클라우드 루틴의 4단계 자동화 성숙도 모델 제시 (뒤 챕터마다 이 4단계를 순서대로 적용)

  • 3. 상단 퍼널(Top of Funnel) — 크리에이티브 자동화

- 광고 이미지/영상/오디오 소재를 템플릿 기반으로 대량 생성 (변형당 최소 5개 이상 생성해 크리에이티브 디렉터가 선별하는 구조) - 이미지 생성 프롬프트를 스킬화 → 매일 특정 시각(예: 오전 5:59)에 자동 실행되는 루프화 → 구글 드라이브 폴더 자동 생성·정리하는 클라우드 루틴화까지 단계별 시연

  • 4. 카피 개인화(Personalization of Copy)

- 뉴스레터·아웃바운드 콜드 이메일에 "퍼지 변수(fuzzy variable)" 개념 적용 — 수신자 정보를 AI가 웹에서 리서치해 문맥에 맞게 자연스럽게 채워 넣음 - 구글 시트와 연동해 리드별 맞춤 변수를 자동 채운 뒤 메일 머지 발송까지 연결

  • 5. 중단 퍼널(Middle of Funnel) — 스피드 투 리드 시스템

- 리드 발생 후 30초 내 AI가 대화를 시작하도록 만드는 예약(appointment booking) 자동화 - 실제 사례: 홈서비스 기업 월매출 300만 달러 → 900만 달러(3배)로 성장한 스피드 투 리드 구축 사례 소개

  • 6. 데이터 수집·트래킹·대시보드 구축

- 자체 애널리틱스 플랫폼을 클로드 코드로 스캐폴딩 → Fable 5로 고품질 디자인 스킨 적용 - SQL 기반 이상치(anomaly) 탐지로 "시그널" 자동 생성(예: 리드 급감, 전환율 급등, 영업담당자 승률 비교) - 클라이언트별 대시보드(20개 클라이언트, 수만 행 데이터) 구축 실비용 공유(세션당 약 12~13달러)

  • 7. 하단 퍼널(Bottom of Funnel) — 고품질 팔로업 자동화

- 이메일·SMS·알림 발송을 사람처럼 느껴지게 자동화하는 넛처링(nurturing) 시스템

  • 8. 시스템 유지·업그레이드 및 고급 팁

- 구축한 시스템을 지속적으로 점검·개선하는 방법 - 무엇을 자동화해도 되고 무엇은 안 되는지에 대한 원칙(6장 참조)

  • 9. 마무리

- 요약, 구독 요청, 저자의 90일 프로그램 Maker School 소개로 종료

03기술적·도구 맥락

구분내용
핵심 플랫폼클로드 코드(Claude Code) — 데스크톱 앱, 코드 실행형 AI 에이전트
모델Fable 5(강의 시점 최상위 모델, 고품질 디자인·복잡 분석용), Opus 5(범용, medium/high reasoning 옵션)
이미지 생성GPT 이미지(OpenAI API) — API 키를 클라우드 루틴 환경변수로 등록해 사용
자동화 계층프롬프트(1회성, PC에서 직접 실행) → 스킬(재사용 가능한 절차 저장) → 루프(로컬에서 스케줄 반복) → 클라우드 루틴(API 키 포함, 클라우드에서 무인 실행)
연동 서비스구글 드라이브(생성물 자동 저장·날짜별 서브폴더 구조), 구글 시트(리드 데이터·머지 변수), 클로드 브라우저(생성 결과 프리뷰·튜닝)
비용 감각클로드 구독 약 월 24~28 캐나다달러, 세션당 크레딧 소모(고사양 대시보드 빌드 1회 약 12~13달러 사례 제시)

04전략적 의미

  • 마케팅 자동화를 "완전 자동화 가능 영역"과 "사람이 남아야 하는 영역"으로 명확히 구분하는 실무적 프레임을 제시 — AI 만능론이 아닌 절제된 활용 원칙 강조
  • 프롬프트→스킬→루프→루틴이라는 자동화 성숙도 모델은 개인/소규모 팀이 단계적으로 무인 운영 시스템을 구축하는 실천 로드맵으로 기능
  • 크리에이티브·카피·데이터 분석처럼 반복적·검증 가능한 작업은 AI 위임, 반면 나쁜 소식 전달·관계 유지·최종 승인처럼 신뢰가 걸린 접점은 사람이 유지해야 한다는 원칙은 에이전시·SMB 마케팅 조직에 바로 적용 가능
  • 실제 매출 규모(월 50만 달러 에이전시, 3배 성장 사례)를 근거로 제시해 이론이 아닌 실행 가능한 사례 기반 학습을 지향

05핵심 워크플로우/방법론

단계내용
1. 프롬프트 실행원하는 결과를 자연어로 직접 지시, 실시간 확인·피드백
2. 스킬로 전환"이걸 스킬로 만들어줘" 지시로 반복 가능한 절차 템플릿화
3. 루프로 전환특정 시각에 자동 반복 실행되도록 로컬 스케줄 설정
4. 루틴으로 전환API 키 등 환경변수를 클라우드에 등록, 사람 개입 없이 클라우드에서 무인 실행
5. 검증 후 확장소규모 스모크 테스트(단일 이미지·소수 리드) 후 문제 없으면 대량 생성으로 확장
6. 상위 모델로 재작업저사양 모델로 초안 뒤 Fable 5(고품질) 등 상위 모델로 디자인·분석 정교화

06활용 시나리오

  • 광고 소재 대량 생산: 템플릿 1개당 최소 5개 변형(3개 템플릿×5=15개) 자동 생성 후 사람이 우승작만 선별, 이후 스킬·루프·루틴화해 매일 자동 배치 생성
  • 콜드 아웃바운드 개인화: 리드 명단(이름·회사·관심사 등)을 구글 시트에서 읽어 AI가 각자에게 맞는 문맥으로 이메일 초안을 자동 작성, 수치 근거 없는 과장 클레임은 배제
  • 리드 반응 30초 대응 시스템: 폼 제출 즉시 AI가 대화를 개시해 예약 전환율을 끌어올리는 스피드 투 리드 구조(홈서비스 기업 3배 성장 사례)
  • 클라이언트 성과 대시보드 자동 구축: 다수 클라이언트의 트래픽·리드·전환·영업 데이터를 통합 분석하고 이상 징후(리드 급감 등)를 자동 감지·시각화

07현황 및 전망

  • 강의 시점(2026-08) 기준 최신 모델(Fable 5)과 클로드 코드의 클라우드 루틴 기능을 활용한 실전 사례를 다루며, AI 에이전트 기반 마케팅 자동화가 개인·소규모 조직도 접근 가능한 수준까지 성숙했음을 보여줌
  • 강사는 향후 유사한 실전형 코스를 추가로 제작할 계획을 밝힘
  • 자동화가 과도해질 경우 고객 관계 훼손 위험을 스스로 목격했다며, "고객이 그 과정을 직접 체감하는지"를 자동화 여부 판단 기준으로 제시 — 향후 마케팅 자동화 논의에서 반복 인용될 만한 실무 원칙

08용어 사전

용어한줄 설명비유/예시
스피드 투 리드(Speed to Lead)리드 발생 직후(예: 30초 내) 즉각 응대해 전환율을 극대화하는 기법손님이 문 두드리자마자 바로 문을 여는 것
퍼지 변수(Fuzzy Variable)정형화된 데이터가 아니라 AI가 문맥을 리서치해 자연스럽게 채워 넣는 개인화 변수이름만 바꾸는 게 아니라 그 사람 관심사까지 반영해 문장을 새로 쓰는 것
프롬프트→스킬→루프→루틴1회성 지시에서 무인 클라우드 자동 실행까지의 자동화 성숙도 4단계손으로 만들기 → 레시피화 → 알람 맞춰 반복 → 자동 주방 로봇 가동
클라우드 루틴API 키 등 환경변수를 클라우드에 등록해 사람 개입 없이 실행되는 자동화 단위무인으로 돌아가는 공장 라인
시그널(Signals)대시보드에서 SQL 기반으로 자동 탐지되는 이상치·특이 패턴 알림평소보다 손님이 갑자기 확 줄었을 때 울리는 경보
