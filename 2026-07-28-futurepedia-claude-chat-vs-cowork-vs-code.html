Claude Chat vs Cowork vs Code: Which One Should You Use?

핵심결론 1Claude의 세 제품은 '생각은 Chat, 위임은 Cowork, 제작은 Code'라는 단순 프레임으로 선택하면 된다
핵심결론 2Chat은 한 턴(turn) 안에서 답을 주고 멈추지만, Cowork·Code는 목표 달성까지 2분에서 40분간 스스로 계속 작업하는 에이전트다

02핵심 내용 구조

세 제품과 접근 경로·요금

  • Claude에는 Chat, Cowork, Code의 세 핵심 제품이 있으며 claude.ai 웹, 모바일 앱, 데스크톱 앱의 세 표면(surface)에서 사용할 수 있다.
  • Chat은 무료 포함 모든 요금제에서 쓸 수 있지만 Cowork·Code는 유료 요금제가 필요하며, 데스크톱은 Pro 이상, 모바일·웹은 최근 추가되어 Max 이상부터(곧 Pro로 확대 예정) 지원된다.
  • 선택 프레임은 'Chat은 생각, Cowork는 위임, Code는 제작'으로 요약된다.

Chat: 생각의 파트너

  • Chat은 브레인스토밍·글쓰기·리서치·아이디어 정리를 위한 왕복 대화형 도구로, 프로젝트(영구 컨텍스트)·커넥터(이메일·캘린더 연결)·아티팩트(옆에 열리는 앱·문서 창)로 확장된다.
  • Chat이 파일을 만들거나 대시보드를 만들어도 모든 작업은 하나의 턴 안에서 끝난 뒤 사용자에게 넘겨지고 대기한다.
  • 결과물을 문서에 복붙하거나 이어붙이는 '잡일'을 하게 되면 그것은 잘못된 모드에 있다는 신호이며, 그 작업은 위임되었어야 한다.

Cowork: 위임하는 어시스턴트

  • Cowork는 질문이 아니라 '업무 배정'으로, 목표를 주면 체크리스트를 만들고 단계별로 처리하며 종종 서브에이전트로 멀티태스킹해 완성 결과를 가져온다.
  • Chat이 답을 주는 순간 끝나는 '자판기'라면 Cowork는 주문을 받아 재료를 모으고 여러 단계 레시피를 거쳐 완성해 내오는 '주방'에 비유된다.
  • Cowork는 데스크톱에선 사용자의 실제 컴퓨터를, 모바일·웹에선 클라우드의 새 샌드박스를 자체 작업 공간으로 확보해 세션 내내 작업을 축적한다.

Cowork의 두 버전: 데스크톱 vs 클라우드

  • 내부 시스템은 동일하고 실행 위치만 다르며, 로컬 파일 작업 여부가 핵심 차이다.
  • 데스크톱 버전은 실제 컴퓨터의 폴더를 배정하면 파일 열람·편집·생성·정리가 가능하지만, 모바일·웹 클라우드 버전은 컴퓨터가 꺼져 있어도 돌아가는 대신 로컬 파일에는 접근하지 못한다.
  • 발표자의 우회법은 원하는 파일을 Google Drive 폴더에 두고 커넥터로 연결해, 어느 표면에서든 컴퓨터 전원과 무관하게 파일을 다루는 것이다.

예약 작업(Scheduled Tasks)으로 무인 실행

  • 한 번 스케줄을 설정해두면 사용자 입력 없이 완전히 자동으로 실행된다.
  • 월요일 아침 자는 동안 지난주 이메일·회의록·고객 뉴스를 읽어 브리핑 문서와 초안 이메일을 미리 준비해두는 식의 무인 워크플로우가 가능하다.
  • 예약 작업은 디바이스가 온라인일 필요가 없어 컴퓨터·폰이 꺼져 있어도 계속 진행된다.

Code: 만드는 엔지니어

  • Code는 앱·웹사이트·자동화·크롬 확장·생산성 도구 등을 평문 영어 설명만으로 코드를 작성해 만들며, 개발자가 아니어도 사용할 수 있다.
  • 데스크톱에선 폴더를 배정해 그 안에 코드베이스 전체를 구축하고, 터미널·개발자 도구 없이 데스크톱 앱만으로 시작하는 것을 권장한다.
  • 모바일·웹에선 (1) 집 컴퓨터의 세션을 폰에서 원격 제어하거나 (2) GitHub 저장소(repo)를 붙여 클라우드 세션을 돌리는 두 옵션이 있다.

03기술적 맥락

  • Cowork와 Code는 계획·실행·지속을 담당하는 동일한 에이전트 코어를 공유하며, 로드되는 대상(파일·앱 vs 코드 저장소)만 다르다.
  • repo는 온라인에 존재하는 프로젝트 폴더이며, 없으면 무료 GitHub 계정으로 빈 저장소를 만들거나 데스크톱 작업을 GitHub에 푸시해 연결한다.
  • 모바일·웹 Cowork는 현재 베타이며 Mac 구독자에게만 우선 배포되어 있어 Pro 사용자는 아직 안 보일 수 있다.

04전략적 의미

  • 모드 구분을 이해하면 모든 일을 Chat으로 처리하며 스스로 조립 잡일을 하는 비효율에서 벗어날 수 있다.
  • 클라우드 실행 + 예약 작업 조합은 '기기 상시 가동'이라는 물리적 제약을 없애 자동 브리핑 등 상시 업무를 가능하게 한다.
  • '내가 원하는 도구가 있었으면 좋겠다'는 니즈는 Code로 직접 구현할 신호로, 소프트웨어 제작의 진입장벽을 크게 낮춘다.

05핵심 워크플로우·방법론

  • 대화가 곧 작업일 때(브레인스토밍·글쓰기·리서치·의사결정)는 Chat을 연다.
  • 여러 단계와 최종 산출물(문서·스프레드시트·리서치 리포트·정리된 폴더)이 있는 어시스턴트급 업무는 결과만 기술하고 Cowork에 위임한 뒤 완료되면 돌아온다.
  • '이런 도구가 존재했으면'이라는 문제는 Code로 기술해 엔지니어처럼 구축한다.

06활용 시나리오

  • 저녁 외출 중 분기 보고서 마감이 떠오르면 폰에서 클라우드 Cowork로 작업을 시작하고 완료 알림을 받아 귀가 후 검토한다.
  • 정기적으로 확인하는 사이트의 데이터를 긁어 포맷하는 도구나 내부 대시보드를 Code로 만든다.
  • 오래 미뤄둔 아이디어의 모바일 앱을 Code로 설명만 해서 프로토타입까지 구현한다.

07현황 및 전망

  • 모바일·웹의 Cowork·Code는 확장 배포 중이며, Pro 요금제로의 롤아웃이 임박해 접근성이 넓어지고 있다.
  • 에이전트형 실행(Cowork·Code)이 대화형(Chat)과 분명히 구분되면서 사용자의 작업 습관 자체가 재편되고 있다.
  • 언급된 Design은 아직 베타지만 강력한 신규 도구로, 용도 구분이 상대적으로 명확하다고 소개된다.

08용어 사전

용어한줄 설명비유·예시
턴(turn)Chat이 한 번 응답하고 멈추는 단위자판기에 넣고 한 번 나오는 결과
서브에이전트Cowork가 체크리스트 항목을 나눠 맡기는 보조 실행 주체주방의 여러 요리사
샌드박스클라우드에 새로 열리는 격리된 작업 환경임시로 빌린 별도 작업 책상
repo(저장소)온라인에 존재하는 프로젝트 폴더클라우드에 놓인 프로젝트 서랍
예약 작업무인·자동으로 정해진 스케줄에 실행되는 Cowork 작업알아서 도는 자동 예약 청소
