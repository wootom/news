클로드와 캡컷을 연결해 음성 지시로 인트로 편집을 반복 수정하는 과정을 소개한다.

클로드와 캡컷 드래프트를 연결해 말로 인트로를 만들고 반복 수정하는 편집 과정.

01핵심 개요

  • 영상 제작자는 캡컷과 GPT 또는 클로드를 함께 쓰되, 발음과 빠른 말속도 문제로 컷 편집은 수동으로 진행한다고 설명한다.
  • 자막 전사에는 하루 3건 무료인 TurboScribe를 사용하며, 고래 모델이 한국어 전사에서 가장 정확하다고 평가한다.
  • TurboScribe에서 수정한 SRT를 캡컷에 불러오고, 프리텐다드 엑스트라 볼드와 네 번째 스타일의 흐림 효과를 적용한다.
  • 클로드 에이전트가 캡컷 드래프트 JSON을 읽고 쓰도록 프로젝트 경로를 제공해 자막·트랙·세그먼트를 편집한다.
  • 초기 결과의 과도한 화면 전환은 컷 수를 15개 미만으로 줄이도록 재지시해 더 보기 편한 인트로로 수정한다.

02핵심 주장 / 논점 구조

  • 제작자는 AI가 영상을 100% 자동화하는 방식이 아니라, 사람이 결과를 확인하고 수정하는 하이브리드 방식을 선호한다고 말한다.
  • 말로 원하는 편집을 설명하면 타이핑보다 빠르게 구조를 전달하고 수정할 수 있다는 점을 작업 방식의 장점으로 제시한다.
  • 클로드나 GPT는 캡컷 프로젝트의 편집을 돕지만, 결과물의 컷 수·효과·구성은 반복 지시로 조정한다.

03원본 촬영본과 캡컷 프로젝트 준비

  • 먼저 인트로 촬영본을 녹화한 뒤 컴퓨터로 옮겨 폴더를 만들고, 캡컷에서 새 프로젝트를 생성한다.
  • 촬영본 폴더를 프로젝트에 업로드한 뒤 실제로 편집할 구간까지 타임라인에 배치한다.
  • 프로젝트 이름은 촬영일 기준으로 '9월 18일 인트로 촬영'처럼 변경해 관리하는 과정을 보여준다.
  • 캡컷의 자동 컷 편집은 말이 빠르고 발음이 부정확할 때 인식이 부정확해 수동으로 처리하는 편이라고 설명한다.

04TurboScribe 고래 모델로 SRT 자막 만들기

  • 캡컷 프로의 자막 생성 결과는 한국어 전사 품질이 좋지 않다고 평가하며 별도 전사 도구를 사용한다.
  • TurboScribe는 하루 3건까지 무료로 쓸 수 있고, 제작자는 유튜브 편집에 이 서비스를 이용한다고 말한다.
  • 파일을 업로드한 뒤 고래 모델을 선택해 전사하며, 이 모델이 가장 정확하다고 소개한다.
  • 전사 결과에서 틀린 단어는 전사 편집 화면에서 문장을 클릭해 수정한 후 SRT로 내려받는다.
  • 다운로드한 SRT 파일을 캡컷의 캡션 추가 기능으로 불러와 문장 단위 자막을 타임라인에 배치한다.

05캡컷 자막 스타일 적용 방식

  • SRT를 불러온 뒤 캡컷에서 문장에 맞춰 자막이 표시되는 상태를 확인한다.
  • 제작자는 자막 폰트로 프리텐다드 엑스트라 볼드를 주로 사용한다고 말한다.
  • 스타일 메뉴의 네 번째 스타일에서 흐림을 조정해 자막이 깔끔하게 보이도록 설정한다.
  • 무료 사용 시 앞부분에 워터마크성 요소가 보일 수 있으며, 이를 한 줄 방식으로 처리하는 모습을 보여준다.

06드래프트 경로와 클로드 에이전트 연결

  • 캡컷 내부의 User Data, Projects, LV Editor Draft 경로를 찾아야 클로드나 GPT가 프로젝트 파일을 다룰 수 있다고 설명한다.
  • 경로를 찾기 어렵다면 Claude Cowork에 캡컷 폴더를 추가하고 LV Editor 관련 폴더와 경로를 찾아 달라고 요청할 수 있다고 말한다.
  • 제작자는 자체 제작한 '캡컷 에디 에이전트'에 드래프트 폴더 경로를 전달해 인트로 인식 여부부터 확인한다.
  • 에이전트는 드래프트 JSON을 직접 읽고 쓸 수 있어 자막 수정, 트랙 추가, 세그먼트 배치가 가능하다고 결과를 제시한다.

07화면 전환 밀도 조정과 최종 반복 수정

  • 초기 지시에서는 체리필터 색상 브랜드 가이드라인과 문장·어절 단위의 잦은 화면 전환을 요청한다.
  • 계획은 Claude Fable 5.1로 세우고 실제 구현은 Claude Opus 4.5 모델로 진행하겠다고 구분해 요청한다.
  • 첫 결과는 화면 전환 수가 너무 많아 난잡하다고 판단하고, 세 어절 후 한 전환 수준으로 줄이며 컷 수를 15개 미만으로 요청한다.
  • 에이전트 설정 없이 Fable 5.1에 바로 요청한 결과는 더 단정하지만 사운드 이펙트와 아이콘이 부족하다고 비교한다.
  • 화면 중간의 검은색 띠가 마음에 들지 않는다는 음성 지시를 전달해 다른 애니메이션으로 대체하도록 다시 렌더링한다.

08용어 사전

용어뜻
TurboScribe제작자가 캡컷 자동 자막 대신 한국어 전사를 위해 쓰는 서비스로, 하루 3건 무료 사용이 가능하다고 소개된다.
고래 모델TurboScribe에서 선택하는 전사 모델로, 제작자는 한국어 전사 정확도가 가장 좋다고 설명한다.
SRT전사 내용을 수정한 뒤 내려받아 캡컷 캡션으로 불러오는 자막 파일 형식이다.
LV Editor Draft캡컷 User Data와 Projects 내부에서 찾아야 하는 드래프트 폴더 경로로, AI 에이전트가 프로젝트를 읽고 쓰는 데 사용된다.
드래프트 JSON클로드 에이전트가 직접 읽고 써서 자막 수정, 트랙 추가, 세그먼트 배치를 수행한다고 설명한 프로젝트 파일이다.
하이브리드 방식AI가 만든 편집 결과를 사람이 확인하고 필요한 부분을 직접 수정하는 제작자의 영상 편집 방식이다.
