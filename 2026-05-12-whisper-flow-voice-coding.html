왜 지금 음성 입력인가?

130 WPM
타이핑 속도
40~50 WPM
바이브 코딩 시대: AI에게 길고 디테일한 지시가 필요 → 프롬프트가 점점 길어짐 → 타이핑이 새 병목.
생각 속도의 절반도 안 되는 속도로 AI에게 지시하고 있다.
02
기존 음성 입력과 다른 점 3가지
차이점 1
필러 워드 자동 제거

"음... 어... 잠깐만..." → 삭제 후 깔끔한 문장만 출력. "아니 잠깐 그 부분 빼고요" → 앞말도 자동 제거.

차이점 2
컨텍스트 인식 톤 조정

Slack → "이거 한번 봐봐" (캐주얼)
GitHub PR → "이 부분 수정했습니다. 검토 부탁" (정형)
같은 말, 다른 맥락, 자동 변환.

차이점 3
한국어 인식 우수

영어권 도구이지만 한국어 전문 용어 정확 인식. "리액트 훅, useEffect, 셀렉트박스" 흘려 말해도 OK.

03
효과 극대화 vs 효과 없는 상황
효과 극대화
  • 마우스 호버 애니메이션처럼 디테일이 많은 긴 지시
  • 말하면서 새 조건이 자연스럽게 떠오르는 경우
  • 소파에 누워 코딩할 때
  • 긴 스크립트 작성 (이 영상 스크립트도 입으로 작성)
차이 없는 상황
  • 짧고 명확한 지시 ("함수 이름 바꿔줘")
  • 코드 한 줄 수정 등 단순 작업
