Fable 5.1, 원샷 디자인으로 AI 슬롭을 끝내고 ChatGPT 5.6을 압도하다

Jack Roberts가 Claude 진영 신규 디자인 모델 Fable 5.1을 실사용 테스트, 저렴하면서도 원샷 품질에서 ChatGPT 5.6을 앞선다고 결론.

01핵심 개요

  • Fable 5.1은 이전 버전 Fable 5 대비 가격은 낮추고 원샷 디자인 품질은 크게 향상됐다.
  • Referral 사이트 클론, Notion 클론, 향수병 365도 회전 등 3개 테스트에서 ChatGPT 5.6과 정면 비교했다.
  • Notion 클론 테스트에서 "Northern HQ"라는 완전히 독자적인 가상 브랜드 요소까지 창작했다.
  • 향수병 회전 애니메이션에서 ChatGPT는 루프가 어긋났지만 Fable 5.1은 한 번에 완벽한 루프를 생성했다.
  • 이미지·영상 생성 툴 OpenArt를 Claude Code CLI에 연동해 워크플로를 확장하는 방법도 함께 시연했다.

02핵심 주장 / 논점 구조

  • 벤치마크 점수보다 실제 결과물이 중요하다 — 진행자는 "벤치마크 퀸을 원하지 않는다"며 데모 위주로 비교를 진행했다.
  • Fable 5.1은 긴 작업(long-running work)에 강하고, 토큰당 산출 품질(효율)이 이전보다 개선됐다.
  • 동일 프롬프트·동일 레퍼런스를 두 모델에 주고 비교했을 때 애니메이션의 "크리스프함"과 디테일에서 격차가 뚜렷했다.
  • 도구(이미지·영상 생성) 연동 여부가 결과물의 완성도를 좌우한다 — Fable 5.1 단독이 아니라 OpenArt 같은 보조 툴 결합이 핵심.
  • ChatGPT 5.6도 특정 영역(속도 등)에서는 여전히 쓸모 있으며, 곧 출시될 "Astra" 모델로 경쟁 구도가 다시 바뀔 수 있다고 전망했다.

03워크플로우 데모 — 3개 원샷 테스트

  • 테스트 1: Referral 참고 사이트 클론. Referral 사이트 URL을 주고 "이걸 참고해서 더 낫게 만들어 달라"고 요청. Fable 5.1은 스크롤 애니메이션이 매끄럽고 여백·간격 처리가 정돈된 반면, ChatGPT 5.6 결과물은 스크롤 애니메이션이 덜 정교하고 섹션 간 간격(gap)이 어색했다.
  • 테스트 2: Notion 웹사이트를 "AI 버전"으로 재해석. Fable 5.1은 원샷으로 진행자 본인의 사진, 팀 멤버, 로고, 자체 브랜드명 "Northern HQ"(Notion의 "Rampage HQ"에 대응하는 독자적 창작물)까지 만들어냈다. 다만 동료 사진 캡션이 부적절하게 생성되는 해프닝도 있었다. ChatGPT 5.6은 다크모드 기반의 전혀 다른 톤으로 재해석했으나 바로 실사용하기엔 부족하다는 평가.
  • 테스트 3: 향수병 365도 회전 애니메이션. ChatGPT는 회전 루프가 완벽하게 이어지지 않았고, Fable 5.1(Claude)은 흠 없는(flawless) 루프를 한 번에 생성했다.
  • 추가 사례: save.com에서 발견한 "call us / push deploy" UI 컴포넌트를 진행자 이름으로 재구성 요청하자 코드 전체를 포함해 한 번에 완성했고, 팟캐스트 브랜드 자산 URL을 주자 브랜드 가이드라인 시스템 전체를 구축했다.

04전략적 의미

  • 원샷 디자인 품질이 상향되면 초기 프로토타이핑·클라이언트 데모 단계에서 디자이너·개발자 리소스 투입 시점을 늦출 수 있다.
  • 모델이 비용까지 낮아지면서 "저비용·고품질 원샷" 조합이 1인 창업자·소규모 팀의 웹사이트 제작 비용 구조를 바꿀 잠재력이 있다.
  • 이미지·영상 생성 도구(OpenArt)를 CLI로 연동하는 흐름이 대중화되면 Claude/ChatGPT 등 범용 LLM이 사실상 풀스택 디자인 에이전트로 기능하게 된다.
  • "안티-AI-슬롭" 후처리(Slop Monster) 같은 별도 레이어가 결합돼야 실사용 가능한 카피·문체가 나온다는 점은, 디자인 자동화가 텍스트 자동화보다 한발 앞서 있다는 시사점을 준다.

06활용 시나리오

  • 스타트업이 랜딩페이지 초안을 하루 만에 뽑아 투자자 데모나 초기 트래픽 테스트에 활용.
  • 에이전시가 클라이언트 브랜드 자산 URL만 던져서 브랜드 가이드라인 시안을 자동 생성한 뒤 다듬는 워크플로.
  • 마케터가 제품 회전 영상(360도 제품 뷰) 같은 반복적 애니메이션 에셋을 광고 소재로 즉시 확보.
  • 콘텐츠 팀이 AI로 초안 카피를 뽑은 뒤 Slop Monster류 도구로 "AI 티" 나는 문장을 세일즈 톤으로 재작성.

07현황 및 전망

  • Fable 5.1은 현재 원샷 웹 디자인·애니메이션 품질에서 ChatGPT 5.6의 최고 모델을 앞서는 것으로 나타났으나, 진행자는 실사용을 위해서는 여전히 추가 프롬프트나 다듬기가 필요하다고 인정했다.
  • ChatGPT 진영은 조만간 신모델 "Astra" 출시가 예고돼 있어 경쟁 구도가 곧 재편될 가능성이 있다.
  • 디자인 자동화 생태계(레퍼런스 갤러리, UI 스나이핑, 브랜드 자산 라이브러리, 안티-슬롭 후처리)가 하나의 통합 워크플로로 묶이는 추세가 확인된다.

08용어 사전

  • Fable 5.1: Anthropic/Claude 계열의 디자인 특화 모델로, 이전 버전보다 저렴하고 원샷 디자인 품질이 향상됨.
  • 원샷(One-shot): 추가 피드백 없이 단일 프롬프트만으로 완성도 높은 결과물을 생성하는 방식.
  • UI 스나이핑(UI sniping): 전체를 처음부터 디자인하지 않고, 마음에 드는 특정 UI 컴포넌트만 추출해 자신의 프로젝트에 삽입하는 기법.
  • OpenArt: 다양한 최신 이미지·영상 생성 모델을 CLI를 통해 Claude, ChatGPT 등 어떤 에이전트에도 연결해주는 통합 플랫폼.
  • Design LIMB 스킬: 여러 크리틱(비평) 에이전트가 서로 결과물을 검토·논쟁하도록 만들어 디자인 품질을 수렴시키는 자체 개발 스킬.
  • Slop Monster: 오픈소스 human-izer 레포와 세일즈/마케팅 어휘 규칙을 결합해 AI 특유의 문체를 인간적인 카피로 바꿔주는 무료 GitHub 도구.
