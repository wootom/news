02AI 도구 및 플랫폼 관련 문의/이슈

  • 클로드(Claude) API 문제: 클로드 AI 모델의 접속 불안정("맛탱이갔나여?", "오버로드", "API Error: 529")에 대한 문의와 일시적인 서비스 불안정 공유가 있었습니다.
  • 크롬 자동 조작 오류: 크롬 브라우저에서 자동 조작 시 "다른 확장 UI가 페이지 위에 떠있다"는 메시지로 인해 작동하지 않는 문제에 대한 문의가 있었습니다.
  • 오픈클로 윈도우 설치 방법: 마이크로소프트에서 지원하는 윈도우 버전의 오픈클로 셋업 방법 가이드 영상이 공유되었습니다. (https://youtu.be/B4z8VUUgnEE?si=fZFI6HqKkRBjtzoG)
  • 헤르메스 모델 사용 문의: 코덱스 정지 이슈로 클로드 코드 모델 대신 헤르메스 사용에 대한 문의와 어떤 모델을 사용하는지에 대한 질문이 있었습니다.

* 한국투자증권 API를 이용한 주식 투자 경험 공유. * COM ActiveX 방식의 트레이딩이 맥미니에서 가능한지, 또는 Open API 방식과의 비교에 대한 질문이 있었습니다. * 한국투자증권 API가 자연어로도 가능하다는 정보가 공유되었습니다.
