* 깃허브 링크: https://github.com/pewdiepie-archdaemon/odysseus

02Hermes 에이전트 및 Nemotron-3-Ultra 모델

  • Hermes 에이전트 업데이트 및 설치:

* 기존 설치자는 Hermes Desktop으로 설치하면 기존 터미널의 에이전트와 연동됩니다 (백업 후 진행 권장). * Hermes Desktop 설치 링크: https://hermes-agent.nousresearch.com/desktop * 현재 요금제 관련 옵션도 있는 것으로 보이며 편의성이 향상되었다는 의견이 있습니다.

  • NVIDIA와의 협력 및 Nemotron-3-Ultra 모델 무료 사용:

* Hermes 에이전트가 NVIDIA와 협력 파트너 관계를 맺어 "Nemotron-3-Ultra" 모델을 NousPortal에서 무료로 사용 가능합니다. * Nous Portal 로그인 연동이 안 될 경우 0$ 결제를 통해 해결 가능합니다.

  • Nemotron-3-Ultra 모델 사용 후기:

* 성능이 그다지 좋지 않다는 의견과 (그록보다 못하다는 평), GPT-5 수준 정도는 되는 것 같다는 의견이 공존합니다. 무료라는 점에서 긍정적인 평가도 있습니다. * 한 사용자는 "가성비 헤르메스에 적합하다"고 언급했습니다.

03숏폼(9:16) 영상 생성 API 서비스 연동

  • 질문: 웹 프로그램에서 API를 통해 30초~1분짜리 쇼츠 영상을 만드는 서비스를 빌드 중인데, Gemini API의 호출 제한(Quota)이 너무 빡빡하여 대안을 찾고 있습니다. 상용화를 위해 쿼터 제한 없는 크레딧 종량제 API가 필요한 상황입니다.

* 대안 고려: Fal AI (Wan 2.5나 Kling 호스팅) 또는 Kling AI 순정 API.

  • 질문: 실제 서비스에 비디오 API를 연동해 본 경험자들에게 안정성이나 가성비 면에서 어떤 모델을 추천하는지 문의했습니다.
  • 질문: 1분짜리 영상을 만들 때 '10초짜리 여러 개 병렬로 뽑아서 서버에서 이어 붙이기'와 'API 자체 Extension 기능으로 늘리기' 중 어떤 방식이 속도나 싱크 면에서 나은지에 대한 조언을 구했습니다.
  • 답변:

* '그록(Grok)'을 한 번 사용해보라는 추천이 있었습니다. * 자체 Extension 기능으로 늘리는 방식은 결과물이 별로라는 의견이 있었습니다 (같은 화면에서 줌 이동이나 변경 정도로 늘리는 느낌).

04모각 (모여서 각자 일하기) 행사 관련

  • 이번 주 토요일 모각 행사가 총 100명으로 마감되었으며, 신청자들에게 문자 안내가 발송되었습니다.

* 결제 후 문자 미수신 시 채널톡으로 문의 요청했습니다: https://gpters.channel.io

  • 오픈클로나 헤르메스 설치 경험이 없는 입문자도 참여 가능하며, AI 주제라면 어떤 것이든 무방하다는 안내가 있었습니다.
  • 모각을 통해 Hermes Desktop 설치에 도전해보는 것을 권장했습니다. 강남역에서 도보 5분 거리입니다.

05ChatGPT 계정 밴(Ban) 문제

  • 문제 발생: 일부 사용자들이 "Cyber Abuse"를 이유로 ChatGPT 계정 밴을 당했다는 사례가 공유되었습니다. 경고 메일 후 계정이 정지되었습니다.
  • 원인 추정:

* 위험한 코드 실행이나 API 키 유출 가능성 언급 (ChatGPT측 답변). * "코덱스 밴"으로 많이 언급되었으며 주로 프로 구독 사용자, 여러 CLI (명령줄 인터페이스) 사용, 또는 여러 사람이 동시 병렬로 계정을 사용하는 경우에 발생한 것으로 보입니다. (예: 회사 내에서 여러 명이 프로 계정을 공유). * IP 주소 문제일 수도 있다는 의견이 있었습니다. * 지역을 달리하여 에이전트를 많이 붙이는 경우 밴 가능성이 제기되었습니다.

  • 대응 방안 및 해결:

* 클레임 메일을 작성하여 이의 신청할 수 있습니다. * OpenAI Developer Community에 케이스 번호와 함께 게시글을 작성하면 빠르게 검토받을 수 있습니다. * 첫 이의 신청 시 가능한 한 많은 정보를 제공하는 것이 좋습니다. * 한 사용자는 "오류"였고 복구되었다고 알려왔습니다. OpenAI 측에서 오류임을 인정하고 해결 중이라는 소식이 공유되었습니다.

  • Claude 계정 밴 관련:

* 맥미니 2대에 클로드 2개 계정 설정 가능 여부 질문 -> ohmyclaw 참조하여 계정 슬롯 형태로 설정 가능하다는 답변. * Claude 에이전트 사용 시 정책 위반 우려에 대한 언급이 있었습니다. * 한 사용자는 맥미니 2대에 연결하여 사용 중 밴을 당했으며, Hermes 연결 사실을 정직하게 공개하고 "I believe this was a mistake" 또는 "Other"를 선택하여 이의 신청을 작성하는 방법을 공유했습니다. (계정 복구 심사에 유리할 수 있음) * 제출 전에 Hermes 연결을 끊어두면 나중에 "이미 조치했다"고 말할 근거가 생겨 더 좋다는 조언도 있었습니다.

  • OpenAI의 API 강제 유도 의혹: 밴 조치가 API 사용을 유도하기 위한 압박일 수 있다는 의견도 나왔습니다.

06Claude 요금제 변경 및 가격 관련

  • Claude Max 요금제 가격 변경 의혹: Max 요금제 가격이 100불에서 110불로 올랐는지에 대한 논의가 있었습니다.

* 기존 구독 계정에서는 100불로, 새로 만들면 110불로 보이는 케이스가 있었습니다. * Pro 요금제도 17불에서 19불로 올랐다는 경험담이 있었습니다. * A/B 테스트 또는 실시간 변경 과정일 수 있다는 추측이 있었습니다.

  • 부가세 관련:

* 월간/연간 청구 방식의 차이로 가격이 다르게 보일 수 있다는 의견이 있었으나, 실제 사진을 통해 계정마다 금액이 다른 상황이 확인되었습니다. * 일부 사용자는 4월부터 110불로 결제하고 있었다고 언급했습니다. * 과거에는 인보이스에 부가세가 없었으나, 2월부터 부가세가 포함되어 110불이 되었을 것이라는 추측이 있었습니다. * 부가세가 아깝다면 결제 위치를 소비세가 없는 미국 주로 설정하는 팁도 공유되었습니다.

  • 코덱스(Codex) 사용량:

* 코딩 관련 작업 시에는 사용량이 부족할 수 있지만, 일상용으로는 적당하다는 의견이 있었습니다. * 일반적인 헤비 유저 (매우 많은 양을 사용하는 사람)들은 부족함을 느낄 수 있습니다. * 코덱스 API SaaS를 개발하려는 시도도 있었습니다.
