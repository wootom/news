01
Dokploy란?
Coolify와 유사한 셀프호스팅 앱 배포 플랫폼. VPS에 설치 후 GitHub 연동으로 코드 푸시 → 자동 재배포.
핵심 기능
  • GitHub 연동 자동 재배포
  • 커스텀 도메인 + SSL 자동 적용
  • 데이터베이스 배포 지원
  • 원클릭 Hostinger 템플릿
바이브 코더에게 의미
  • Claude Code/Cursor로 만든 앱 바로 공개
  • DevOps 지식 없이 5분 배포
  • git push만 하면 자동 업데이트
02
배포 단계별 흐름
1
Hostinger VPS 선택 — KVM1/2/4/8 중 앱 규모에 맞게 선택. 서버 위치 가장 가까운 곳으로.
2
Dokploy 원클릭 설치 — OS 선택 시 Dokploy 템플릿 선택. 명령어 실행 불필요, 자동 설치.
3
GitHub 계정 연동 — Dokploy 대시보드에서 GitHub 앱 연결.
4
레포지토리 선택 및 배포 — 배포할 GitHub 레포 선택 → 첫 배포 실행.
5
커스텀 도메인 + HTTPS — 도메인 연결, SSL 자동 발급·적용.
6
이후 자동화 — git push할 때마다 Dokploy가 감지하여 자동 재배포.
03
VPS 플랜 가이드
플랜추천 상황
KVM 1소규모 앱 1~2개, 개인 포트폴리오
KVM 2중간 규모 앱, 영상 시연 선택 플랜
KVM 4여러 앱 동시 운영, 트래픽 있는 서비스
KVM 8대규모 서비스, 팀 프로젝트
