픽스필드 8개 모델로 비 오는 밤 골목 영상 생성 실험 및 AI 에이전트 협업 방식 분석

픽스필드 8개 모델 비교 실험으로 AI 에이전트와 인간의 상이한 평가 기준 및 협업 필요성 확인

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

01핵심 개요

  • 픽스필드 플랫폼에서 8개 영상 생성 모델에 동일한 프롬프트를 입력해 공정성을 확보한 비교 실험을 수행함
  • AI 에이전트 벨라는 문장 준수도를, 크리에이터는 영화적 연출을 기준으로 평가하여 상이한 1위를 선정함
  • 그록 이미지 1.5 모델이 웅덩이를 실제로 뛰어넘는 동작을 구현해 벨라 기준 1위를 차지함
  • 시덴스 2.5 모델은 우산 소실에도 불구하고 스토리텔링 잠재력으로 크리에이터 기준 1위를 기록함
  • 성별 미지정 시 AI가 학습 데이터 편향으로 남성으로 생성되는 현상과 협업의 필요성을 확인함

02핵심 주장 / 논점 구조

  • AI 에이전트와 인간의 평가 기준 차이는 창작물의 완성도에 필수적인 보완 요소로 작용함
  • 단일 모델 의존보다 다중 모델 비교를 통해 각 모델의 강점과 한계를 명확히 파악할 수 있음
  • 프롬프트의 세부 조건 준수 여부가 AI 영상 생성 품질 평가의 핵심 지표임
  • AI의 학습 데이터 편향은 명시적 지시 없이는 특정 성별이나 이미지로 고정되는 경향이 있음

03실험 설계 및 모델 구성

  • 픽스필드 UI를 활용해 5초, 16:9, 720p, 고비트레이트로 통일된 설정을 적용함
  • 클링 4.0, 시덴스 2.5, 시덴스 2.0, 미니맥스 H3, WAN 3.0 프라임 등 8개 모델 사용
  • 그록 이미지 1.5, 플럭스 3 비디오, 제미나이 옴니 플래시 1.1 모델도 동일 조건으로 실행
  • 비 오는 밤 골목에서 노란 우산을 든 사람이 웅덩이를 뛰어넘고 걸어오는 단일 프롬프트 사용

04모델별 영상 생성 결과 분석

  • 시덴스 2.5는 고품질 질감을 보였으나 뛰는 순간 노란 우산이 화면에서 사라지는 결함 발생
  • 시덴스 2.0은 물방울이 가장 많이 튀고 카메라 방향으로 다가오는 동작을 정확히 구현
  • 그록 이미지 1.5는 발이 바닥에서 떨어지는 명확한 점프 동작과 우산 유지로 문장 준수도 1위
  • 제미나이 옴니 플래시 1.1은 점프 동작이 가장 크지만 우산 소실과 짧은 지속시간을 보임

05AI 에이전트와 인간의 평가 기준 차이

  • 벨라는 '문장에 시킨 일을 지켰는가'를 기준으로 그록 이미지 1.5를 1위로 선정
  • 크리에이터는 '영화적 연출과 스토리 전달력'을 기준으로 시덴스 2.5를 1위로 선정
  • 시덴스 2.5는 등을 보이며 걷는 구성이 스토리텔링에 유리하다는 평가로 인간 기준 1위
  • 두 주체는 서로 다른 관점을 유지하되 상호 보완적으로 최종 결과물을 고르는 방식 제안

06학습 데이터 편향과 성별 생성 현상

  • 프롬프트에 '사람'이라고만 기재했으나 8개 모델 모두 남성 캐릭터로 영상 생성
  • AI 학습 데이터에서 비 오는 밤 골목 걷기 장면이 주로 남성으로 촬영된 영향으로 분석
  • 특정 성별을 원할 경우 프롬프트에 명시적으로 기재해야 원하는 결과가 도출됨
  • AI의 내재된 편향은 명시적 제어가 없으면 기본값으로 작동하는 특징을 보임

07협업 방식 및 향후 전망

  • AI 에이전트는 문장 준수도를, 인간은 예술적 판단을 담당하는 역할 분담 모델 제시
  • 벨라는 크리에이터의 스타일을 학습하여 향후 판단을 조정할 수 있음을 확인
  • 다양한 AI 모델을 실험하며 필요에 따라 적합한 모델을 선택하는 워크플로우 권장
  • 인간과 AI의 시각 차이를 활용하면 더 많은 사람에게 공감되는 영상 제작 가능
