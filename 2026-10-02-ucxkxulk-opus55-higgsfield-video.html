클로드 Opus 5.5는 코드로 글자·도형을 만들고 Higgsfield로 실사 장면을 보완했다

코드 그래픽은 Opus 5.5, 실사·3D 장면은 Higgsfield, 사운드는 ElevenLabs로 비교했다.

01핵심 개요

  • 영상 제작 네 사례를 Opus 5.5 단독 코드 버전과 Higgsfield 연결 버전으로 만들고 결과·시간·크레딧을 비교했다.
  • 코드 생성은 글자와 도형, 장면 구성에 강했고, Higgsfield는 사람·실제 공간·3D 에셋처럼 코드로 표현하기 어려운 부분을 보완했다.
  • 출시 영상은 Higgsfield 실사 컷 네 개를 넣어 약 15분에 완성했고, 240크레딧을 사용했다.
  • 사운드는 코드 합성과 ElevenLabs 결과를 비교했으며, 3D 작업실과 트로이 목마 예고편도 각각 다른 도구 조합으로 제작했다.
  • 네 사례의 Higgsfield 사용량은 채택하지 않은 결과까지 포함해 약 439크레딧이며, 실제 회사 소개 영상은 약 970크레딧을 썼다.

02핵심 주장 / 논점 구조

  • Opus 5.5는 영상 파일을 직접 생성하는 모델이 아니라 HTML·자바스크립트·파이썬 코드로 화면을 그리고 프레임을 저장해 영상을 만든다.
  • 코드로 표현하기 어려운 실사 인물과 공간은 Higgsfield로 만들고, 글자와 도형은 코드로 얹는 방식이 효과적이었다.
  • 음악과 효과음은 코드 또는 ElevenLabs가 적합했고, 장면에 맞춰 도구 결과를 조립하는 역할은 Opus 5.5가 맡았다.
  • 같은 프롬프트를 사용하고 수정 요청은 버전마다 최대 두 번으로 제한했으며, Claude 사용량과 Higgsfield 크레딧을 따로 기록했다.

03MCP 연결과 비교 실험의 조건

  • Higgsfield는 AI 영상·이미지·오디오·3D 제작 서비스이며, 영상에서는 MCP 커넥터 하나로 Claude와 연결했다.
  • MCP는 AI가 외부 도구를 호출하도록 연결하는 규격이며, 연결 뒤 Claude는 영상 생성과 음성·3D 관련 도구를 요청할 수 있었다.
  • 예시 프롬프트는 Opus 5.5 공개 첫 주에 공개된 영상 제작 사례 53건과 한국어 번역 프롬프트 17개를 모은 저장소에서 골랐다.
  • Claude는 구독 요금제를 사용해 이용량으로 기록했고, 이를 금액으로 환산하지 않았으며 Higgsfield는 크레딧으로 집계했다.

04출시 영상: 코드 그래픽과 실사 컷의 조합

  • Opus 5.5 단독 버전은 가상의 AI 스타트업 랜마를 설정하고 수학 증명 흐름을 담은 42초 영상을 약 29분 만에 만들었다.
  • 검정·주황 색상과 큰 글자, 도형, 파이썬으로 합성한 배경 음악은 정돈됐지만 사람이나 실제 공간 장면은 없었다.
  • Higgsfield 버전은 5초·1080p 컷당 60크레딧을 확인한 뒤 광선·연구자·도시·서버홀 영상 네 컷을 만들어 총 240크레딧을 썼다.
  • 실사 컷에 글자와 로고를 넣지 않고 글자는 코드로 배치했으며, 완성에는 약 15분과 약 6만 출력 토큰이 들었다.
  • 단독 버전은 약 18만 출력 토큰을 사용했다. 두 버전은 한 번씩 실행한 결과라 시간 차이가 항상 같다고 볼 수 없다고 밝혔다.

05사운드: 코드 합성과 ElevenLabs 비교

  • 두 방식 모두 영상에서 컷 전환 시점 여섯 곳을 찾은 뒤 배경 음악과 효과음을 영상에 맞춰 배치했다.
  • 코드 버전은 파이썬으로 소리를 합성해 약 13분 걸렸고, 효과음 20곳 중 19곳을 목표 시점에서 1밀리초 이내로 맞췄다.
  • ElevenLabs 버전은 음악과 효과음을 생성해 약 11분 걸렸지만, 컷과 박자를 맞추려고 일부를 늦추고 1.6% 빠르게 재생하거나 한 박을 잘라냈다.
  • 코드 소리는 장면 전환에 정확했지만 전자음 느낌이 강했고, ElevenLabs 소리는 악기와 효과음에 가까워 풍성했지만 추가 편집이 필요했다.
  • Higgsfield 오디오 도구 설명은 음성 생성에 한정돼 있어 이 실험에서는 음악·효과음 제작에 사용하지 않았다.

063D 작업실: 에셋과 동작 라이브러리의 효과

  • 가구와 카메라 움직임만 요청한 첫 시도에서는 코드 버전이 더 나았고, 블렌더 버전도 기본 도형을 코드로 조합하는 수준이었다.
  • 요청을 바꿔 사람의 입장·착석, 창문 빛줄기, 유리·금속 반사를 포함하자 도구별 차이가 드러났다.
  • 코드 버전은 Three.js로 장면을 만들고 96번 겹쳐 그려 초점 앞뒤가 흐려지는 효과를 냈지만, 사람 형상과 동작은 단순하고 딱딱했다.
  • Higgsfield 버전은 에셋 카탈로그의 책장·화분·책 더미·러그를 배치하고, 캐릭터 이미지를 3D 모델로 바꾼 뒤 걷기·앉기 동작을 적용했다.
  • 타이핑 손을 수정하고 해당 구간을 다시 렌더링하는 데 약 17분이 걸렸다. 결과 전체는 약 62분, 54크레딧이었으며 극적인 빛줄기는 코드 버전이 더 강했다.

07트로이 목마 예고편과 실험의 결론

  • Opus 5.5 단독 예고편은 코드로 장면을 그려 약 28분 만에 완성했지만 인물은 실루엣에 가까웠고 기본 음성은 예고편 분위기에 맞지 않았다.
  • Higgsfield 버전은 장면별 이미지를 만든 뒤 영상으로 움직여 실사 컷 아홉 개를 구성했으며, 약 25분과 145크레딧을 사용했다.
  • 그림만 비교하도록 두 버전의 소리를 제거하고 같은 Marcus 나레이션 파일 네 개와 같은 요청으로 만든 ElevenLabs 음악·효과음을 사용했다.
  • 네 사례에서 Higgsfield는 사람과 실제 공간 장면에 특히 효과적이었고, 글자·도형 중심 영상은 Opus 5.5 단독 코드 제작으로도 충분했다고 정리했다.
  • 보너스 단테랩스 소개 영상은 8개 장면에 이미지를 먼저 만든 뒤 영상화해 50초로 완성했다. 약 14분이 걸렸고 970크레딧을 썼다.
