Union Alpha는 무료 접근과 장문맥 정확도로 경쟁 모델과 유사한 결과를 보였다.

Union Alpha는 무료 접근, 26만2,000토큰 문맥, 200K 테스트 99.6%를 제시했다.

01핵심 개요

  • Union Alpha는 개발 주체가 공개되지 않은 스텔스 모델이며, OpenRouter에서 현재 무료로 사용할 수 있다고 소개됐다.
  • 모델의 컨텍스트 윈도우는 26만2,000토큰으로 제시됐고, 비공식 벤치마크 성과에는 주의가 필요하다고 언급됐다.
  • 호텔 랜딩페이지 테스트에서 단순 프롬프트 결과는 Opus 5보다 약간 낮았으나, 상세 지시에서는 Astra와 차이가 크지 않았다.
  • 3D 레이싱 게임과 모션 그래픽 생성에서 Union Alpha는 Astra와 비슷한 수준의 작동 결과를 보였다.
  • 8-needle 테스트에서 128K는 100%, 수정 200K는 99.6%를 기록하며 장문맥 정보 회수 정확도를 보였다.

02핵심 주장 / 논점 구조

  • Union Alpha는 제작 AI 연구소가 알려지지 않은 상태지만, OpenRouter를 통해 무료로 시험 가능한 모델로 소개됐다.
  • OpenRouter CEO·공동창업자가 공개한 성능 수치는 비공식 자료이므로 이해관계와 벤치마크 한계를 함께 고려해야 한다고 설명했다.
  • 영상의 평가는 프런트엔드, 게임, 모션 디자인, 장문맥 회수 테스트를 Astra·Opus 5와 비교하는 방식으로 진행됐다.
  • 비용이 아직 확정되지 않았으므로 Opus 5보다 결과가 낮더라도 모델의 절대적 우열을 단정하기 어렵다고 밝혔다.

03공개 성능 수치와 무료 접근 방식

  • DeepSuite 그래프에서는 Union Alpha가 Astra, Fable, Opus 5와 비슷한 성능을 보이는 것으로 제시됐다.
  • Alex는 Union Alpha가 Terminal Bench 2.1과 bench verified에서 5.6 Soul을 앞섰다고 게시한 것으로 소개됐다.
  • 같은 게시물 기준으로 Union Alpha는 Terminal Bench 2.1에서 Opus 5도 앞섰다고 언급됐다.
  • 접근은 openrouter.ai에서 계정을 만든 뒤, OpenCode 같은 하니스에서 모델 목록의 Union Alpha를 선택하는 방식으로 설명됐다.

04단순 호텔 랜딩페이지와 Opus 5 비교

  • '런던의 가짜 부티크 호텔 랜딩페이지'를 만들라는 단순 프롬프트와 외부 스킬 미사용 조건을 적용했다.
  • Union Alpha는 3분 37초 만에 히어로 섹션과 롤링 배너를 포함한 단순한 페이지를 생성했다.
  • 생성물은 둥근 모서리와 표준화된 카드 중심의 전형적 AI 디자인처럼 보이지 않는 점이 긍정적으로 평가됐다.
  • 같은 프롬프트의 고노력 설정 Opus 5는 예약 가능 여부 확인 영역과 스크롤 모션을 제공해 약간 우세하다고 평가됐다.

05Dune House 상세 프롬프트의 Astra 비교

  • 두 번째 테스트는 캘리포니아 조슈아트리의 가상 사막 호텔 'Dune House'용 반응형 홈페이지 제작이었다.
  • Union Alpha 결과는 첫 테스트보다 크게 개선됐으며, 히어로 이미지와 이미지 활용으로 더 정교한 페이지를 만들었다고 평가됐다.
  • Astra도 배경 이미지 히어로 섹션과 명확한 예약 가능 여부 확인 영역을 포함한 결과를 생성했다.
  • 평가자는 Astra에 근소한 우위를 줬지만, Astra와 Union Alpha 사이의 차이는 크지 않다고 판단했다.

06브라우저 3D 레이싱 게임 생성 결과

  • 기존 Fortnite 클론 프롬프트와 동일한 참조 이미지를 Union Alpha에 제공했지만, 매번 오류가 발생해 실행되지 않았다고 밝혔다.
  • 대신 스타일화된 해안 고속도로를 배경으로 하는 브라우저용 3D 아케이드 레이싱 게임 제작을 요청했다.
  • Union Alpha는 3JS 기반의 단일 원형 트랙 게임을 만들었고, 조작·물리 효과·그래픽은 무난하게 작동했다.
  • Astra 결과도 같은 오디오와 유사한 로딩 화면, 부드러운 조작과 가드레일 충돌 물리를 보여 두 모델을 같은 수준으로 평가했다.

07모션 그래픽과 8-needle 장문맥 검증

  • Higsfield 모션 스킬을 사용해 인터넷에서 메시지가 이동하는 과정을 설명하는 2D 모션 영상을 생성하도록 요청했다.
  • 이 테스트는 MCP 서버가 Seed Dance를 호출하는 구조에 기반했으며, Union Alpha도 프런티어 모델과 같은 방식으로 작동했다고 설명했다.
  • 공식 128K 8-needle 테스트에서는 100%를 기록했고, 20만 토큰을 채운 수정 버전에서는 99.6%를 기록했다.
  • 수정 200K 테스트의 오차는 아포스트로피 5개였으며, 8개의 유사 문장 중 두 번째 항목을 정확히 회수하는 과제였다.
