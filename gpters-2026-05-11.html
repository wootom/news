02
AI 에이전트 개발 및 활용 (Hermes · OpenClaw · Claude)
Hermes

Hermes 주요 업데이트

  • Windows Native 버전 출시
  • Achievements 기능 추가
  • Claude Code/Codex 비공식 연결 팁 공유
  • 칸반 기능 활용 할 일 관리 사례
  • 밋업 코리아 라이브 시청
OpenClaw

오픈클로 활용 사례

  • 카카오톡 봇(뽀짝이) 개발 — SQLite 폴링+웹훅+크론잡
  • Zotero 통합 논문 관리 자동화 아이디어
  • 챗앱 clickclack 오픈소스 공개
  • 공식 스킬 마켓: clawhub.ai
  • 스킬 저장소: skills.sh
Claude / Codex

모델 활용 팁

  • Codex: 코드 문제 해결력 우수
  • Claude: 세부 지시 중요, 4.7 이후 토큰 소모 논의
  • Claude Code 5시간 제한 증가 + 피크 제한 제거
  • Opus API 속도 제한 상향
  • PPT 이미지 생성 → GPT 압도적, 디자인 코딩 → Claude
인프라

에이전트 서버 구축

  • 저전력 미니 PC (N100, 16GB/512GB) 인기
  • 맥미니 AI 에이전트 서버 → RAM이 CPU보다 중요
  • AMD Ser8 미니 PC 저소음·저전력 장점
  • WSL2+Ubuntu 권장 (Windows 네이티브 불편)
  • Tailscale로 로컬 문서 외부 접근
자동화

회의 전사 및 요약

  • Zoom / Google NotebookLM 활용
  • 실시간 자막 품질 이슈 논의
  • 젠스파크 Speakly, 아이폰 실시간 자막 등 대안
  • 에이전트 스웜 — 조사+검토+생성 역할 분리
기술 일반

개발 인사이트

  • Claude 모델은 XML 패턴을 잘 읽음
  • SQLite: 가볍고 간단, 동시 접속 약점
  • AI Effort 설정(Low/Mid/High) → 속도·추론 트레이드오프
  • 에이전트 자가 판단 오류 사례 공유 (유머)
  • Google 채용 시험 AI 도구 허용 뉴스
