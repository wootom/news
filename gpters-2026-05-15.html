1. 클로드(Claude) 유료 플랜 및 크레딧 변경

  • 6월 15일부터 Max 20x 플랜 가입자, 월 $200 크레딧 제공 (Agent SDK, claude -p, Claude Code GitHub Actions)
  • 크레딧은 기존 구독 사용량 한도와 별도 관리 — 대화형 사용에는 영향 없음
  • 월 크레딧 소진 시 'extra usage' 수동 활성화 필요 (이월·현금 전환 불가)
  • 일부 사용자들 Kodex/API 요금제 전환 고려 — 정책 명확화 긍정 vs. 추가 과금 우려

2. LLM 사용 경험 및 비교

  • Kodex: Claude Max 대비 쾌적한 사용 경험, 만족도 높음
  • Claude Opus 4.7: 성능 불만 언급, 4.8 또는 Misos 버전 개선 기대
  • GPT: 툴 콜링 또는 작업부터 즉시 시작하는 특성
  • Gemini: 프론트엔드·디자인 작업에 강점, 코딩·추론 개선 시 기대

3. Agent 프레임워크 비교 (Hermes vs OpenClaw vs PI)

  • Hermes: 장기 물고 늘어지기, 스킬 관리 우수, 퍼스널리티 프리셋 지원
  • OpenClaw: 순차 처리, 탄탄하지만 필요한 것 없다고 자주 언급하는 경향
  • PI Agent: 빠르고 컨텍스트 주입 최적화, OAuth 지원, 가볍고 확장 가능
  • 멀티 에이전트 협업: Kanban 보드 활용으로 역할 분배 효율화

4. LLM 기반 지식 관리 및 자동화

  • 옵시디언 + Hermes 연결 — AI 브레인 구축 (검색·요약·연결·초안 작성 통합)
  • 사진/문서 정리 자동화: 기존 데이터 풍부 시 90% 자동화 가능 예상
  • Hermes + SuNO 음악 생성 AI 연동 → 플레이리스트 자동 생성 및 YouTube 업로드 사례

5. AI 기술 및 활용 동향

  • Meta AI 한국 상륙 — 단, Hermes/OpenClaw와 직접 OAuth/API 연동 현재 미지원
  • Gemini-omni 신모델: 텍스트 일관성 우수, 영상 생성 시 텍스트 깨짐 없음
  • 택배 검사 로봇: 물품 하차 → 송장 뒤집기 → 컨베이어 올리기 실제 자동화 라이브 시연
