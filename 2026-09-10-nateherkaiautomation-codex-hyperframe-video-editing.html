Codex와 Hyperframes로 전사·비트 설계·검수를 반복하는 AI 영상 편집 과정을 안내한다.

Codex와 Hyperframes로 전사부터 모션 그래픽 검수까지 AI 영상 편집 흐름을 구현한다.

01핵심 개요

  • Codex 데스크톱 앱과 Hyperframes GitHub 저장소를 연결해 로컬 프로젝트에서 AI 영상 편집 환경을 구성한다.
  • 작업 흐름은 영상 전사, 실수·침묵 구간 컷, 장면별 비트 계획, 렌더 결과 검수와 반복 수정으로 제시된다.
  • 11Labs Speech to Text API를 전사에 사용하며, 화자는 로컬 Whisper보다 빠르지만 유료라고 설명한다.
  • Hyperframes와 Astra는 HTML 기반 애니메이션, 자막, 화면 크롭, B-roll, 음악·효과음 동기화를 수행하는 사례로 소개된다.
  • 14분 분량 페이스캠·화면 녹화 영상은 전사와 컷을 거쳐 9분으로 줄인 사례가 제시된다.

02핵심 주장 / 논점 구조

  • 영상은 Codex와 Hyperframes를 이용하면 영상 편집 경험이 없어도 자연어 지시로 모션 그래픽과 애니메이션을 만들 수 있다고 설명한다.
  • AI 편집의 순서는 전사, 컷 편집, 비트 계획, 검수·수정 반복이며 각 단계가 뒤 단계의 동기화 정확도를 뒷받침한다.
  • 구체적인 편집 요구를 프롬프트로 제공할수록 화면 위치, 전환 시점, 자막과 영상 요소를 의도에 맞춰 제어할 수 있다고 제시한다.
  • 화자는 무료 Skool 커뮤니티의 AI skills 또는 YouTube resources에서 Hyperframes student kit을 받을 수 있다고 안내한다.

03편집 결과 사례와 숏폼 구성

  • 페이스캠과 화면 녹화본 두 개를 준 14분 영상은 실수·말더듬·빈 구간을 잘라 9분으로 편집됐다고 소개한다.
  • 해당 영상에는 18개 카드 도입 애니메이션, 둥근 크롭, 배경, 개념 사이 전환 카드가 Hyperframes와 Codex로 만들어졌다고 설명한다.
  • Claude 관련 릴은 spec, verifier, environment의 세 층을 순서대로 보여 주며 시청 지속을 위한 오픈 루프를 구성한다.
  • 숏폼은 약 1~2초마다 장면을 전환하고, B-roll·종이 질감의 3D 애니메이션·자막·음악·효과음을 동기화한 사례로 제시된다.

04B-roll과 맥락 자산 활용 사례

  • AIS Live 광고용 9x6 버전에서는 화자의 YouTube 영상, 과거 AIS Live 세그먼트, VIP 세션 등을 B-roll로 사용했다고 설명한다.
  • AI가 광고 문맥에 맞춰 Pat이 등장하는 장면, Hyper Agent와 Alex의 세션, AIOS·second brain 관련 영상을 배치한 사례가 나온다.
  • AIS Live 로고는 Google Drive에서 찾아 애니메이션 처리했으며, 콘텐츠가 이론보다 실제 사례처럼 느껴지도록 했다고 평가한다.
  • 구독 및 Skool 커뮤니티 참여를 요청하는 CTA에서는 skills·docs·강좌·이벤트 자산의 스크린샷과 이미지를 활용했다고 말한다.

05Codex 로컬 프로젝트와 Hyperframes 설치

  • 데스크톱에 'Hyperframes demo' 폴더를 만들고 Codex에서 로컬 프로젝트로 지정해 작업 공간을 연다.
  • GitHub의 Hyperframes 저장소 URL을 Codex에 붙여 넣고, 저장소와 의존성 및 필요한 skills를 프로젝트에 설치하도록 요청한다.
  • 프로젝트 파일에는 영상 프로젝트, 렌더 결과물, 기타 파일이 채워지며, localhost에서 프로젝트를 보고 요소를 조정할 수 있다고 설명한다.
  • 단순히 영상 파일을 주고 편집을 요청할 수도 있지만, 시연에서는 원하는 연출을 구체적으로 지시하는 방식을 택한다.

06전사·컷·비트 계획·검수의 작업 흐름

  • 첫 단계인 전사는 음성 전체 텍스트와 단어 발화 시점을 초·밀리초 단위로 파악해 자막과 애니메이션을 맞추기 위한 과정이다.
  • 두 번째 단계에서는 실수와 약 5초의 침묵 같은 구간을 잘라 빠른 흐름을 만들며, 시연 프롬프트는 0.5초 또는 1초의 침묵도 원치 않는다고 지정한다.
  • 비트는 각 장면을 뜻하며, Astra가 전사문을 읽고 의도를 이해해 릴 또는 영상에 들어갈 장면 구성을 계획한다.
  • 마지막에는 에이전트가 결과물을 다시 보고 스크린샷과 전사문을 확인해 동기화·화면 범위를 검증하고, 만족할 때까지 반복한다.

0711Labs API와 세부 모션 디자인 지시

  • 11Labs에서 API key를 만들 때 Speech to Text 권한만 부여해 전사용으로 쓸 수 있으며, 키는 공유하지 말아야 한다고 경고한다.
  • Codex에 .env 파일을 만들고 11Labs API key를 저장하며, agents.md에 향후 전사는 11Labs를 사용하라는 규칙을 추가한다.
  • 화자는 Whisper도 무료 로컬 전사 도구로 쓸 수 있으나 더 느리다고 말하며, 월 5달러 플랜의 11Labs를 선호한다고 밝힌다.
  • 시연 지시는 왼쪽 모션 그래픽과 오른쪽 3D 애니메이션, 하단 파란 강조 자막, 둥근 페이스캠 크롭, 50% 불투명 배경을 구체적으로 요구한다.
  • 최근 YouTube 영상 4~6개를 3D로 펼쳐 동시에 재생하고, 마지막에는 얼굴을 왼쪽에 크게 배치한 뒤 오른쪽에 아이콘·모션 그래픽을 넣도록 요청한다.

08용어 사전

용어뜻
HyperframesCodex 프로젝트에 GitHub 저장소로 불러와 HTML 기반 모션 그래픽과 영상 편집을 수행하도록 사용하는 도구다.
Codex로컬 프로젝트에서 Hyperframes 저장소와 파일을 다루고, 자연어 편집 지시를 수행하는 데스크톱 앱으로 소개된다.
Astra전사문을 읽고 영상의 의도를 파악해 장면별 비트를 계획하며 Hyperframes 등 도구를 활용하는 모델로 언급된다.
비트릴이나 영상에서 개별 장면을 뜻하며, 텍스트의 의미와 발화 시점에 맞춰 설계하는 편집 단위다.
agents.md프로젝트 작동 방식과 전사 도구 선택 등 사용자의 편집 규칙을 기록해 Codex가 이후 작업에 따르도록 하는 파일이다.
11Labs Speech to Text영상 음성을 전사하기 위해 API key와 Speech to Text 권한을 설정해 사용하는 유료 서비스다.
