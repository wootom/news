이벨스는 실제 과제를 모델·도구·스킬 조합별로 실행해 결과와 레시피를 비교하는 서비스다

실제 과제를 AI 조합별로 실행하고 결과물과 제작 레시피를 비교하는 이벨스

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

01핵심 개요

  • 이벨스는 같은 과제를 여러 AI 조합에 맡기고, 모델 이름을 가린 결과물을 나란히 비교하도록 만든 서비스다.
  • 모델·생성 도구·스킬을 조합해 실행하며, 결과물의 승패 투표와 승률을 조합 단위 리더보드에 쌓는다.
  • 공개 결과물은 250개가 넘고, 이번 달 리더보드에는 43개 조합과 결과물 141개가 올라와 있다.
  • 첫 커밋부터 배포까지 2주 남짓 걸렸고, 세 명의 팀원이 1,685개 커밋을 쌓았으며 1,000개 이상에 AI가 공동 작성자로 기록됐다.
  • 클로드·챗GPT 구독 계정을 연결해 추가 비용 없이 실행할 수 있으며, 서비스는 미국 사용자를 기준으로 영어로 먼저 출시됐다.

02핵심 주장 / 논점 구조

  • 모델별 벤치마크는 정해진 시험 점수이므로 랜딩 페이지나 광고 영상처럼 정답이 하나가 아닌 실제 과제를 대변하기 어렵다고 설명한다.
  • 같은 모델도 과제에 따라 순위가 달라질 수 있어, 사용자의 실제 작업을 여러 조합으로 실행해 결과물을 비교하는 방식이 필요하다고 제안한다.
  • 이벨스의 핵심은 결과물의 선호도뿐 아니라 어떤 모델·도구·스킬과 실행 조건이 결과를 만들었는지 함께 확인하는 데 있다.

03과제 실행과 블라인드 비교 방식

  • 사용자는 만들고 싶은 것을 입력하고 에이전트 모델, 생성 도구, 스킬로 구성된 조합을 최대 네 개까지 선택한다.
  • 모든 조합은 같은 입력과 첨부 파일로 시작하며 서로 다른 작업 공간에서 실행돼 다른 조합의 파일을 볼 수 없다.
  • 결과물은 모델명을 가린 채 양쪽에 나란히 제시되고, 사용자는 더 마음에 드는 쪽이나 둘 다 아닌 쪽을 선택한다.
  • 결과가 마음에 들지 않으면 조합별로 수정을 요청할 수 있으며, 수정 횟수는 턴으로 기록된다.

04리더보드와 실행 레시피

  • 투표 결과는 조합별 승리·패배 횟수와 승률로 쌓이며, 모델 하나가 아니라 도구와 스킬을 포함한 조합 단위로 순위를 매긴다.
  • 이번 달 리더보드에는 43개 조합과 결과물 141개가 등록돼 있고, 공개 결과물은 웹사이트·앱·영상·3D·게임 등을 포함해 250개가 넘는다.
  • 레시피에는 모델, 생성 도구, 스킬, 프롬프트와 설정, 수정 턴 수가 기록되며, 결과물 페이지에서 같은 과제를 다시 시작할 수 있다.
  • 다람쥐 게임 과제에서 오퍼스 5.5는 7분 36초와 입력 28만·출력 41,000토큰을, GPT6 아스트라는 6분 28초와 입력 17만3천·출력 2만 토큰을 기록했다.

05생성 도구·스킬과 구독 연결

  • 텍스트 모델뿐 아니라 Seedance와 클링 같은 영상 생성 AI, 블렌더 같은 소프트웨어도 같은 조건으로 비교할 수 있다고 소개한다.
  • 공개 스킬 37,000개가 정리돼 있으며, 스킬을 붙인 조합과 쓰지 않은 조합을 비교해 스킬의 효과를 살펴볼 수 있다.
  • 클로드나 챗GPT 구독 계정을 연결해 실행하면 추가 비용 없이 시작할 수 있고, 공개 결과물 열람은 로그인 없이 가능하다.
  • 계정 연결은 각 서비스의 공식 로그인 화면을 거치며, 클로드 로그인은 격리된 작업 공간에서 진행하고 계정 연결은 언제든 끊을 수 있도록 설계했다고 설명한다.

062주 개발 과정과 AI 활용

  • 세 명의 팀원이 첫 커밋부터 배포까지 2주 남짓 작업해 1,685개 커밋을 쌓았고, 하루 평균은 100개 이상, 최다 기록은 311개였다.
  • AI가 공동 작성자로 올라간 커밋은 1,000개가 넘으며, 오퍼스 5.5가 720개, 코덱스가 약 200개를 차지했다.
  • 먼저 서버와 데이터베이스가 없는 HTML 화면으로 디자인을 확정한 뒤 넥스트 JS로 포팅했고, 목업과 실제 앱을 비교해 한 차례에 57곳을 수정했다.
  • 용어 정의와 기능별 결정 기록을 문서로 남기고 기능별 작업 폴더를 분리해 에이전트를 병렬로 실행했으며, 남은 작업 폴더는 57개였다.

07미국 시장 선택과 오픈 베타의 한계

  • 새 모델을 먼저 써보고 여러 구독을 이용하는 사람이 미국에 많다고 판단해 처음부터 영어 화면과 미국 사용자를 기준으로 만들었다고 밝혔다.
  • 투표는 개인 취향을 반영하므로 리더보드의 승률이 모든 사용자에게 맞는 답을 보장하지 않으며, 직접 과제를 실행해 보라고 권한다.
  • 같은 모델과 프롬프트를 사용해도 실행 결과는 달라질 수 있어 레시피는 제작 기록이지 동일 결과를 보장하는 설명서는 아니라고 설명한다.
  • 일부 결과물은 실행 기록이 비어 있고 화면은 아직 영어이며, 2주 만에 만든 서비스인 만큼 버그가 있을 수 있어 오픈 베타 피드백을 요청한다.

08용어 사전

용어뜻
조합이벨스에서 과제를 실행하는 구성으로, 에이전트 모델과 생성 도구, 스킬을 함께 선택한다.
블라인드 비교결과를 만든 모델 이름을 감춘 채 두 결과물을 보여 주고 사용자가 선호하는 쪽을 고르는 방식이다.
레시피결과물에 사용된 모델·도구·스킬·프롬프트·설정과 수정 횟수 등 제작 과정을 기록한 정보다.
턴결과물을 수정 요청하며 진행한 횟수로, 몇 번의 수정 끝에 나온 결과인지 함께 기록한다.
스킬에이전트에게 제공하는 작업 설명서와 같은 것으로, 붙인 경우와 쓰지 않은 경우를 비교할 수 있다.
