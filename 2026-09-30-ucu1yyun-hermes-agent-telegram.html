Hermes Agent를 VPS에 설치하고 OpenRouter·텔레그램을 연결해 웹 조사를 실행한다

Hermes Agent를 VPS에 배포하고 OpenRouter·텔레그램을 연결해 웹 조사까지 수행한다.

01핵심 개요

  • Hermes Agent는 Nouse Research가 만든 무료 오픈소스 에이전트로, 개인 서버에서 상시 실행하는 AI 비서다.
  • 일반 챗봇과 달리 일정에 따라 작업하고 먼저 메시지를 보낼 수 있으며, 사용자의 작업 방식과 반복 절차를 기억한다.
  • 영상은 Hostinger의 KVM 2 VPS에 Hermes를 설치하고 OpenRouter의 모델과 텔레그램 봇을 연결하는 과정을 안내한다.
  • 텔레그램 계정 ID를 허용 목록에 등록해 접근을 제한하고, 게이트웨이를 실행해 휴대전화에서 에이전트와 대화한다.
  • 예시로 이메일 마케팅 관련 유튜브 영상 5개를 조사해 서버 파일로 저장하지만, 제공된 자막에는 예약 작업 설정 과정이 나오지 않는다.

02핵심 주장 / 논점 구조

  • Hermes Agent는 자체 서버에서 계속 실행되며, 채팅 앱을 통해 요청을 받고 작업 결과를 전달하는 개인용 에이전트로 소개된다.
  • 핵심 차이는 상시 실행, 대화 간 기억, 복잡한 요청의 절차를 스킬로 저장해 다시 활용하는 기능이다.
  • 노트북·상시 켜진 기기·VPS 중 실행 환경을 고르며, 영상은 수면과 네트워크 관리 부담을 이유로 VPS를 택한다.

03Hostinger KVM 2 선택과 서버 배포

  • 영상에서는 Hostinger의 Hermes 자동 설치 옵션을 사용하고, CPU 2코어·메모리 8GB·저장 공간 100GB인 KVM 2를 선택한다.
  • 웹 탐색 스킬과 Docker 컨테이너가 자원을 사용하므로, 더 작은 요금제는 작업 중 느려지거나 멈출 수 있다고 설명한다.
  • 등록 기간은 1개월·12개월·24개월 중 선택하며, 영상은 24개월이 월 단가가 낮고 쿠폰 적용을 고려하면 12개월도 권한다.
  • 서버 위치는 사용자와 가깝거나 지연 시간이 낮은 곳을 고르고, 예시로 미국 보스턴의 지연 시간 8ms를 보여준다.

04초기 설정: OpenRouter와 모델 선택

  • 터미널에서 Hermes 설정 마법사를 실행하고, 빠른 설정과 AI 제공자로 여러 모델을 한 계정에서 이용할 수 있는 OpenRouter를 선택한다.
  • OpenRouter 계정에 크레딧을 충전하고 API 키를 만들어 터미널에 입력하며, 영상은 시작 예산으로 기본값인 10달러를 제시한다.
  • API 키는 비밀번호처럼 취급하고, 키 생성 뒤 다시 볼 수 없으므로 복사해 안전한 곳에 보관하라고 안내한다.
  • 기본 모델 예시로 DeepSeek V4를 선택하며, GPT 5.4 Mini와 생각 태그가 켜진 Qwen 3.x 추론 모델은 도구 호출에 부적합할 수 있다고 말한다.

05텔레그램 연결과 접근 제한

  • 텔레그램 BotFather에서 새 봇을 만들고 토큰을 설정 마법사에 입력해 Hermes가 메시지를 주고받도록 연결한다.
  • 기존 OpenClaw 등의 봇 토큰을 재사용하면 두 에이전트가 같은 봇을 두고 충돌할 수 있어 Hermes용 봇을 새로 만들라고 안내한다.
  • Userinfobot으로 확인한 개인 텔레그램 ID를 허용 목록에 등록해, 다른 사람이 봇을 찾아 AI 크레딧을 사용하는 일을 막는다.
  • 개인 ID를 home channel로 지정하면 예약 작업 결과와 에이전트가 먼저 보내는 메시지를 받을 곳으로 설정된다.

06게이트웨이 실행과 첫 메시지

  • Hermes gateway install로 텔레그램 연결을 구성한 뒤 Hermes gateway run을 실행해 메시지를 전달하는 게이트웨이를 띄운다.
  • 실행 중 root 권한 오류가 발생하자 영상에서는 Hermes 사용자 권한으로 게이트웨이를 실행하는 명령을 적용한다.
  • 봇에 첫 메시지를 보내 응답을 확인하고, 응답이 없으면 API 키·허용 목록의 사용자 ID·게이트웨이 상태를 점검하라고 안내한다.
  • 설정 진단 명령으로 Hermes doctor를 소개하고, 해결되지 않으면 Hermes setup을 다시 실행하는 방법을 제시한다.

07스킬을 활용한 웹 조사와 결과 저장

  • 스킬은 복잡한 요청의 절차를 저장해 반복 실행하는 워크플로이며, 메모리는 대화가 달라져도 사용자의 정보를 이어서 기억하는 기능이다.
  • 예시 요청은 이메일 마케팅 입문 관련 유튜브 영상 상위 5개의 제목·채널·내용을 조사하고, 빠진 주제를 정리하는 것이다.
  • 에이전트는 필요한 Chrome을 설치하고 웹페이지를 조사한 뒤 결과를 요약해 알리며, 파일은 서버의 optata/e-marketing-top5-YouTube.md에 저장한다.
  • 영상은 조사 결과가 서버에 저장되고 같은 작업을 일정에 따라 실행할 수 있다고 설명하지만, 제공된 자막은 실제 예약 설정 단계까지 보여주지 않는다.
