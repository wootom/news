클로드와 p5.js로 개발자와 선생님 역할을 부여해 코드를 이해하고 수정하는 학습법

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

바이브 코딩의 한계와 두 역할 코딩 개념

  • 바이브 코딩은 말로 지시하면 AI가 코드를 생성하지만, 사용자가 코드를 몰라 수정 시 처음부터 다시 부탁해야 하는 문제가 있다.
  • 코딩은 제작 후에도 발전과 운영이 필요하므로 모듈의 역할과 변경 시 영향을 아는 것이 필수적이다.
  • 두 역할 코딩은 AI에게 개발자(제작)와 선생님(설명) 역할을 동시에 부여해 사용자가 성장할 수 있게 하는 방법이다.

p5.js 에디터와 점균 시뮬레이션 코드 분석

  • p5.js는 웹 브라우저에서 자바스크립트 코드를 작성하고 즉시 실행해 시각적 결과를 확인할 수 있는 그래픽 프로그래밍 환경이다.
  • 점균 시뮬레이션 코드는 개미 4,000마리가 밝은 쪽으로 이동하고 지나간 자리에 흰 점을 남기는 단순 규칙을 기반으로 혈관 같은 그물망을 생성한다.
  • 코드는 프로그램 시작 시 한 번 실행되는 setup 함수와 1초에 60번 반복되는 draw 함수로 구성되며, 반복 실행으로 애니메이션이 생성된다.

초보자 친화적 코드 개선 및 에러 해결 과정

  • AI에게 초보자임을 명시하고 코드를 쉽게 설명하게 요청하면, 복잡한 알고리즘이 자연 현상 비유로 단순화되어 이해가 쉬워진다.
  • AI가 생성한 코드에는 조절판 구역에 숫자 10개와 그 의미를 주석으로 명시해 사용자가 쉽게 실험할 수 있도록 구성된다.
  • HTML 코드가 포함된 파일 전체를 p5.js에 붙여넣으면 에러가 발생하지만, 자바스크립트 부분만 추출해 해결할 수 있다.

코드 파라미터 실험 및 재사용 지침 작성

  • 개체 수를 500마리로 줄이면 패턴이 단순해지고, 센서 각도나 거리 등을 수정하면 시각적 패턴이 변화함을 확인할 수 있다.
  • AI에게 개발자와 선생님 역할을 담은 지침을 작성하게 하면, 이후 대화에서 이 지침을 제공해 즉시 학습 친화적 코딩 모드로 진입할 수 있다.
  • 사용자가 좋아하는 결과물을 기반으로 에러를 해결하며 학습하면 동기 부여가 되어 자연스럽게 코드 전문가로 성장할 수 있다.
