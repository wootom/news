03VPS 신규 설치 흐름 (Hostinger 예시)

  1. 원클릭 템플릿 페이지에서 Get Started (약 499루피) 또는 KVM 1/2 플랜 선택
  2. 초기 설정에서 Anthropic/OpenAI/Gemini/X API 키 입력 (기본으로 gateway token 제공)
  3. 예: Google AI Studio에서 Gemini API 키 생성 → 붙여넣기 → Deploy
  4. Open 버튼으로 접속, gateway token 복사 → 로그인

(설정 딥링크)

04모바일 앱 페어링

단계내용
앱 설치App Store/Play Store에서 "openclaw"(openclaw Foundation) 검색·설치
연결 시작앱에서 Continue → Connect gateway (QR 스캔 또는 수동)
도달성 확보Tailscale 또는 public URL/IP 중 선택 (영상은 HTTPS URL 사용)
페어링웹 인스턴스에 /pair QR 또는 자연어로 "iPhone 페어링해줘" 요청
코드 적용생성된 setup code 복사 → 앱에 붙여넣기 → Apply → Trust & Connect
실전 팁: /pair QR 슬래시 명령이 종종 작동 안 함 → 자연어 프롬프트로 페어링 요청하면 에이전트가 안내. public URL 방식은 HTTPS가 필수이며, 인스턴스에 URL을 명시적으로 알려줘야 안정적.

05페어링 후 가능한 것

노트북 없이 전 세계 어디서나 openclaw 원격 사용. 웹·모바일 세션 동기화(모바일 메시지가 웹에도 표시). 앱 내 기능: 음성(talk) 모드, 에이전트, 크론 잡, 세션, 스킬 추가, 워크로드 등 웹 버전 대부분 기능 제공.
