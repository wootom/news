Astra 6.2와 Fable 5.2 비교: Fable이 7승으로 품질 우위, Astra가 7.2배 저렴한 비용

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

분석 범위: 원문 전체 34,337자 · 6개 구간. 원문 대조한 핵심 인용 33개를 바탕으로 요약했습니다.

테스트 설계 및 12개 유스케이스 비교 기준

  • GPT Astra 6.2와 Fable 5.2를 웹 디자인, 전문 슬라이드 제작, 여행 계획, 3D 월드 등 12개의 실제 사용 사례로 정면 대결시켰다.
  • 두 모델은 서로 간섭하지 않도록 분리된 워크트리에서 동일한 조건과 프롬프트로 실행되어 공정성을 확보했다.
  • 평가 지표로는 실행 시간, 입력 및 출력 토큰 수, 그리고 API 과금 기준 달러 비용을 측정하여 모델별 적합성을 분석했다.

코딩 및 에이전트 작업에서의 효율성 차이

  • 특정 코딩 작업에서 Fable은 56분간 실행되어 API 비용 17.5달러를 기록한 반면, Astra는 12분 만에 2.5달러로 완료되어 Astra가 승리했다.
  • 다른 작업에서는 Fable이 스트로크 한계에 부딪혀 작업을 중단한 반면, Astra는 이를 우회하는 방식으로 더 효율적인 결과를 도출했다.
  • 일부 시각화 작업에서는 Fable이 63달러, Astra가 7.5달러를 소모했으며, Fable의 출력 품질이 우수해 Fable이 승리했다.

3D 인터랙티브 월드 및 영상 제작 품질

  • 3D 가상 서밋 월드 생성에서 Fable은 실내 스케일 트랙을, Astra는 야외 콘서트 스타일을 구현했으며, 시각적 완성도에서 Astra가 우세했다.
  • Fable 5.2는 입력 토큰당 8달러, 출력 토큰당 40달러의 높은 단가를 가지며, 이는 Astra보다 토큰 효율이 낮은 결과로 이어졌다.
  • 영상 제작 시 Fable 5.2는 사운드 디자인과 B-롤 선택이 더 몰입감 있게 평가되어 Astra보다 4배 비싼 비용에도 불구하고 승리했다.

유튜브 영상 파이프라인 및 학습 가이드 테스트

  • 유튜브 영상 제작 파이프라인에서 Fable은 5시간 이상 소요되어 비정상적인 실행 시간을 기록했으나, 출력 품질은 매우 아름다웠다.
  • Astra는 7달러로 저비용을 기록했으나 품질이 열악해 Fable이 승리했으며, Fable은 구형 스킬을 호출하는 오류도 발생했다.
  • 26단계 학습 가이드 생성 작업에서 Fable은 17달러, Astra는 2달러를 소모했으며, Astra가 더 적은 비용으로 승리했다.

여행 계획 및 스프레드시트 작업 결과

  • 여행 계획 시나리오에서 두 모델 모두 샌프란시스코, 요세미티, 지온을 포함한 유사한 일정을 독립적으로 생성했다.
  • Fable은 시각적 디자인보다 상세한 정보 제공에 강점을 보여 여행 계획 항목에서 승리했으며, Astra는 디자인이 덜 혼란스러웠다는 평가를 받았다.
  • 스프레드시트 작업에서 두 모델 모두 수식 기능을 올바르게 구현했으며, Fable이 15달러, Astra가 2.5달러를 소모해 Fable이 품질로 승리했다.

종합 결과 및 비용 대비 성능 분석

  • 12개 유스케이스 중 Fable 5.2가 7승, Astra 6.2가 5승으로 Fable이 질적 우위를 점했으나, 총 API 비용은 Fable이 7.2배 더 비쌌다.
  • Fable은 더 긴 실행 시간과 높은 토큰 소모를 보였으며, Astra는 토큰 효율성이 높아 저비용으로 안정적인 성능을 유지했다.
  • 고급 스킬을 적절히 쌓아 올리는 환경에서는 Astra가 Fable에 버금가는 성능을 발휘할 수 있어, 용도별 모델 선택이 중요하다고 결론지었다.
