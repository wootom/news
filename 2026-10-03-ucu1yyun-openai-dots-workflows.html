OpenAI의 dots는 출장 준비와 고객 피드백 업무를 대화로 연결해 처리 과정을 시연했다

출장과 피드백 업무를 맡긴 dots 시연, 진행 중과 완료를 구분하다

01핵심 개요

  • OpenAI dots 시연에서 사용자는 전화로 LA 출장 조건을 제시하고 항공편·호텔 후보를 확인했지만, 영상 끝까지 항공권은 예약 진행 중이었다.
  • 항공편은 회사 규정과 환불 가능 여부가 조건이었고, 회의 시간에 맞춰 공항 이탈·차량 이동 시간을 고려해 더 이른 도착을 검토했다.
  • 호텔은 실버 레이크 풀 앤 인과 카라가 후보로 제시됐으며, 사용자가 사진과 지도를 보고 실버 레이크를 선택했지만 예약 확정은 제시되지 않았다.
  • 고객 피드백 절차는 수동 수집, 통합 목록 분류, Linear 작업·PR 연결, 수정 상태와 재검증 추적으로 설명됐고 자동 수집은 아니었다.
  • 최근 24시간의 주요 문제로 신뢰성이 거론됐지만 전체 순위는 확인 중이었으며, 미답변 Slack 메시지의 답장 초안 작성도 요청했다.

02핵심 주장 / 논점 구조

  • 시연의 중심은 전화 대화로 여러 업무를 맡기고, 중간에 조건을 바꾸며 처리 과정을 확인하는 모습이다.
  • 요청한 업무와 실제 완료된 결과를 구분해야 한다. 호텔 후보 선택은 나왔지만 항공권은 예약 중이라고 영상 끝에 언급됐다.
  • 출장 준비와 피드백 분석 모두 결과 조건을 전달하고, 도구를 거쳐 처리하며, 마지막에 완료 여부를 확인하는 흐름으로 제시됐다.
  • 시연은 업무가 모두 끝났거나 성능이 항상 같다는 증명이 아니라, dots에 업무를 맡기는 과정을 보여준다.

03LA 출장 조건과 항공편 검토

  • 사용자는 다음 날 LA에서 오후 3시쯤 할리우드에 도착해야 하고, 회사에서는 오전 10시쯤 출발 가능하다고 설명했다.
  • 항공편 조건은 회사 출장 규정 준수와 환불 가능 여부였다. 초기에 사우스웨스트의 오전 11시 30분 출발·오후 12시 55분 도착 후보가 약 326달러로 제시됐다.
  • 이후 브라우저 화면을 살펴보며 사우스웨스트 항공편의 오전 11시 20분 도착 가능성을 확인하고, 규정에 맞는 환불 요금인지 검토했다.
  • LAX에서 나오는 데 30~45분, 차로 이동하는 데 45~75분을 예상해 정오에 가까운 도착이 더 여유롭다는 판단으로 조건을 조정했다.

04호텔 후보 선택과 예약 상태

  • 호텔 후보로 실버 레이크 풀 앤 인과 할리우드에 더 가까운 카라가 제시됐다.
  • dots는 호텔 사진과 지도를 채팅으로 보내겠다고 했고, 사용자는 사진을 본 뒤 실버 레이크 풀 앤 인을 선택했다.
  • dots는 1박 예약을 준비하면서 총금액과 취소 조건을 확인하겠다고 답했다.
  • 영상에는 결제 영수증이나 예약 확정 결과가 나오지 않으므로, 호텔 후보 선택과 예약 완료를 같은 단계로 볼 수 없다.

05고객 피드백 수집·수정 절차

  • 현재 절차는 채널의 제보와 답글을 수동으로 읽어 통합 목록에 넣고 분류하는 방식이며, 새 메시지를 자동 수집하지 않는다.
  • 실제 문제는 확인된 Linear 작업 항목과 연결하고, 해당 작업을 PR과 이어 수정 중·배포·재검증 상태를 추적한다고 설명했다.
  • 작업 항목끼리 대조하는 일은 아직 끝나지 않았으며, 대시보드는 작업 내용을 요약하는 역할로 언급됐다.
  • 해결책이 없는 큰 문제를 우선 찾고, 수정이 반영되면 Slack에 PR 링크와 재시도 요청을 남긴 뒤 실제 해결 여부를 재검증하는 흐름을 제안했다.

06최근 피드백에서 드러난 신뢰성 문제

  • 최근 24시간의 피드백을 묻자 dots는 답이 없거나 도구에 접근하지 못하는 상황을 신뢰성 문제로 들었다.
  • 사용자가 dots가 실제로 일하는지 알기 어렵다는 점도 언급됐다. 응답 누락, 도구 접근 실패, 불분명한 진행 상황이 사례다.
  • 설명에서는 실제 실행 실패와 진행 상태가 보이지 않는 문제가 함께 다뤄졌다.
  • dots는 전체 발생 건수 순위를 확인 중이라고 밝혔으므로, 신뢰성이 가장 많이 나온 불만이라고 확정하지 않았다.

07미답변 Slack 메시지와 시연의 마무리

  • 사용자는 dots와 함께 출시한 ChatGPT, Slack, Teams의 관계를 묻는 주요 Slack 메시지 중 아직 답하지 못한 것을 모아 답장 초안을 요청했다.
  • 요청은 답장 초안 작성이며 실제 메시지 발송이 완료됐다는 내용은 영상에 나오지 않는다.
  • 마무리에서 사용자는 항공권이 여전히 예약 중이고, 호텔 후보를 골랐으며, 피드백 절차와 우선순위를 정리할 수 있다고 말했다.
  • 시연은 결과를 맡길 때 원하는 결과, 지켜야 할 조건, 완료를 확인할 증거를 함께 정하라는 요령으로 끝난다.

08용어 사전

용어뜻

Linear고객이 제기한 실제 문제를 기록하고 수정 작업과 연결하는 작업 항목 관리 도구로 언급됐다.
