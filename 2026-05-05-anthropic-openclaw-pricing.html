01
핵심 개요 — 무슨 일이 벌어지고 있나

Anthropic(Claude AI 개발사)이 사용자가 오픈클로(openclaw)나 Hermes 같은 AI 에이전트 오케스트레이션 도구(여러 AI를 연결해 복잡한 작업을 자동화하는 소프트웨어)를 쓴다고 감지하면 추가 요금을 부과하거나 요청을 거부한다는 의혹이 제기됐습니다.

문제의 핵심

동일한 API 호출인데 특정 도구 사용 여부에 따라 요금이 달라짐

영향 범위

Claude Code 직접 호출 사용자 + 오픈소스 AI 도구 개발자

02
구체적 사례 — 어떤 일이 있었나
Theo Brown의 트윗 (실제 사례)

"최근 커밋에 'openclaw' 언급이 있으면 Claude Code가 요청을 거부하거나 추가 요금을 부과한다. 빈 레포에서 Claude Code를 직접 호출했는데도 차별 적용됐다."

패턴 분석
  • 코드/커밋 메시지에 오픈클로 언급 감지
  • AI 에이전트 "하네스" 사용 패턴 탐지
  • 감지 시 → 거부 또는 추가 과금
03
기술적 맥락 — 하네스(Harness)란 무엇인가

AI 하네스(Harness) = 여러 AI 모델이나 도구를 연결해 복잡한 작업을 자동화하는 오케스트레이션 프레임워크(일종의 AI 지휘 시스템)

  • 오픈클로(openclaw): 오픈소스 AI 에이전트 오케스트레이션 프레임워크
  • Hermes: 유사한 AI 에이전트 도구
  • 이런 도구들은 Claude API를 반복·대량 호출하는 경향
Anthropic의 논리
"고자원 사용 패턴 = 더 많은 비용 부담"
04
전략적 의미 — 생태계 vs 수익화 딜레마
Anthropic 입장
  • 연산 비용이 실제로 더 많이 드는 패턴
  • 공정한 가격 정책 적용
  • 지속 가능한 비즈니스 모델 필요
사용자/개발자 반발
  • 동일 API 호출인데 차별 적용 불공정
  • 오픈소스 생태계 억압 우려
  • 신뢰 훼손 — OpenAI 등 경쟁사로 이탈 유발
05

06
활용 시나리오 — 영향받는 사용자 유형
AI 에이전트 개발자

오픈클로·Hermes 기반 서비스 운영 중. 갑작스러운 추가 비용 또는 서비스 차단 위험.

Claude Code 사용자

특정 오픈소스 도구와 함께 코딩 자동화. 요청 거부나 초과 청구 경험 가능.
