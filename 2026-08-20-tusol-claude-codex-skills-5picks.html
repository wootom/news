아 이거 비밀인데 (클로드 스킬)

01핵심 개요

항목내용
형식투쏠(AI 에이전트) 채널의 실전 데모 영상. 코덱스와 클로드 코드 두 세션을 동시에 띄워놓고 다섯 가지 스킬을 직접 실행해 보여준다.
화자투쏠(유튜버)
핵심 문제의식클로드 코드·코덱스 사용자들이 잘 모르거나 놓치고 있는 유용한 스킬(확장 기능)들을 실사용 데모로 소개하고, 바이브 코딩(AI와 대화하며 개발) 생산성을 높이는 실전 워크플로우를 제시.
소개된 스킬 5가지① 워치비디오(유튜브 영상을 프레임 단위로 직접 "보게" 해주는 스킬) ② 슈퍼파워스(브레인스토밍→계획→구현을 체계화하는 운영 시스템급 스킬) ③ 코덱스 플러그인(클로드로 계획, 코덱스로 구현, 상호 교차검증하는 협업 스킬) ④ 그릴미(모호한 아이디어를 질문으로 구체화하는 인터뷰형 스킬) ⑤ 리모션(모션 그래픽·영상 편집을 코드로 생성하는 스킬)
부가 도구타임리스(Timeless) — 단순 음성 전사가 아니라 두서없는 말을 구조화된 프롬프트로 변환해주는 음성 입력 프로그램. 웹앱과 터미널 양쪽에서 사용 가능.
실행 방법클로드 코드는 슬래시(/) 입력으로 스킬 목록 확인, 코덱스는 Shift+$ 단축키로 스킬 목록을 불러와야 한다는 인터페이스 차이가 있다.

02핵심 기능/내용 구조

  1. 도입 및 인터페이스 차이 설명: 클로드 코드에서는 슬래시(/)를 입력하면 슈퍼파워스, 라이팅 플랜 등 설치된 스킬 목록이 표시되지만, 코덱스에서는 슬래시로 스킬 목록이 뜨지 않고 Shift+$(달러 표시)를 눌러야 스킬을 불러올 수 있다는 두 도구의 UI 차이를 먼저 짚는다.
  2. 스킬 1 - 워치비디오(Watch Video): 클로드·코덱스에게 "눈"을 달아주는 스킬로, 유튜브 링크만 주면 기본적으로는 자막(스크립트)만 가져올 수 있지만, 워치비디오 스킬을 쓰면 영상을 실제로 다운로드해 프레임 단위로 나눠 시각적으로 "보고" 분석할 수 있게 된다. 데모에서 스킬 없이 영상을 요청하면 자막만 가져온다고 답하지만, 스킬을 적용하면 "비주얼 모드"로 영상의 모션 그래픽 스타일까지 구체적으로 분석(예: "본편은 스튜디오 녹색 UI 모션, 사이드 결과물은 정지 일러스트에 느린 줌을 얹은 스틱 애니메이션"이라는 식의 상세 분석)해낸다. 진행자는 이를 유튜브 콘텐츠 벤치마킹에 활용하고 있다고 소개한다.
  3. 부가 도구 타임리스 소개: 데모 중 타이핑 대신 특정 버튼을 누르고 말하면 텍스트로 변환되는 모습을 보여주며, 이 프로그램이 '타임리스'라고 소개한다. 단순 음성 전사와 달리, 두서없이 말한 내용(예: 백엔드·프론트엔드 다 필요한데 스택을 모르겠다는 두서없는 요청)을 구조화된 프롬프트로 정리해주는 점이 코덱스 내장 음성 입력 대비 차별점이라고 시연한다.
  4. 스킬 2 - 슈퍼파워스(Superpowers): 깃허브 스타 수가 20만 개에 달하는 인기 스킬로, "AI가 성급하게 코드를 짜지 않고 숙련된 개발팀의 업무 순서대로 일하게 만드는 운영 시스템"으로 요약한다. 브레인스토밍(요구사항 정리) → 라이팅 플랜(작업 순서 설계) → 유즈 깃 워크트리(안전한 작업 공간 구성) → 테스트 드리븐 디벨롭먼트(TDD 방식 구현) 순으로 이어지는 올인원 워크플로우이며, 진행자는 이 스킬 사용 여부에 따라 결과물 품질 차이를 크게 체감한다고 강조한다.
  5. 스킬 3 - 코덱스 플러그인(코덱스 스킬): 오픈AI가 직접 만든 플러그인으로, 터미널에서 코덱스를 호출할 수 있게 해주며 코덱스 리뷰, 코덱스 구현 지원, 결과 가져오기 등의 기능을 제공한다. 데모에서는 "계획은 클로드 페이블5로 세우고, 실제 구현은 코덱스(루나 모델 중 추론도 높은 하이 모델)로 하며, 서로 교차 검증(클로드가 코덱스 구현을 검토하고 그 반대도 수행)한 뒤 메인 브랜치에 머지하는" 협업 프레임워크를 자연어로 지시해 실제로 이런 계획이 구조화되어 나오는 과정을 보여준다.
  6. 스킬 4 - 그릴미(Grill Me): 모호한 아이디어를 인터뷰 형식의 질문으로 구체화해주는 스킬. 데모에서 "개인 ERP를 만들고 싶은데 뭘 넣어야 할지 모르겠다"고 요청하자, "가장 없애고 싶은 혼란이 무엇인가", "ERP가 어디까지 관리해야 하나", "가장 중요한 사용자 역할은", "핵심 순간은 무엇인가" 등 라운드별 질문을 순차적으로 던지며 답변을 하나씩 받아 요구사항을 구체화하는 구조를 보여준다. 진행자는 이를 이전에 소개했던 '깃허브 매니페스트' 방식과 유사하다고 언급한다.
  7. 스킬 5 - 리모션(Remotion): 코드로 모션 그래픽과 영상 편집을 생성하는 도구로, 진행자 채널 영상 도입부의 모션 그래픽이 모두 이 도구로 제작됐다고 밝힌다. 리모션 공식 사이트의 문서(Docs) → AI → Skills 메뉴에서 스킬을 설치한 뒤, 레퍼런스를 제공하면 유사한 모션 그래픽을 만들 수 있다고 소개한다.
  8. 마무리 및 타임리스 재강조: 다섯 스킬 소개를 마치며, 진행자는 앞으로 키보드 타이핑 대신 타임리스를 활용한 음성 기반 작업 방식으로 전환할 계획이라 밝히고, GPT 라이브 등장으로 음성 기반 작업 흐름이 더 정교해지고 있다고 언급한다. 타임리스와의 협업을 통해 시청자를 위한 할인 혜택도 준비했다고 안내하며 마무리한다.

03기술적 맥락

이번 영상에서 소개된 스킬들은 클로드 코드·코덱스 같은 CLI 기반 AI 코딩 에이전트에 사후적으로 장착하는 확장 기능(스킬/플러그인) 생태계를 보여준다. 워치비디오는 LLM이 기본적으로 텍스트(자막)만 처리할 수 있다는 한계를, 영상을 프레임 단위로 쪼개 멀티모달로 분석하게 만들어 우회하는 방식이다. 슈퍼파워스는 AI 에이전트가 요구사항 파악 없이 바로 코드를 작성해 품질이 들쭉날쭉해지는 문제를, 브레인스토밍→계획→격리된 작업공간(깃 워크트리)→테스트 주도 개발이라는 소프트웨어 공학의 정석 프로세스를 강제함으로써 해결하려는 접근이다. 코덱스 플러그인을 활용한 "클로드로 계획, 코덱스로 구현, 상호 교차검증" 워크플로우는 서로 다른 모델(클로드 페이블5, 코덱스 루나 하이 모델)의 강점을 조합해 결과물의 신뢰성을 높이려는 멀티 모델 오케스트레이션 전략을 보여준다. 그릴미는 요구사항 명세가 불충분한 상태에서 AI가 임의로 가정하고 진행하는 문제를, 구조화된 인터뷰 질문으로 사용자의 암묵적 요구를 명시적으로 끌어내는 방식으로 해결한다.

04전략적 의미

첫째, AI 코딩 에이전트의 경쟁력은 이제 모델 자체의 성능뿐 아니라 "어떤 스킬·플러그인 생태계를 갖췄는가"로 옮겨가고 있으며, 슈퍼파워스처럼 20만 스타를 넘긴 오픈소스 스킬의 존재는 이런 생태계가 실사용자들에게 실질적 가치를 인정받고 있음을 보여준다. 둘째, 워치비디오처럼 텍스트 전용 모델에 시각 분석 능력을 부여하는 스킬은, 콘텐츠 벤치마킹·경쟁 분석 등 기존에는 사람이 직접 봐야 했던 작업을 AI로 위임할 수 있게 해 크리에이터 워크플로우에 실질적 변화를 준다. 셋째, 클로드와 코덱스를 상호 교차검증에 활용하는 멀티 모델 협업 패턴은, 단일 모델의 환각이나 편향을 다른 모델이 검증하게 함으로써 코드 품질을 높이는 실용적 접근으로, 향후 AI 개발 워크플로우의 표준 패턴이 될 가능성을 시사한다. 넷째, 음성 기반 프롬프팅(타임리스)의 부상은, 타이핑이라는 병목을 없애고 사람이 자연스럽게 말하는 두서없는 요청을 AI가 구조화된 작업 지시로 변환하는 방향으로 개발 인터페이스가 진화하고 있음을 보여준다.

06활용 시나리오

  1. 유튜브 콘텐츠 제작자의 벤치마킹: 경쟁 채널이나 레퍼런스 영상의 모션 그래픽·편집 스타일을 분석하고 싶을 때, 워치비디오 스킬로 자막이 아닌 실제 화면을 분석시켜 구체적인 제작 기법(스튜디오 UI 모션, 스틱 애니메이션 등)을 파악할 수 있다.
  2. 바이브 코딩으로 새 프로젝트를 시작하는 개발자: 아이디어는 있지만 기술 스택이나 세부 요구사항이 불명확할 때, 그릴미로 요구사항을 먼저 구체화한 뒤 슈퍼파워스의 브레인스토밍→라이팅플랜→구현 순서를 따라 체계적으로 프로젝트를 설계할 수 있다.
  3. 복잡한 풀스택 프로젝트의 품질 관리: ERP 시스템처럼 백엔드·프론트엔드가 모두 필요한 프로젝트에서, 계획은 한 모델(클로드)로 세우고 구현은 다른 모델(코덱스)로 수행한 뒤 서로 교차검증하게 함으로써 단일 모델 의존의 리스크를 줄일 수 있다.
  4. 타이핑 없는 음성 기반 개발 워크플로우 구축: 반복적으로 프롬프트를 입력해야 하는 개발자가 타임리스 같은 음성 구조화 도구를 도입해, 두서없이 말한 요청을 AI가 알아서 명확한 작업 지시로 정리하게 함으로써 입력 병목을 줄일 수 있다.

07현황 및 전망

영상 시점 기준 슈퍼파워스는 깃허브 스타 20만 개를 넘긴 인기 오픈소스 스킬로 자리잡았으며, 클로드 코드·코덱스 생태계에서 스킬·플러그인을 조합해 쓰는 방식이 실전 개발자들 사이에서 표준 워크플로우로 자리잡아가는 추세임을 보여준다. 진행자는 향후 타임리스와 GPT 라이브 등 음성 기반 도구를 활용해 타이핑 없는 작업 흐름으로 완전히 전환할 계획이라 밝혔으며, 다음 영상에서는 음성 입력에 대한 추가적인 번역·고품질화 플로우를 소개하겠다고 예고했다. 코덱스 플러그인처럼 서로 다른 AI 도구를 교차검증 방식으로 조합하는 멀티 모델 협업 패턴은, 향후 AI 코딩 워크플로우가 단일 모델 의존에서 벗어나 여러 모델의 강점을 조합하는 방향으로 발전할 가능성을 시사한다.
