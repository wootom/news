길이약 69분(4120초)
핵심결론 1루프 엔지니어링은 '루프를 시작·재개하는 것'이 아니라 의도(goal)에 도달할 때까지 '루프를 끝나지 않게 만드는' 공학이며, 에이전트가 에이전트를 스티어링하는 방식으로 진화 중
핵심결론 2새 프론티어 모델 '페이블 5(MTS 프리뷰)'는 작업 구조 분해와 서브에이전트 위임을 뛰어나게 수행해, 사람이 만들던 하네스를 모델이 흡수하는 방향이 명확해짐
핵심결론 3토큰 값은 석유·전기처럼 계속 비싸질 것으로 보며, 접근 여력에 따른 '토큰 신분제' 격차와 오픈소스·중국 모델(Qwen 3.7 Max, 딥시크 V4, 샤오미 미모) 활용 전략을 논의

02핵심 내용 구조

roach-pi와 골(goal) 워크플로우

  • 정승현 개발자(릿 소속, 전 배민)가 만든 roach-pi는 오픈소스 하네스 '파이(pi)' 위에 자신의 스킬과 방법론을 얹은 도구로, Claripi 단계에서 프롬프트가 모호하면 명확해질 때까지 인터뷰하는 골 지향적 구조.
  • OMX·OMC·우로보로스와 유사한 '작업 전 명확화' 패턴을 갖되, 모호도를 수학적으로 점수화하지 않고 에이전트가 이해했다고 판단할 때까지 반복하는 방식으로 차별화.

사람이 병목이라는 문제와 스티어링

  • 안드레 카파시의 '이해는 아웃소싱할 수 없는 물질'이라는 말에 공감하며, 사람이 있어야 할 곳은 의도를 주는 앞단과 검증·책임을 지는 뒷단이라고 정의.
  • roach-pi는 토큰을 적게 쓰는 방향을 지향해 만들어졌으며, 사람을 LLM 하네스의 한 요소로 간주.

루프 엔지니어링의 정의와 변화

  • 과거 랄프 루프(Ralph Loop)는 루프 '밖'에서 스펙 등 고민을 끝내고 while 루프만 돌려 완수까지 반복하는 방식이었으나, 지금의 루프 엔지니어링은 루프 '안'에서 에이전트가 에이전트를 스티어링하며 고민.
  • 피터 스테인버그가 "프롬프트를 얘기하지 말고 루프를 설계하라"고 트윗하며 바이럴됐고, 골과 클로드의 다이나믹 워크플로우가 루프 엔지니어링 계열로 분류됨.

페이블 5(신규 프론티어 모델) 충격

  • 발표 당일 사용해 본 결과 작업 구조 분해·서브에이전트 위임 능력이 압도적이었고, 두 줄 프롬프트로 돌린 갤러그 게임 벤치마크에서 에셋까지 옛날 게임기 수준으로 스스로 생성.
  • 다만 1시간도 못 돌리고 중단되는 사례가 잦아 상용화까지는 시간이 더 필요하다는 평가.

메모리 시스템 철학

  • roach-pi 메모리는 유사도 검색이 아닌 키워드 매칭으로 굳어졌으며, 에이전트에게 검색 도구를 주면 검색어를 잘 넣기 때문. 장애·디버그·픽스 관련 키워드를 LLM이 정리해 저장.
  • 롱텀 메모리보다 200개 정도만 저장하고 오래된 것은 자동 삭제하는 구조를 선호. 현재 토큰 비용상 대규모 롱텀 메모리는 엔터프라이즈에서 무리라고 판단.

캐시 안정성과 리즈니스(reasness)

  • KV 캐시가 깨지면 응답이 느려지고 미적중분을 비용으로 지불하게 되는데, 세션 중 퍼미션(욜로 등) 변경이 캐시를 깨뜨리는 대표 원인.
  • 리즈니스 레포지토리는 캐시를 깨는 동작을 막거나 경고하며, 딥시크·샤오미 미모와 함께 쓰면 캐시 적중 시 시간당 1달러 미만도 가능.

03기술적 맥락

  • 하네스 엔지니어링, 컨텍스트 엔지니어링, 스레드 관리(코덱스 앱의 아카이빙·핀), 프롬프트 캐싱 등 에이전트 코딩의 세부 개념이 급격히 세분화되는 국면.
  • 클로드 코드는 서브에이전트 네스티드 뎁스(중첩 스폰 개수)를 늘리는 방향을 게시했고, 다이나믹 워크플로우는 루프 안에서 자바스크립트 코드를 생성해 에이전트를 조율.

04전략적 의미

  • '하네스는 모델이 높은 확률로 흡수'하므로 인간의 역할은 의도(intent)와 평가 지표(evaluation metric) 설정으로 수렴한다는 전망.
  • 코드는 '노동'이며 그 노동은 에이전트가 맡고, 엔지니어는 컴퓨터 공학보다 컴퓨터 과학(안정적 시스템 설계) 쪽으로 이동할 것.

05핵심 워크플로우·방법론

  • 골 실행 전, 에이전트와 "이거 코드베이스 보고 확인해 줘 → 어떻게 구현하면 돼"를 여러 턴 주고받아 의도를 다듬은 뒤 실행.
  • 꿀팁: "깐깐하고 비평적인 적대적 리뷰어에게 검토받기 전에 절대 골을 끝내지 마라"를 넣으면 작업 완수율이 약 30% 상승.
  • 유사 작업은 한 스레드 안에서 이어가 컴팩션(압축) 시에도 의도가 유지되게 함.

06활용 시나리오

  • 비개발자도 코덱스 앱 수준의 도구로 반복 리뷰 처리, 에러 발생 시 자동 PR 생성 등 일상 자동화 가능.
  • 3Blue1Brown식 애니메이션은 헤르메스의 마님(MANIM) 스킬 + 일레븐랩스 나레이션을 코드로 결합해 제작하는 다큐멘터리 워크플로우로 응용.

07현황 및 전망

  • roach-pi 로드맵은 Claripi를 빼고 '울트라 워크' 하나로 단순화, 다이나믹 워크플로우 개념을 녹여 서브에이전트에 경제 효율적으로 서빙하는 방향.
  • 중국 프론티어 모델은 개발에는 무리 없으나 중국어 출력·비엔지니어 업무 취약으로 기업 내부 시스템에는 미국 소타 모델이 여전히 경제적이라는 판단. '바이오 토큰'(운동·식단으로 사람의 체력 토큰 확보) 개념도 강조.

08용어 사전

용어한줄 설명비유·예시

루프 엔지니어링의도 달성까지 루프가 끝나지 않게 설계하는 공학목표 도달 전까지 멈추지 않는 훌라후프
KV 캐시이전 대화 문맥을 캐싱해 속도·비용을 아끼는 구조앞 문장이 바뀌면 뒤가 통째로 재계산
토큰 신분제토큰 사용 여력에 따라 벌어지는 능력·기회 격차석유·비싼 전기처럼 공급되는 자원
