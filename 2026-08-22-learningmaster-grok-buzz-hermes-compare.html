이제 AI 에이전트가 대신하는 시대! 그록봇 vs 버즈 vs 엘엠스 비교

01핵심 개요

항목내용
형식배움의 달인 채널 운영자 김문정이 본인이 실제로 굴리고 있는 3개 멀티에이전트 플랫폼(xAI 그록봇, 버즈, 엘엠스/LMS)의 화면을 직접 보여주며 사용법과 체감 장단점을 비교하는 단독 진행 영상
화자김문정 (배움의 달인 채널 운영자)
배경최근 그록봇(xAI), 에르메스(LMS) 봇 모드가 잇달아 출시되었고, 화자는 한 달 전부터 버즈를 써오던 상황에서 세 플랫폼을 비교하게 됨
핵심 주장과거에는 "하나의 에이전트와 인간의 협업"이었다면, 이제는 "에이전트와 에이전트, 또는 에이전트 집단 간의 협업" 사이에 사람이 개입(휴먼 인 더 루프)하는 방식으로 업무 형태가 바뀌고 있다는 것
공통 운영 방식화자는 각 플랫폼에서 개별 에이전트에게 직접 지시하지 않고, 전체를 총괄하는 "본사(다린 홀딩스)" 역할의 상위 에이전트에게만 요청을 던지면 본사가 하위 에이전트들을 알아서 조율해 처리하는 방식을 쓰고 있음

02핵심 기능/내용 구조

  1. 그록봇(xAI Grok Bot) — 가장 쉬운 입문용: xAI가 만든 봇 플랫폼으로, 봇 하나를 만들면 그 봇이 다시 다른 봇들을 생성하도록 위임할 수 있다. 화자는 자신의 취향·관심사·업무 방식을 총괄 봇("참모실/치프 오브 커맨더")에게 한 번에 입력했더니 필요한 하위 봇들을 알아서 세팅해줬다고 소개한다. 가장 큰 특징은 봇마다 가상 컴퓨터(VM)가 딸려 있다는 점 — 메모리 약 16GB, 저장공간 약 128GB 수준의 VM 안에 옵시디언을 설치하고 본인의 실제 옵시디언 볼트와 싱크시켜, 자기 컴퓨터가 꺼져 있어도 그록봇을 통해 노트를 열람·작성할 수 있다. 이는 과거 유행했던 "맥미니에 오픈클로드를 깔아 24시간 상시 에이전트를 돌리는" 방식과 달리 별도 물리 머신이 필요 없다는 장점으로 이어진다. 투자 관리용으로는 김기헌 대표가 만든 "분리자" MCP와 토스 API를 연동한 에이전트를 운용해 리포트 생성과 계좌 매매를 함께 처리하며, 실제로 주가 하락 시 "추가 매수하지 말라"는 조언을 받아 따른 경험도 소개한다. 이 밖에 여러 에이전트가 서로 회의(토론)하도록 팀을 구성하는 기능, Gmail 플러그인으로 파트너십 제안 메일만 골라 응대 초안을 만드는 비서 에이전트, 챗GPT 앱을 원격 컨트롤하는 에이전트 등 플러그인 생태계가 풍부하다는 점을 강조한다.
  2. 버즈(Buzz) — 커스터마이즈 가능한 오픈소스: 슬랙과 비슷한 쓰레드 기반 UI로, 작업별로 쓰레드가 생성되어 업무 이력 관리에 유리하다. "펄스"에서 진행한 작업을 확인할 수 있고 인박스로 알림도 받는다. 그록봇과의 결정적 차이는 에이전트를 구동하는 AI 모델(두뇌)을 직접 선택할 수 있다는 점 — 코덱스, xAI, 커서, 페이블, 업스테이지 등 다양한 모델을 에이전트 목적에 맞게 조합할 수 있다. 예시로 엑스필드(Hexfield) MCP가 연결된 에이전트 "세린"과, X(트위터)에서 이미지를 조사하는 "소연" 에이전트를 연계해, 소연이 조사한 내용을 세린에게 넘기면 세린이 엑스필드로 이미지를 생성하는 식의 에이전트 간 협업(체이닝)을 시연한다. 오픈소스이며 깃허브에서 내려받아 레일웨이(Railway)에 배포하면 거의 비용 없이 운영 가능하고, 도커 설치도 지원한다. 화자는 레일웨이에 올려 사용 중이며 비용 부담이 거의 없다고 언급한다.
  3. 엘엠스(LMS) — 봇 간 커뮤니케이션에 강점: 기존에 LMS에서 쓰던 "프로파일"들을 봇 형식으로 전환한 구조. 버즈와 유사하게 에이전트별로 구동 모델(브레인)을 다양하게 선택할 수 있으며, 특히 누 포털(모델 제공 플랫폼) 가입 시 업스테이지 솔라 프로 4, 롱캣 등 여러 모델을 한시적으로 무료 제공받아 활용할 수 있다(업스테이지 솔라 프로 4는 8월 25일까지 무료). LMS의 장점은 봇과 봇 사이의 커뮤니케이션이 특히 원활하다는 점이며, 단점은 공식 모바일 앱이 없어 이동 중 활용도가 그록봇·버즈보다 떨어진다는 점이다.
  4. 결론 — 용도별 선택 기준: 화자는 "그록봇의 기능이 더 뛰어나다"기보다 "쉽다"는 점에서 입문자에게 가장 추천할 만하다고 평가한다. 반면 기존에 구축해둔 스킬이나 MCP 자산이 있는 사람에게는 모델 커스터마이즈가 자유로운 버즈가 적합하다고 본다. 세 플랫폼 모두 화자 개인 회사("다린 홀딩스") 산하의 "본사" 에이전트가 총괄하며, 개별 에이전트 기능을 일일이 외우는 대신 본사에만 요청하면 본사가 하위 에이전트를 조율하는 방식을 취하고 있다고 설명한다.

03기술적 맥락

세 플랫폼 모두 공통적으로 "멀티에이전트 오케스트레이션"을 지향한다는 점에서 기술적 뿌리를 공유한다. 그록봇은 에이전트마다 격리된 가상 컴퓨터(VM) 환경을 제공해 파일시스템 상태(옵시디언 볼트 등)를 유지한 채 상시 구동할 수 있게 하며, 이는 로컬 머신에 상시 프로세스를 띄워야 했던 기존 "맥미니 + 오픈클로드" 방식의 인프라 부담을 클라우드 쪽으로 옮긴 것으로 볼 수 있다. 버즈와 LMS는 VM 제공보다는 "모델 선택의 자유도"와 "봇 간 메시지 전달(쓰레드/커뮤니케이션)"에 무게를 둔 아키텍처로, 사용자가 이미 구축한 MCP(Model Context Protocol) 연동이나 스킬 자산을 재사용하기 쉽다는 차별점이 있다. 영상에서 언급된 MCP 연동 사례로는 분리자(투자 리포트), 엑스필드(이미지 생성), 김기헌 대표가 만든 커스텀 MCP 등이 있으며, 이는 각 플랫폼이 표준 MCP 프로토콜을 통해 외부 도구·데이터 소스와 연결되는 구조임을 보여준다.

04전략적 의미

첫째, 화자가 반복 강조하는 "본사(상위 에이전트)에게만 요청하고 본사가 하위 에이전트를 조율한다"는 운영 패턴은, 에이전트 수가 늘어날수록 사용자가 각 에이전트의 기능을 일일이 기억하기 어려워지는 문제에 대한 실전 해법으로, 향후 "에이전트 오브 에이전트(오케스트레이터 계층)" 설계가 개인 사용자 단에서도 표준적인 대응 패턴이 될 수 있음을 시사한다. 둘째, 그록봇의 VM 내장 방식은 로컬 상시구동 인프라(맥미니 등)의 필요성을 낮춰, 저사양 기기(16GB 미만 메모리) 사용자도 무거운 에이전트 워크플로우를 클라우드에서 상시 실행할 수 있게 한다는 점에서 에이전트 활용의 진입장벽을 낮추는 방향으로 작동한다. 셋째, 화자가 "에이전트와 에이전트, 에이전트 집단의 협업 사이에 휴먼 인 더 루프가 들어간다"고 정리한 표현은, AI 활용의 무게중심이 "사람이 AI를 직접 조작"하는 단계에서 "AI 팀을 사람이 감독·승인"하는 단계로 이동하고 있음을 보여주는 관찰로 읽을 수 있다. 넷째, 무료 모델 프로모션(업스테이지 솔라 프로 4, 롱캣 등)을 활용해 비용 없이 여러 브레인 모델을 실험해볼 수 있다는 점은, 멀티에이전트 플랫폼 입문 시 초기 비용 부담을 낮추는 실용적 팁으로 기능한다.

05핵심 워크플로우 또는 비교표

플랫폼운영 주체핵심 특징모델 선택 자유도모바일 지원비용화자 평가
그록봇 (xAI)xAI에이전트별 가상 컴퓨터(VM) 내장, 옵시디언 등 상시 파일시스템 유지낮음(주로 xAI 모델)지원별도 언급 없음가장 쉬움, 입문자 추천
버즈 (Buzz)오픈소스슬랙형 쓰레드 UI, 에이전트 간 체이닝(예: 소연→세린) 시연높음(코덱스·xAI·커서·페이블·업스테이지 등)지원레일웨이 배포 시 거의 무료기존 MCP·스킬 자산 있는 사용자에게 적합
엘엠스 (LMS)LMS봇 간 커뮤니케이션 특화, 프로파일→봇 전환높음(누 포털 통해 무료 모델 다수)미지원(공식 앱 없음)무료 모델 프로모션 활용 가능봇 간 협업엔 강점, 이동 중 활용도는 낮음

06활용 시나리오

  1. 저사양 개인 컴퓨터로 상시 에이전트를 운영하려는 사용자: 맥미니 등 별도 상시구동 머신을 마련하기 어려운 경우, 그록봇의 VM 내장 구조를 활용해 옵시디언 볼트를 클라우드에 싱크하고 외출 중에도 노트 열람·작성 업무를 에이전트에게 위임하는 방식을 참고할 수 있다.
  2. 이미 MCP·스킬 자산을 구축한 파워유저의 플랫폼 전환 검토: 특정 워크플로우(투자 리포트, 이미지 생성 등)를 위한 MCP 연동을 이미 만들어둔 사용자가, 모델 선택 자유도가 높은 버즈나 LMS로 옮겨 기존 자산을 재사용하며 모델별 성능·비용을 실험하는 데 이 비교를 참고할 수 있다.
  3. 에이전트 수가 늘어나 관리가 어려워진 사용자의 오케스트레이터 도입: 여러 목적의 에이전트를 개별적으로 호출하다 관리 부담이 커진 경우, 화자의 "본사에만 요청 → 본사가 하위 에이전트 조율" 패턴을 벤치마킹해 상위 오케스트레이터 에이전트를 구성하는 설계에 참고할 수 있다.
  4. 무료 모델 프로모션을 활용한 비용 절감 실험: 업스테이지 솔라 프로 4, 롱캣 등 한시 무료 모델을 제공하는 누 포털 같은 서비스를 통해, 비용 부담 없이 여러 브레인 모델의 실제 업무 성능을 비교 테스트하려는 사용자에게 실용적인 진입 경로가 된다.

07현황 및 전망

영상 시점 기준 그록봇(xAI), 버즈, 엘엠스(LMS) 봇 모드는 모두 최근 수개월 내 출시·업데이트된 상태로, 화자는 "에이전트들이 너무 빠르게 계속 나오고 업데이트되고 있어" 구체적인 세부 활용법을 깊게 다루기보다는 전체적인 사용 감각과 선택 기준을 전달하는 데 집중했다고 밝힌다. 업스테이지 솔라 프로 4 무료 제공은 2026년 8월 25일까지로 한정되어 있어 시의성이 있다. 화자는 세 플랫폼을 용도별로 병행 사용 중이며, 특히 최근에는 그록봇의 접근성과 플러그인 다양성에 이끌려 그록봇을 더 집중적으로 연구하고 있다고 언급해, 향후 개인 단위 멀티에이전트 운영에서 "쉬운 입문 플랫폼 + 커스터마이즈 가능한 백엔드 플랫폼"을 함께 쓰는 하이브리드 운영이 늘어날 가능성을 시사한다.

08용어 사전

용어한줄설명비유
그록봇(Grok Bot)xAI가 제공하는 에이전트 플랫폼으로, 에이전트마다 가상 컴퓨터(VM)가 딸려 있어 파일시스템 상태를 상시 유지각 봇에게 개인 노트북 한 대씩 쥐여준 것과 유사
버즈(Buzz)쓰레드 기반 UI를 가진 오픈소스 멀티에이전트 플랫폼, 구동 모델을 자유롭게 선택 가능업무별 대화방을 만들고 방마다 다른 담당 직원(모델)을 배치하는 것과 유사
엘엠스(LMS)기존 프로파일을 봇 형식으로 전환한 플랫폼, 봇 간 커뮤니케이션에 특화여러 비서가 서로 메모를 주고받으며 협업하는 사무실 구조
MCP (Model Context Protocol)AI 에이전트가 외부 도구·데이터 소스에 표준화된 방식으로 연결되도록 하는 프로토콜에이전트에게 꽂아 쓰는 확장 어댑터
휴먼 인 더 루프(Human in the Loop)에이전트(들)의 자동화 프로세스 중간에 사람이 검토·승인·개입하는 구조자동 조립 라인 중간에 품질 검사원이 서 있는 것
본사(오케스트레이터 에이전트)여러 하위 에이전트를 조율·관리하는 상위 에이전트실무자에게 직접 지시하지 않고 팀장에게만 업무를 맡기는 구조
