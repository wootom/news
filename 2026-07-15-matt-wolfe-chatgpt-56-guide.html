02핵심 내용 구조

발표자 Matt Wolfe는 새 ChatGPT 앱을 크게 세 축으로 소개한다.

  • 통합 앱 투어: 기존에 흩어져 있던 ChatGPT, Codex(개발자용), 브라우저 앱, ChatGPT Work(일반 사용자용)를 하나로 합쳤다. 왼쪽 상단 드롭다운으로 전환한다.
  • 주요 신기능

- Sites: 웹 호스팅·백엔드·CDN 없이도 웹사이트·앱·게임을 만들면 즉시 온라인에 게시되고 누구나 접근·공유 가능하다. (CDN = Content Delivery Network, 콘텐츠 전송망) - 내장 브라우저 + Annotate: 화면의 특정 영역을 선택해 지시할 수 있고, 다른 브라우저의 쿠키·비밀번호를 가져와 대신 로그인한다. - Scheduled Tasks(예약 작업): 매일/매시간 자동 실행되는 작업. 다운로드 폴더 정리, 일일 브리핑, 팔로업 모니터링 등. - 사이드 사이드바 채팅: 코딩 중에도 별도 질문 창을 열어둘 수 있다. - 컴퓨터 사용(Computer Use): 설정에서 허용하면 앱·Chrome·내부 브라우저를 직접 제어한다.

  • 실전 프롬프트 시연: 개인 비서 활용, 파일 관리, Codex 코딩, 영상 생성 등.

03기술적·시장 맥락

이 통합의 핵심은 "도구 전환 비용 제거"와 "맥락(Context)의 통합"이다. 발표자는 개인 비서 프로젝트에 Gmail, 캘린더, Slack, Granola(회의록), Google Drive, GitHub 등 전체 업무 데이터를 연결했다. 그 결과 비서는 사용자의 비즈니스 전반을 파악하고 있어 별도 설명 없이도 조언과 실행이 가능하다. 발표자는 Codex에서 68억 개(6.8 billion) 토큰을 사용했고, 특정 날짜에는 하루 20억 개(2 billion) 토큰을 소비했다고 밝혀 실사용 강도를 증명했다. (토큰 = LLM이 처리하는 텍스트 단위)

04전략적 의미

  • SaaS 구독·개발자 고용의 대체: 발표자는 비즈니스 대시보드 'Wolf Control Tower', 추천 알고리즘, 도크 토글 앱 등을 직접 만들었다. 필요한 기능을 월 구독하거나 개발자를 고용하지 않고 스스로 맞춤 제작(bespoke)할 수 있다.
  • AI 제작물의 품질 향상: 5.6 모델이 만든 웹사이트는 더 이상 'vibe-coded(AI 티 나는)' 느낌이 나지 않을 만큼 정교해졌다.
  • 읽기 전용(Read-only) 안전장치: 발표자는 비서에게 읽기 권한만 주고, 이메일·메시지는 초안(draft)까지만 작성하게 해 검토 후 전송하는 방식을 택했다.

06활용 시나리오

  • 개인 비서 훈련: 전체 데이터 접근 스킬 + 이메일/채팅 문체 프로필을 만들어, 사용자처럼 글을 쓰고 과거 대화(session ID)를 참조해 책 원페이저·슬라이드 덱·패널 준비 자료(32페이지 문서)를 자동 생성.
  • 영업 리드 발굴: "샌디에이고 소상공인 대상 AI 컨설팅 리드 20개 찾고 개인화 이메일 초안 작성" → Gmail 초안 20건 자동 생성.
  • 파일 관리 자동화: 다운로드 폴더 65개 파일을 1분 23초 만에 기존 폴더로 정리, 썸네일 21개를 이미지 내용 기반으로 1분 19초 만에 자동 리네임.
  • 코딩·게임 제작: Craigslist 재해석 사이트 'Corner Post', 클론 퍼즐 게임 'Echo Garden' 제작.
  • 영상 제작: 한 번의 프롬프트로 대본·캐릭터·스토리보드·영상(Seedance 2.0)·자막까지 완성, Nate Herk는 AI만으로 토킹헤드 영상 제작.
