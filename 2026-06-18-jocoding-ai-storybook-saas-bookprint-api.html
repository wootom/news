01핵심 개요

항목내용

핵심 도구스위트북 북프린트(BookPrint) API — 인쇄·제본·포장·배송 전 과정 자동화

수익 예시고객 결제 29,000원 → 제작비 13,860원 차감 → 파트너 15,140원 수익

02핵심 내용 구조

  • 콘셉트: 화면 속에만 머물던 디지털 콘텐츠를 클릭 한 번에 진짜 종이책으로 전환·배송.
  • 북프린트 API: 20년 넘게 포토북·단행본을 만든 스위트북이 자체 생산 라인을 REST API로 개방. 파트너는 콘텐츠·결제만 책임지면 인쇄·제본·후가공·포장·배송 자동 처리.
  • 과금 구조: API 사용료 자체는 0원, 실제 인쇄 시에만 권당 단가 차감(선불 충전식) → 1인 개발자도 부담 없음.
  • 구현 단계: 1단계(디지털 PDF SaaS) → 2단계(실물 책 연계 SaaS).

03기술적 맥락

  • 개발 환경: GitHub Codespaces(클라우드 IDE)로 로컬 설치 없이 브라우저만으로 개발. AI는 Claude Code 사용(Codex CLI·Gemini CLI 등 무관).
  • 풀스택 구성: Next.js 프론트+서버리스 백엔드, Supabase(DB·로그인), Polar(글로벌 결제, 샌드박스 테스트 지원), OpenAI(텍스트·이미지 생성).
  • 배포: Vercel CLI를 AI가 자동 실행해 배포, Vercel Integrations로 Supabase를 환경변수까지 자동 연동.
  • AI 친화 문서: 북프린트 API는 llms.txt / llms-full.txt 제공 → 11,000줄 문서를 사람이 안 읽어도 AI 에이전트가 읽고 정확히 구현.

04전략적 의미

  • 실물 연계형 신수익 채널: 디지털 콘텐츠에 실물 책을 더해 객단가(ARPU)를 높이는 새 비즈니스 모델.
  • 진입장벽 붕괴: 바이브 코딩 + CLI·API 자동 연동 + AI 친화 문서로 1인 개발자도 풀스택 실물 연계 서비스 구축 가능.
  • API 경제의 진화: 인쇄·물류 같은 오프라인 인프라까지 API로 추상화돼, 콘텐츠 기업이 제조·배송 없이 실물 상품 판매.

05핵심 워크플로우/방법론

  • 1단계 흐름: 로그인(Supabase) → 동화 주제 입력 → Polar 결제 → OpenAI(GPT-5.5·GPT 이미지 2)로 글·그림 생성 → 동화책 PDF 미리보기·다운로드.
  • 2단계 흐름: 완성 PDF + 배송지 입력 → Polar 결제 → 북프린트 API로 인쇄·제본·포장·배송(2~3일 도착). 규격은 고아질 스퀘어북 하드커버(표지 포함 24p).
  • AI 자동 연동 팁: Supabase·Polar의 CLI와 OpenAI API 문서 URL을 AI에 제공 → 오류 메시지를 붙여넣으면 Claude Code가 자동 수정. 샌드박스(테스트 카드 4242…)로 결제 검증 후 라이브 전환은 API 키·베이스만 교체.

06활용 시나리오

  • 여행·라이프로그: 여행 사진 포토북, 운동 일지, 펫 포토북 등 기록을 실물 책으로 전환해 객단가 상승.
  • 교육·기관·단체: 퀴즈·교육 참여자 콘텐츠를 묶어 실물 결과물로 제작.
  • 크리에이터·1인 출판: 자작 소설, 전자책의 실물 출판, AI 화보집 등 디지털 팬덤을 실물 굿즈로 확장.

07현황 및 전망

  • 데모에서 실제 하드커버 동화책이 2~3일 만에 배송·도착, 실크필 코팅·PUR 제본 등 인쇄 품질도 충분히 양호.
  • 샌드박스→라이브 전환은 API 키·베이스 교체만으로 즉시 가능해 운영 진입이 매우 단순.
  • 기존 디지털 콘텐츠 사업자도 실물 연계로 추가 수익 창출이 가능하며, 바이브 코딩 시대에 실물 연계형 SaaS가 폭넓게 확산될 전망.

08용어 사전

용어한줄 설명비유/예시
바이브 코딩AI에게 자연어로 지시해 코드를 생성·개발하는 방식말로 주문하면 요리가 나오는 식
SaaS구독·결제형으로 제공되는 클라우드 소프트웨어 서비스넷플릭스처럼 쓰는 만큼 내는 소프트웨어
REST API정해진 규칙으로 서비스 기능을 호출하는 인터페이스식당 메뉴판으로 주문하는 표준 창구
북프린트 API인쇄·제본·포장·배송을 자동 처리하는 스위트북 API원고만 보내면 책이 집까지 오는 자판기
서버리스서버 관리 없이 함수 단위로 실행하는 백엔드 방식필요할 때만 켜지는 자동 주방
SupabaseDB·로그인·인증을 제공하는 백엔드 서비스데이터 보관과 회원 관리를 대행하는 창고
Polar글로벌 결제를 처리하는 서비스(샌드박스 지원)온라인 가게의 계산대
llms.txtAI 에이전트가 읽도록 정리한 개발 문서 형식AI 전용 사용 설명서
