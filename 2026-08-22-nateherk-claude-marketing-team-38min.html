01핵심 개요

항목내용
형식Nate Herk가 가상의 캔 커피-단백질 음료 브랜드 "Perk Form"을 예시로, Claude Code 프로젝트를 처음부터 구성해 Higsfield(AI 이미지·영상 생성 툴)와 MCP로 연결하고, 웹사이트부터 광고 크리에이티브·소셜 콘텐츠·UGC 영상·분석 시트까지 실시간으로 생성하는 실습형 튜토리얼 영상
화자Nate Herk (AI Automation 채널 운영자)
핵심 문제의식기술 지식이나 영상·이미지 편집 능력이 없어도, Claude Code에 "무엇을 요청할지"만 알면 1인이 마케팅팀 전체 역할(브랜딩, 웹사이트, 광고, 소셜, UGC, 분석)을 수행할 수 있다는 주장
핵심 전제 — 3P 프레임워크AI 마케팅 자산이 "제네릭한 AI 슬롭"으로 전락하지 않으려면 사전에 Pain(고객이 겪는 문제)·Person(그 문제를 겪는 구체적 인물)·Promise(브랜드가 그 문제를 해결한다는 약속) 세 가지를 명확히 정의해 Claude에게 컨텍스트로 제공해야 한다는 것이 전체 워크플로우의 출발점
사용 도구Claude Code(데스크톱), Higsfield(Kling 2.5·Gemini·Flux·Sora·GPT Image 2·Nano Banana 등 다중 이미지/영상 모델을 하나의 구독으로 통합 제공하는 AI 생성 플랫폼, MCP로 Claude와 연결), Scroll World(스크롤 인터랙션 기반 3D 웹사이트를 만드는 오픈소스 GitHub 리포)
예시 브랜드Perk Form — 커피 향과 단백질을 결합한 캔 음료(바닐라 라떼, 솔티드 캐러멜, 볼드 모카 3종). 타겟 페르소나는 "커피에 의존하고 단백질을 챙기지만 아침을 자주 거르는 바쁜 피트니스 지향 직장인"

02핵심 기능/내용 구조

  1. Claude Code 프로젝트 폴더 설정 및 CLAUDE.md 작성: 데스크톱에 빈 폴더를 만들고 Claude Code(로컬 데스크톱 앱)로 열어 "trust workspace"를 승인한 뒤, 자연어로 비즈니스 정보(이름, 업종, 3P 등)를 덤프하면 Claude가 자동으로 claude.md(프로젝트 운영 문서 — 향후 세션이 무엇을 참고해야 하는지 안내)와 context/(브랜드 포지셔닝, 페르소나, 제품 정보, 보이스&카피, 메시지 뱅크, 플레이북, 랜드스케이프 문서), assets/(로고·제품샷 원본), output/(생성물 저장) 폴더 구조를 자동 생성. CLAUDE.md는 매일·매주 업데이트하는 살아있는 문서로 취급하며 "이것도 CLAUDE.md에 추가해줘"라고 지시하면 됨.
  2. "Grill Me" 스킬을 활용한 비즈니스 인터뷰: 사용자가 어떤 정보를 줘야 할지 막막할 때 쓰는 재사용 워크플로우(스킬)로, 마크다운 파일 형태의 프롬프트를 프로젝트에 설치하면 Claude가 사용자의 마케팅 사고방식을 파악할 때까지 한 문항씩 계속 질문하며 인터뷰하고 그 결과를 저장해 향후 컨텍스트로 활용. Nate Herk 본인의 무료 스쿨 커뮤니티에서 배포.
  3. 에셋 투입 및 검증: 로고(라이트/다크 모드, 텍스트형, 아이콘형), 제품샷(스튜디오컷 포함 11장), 브랜드 가이드라인 PDF(컬러, 로고 시스템, 타이포그래피)를 assets/ 폴더에 드래그해 넣음. 폴더가 UI상 깨져 보이는 경우에도 "이 폴더 안의 파일들이 보이는지" 직접 물어보면 Claude가 실제로 파일을 읽어 목록을 확인해주는 방식으로 검증 가능.
  4. Higsfield MCP 연결: Higsfield 계정에서 "MCP and CLI" 메뉴로 들어가 Claude용 연결 URL을 복사 → Claude의 Customize → Connectors → Add custom connector에 붙여넣고 이름 지정 → 로그인 승인. 연결 후에는 Claude에게 "이미지 만들어줘", "마케팅 스튜디오로 가줘"라고 말하면 Claude가 Higsfield UI를 대신 조작하므로 사용자가 직접 Higsfield 화면을 들어갈 필요가 없어짐.
  5. Scroll World 기반 인터랙티브 웹사이트 생성: Scroll World GitHub 리포 URL을 Claude에 붙여넣고 "우리 로고·브랜드 가이드라인·제품샷과 이 리포를 결합해 프리미엄하고 인터랙티브한 웹사이트를 만들어달라, 3P와 페르소나를 반영해 카피와 구조를 설계해달라"고 한 번에 요청. Claude는 브랜드 가이드라인 PDF에서 색상 체계를 그대로 가져오고, 페인포인트("아침에 두 가지 음료가 필요 없어야 한다")로 문을 열고, 스크롤에 따라 커피와 단백질 이미지가 하나로 합쳐지는 애니메이션, 3가지 맛별 Higsfield 생성 영상(Kling 2.5)이 스크롤과 연동되는 인터랙션을 한 번의 프롬프트로 구현. 로컬호스트에서 확인 후 GitHub→Vercel 연결로 퍼블릭 배포(영상에서는 상세 과정 생략, 별도 영상 안내).
  6. 4종 마케팅 에셋 동시 생성 요청: 같은 채팅에서 병렬로 아래 4개 프롬프트를 순차 전송해 백그라운드로 동시 처리시킴. 각 프롬프트에 "브랜드 컨텍스트를 반영해서", "완료 후 비용을 알려달라", "output 폴더 내 지정 폴더에 저장해달라"를 공통으로 포함시키는 것이 패턴.

- 광고 크리에이티브: BOGO(1+1) 프로모션용 이미지 광고 세트를 대량 생성 요청 → 18개 생성, 총 $3.43. 카피 없는 빈 템플릿도 함께 생성해 향후 카피만 교체 재사용 가능. - 시즐릴(Sizzle Reel): Higsfield 마케팅 스튜디오(음악·편집·템포를 자동으로 붙여주는 기능) 활용, 세로형·가로형 각 1편 생성 → 약 $17.55(영상이 이미지보다 고비용). - 인스타그램 캐러셀: 브랜드 스토리·타겟·문제해결·맛 소개를 담은 캐러셀 5세트(세트당 7~8장) 생성 → 약 $9.56. - UGC(사용자 생성 콘텐츠) 스타일 영상 광고: 세로형, 실제 사용자가 제품을 들고 리뷰하는 듯한 연출로 여러 버전 생성. Higsfield는 이 과정에서 (a) 캐릭터 이미지 4종 생성 → (b) 스토리보드(보드) 생성으로 장면을 사전 계획 → (c) Kling 2.5 등으로 영상 생성 → (d) QA 패스(스크린샷 검수, 로고나 텍스트 오류 있는 컷은 자동 반려)의 4단계 파이프라인을 거침. 결과물은 사실적이지만 다소 "광고스러운" 톤이라는 한계를 화자가 직접 지적.

  1. 재사용 가능한 스킬화: 생성된 결과물 중 마음에 드는 스타일(예: 특정 캐러셀 디자인)을 "이 스타일로 스킬을 만들어줘"라고 요청하면 이후 동일 스타일 반복 생성이 가능해지고, 반대로 "이 스타일은 다시 쓰지 말아줘"로 배제도 가능.
  2. 분석 트래커(Excel) 자동 생성: 4라운드 생성이 끝난 뒤 "생성 이력을 추적할 엑셀 시트를 만들어달라"고 요청 → 약 8분 만에 output/analytics/에 브랜드 컬러·탭 디자인까지 브랜드 가이드라인을 반영한 Excel 파일 생성. 시트 구성은 생성 로그(ID·날짜·유형·캠페인·채널·핵심 앵글·산출물·사용 모델·크레딧·비용·상태), 크리에이티브 에셋 목록, 앵글별 성과, 카피 뱅크, 비용 요약 탭으로 구성되며 향후 조회수·참여도·전환 데이터를 추가해 성과 분석에 활용 가능.

03기술적 맥락

이 워크플로우의 핵심은 Claude Code가 단순 채팅 도구가 아니라 "디렉터리/프로젝트 기반"으로 동작한다는 점을 활용해, 프로젝트 폴더 자체를 지속적으로 성장하는 비즈니스 지식 베이스로 만드는 것이다. Higsfield는 MCP(Model Context Protocol) 커넥터를 통해 Claude와 연결되며, 이로써 Claude가 자연어 요청을 Higsfield의 다양한 모델(이미지: GPT Image 2·Nano Banana·Flux 등, 영상: Kling 2.5·Gemini·Sora 등)에 대한 구체적 API/UI 조작으로 자동 변환한다. 즉 사용자는 모델 선택이나 프롬프트 엔지니어링을 직접 하지 않고, 비즈니스 목표와 맥락만 자연어로 전달하면 된다. 웹사이트 구축에는 별도 오픈소스 리포(Scroll World)를 Claude에게 링크만 전달해 통합시키는 "리포 URL 투입" 패턴이 사용됐다. UGC 영상 생성은 캐릭터 생성 → 스토리보드 → 영상 생성 → QA 검수의 4단계 파이프라인으로 자동화되어 있어, 단일 프롬프트가 아니라 Claude가 내부적으로 여러 서브태스크를 계획하고 실행하는 에이전틱 워크플로우임을 보여준다.

04전략적 의미

첫째, "AI 슬롭"과 "온브랜드 자산"을 가르는 결정적 차이는 모델 성능이 아니라 사전에 얼마나 명확한 비즈니스 컨텍스트(3P, 브랜드 가이드라인, 페르소나)를 시스템에 심어주었는가에 있다는 것이 영상 전체를 관통하는 메시지다. 둘째, CLAUDE.md·context 폴더·스킬이라는 3층 구조(운영 지침, 지식 베이스, 재사용 워크플로우)는 비개발자도 소프트웨어 프로젝트처럼 "누적되는 자산"을 구축할 수 있게 해주며, 매 세션 처음부터 설명을 반복할 필요가 없어진다. 셋째, MCP 커넥터를 통해 Claude가 전문 SaaS 툴(Higsfield)의 UI를 대신 조작하는 패턴은 향후 다른 마케팅·디자인 툴에도 일반화 가능한 "에이전트가 도구를 운전한다"는 상호작용 모델을 제시한다. 넷째, 볼륨 생성(18개 광고, 5세트 캐러셀 등)과 비용 투명성(건별 비용 자동 보고)을 결합해 "많이 만들고 데이터로 검증한다"는 퍼포먼스 마케팅 사이클을 코딩 지식 없이 실행 가능하게 만들었다는 점에서, 향후 실제 성과 데이터(조회수·전환)를 다시 Claude에 연결해 "무엇이 잘 됐는지 분석 → 잘 된 것 더 생성"하는 폐루프 최적화로 확장 가능하다고 시사한다.

06활용 시나리오

  1. 신규 D2C 브랜드의 초기 마케팅 자산 구축: 정식 마케팅팀이나 에이전시 없이도 창업자가 3P(Pain·Person·Promise)만 명확히 정리해 Claude Code 프로젝트에 입력하면, 로고·웹사이트·광고·소셜 콘텐츠까지 하루 안에 일관된 브랜드 톤으로 초안을 확보할 수 있다.
  2. AI 마케팅 서비스를 제공하려는 프리랜서/에이전시의 클라이언트 온보딩: 클라이언트별로 별도 Claude Code 프로젝트 폴더를 만들어 브랜드 가이드라인과 3P를 컨텍스트로 저장해두면, 이후 프로젝트마다 반복 설명 없이 온브랜드 산출물을 빠르게 생성하는 표준 온보딩 프로세스로 활용할 수 있다.
  3. 프로모션 시즌마다 광고 크리에이티브를 대량으로 테스트해야 하는 퍼포먼스 마케터: BOGO 같은 프로모션 문구만 바꿔 "브랜드 컨텍스트 반영 + 비용 보고"를 조건으로 건별 요청하면, 카피 없는 템플릿을 재사용해 다음 프로모션에서 카피만 교체하는 방식으로 제작 비용과 시간을 절감할 수 있다.
  4. UGC 스타일 영상이 필요하지만 실제 크리에이터 섭외가 어려운 소규모 브랜드: 캐릭터 생성부터 스토리보드, QA 검수까지 자동화된 파이프라인을 활용해 초기 소셜 콘텐츠 실험을 진행하되, 결과물이 다소 "광고스럽다"는 한계를 인지하고 실제 UGC 벤치마킹이나 스크립트 검수 단계를 추가로 설계할 수 있다.
  5. 콘텐츠 생성과 성과 분석을 연결하려는 그로스팀: 매 생성 라운드마다 Excel 트래커에 앵글·비용·산출물을 자동 기록하게 하고, 추후 조회수·전환 데이터를 붙여 "어떤 앵글과 카피가 잘 통했는지" 주기적으로 리뷰하는 폐루프 최적화 프로세스를 구축할 수 있다.

07현황 및 전망

Higsfield는 다중 AI 생성 모델(이미지·영상)을 단일 구독으로 통합 제공하며 MCP를 통해 Claude와 직접 연동되는 초기 단계의 생태계를 보여준다. 화자는 Higsfield가 "가장 저렴한 툴은 아니"라고 인정하면서도, 여러 모델을 개별 구독하는 것보다 통합된 편의성과 마케팅 스튜디오 같은 부가 기능의 가치를 강조한다. 영상은 UGC 영상 결과물이 아직 "광고처럼 느껴지는" 한계, 로고 디테일이 가끔 틀리는 등 완전 자동화의 한계도 솔직하게 노출하며, 향후 방향으로는 (1) 성과 데이터와의 연결을 통한 폐루프 최적화, (2) 실제 UGC 벤치마킹 자료를 학습시켜 더 organic한 톤 구현, (3) 스킬 축적을 통한 브랜드별 재사용 가능한 제작 레시피 확장을 제시한다.

08용어 사전

3P (Pain·Person·Promise)마케팅 자산 제작 전 정의해야 할 세 요소: 고객의 문제, 그 문제를 겪는 구체적 인물, 브랜드의 해결 약속소설을 쓰기 전 인물·갈등·결말을 정하는 것과 같은 사전 설계 단계
MCP (Model Context Protocol)AI 모델(Claude)이 외부 서비스(Higsfield)를 직접 조작할 수 있게 연결하는 표준 프로토콜리모컨을 하나로 통합해 여러 가전을 한 번에 조작하는 유니버설 리모컨
CLAUDE.mdClaude Code 프로젝트의 운영 지침을 담은 마크다운 문서로, 매 세션마다 무엇을 참고할지 안내신입 직원에게 주는 업무 매뉴얼 겸 온보딩 문서
스킬(Skill)특정 작업 방식을 저장해 반복 재사용할 수 있는 마크다운 기반 프롬프트 워크플로우요리 레시피 — 한 번 정리해두면 매번 같은 결과를 재현
