안드레 카파시는 Claude에 구현을 맡기고 짧은 지시와 시각화로 작업을 이끈다.

안드레 카파시가 Claude에 작업을 위임하고 짧은 지시와 실험으로 AI를 활용하는 방식

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

Claude Code에 코딩 작업을 맡기는 기본 방식

  • 영상에 따르면 카파시는 Mac 데스크톱 앱인 Claude Code에서 Opus 5.5를 Medium Effort로 사용한다. 직접 코드를 읽거나 쓰고 터미널 명령을 실행하기보다 Claude와 대화하며 작업을 맡긴다.
  • 모델에게 설명을 요청할 때는 불필요한 단어를 줄이고 어휘를 엄격히 제한하는 항공기 정비 매뉴얼 영어 표준인 ASD-STE100을 활용한다고 소개한다.

요구사항을 줄이고 짧은 지시로 작업시키기

  • 카파시는 프롬프트에 요구사항을 계속 더하면 모델의 결과가 나빠질 수 있다고 본다. 사람이 요청 간의 상충 관계를 제대로 파악하지 못할 수 있다는 설명이다.
  • 영상은 그의 최근 지시가 짧고 단순해지는 추세라고 전한다. 복잡한 조건을 길게 적기보다 필요한 작업을 간결하게 전달하는 방식이다.

보안 점검과 배포를 Claude에 위임하기

  • 프로젝트 보안을 강화할 때 카파시는 Claude에 “최근 사이버 관련 내용을 확인하라”고 짧게 요청했고, Claude는 여러 하위 에이전트를 보내 작업을 수행했다고 한다.
  • 배포 과정에서는 서버 IP 주소를 제공한 뒤 “update, deploy, secure, harden, optimize”라고 지시했다고 설명한다.

이해하기 어려운 내용은 그림과 영상으로 바꾸기

  • 카파시는 글을 읽는 것보다 이미지를 빠르게 파악할 수 있다는 점을 활용해, 이해가 안 되는 내용을 다이어그램이나 HTML 페이지로 설명해 달라고 요청한다.
  • 필요하면 맞춤형 설명 영상도 만들게 한다. 영상에서는 Opus 5.5 같은 모델이 긴 설명을 읽는 시간보다 빠르게 시각 자료를 만들 수 있다는 취지를 전한다.

공개 벤치마크를 그대로 믿지 않는 태도

  • 카파시는 공개 벤치마크를 신뢰하지 않는 편이며, Hacker News 댓글에서 Epoch AI의 ECI를 보라고 권했다고 영상은 전한다.
  • 영상은 ECI를 여러 벤치마크와 모델 점수를 분석해 각 벤치마크가 주목할 만한지 살펴보는 ‘벤치마크의 벤치마크’로 설명한다.

좌표별 육지·바다 답변으로 세계 지도를 만들기

  • 카파시는 모델에 위도와 경도 좌표를 주고 ‘육지인가, 물인가’를 묻는 실험을 했다. 답변을 육지와 바다에 해당하는 색으로 표시해 세계 지도를 만들었다고 한다.
  • 영상은 이 실험이 Opus 5.5 같은 모델의 신경망에 세계 지식이 압축돼 있다는 점을 보여주려는 사례라고 설명한다.

HackerTube를 직접 만들어 공개하기

  • 카파시는 YouTube 콘텐츠를 보고 불만을 느낀 뒤 Hacker News에서 반복적으로 추천된 영상만 모은 ‘HackerTube’를 만들었다. Hacker News의 콘텐츠를 수집해 장기간 추천된 고품질 영상의 아카이브를 구성했다고 소개된다.
  • Claude에 인사한 뒤 Hacker News에서 여러 해 동안 반복 추천된 영상으로 제한한 YouTube 스타일 사이트를 만들어 달라고 요청했고, 완성한 프로젝트를 온라인에 공개했다.

데이터 정리에는 필터와 Sonnet 하위 에이전트를 활용하기

  • 데이터 프로젝트에서는 Claude로 URL, 정규식, 스팸 등을 걸러내는 필터를 만든다. 남은 데이터는 형식이 깔끔하지 않아도 Claude Code 작업 흐름을 통해 주로 Sonnet에 보낸다고 한다.
  • 영상은 Opus 5.5가 Medium Effort에서 여러 Sonnet 하위 에이전트에 일을 나누는 위임 구조를 카파시가 선호한다고 전한다.

앱 대신 데이터와 프롬프트를 공유하기

  • 카파시는 자신이 만든 앱을 그대로 공유하기보다 데이터 소스와 프롬프트를 제공하는 방식을 택한다고 설명한다. 받은 사람이 Claude로 인터페이스나 앱을 각자 맞춤 제작할 수 있다는 취지다.
