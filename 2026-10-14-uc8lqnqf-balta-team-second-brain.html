발다로 팀별 권한 관리 가능한 AI 세컨드 브레인 구축

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

01핵심 개요

  • 발다는 오픈 소스 기반 팀 세컨드 브레인으로, 10인 미만 팀은 무료 사용 가능
  • 폴더 단위 세분화 권한 설정으로 C레벨 등 기밀 문서 접근을 AI까지 통제
  • MCP 서버 연동으로 웹 기반 Claude 등 외부 AI가 권한 범위 내 문서 조회
  • 옵시디언과 유사한 마크다운 인터페이스로 기존 LLM 위키 데이터 이식 용이
  • 자체 호스팅 옵션 제공으로 데이터 주권 확보 및 프라이빗 MCP 구성 가능

02핵심 주장 / 논점 구조

  • 개인용 옵시디언 위키를 팀 공유 환경으로 전환 시 발생하는 권한 통제 문제 해결
  • 발다(Balta)를 활용해 팀원별 문서 가시성과 AI 에이전트 접근 권한을 분리
  • 오픈 소스 도구와 MCP 연동을 통해 프라이빗한 조직 브레인 운영 방안 제시

03발다(Balta) 도구 개요 및 비용

  • 발다는 조직 전용 세컨드 브레인으로 오픈 소스이며 기본 호스팅 서비스 제공
  • 월 12,000원 프로 요금제 적용 시 팀원 10명까지 무료 사용 가능
  • 슬랙과 달리 팀원 추가 시 추가 비용 발생 없이 무제한 멤버 등록 지원
  • 구글 로그인 지원 및 옵시디언과 유사한 마크다운 기반 인터페이스 제공

04폴더 단위 세분화 권한 설계

  • 멤버 초대 시 매니저, 편집, 읽기 전용 등 폴더별 접근 권한을 세밀하게 설정
  • 컨텍스트, 데일리 등 민감 폴더를 특정 팀원에게 비공개 처리하여 접근 차단
  • 팀원 계정으로 로그인 시 권한이 없는 폴더는 빈 상태로 표시되어 내용 확인 불가
  • 개인 볼트와 팀 볼트를 분리하여 운영하며 각 볼트별로 독립적인 권한 체계 적용

05MCP 연동 및 외부 AI 에이전트 제어

  • 발다 내장 MCP 서버를 통해 웹 기반 Claude 등 외부 AI와 조직 브레인 연결
  • 엑세스 토큰 발급 및 헤더 인증을 통해 AI의 문서 읽기, 쓰기, 삭제 기능 제어
  • 권한이 제한된 팀원의 AI 에이전트는 차단된 폴더 내 노트를 조회할 수 없음
  • AI가 권한 범위 내에서만 문서 검색 및 요약 가능하여 정보 유출 방지

06옵시디언 대비 이점 및 데이터 이식

  • 옵시디언과 유사한 그래프 뷰와 마크다운 편집 환경으로 학습 비용 최소화
  • 기존 개인 세컨드 브레인 볼트를 발다로 이식하여 팀 공유 인프라로 전환
  • 클로드 코드, 코덱스 등 다양한 AI 도구와 인터페이스 호환성 확보
  • 단순 인터페이스 차이만 존재하여 기존 LLM 위키 사용 경험 그대로 활용 가능

07자체 호스팅 및 향후 확장 전략

  • 클라우드 서버에 오픈 소스 발다를 직접 호스팅하여 데이터 주권 확보 가능
  • 레일레이, 카페24 등 자체 서버에서 MCP 서버를 구축해 프라이빗 운영
  • 직급별(A, B, C 레벨) 구글 계정과 에이전트를 분리해 권한 계층화
  • 조직 내 기밀 정보 보호를 위한 다중 에이전트 기반 접근 제어 모델 제안
