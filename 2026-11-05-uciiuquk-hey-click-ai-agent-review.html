화면을 공유하며 음성으로 상호작용하는 AI 에이전트 헤이클릭의 수학, 영어, 코드, 주식 분석 활용 리뷰

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

헤이클릭의 인터페이스와 기본 기능

  • 헤이클릭은 사용자의 컴퓨터 화면을 함께 보며 음성으로 질문과 답변을 주고받는 AI 에이전트 서비스입니다.
  • 사용자가 화면의 특정 부분을 가리키거나 설명을 요청하면, AI는 해당 영역에 초록색 커서를 표시하며 텍스트, 그림, 3D 그래픽을 활용해 설명합니다.
  • 이 도구는 기존 채팅창 기반 텍스트 상호작용을 넘어, 개인 튜터처럼 실시간으로 화면 내용을 분석하고 시각 자료로 풀어내는 UI/UX를 제공합니다.
  • 맥과 윈도우에서 사용 가능하며, 초기 베타 버전 이후 정식 출시되어 유료 서비스가 시작되었습니다.

수능 수학 문제 풀이 시연

  • 2026학년도 수능 수학 3번 문제(시그마 기호 활용)를 입력하자, AI는 미지의 합을 두 배로 묶어 계산하는 과정을 단계별로 음성으로 설명했습니다.
  • 사용자가 이해가 안 된다며 재요청하자, AI는 '돈 지갑' 비유를 들어 각 항의 값을 미지 금액으로 설정하고 전체 합이 10임을 유도하는 방식으로 재설명했습니다.
  • 2번 문제(미분 개념)에 대해선 파인만 기법을 활용해 3D 그래픽으로 곡선 위 지점의 경사를 시각화하고, h가 0에 가까워지는 과정을 설명했습니다.
  • AI는 사용자가 경사 개념을 이해했는지 확인하기 위해 '가로 2, 세로 6 이동 시 경사'라는 간단한 퀴즈를 출제하고 정답 3을 확인했습니다.

영어 문법 분석 및 코드 해석

  • 영문 기사 화면을 보여주자 AI는 'AI가 유권자를 오도할 수 있다'는 핵심 내용을 요약하고, 현재 진행형, 분사구문, 관계대명사절 등 시험 빈출 문법을 설명했습니다.
  • AI는 능동형 분사 'causing'과 수동형 'caused'의 차이를 퀴즈로 확인하며, 'get' 뒤 목적어 구조와 'for'가 남는 부정사 표현을 학습 포인트로 제시했습니다.
  • 옵시디언용 AI 플러그인 자바스크립트 코드에 대해선 빌드 결과물과 원본 소스의 차이를 설명하고, 화살표 함수, 디폴트 파라미터, 삼항 연산자 사용법을 해석했습니다.
  • 코드 개선 사항으로 API 키의 안전한 저장 방식 점검과, 모델 호출 실패 시 오류 처리 로직의 적절성을 확인해야 한다고 조언했습니다.

SK하이닉스 주식 차트 분석

  • SK하이닉스 주봉 차트를 분석한 결과, 주가는 20주선 아래에서 60주선 근처에서 반등을 시도 중이며, 124만~130만 원 구간이 지지 확인 후 분할 매수 후보로 제시되었습니다.
  • 120만 원 아래로 주봉이 마감할 경우 매수 계획을 재검토해야 하며, 160만~180만 원 구간은 이전 거래량과 20주선이 겹치는 저항선으로 분석되었습니다.
  • 거래량 분석에서 가격 하락 구간에서 거래량이 크게 늘어난 것은 매도 압력이 강했음을 의미하지만, 이후 거래량 감소만으로 바닥을 단정할 수 없다고 설명했습니다.
  • 추가 매수 시 지지 구간에서 하락 거래량이 줄고 반등 거래량이 늘어나는 조합을 확인하는 것이 유리하며, 급등락에 따른 손실 위험을 경고했습니다.

요금제 및 교육적 활용 가치

  • 헤이클릭은 월 25회 무료 사용이 가능하며, 프로 요금제 가입 시 레퍼럴 코드를 통해 할인 혜택을 받을 수 있습니다.
  • 학생 대상 할인 정책이 존재하며, 별도의 교재 없이 PDF 자료와 AI 에이전트만으로 3D 그래픽을 활용한 맞춤형 학습이 가능하다고 평가했습니다.
  • 부끄러움을 타는 학생이 혼자 이어폰을 꽂고 AI와 대화하며 공부할 수 있어, 사교육과 공교육 모두에서 학습 효율성을 높이는 도구로 활용 가치가 있다고 언급했습니다.
