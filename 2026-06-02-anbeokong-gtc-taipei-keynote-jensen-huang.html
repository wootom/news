젠슨황 GTC Taipei 키노트 핵심 — AI Agent가 인프라 모든 걸 바꾸다

안될공학(에러)이 GTC Taipei 키노트 현장에서 직접 청취·정리한 발표 핵심. 젠슨 황의 핵심 프레임은 "컴퓨트 = 매출(Compute is Revenue)"이며, 베라루빈(Vera Rubin)을 단일 GPU가 아닌 랙 스케일 AI 팩토리 플랫폼으로 포지셔닝.

목차핵심 개요핵심 내용 구조 — "컴퓨트 = 매출" 프레임기술적 맥락 — 베라루빈 = 랙 스케일 플랫폼전략적 의미 — 엔비디아의 "풀 패키지" 지배핵심 워크플로우 — 에이전트 정의와 케이던스 협력활용 시나리오현황 및 전망용어 사전

01핵심 개요

항목내용
행사NVIDIA GTC Taipei 키노트 (대만, 타이페이 뮤직센터)
핵심 메시지"Useful AI has arrived" — AI가 실제로 돈을 벌기 시작
중심 프레임컴퓨트 = 비용(Cost) → 컴퓨트 = 매출(Revenue) 전환
대표 제품베라루빈(Vera Rubin) 랙, 베라 CPU, 블루필드4(STX), 스펙트럼X 포토닉스, AI PC
양산 선언베라루빈 풀 프로덕션(full production) 진입 — 30개국·350개 공장 가동
수혜 키워드케이던스(칩 설계), HBM4, NAND 플래시, 실리콘 포토닉스, 유니트리(로봇)

02핵심 내용 구조 — "컴퓨트 = 매출" 프레임

  • AI 추론(inference)·에이전트 시대 진입 → 사용자가 AI를 쓸수록 토큰 생산 → 토큰이 곧 서비스 매출
  • 컴퓨터의 의미 전환: "돈 쓰는 기계(코스트 센터)" → "24시간 토큰 찍어내는 디지털 프린터(매출 센터)"
  • AI 팩토리(AI Factory) 비유: 일반 공장이 자동차·반도체 생산하듯, AI 팩토리는 토큰·코드·이미지·영상·검색결과 등 "지능" 생산
  • 성능 지표 전환: 기존 FLOPS·추론 레이턴시 → 와트당 토큰 수(token per watt)·에이전트 스루풋·토큰 코스트

03기술적 맥락 — 베라루빈 = 랙 스케일 플랫폼

  • 베라루빈은 단일 GPU 아님 → GPU + 베라 CPU + 블루필드4(DPU) + 스토리지 + 시큐리티 + 네트워크 통합 시스템
  • DSX: AI 팩토리 전체 설계·배치·운용 플랫폼(PC의 OS에 해당) — 전력당 토큰 극대화 목표
  • 베라 CPU: 88코어, 초당 1.2TB 대역폭, 올림푸스 코어(스페이셜 멀티스레딩) — X86 대비 1.8배, SQL 데이터 처리 3배, 실시간 스트리밍(뉴욕증권거래소 사례) 6배 빠름
  • 스펙트럼X 포토닉스(CPO, 코패키지드 옵틱스): 전기→광신호 이동 거리 단축 → 100만 GPU AI 팩토리 연결 기반 (TSMC 협력)
  • 블루필드4 STX: NAND 플래시 기반 KV 캐시 저장 → 긴 멀티턴 대화·장기 컨텍스트 대응 (키옥시아·샌디스크 수혜)

04전략적 의미 — 엔비디아의 "풀 패키지" 지배

  • 메시지: GPU 하나가 빠르냐가 아니라, 같은 전력으로 랙 전체가 얼마나 많은 매출 작업을 하느냐
  • CPU까지 자체 설계 → 고객은 "부품 선택"이 아니라 "AI 공장 전체를 패키지로 구매"
  • AI 버블론 반박: 스탠퍼드 공대 출신답게 "컴퓨트→매출" 그래프로 숫자 제시, 지속가능성 강조
  • 디바이스 시장 진출: AI PC(마이크로소프트·미디어텍 협력), 노트북·디지털 스테이션 — 맥미니/맥스튜디오 타겟

05핵심 워크플로우 — 에이전트 정의와 케이던스 협력

  • 엔비디아의 에이전트 정의: LLM(두뇌) + 하네스(harness)의 결합

- 하네스 = 메모리 관리 + 컨텍스트 + 툴 사용 + 코드 실행 + 권한·보안 + 반복 구조 설계

  • 엔터프라이즈 에이전트 툴키트 공개 (openclaw·Claude Code 등 + CUDA-X 라이브러리 + Nemotron 오픈모델 결합)
  • 케이던스(Cadence) 협력: 반도체 칩 설계·검증(RTL·타이밍·테스트벤치) 워크플로우를 에이전트화

- 엔비디아가 자사 칩 설계·검증의 첫 고객 → 발표 직후 케이던스 주가 급등

  • AI PC 코어: 블랙웰 RTX GPU + 그레이스 CPU 20코어 + LPDDR5X 128GB + 1페타플롭스

06활용 시나리오

  1. AI 데이터센터 구축사: 베라루빈 랙 단위 도입으로 전력당 토큰 효율 극대화, 단일 벤더 통합 운용
  2. 반도체 기업: 케이던스 에이전트 솔루션 도입으로 RTL 설계·검증 자동화, 자체 EDA 구축 부담 절감
  3. 금융 트레이딩(HFT/MFT): 베라 CPU 초저지연 실시간 스트리밍으로 초당 단타·데이터 파이프라인 가속
  4. 개인 개발자: AI PC·디지털 스테이션으로 데이터센터 없이 로컬 고성능 AI 워크로드 실행
  5. 로보틱스: 아이작 그루트·유니트리(31 자유도) 레퍼런스 모델 기반 휴머노이드·자율주행 개발

07현황 및 전망

  • 베라루빈 풀 프로덕션 선언 → 최태원 회장 참석(삼성 콜), HBM4 SK하이닉스는 아직 콜(qualification) 미완 단계
  • 엔비디아는 GPU→CPU→네트워크→스토리지→디바이스→로봇까지 에이전트 시대 인프라 전 영역 수직 장악 시도
  • 차세대 플랫폼: 블랙웰 → 루빈 파밀리아 → AI PC·피지컬 AI(코스모스) 로드맵 확장

08용어 사전

용어한줄 설명비유/예시
AI 팩토리(AI Factory)전기를 넣으면 24시간 토큰·지능을 생산하는 데이터센터자동차 공장처럼, 원료(전력) 넣고 제품(토큰) 찍어내는 공장
컴퓨트 = 매출AI 추론이 늘수록 토큰·서비스 매출이 발생한다는 프레임동전 넣으면 돈을 찍어내는 자판기
베라루빈(Vera Rubin)엔비디아 차세대 랙 스케일 AI 시스템 전체GPU 하나가 아니라 공장 생산라인 통째
베라 CPU엔비디아 자체 설계 88코어 서버 CPUGPU 옆에서 데이터를 빨리 날라주는 조수
하네스(Harness)LLM이 실제 업무를 하도록 묶어주는 실행 구조두뇌(LLM)에 손발(메모리·툴·권한)을 달아주는 장치
CPO(코패키지드 옵틱스)칩 옆에 광통신을 붙여 전기→광 이동거리를 줄이는 기술데이터 고속도로를 빛으로 깔기
KV 캐시긴 대화·컨텍스트를 기억하기 위한 임시 저장 데이터대화 내용을 적어두는 메모장
콜(Qualification)부품이 시스템에 결합됐을 때 정상 작동하는지 검증부품 합격 후에도 완성차 조립 테스트 통과 필요
