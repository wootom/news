2
기존 AI의 3대 한계 vs 코워크의 해결

기존 AI 한계

  • 한 단계 단위 답변 — 옆에 붙어 지시
  • 매 세션 기억 소실
  • 로컬 파일 미접근 (복붙 반복)

코워크의 해결

  • 다단계 자동 실행 (PM 위임)
  • 프로젝트 메모리 영구 저장
  • 로컬 폴더 직접 읽기·쓰기
3
4대 핵심 기능

① 로컬 파일 관리

클로드가 내 컴퓨터 폴더를 직접 읽고 쓴다 (50MB/파일)

"직원이 캐비닛을 직접 연다"

② 크롬 연동

웹 브라우저 자동 조작 — 페이지 클릭/스크롤/정보 추출

"직원이 인터넷 자료를 가져온다"

③ 병렬 작업

큰 일을 자동 분해 → 동시 실행 → 시간 단축

"셰프 여럿이 동시에 코스 요리"

④ 전문 문서 생성

엑셀(함수·차트), PPT(레이아웃), 워드 모두 작동

"글 쓰는 비서 → 업무 아는 비서"

⚠️ 안전장치: 민감 작업은 사전 확인 요청, 10분 무응답 시 자동 중단
4
디스패치 (원격 조작)

핸드폰 = 리모컨

모바일 앱에서 명령만 송신

데스크탑 = 일터

실제 처리는 집 PC에서 — 성능·MCP·폴더 그대로 활용

조건

Pro/Max 구독 + 최신 데스크탑 앱

5

6
확장: 커넥터 / 스킬 / 플러그인

커넥터 (MCP)

"AI 세계의 USB-C 콘센트" — 노션·슬랙·깃허브 연결 통로

스킬 (Skills)

특정 작업 매뉴얼 폴더 + 점진적 공개 (필요할 때 로드)

플러그인

스킬+커넥터+에이전트+훅을 패키지로 — 카톡 앱처럼 묶어 배포

한도: 플러그인당 200MB / 5,000 파일 · 계정당 마켓플레이스 25개 · 마켓당 플러그인 500개
7
실전 시작 6단계
  1. 데스크탑 앱 설치 (맥/윈도우, Pro 이상)
  2. 첫 프로젝트 생성 — 작게 시작 (주간 보고서 폴더 등)
  3. 디스패치 원격 실행 1회 체험
  4. 기본 스킬 활용 — 엑셀·PPT 만들기 시켜보기
  5. 커넥터 추가 — 매일 쓰는 도구(G드라이브·Gmail 등)
  6. 마켓플레이스에서 플러그인 둘러보기 + 적합한 것 설치
