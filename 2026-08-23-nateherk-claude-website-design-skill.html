클로드 코드로 프리미엄 스크롤형 웹사이트를 만드는 무료 스킬 '스크롤크래프트

01핵심 개요

항목내용
형식Nate Herk가 자신이 만든 클로드 코드(Claude Code) 커스텀 스킬 "ScrollCraft(스크롤크래프트)"를 소개하고, 자신이 운영하는 AI Automation Society(AIS) 웹사이트를 실제로 다시 디자인하는 라이브 데모 영상
화자Nate Herk (AI 자동화 교육 채널 운영자, AI Automation Society 커뮤니티 창립자)
핵심 문제의식클로드 코드로 만든 웹사이트가 대부분 뻔한 "AI 슬롭(AI slop)" 형태에 그친다는 문제의식 하에, 인터뷰 기반으로 브랜드/톤/자산을 파악해 매번 다른 결과물을 내는 프리미엄 스크롤 연동형 랜딩페이지 생성 스킬을 무료로 공개
핵심 내용(1) 스크롤과 페이지 요소가 동기화되는 "스크롤 연동(scroll-driven)" 인터랙션 디자인 철학, (2) 사용자 인터뷰를 통해 톤·저널니·실제 보유 자산을 파악하는 프로세스, (3) key.ai를 통한 이미지/영상 자산 자동 생성 및 스티칭, (4) 빌드 후 스크린샷 기반 자체 검증(verification pass), (5) AIS 웹사이트 실전 리디자인 및 피드백 반영 2회 반복 시연
배포 방식무료 스쿨(Skool) 커뮤니티의 클래스룸 "All YouTube Resources"에서 클로드 코드 플러그인 또는 폴더/파일 형태로 다운로드 가능

02핵심 기능/내용 구조

  1. 스킬명 "ScrollCraft"의 핵심 철학: 스크롤이 페이지의 무언가(숫자 카운트업, 이미지 페이드, 지도 위 점 연결 등)와 동기화되도록 설계해 사용자가 "훅(hook)"에 걸려 계속 스크롤하게 만드는 것이 목적. 숏폼 콘텐츠처럼 초반에 시선을 끌지 못하면 이탈한다는 전제로, 타이포그래피·여백·질감 같은 디자인 요소도 스킬에 내장되어 있으며 고정된 템플릿이 아니라 매번 다른 결과물을 생성한다.
  2. 인터뷰 기반 요구사항 수집: 스킬 실행 시 "방문자가 처음 무엇을 보고 어떤 순서로 이어질지(스크롤 저널니)", "끝까지 봤을 때 방문자가 믿어야 할 한 문장(기능 나열이 아닌)", "실제 보유 자산(사진, 이벤트 스크린샷, 커뮤니티 스크린샷 등)", "이 사이트만의 시그니처 무브" 등을 순차적으로 질문. Nate는 AIS 사이트를 위해 "프리미엄하고 신뢰감 있는, 에디토리얼한 톤"과 "모든 주장에는 근거(receipt)가 있어야 한다"는 시그니처 원칙을 입력했다.
  3. key.ai를 통한 자산 자동 생성: key.ai는 이미지·영상 생성 모델들을 위한 오픈라우터 유사 서비스로, API 키를 발급받아 클로드 코드 프로젝트의 환경변수에 넣으면 스킬이 필요에 따라 이미지를 생성하고 이를 영상으로 변환한 뒤 자동으로 스티칭까지 수행한다. Nate는 이번 데모에서 "미니멀한 로우폴리(low poly) 기하학적 인간 형상" 스타일의 교육 장면 이미지를 추가로 생성해달라고 요청했다.
  4. 빌드 후 자체 검증 프로세스: 사이트 생성이 끝나면 "하네스가 판단할 수 없는 부분을 키프레임 단위로 확대해 검토"하는 문구와 함께, 실제로 스크린샷을 찍어 어색하거나 잘못된 부분이 없는지 스스로 점검하는 검증 단계(verification pass)를 거친다. 이 과정 덕분에 첫 결과물의 완성도가 높아진다고 설명.
  5. AIS 리디자인 1차 결과: 생성에 약 30분이 소요되었고, 라이브 최신 회원 수(441.5, 실제 스쿨 커뮤니티 수치와 동일) 자동 반영, "0/9 출처 잠금 해제" 방식의 스크롤 연동 소스 공개, 글로브 애니메이션으로 회원 증가 시각화, 실제 화상통화 스크린샷 기반 증언(Glenn·Casper·Amy), 원본 사이트에 없던 "4쿼터 연속 리더보드 1위" 스크린샷을 스스로 찾아 삽입, 로우폴리 인증과정 영상, 9개 출처 재확인 섹션 등이 포함됐다.
  6. 1차 피드백 반영: Nate는 (a) 히어로 섹션이 밋밋함, (b) 글로브 회원 수 애니메이션 속도가 너무 빠름, (c) 인증 섹션 링크가 실제 대기자 명단(waitlist)로 연결되어야 함, (d) "Register" 섹션 삭제 등을 구두로 지시했고, 이는 별도 코딩 지식 없이 자연어 피드백만으로 처리됐다.
  7. 2차 결과 반영 확인: 재생성 후 히어로 섹션이 매거진 커버 스타일로 변경되고 글로브 애니메이션 속도가 느려져 숫자 상승과 지도 위 점 연결을 스크롤로 따라갈 수 있게 되었으며, Register 섹션이 삭제되고 카피가 코호트에 맞게 더 구체적으로 수정됐다. Nate는 추가로 "타이프라이터 효과"를 요청해 텍스트가 타이핑되듯 나타나는 애니메이션과 얼굴 이미지들이 한 번에 하나씩 순차적으로 나타나는 애니메이션까지 추가로 시연했다(재로드 시 약간의 버그 있음을 언급).
  8. 모델/도구 스택: 클로드 코드 데스크톱 앱 기반, 이미지/영상 생성은 key.ai(다중 모델 라우팅), 사용자는 클로드 코드에 대한 기본 지식(Nate의 기존 6시간짜리 강의 시청 권장)이 있다고 전제.

03기술적 맥락

이 스킬은 클로드 코드의 "스킬(skill)" 확장 메커니즘 — 특정 작업에 대한 지침·디자인 원칙·워크플로우를 사전 정의된 텍스트/스크립트 묶음으로 등록해 재사용하는 기능 — 을 활용해, 단순 프롬프트 반복 대신 구조화된 인터뷰 프로세스와 외부 API(key.ai) 연동, 빌드 후 스크린샷 자체 검증까지 하나의 파이프라인으로 묶은 사례다. 특히 "하네스가 판단할 수 없는 부분을 키프레임으로 확대 검토"한다는 설명은 클로드 코드가 생성한 결과물을 별도로 스크린샷 찍어 비전 모델로 재검토하는 자체 QA 루프가 스킬 안에 내장되어 있음을 시사하며, 이는 코드 생성뿐 아니라 시각적 결과물의 품질까지 자동으로 교정하려는 시도다. 또한 key.ai를 이미지/영상 생성의 라우팅 계층으로 활용해 여러 모델 중 필요에 맞는 것을 선택하고, 생성된 이미지를 영상으로 변환·스티칭까지 자동화한 점은 텍스트-투-웹사이트 파이프라인이 이제 텍스트-투-멀티미디어-투-웹사이트로 확장되고 있음을 보여준다.

04전략적 의미

첫째, "AI로 웹사이트를 만들면 다 비슷해 보인다"는 대중적 인식에 대응해 인터뷰 기반 커스터마이징 + 스크롤 인터랙션 디자인 원칙을 스킬에 내장함으로써, 동일한 도구(클로드 코드)로도 브랜드별로 차별화된 결과물을 낼 수 있음을 실증했다는 점에서, 향후 "범용 AI 결과물의 균질화" 문제에 대한 해법으로 도메인 특화 스킬/플레이북 축적이 중요해질 것을 시사한다. 둘째, 자연어 피드백만으로 애니메이션 속도, 링크 대상, 섹션 삭제 등 세부 수정이 즉시 반영되는 모습은 비개발자도 반복적인 개선 루프를 스스로 돌릴 수 있음을 보여주며, 이는 웹 에이전시·프리랜서 디자이너의 초기 시안 제작 단계를 상당 부분 대체할 잠재력을 지닌다. 셋째, 빌드 후 스크린샷 자체 검증 단계를 명시적으로 스킬에 포함시킨 것은, 단순 "생성"에서 "생성 후 자체 QA"로 AI 워크플로우의 기본 단위가 확장되고 있다는 더 넓은 트렌드(에이전틱 워크플로우의 self-check 내재화)와 맞닿아 있다. 넷째, 무료 배포 전략(스쿨 커뮤니티 유입 목적)은 크리에이터가 자체 개발한 스킬/프롬프트 자산을 무료 미끼로 활용해 유료 커뮤니티나 코스로 퍼널링하는 전형적인 크리에이터 경제 패턴을 보여준다.

05핵심 워크플로우 또는 비교표

단계내용산출물/결과
1. 스킬 호출클로드 코드에서 "scroll" 입력 시 ScrollCraft 스킬 활성화스킬 설명: "프리미엄 스크롤 연동 인터페이스 랜딩페이지 빌드"
2. 인터뷰스크롤 저널니, 핵심 메시지, 보유 자산, 시그니처 무브 등 질의톤·구조·자산 목록 확정
3. 자산 생성key.ai API로 이미지 생성 → 영상 변환 → 스티칭로우폴리 스타일 등 커스텀 비주얼 자산
4. 사이트 빌드인터뷰 답변 기반으로 스크롤 연동 섹션 구성약 30분 소요, 라이브 데이터 자동 반영
5. 자체 검증스크린샷 기반 키프레임 단위 시각 검토첫 결과물 완성도 상승
6. 피드백 반영자연어로 애니메이션 속도·링크·섹션 삭제 등 지시즉시 반영된 2차 버전

06활용 시나리오

  1. AI 자동화 교육 크리에이터/커뮤니티 운영자: 자체 커뮤니티(스쿨 등) 랜딩페이지를 실제 회원 수·리더보드 성과 등 라이브 데이터와 연동한 스크롤형 사이트로 재구성해, 신뢰 요소(receipt)를 시각적으로 강조하는 데 이 스킬을 적용할 수 있다.
  2. 1인 에이전시/프리랜서 웹디자이너: 클라이언트 요구를 인터뷰 형식으로 받아 여행사, 물리적 제품 판매, 개인 브랜딩 등 업종별로 톤이 다른 시안을 빠르게 여러 벌 생성한 뒤, 클라이언트 피드백을 자연어로 반영해 초안 제작 시간을 단축할 수 있다.
  3. 비개발자 소상공인/1인 창업자: 코딩 지식 없이도 클로드 코드 기본 사용법만 익히면, 보유한 실제 사진 몇 장과 브랜드 가이드라인만 입력해 프리미엄한 느낌의 랜딩페이지를 직접 만들고 반복 수정할 수 있다.
  4. 콘텐츠/마케팅 담당자: key.ai 연동을 활용해 별도 디자인 툴 없이 로우폴리·미니멀 등 특정 비주얼 스타일의 이미지·영상 자산을 요청 즉시 생성하고, 이를 스크롤 애니메이션에 바로 삽입하는 워크플로우를 마케팅 캠페인 페이지 제작에 응용할 수 있다.

07현황 및 전망

Nate는 이 스킬을 완전 무료로 자신의 스쿨 커뮤니티 클래스룸("All YouTube Resources")에 공개했으며, 클로드 코드 플러그인 형태 또는 폴더/파일 직접 삽입 방식으로 배포하고 있다. 영상에서 시연된 AIS 사이트는 두 차례의 피드백 반영을 거쳐 완성도를 높였고, 히어로 섹션 애니메이션·타이프라이터 텍스트 효과 등 세부 조정이 실시간으로 가능함을 보여주었다(다만 재로드 시 얼굴 이미지 순차 등장 애니메이션에 약간의 버그가 있음을 스스로 언급). 향후 이런 "인터뷰 기반 커스텀 스킬" 접근은 클로드 코드의 스킬 생태계가 코딩 작업을 넘어 디자인 취향과 브랜드 보이스까지 구조화해 담아내는 방향으로 확장되고 있음을 보여주는 사례로, 유사한 버티컬 특화 스킬(예: 이커머스, 포트폴리오, SaaS 랜딩)의 등장이 이어질 것으로 예상된다.

08용어 사전

용어한줄설명비유
스크롤 연동 디자인(Scroll-driven design)사용자의 스크롤 위치에 맞춰 애니메이션·숫자·이미지가 순차적으로 변화하도록 만드는 웹 인터랙션 기법손가락으로 페이지를 넘길 때마다 만화책 장면이 하나씩 살아 움직이는 것
클로드 코드 스킬(Claude Code Skill)특정 작업에 대한 지침·워크플로우·디자인 원칙을 미리 등록해 반복 호출할 수 있는 확장 기능셰프에게 미리 정해둔 레시피 카드를 건네 항상 같은 기준으로 요리하게 하는 것
