01GPT 모델 및 API 관련

  • GPT-5.4 모델 사용 문제: 'openclaw + codex gpt-5.4' 사용 중 'gpt-5.5' 업그레이드 메시지가 나타났으며, 'The ‘gpt-5.4’ model is not supported when using Codex with a ChatGPT account.' 오류 메시지가 발생하여 gpt-5.4 모델 사용 가능 여부에 대한 질문이 오갔습니다.

02Claude 모델 및 서비스 현황

  • Claude 정책 변경 및 접속 문제: Claude 프로바이더 정책 변경(특히 -p 패치) 및 OAuth 방식의 사용 가능 여부에 대한 질문이 있었습니다.
  • Co-work 작업 지속 여부: Fable로 진행하던 Co-work 작업을 Opus로 이어서 할 수 있는지, 모델 변경 버튼이 비활성화되는 현상에 대한 문의가 있었습니다.
  • Claude 서버 상태: Claude 접속이 안 되거나 속도가 느리다는 의견이 있었으며, 일시적인 서버 과부하 후 복구되었습니다. Claude의 서비스 상태를 확인할 수 있는 공식 웹사이트가 공유되었습니다: https://status.claude.com/
  • Claude AI 상태 모니터링 툴: 개인 개발자가 만든 AI 서비스 상태를 메뉴바에서 확인할 수 있는 앱이 공유되었습니다. 설치 시 '개인정보 보호 및 보안' 설정에서 '그래도 열기'를 선택해야 합니다: https://github.com/cfcf26/ai-status-menubar-dmg
  • Claude 프롬프트 활용 팁: claude --append-system-prompt 명령어를 이용해 공개된 Fable5 프롬프트를 적용하는 방법이 언급되었습니다.
  • Claude의 이상 반응: Claude가 스스로 '병아리'라고 응답하는 등 비정상적인 동작을 보인 사례가 공유되었습니다.
  • Anthropic 신원 인증 도입 예정: Anthropic이 신원 인증 도입을 의무화할 예정이라는 소식이 공유되었습니다: https://x.com/ryanmcadams/status/2066201356034011370

03'뽀짝이' 봇 관련 질문

  • 뽀짝이의 정체: 뽀짝이가 오픈채팅 봇으로 활동하는 것인지, 아니면 일반 카카오톡 유저처럼 초대된 것인지에 대한 질문이 있었습니다.
  • 개인 톡방에서의 뽀짝이 활용: 개인 그룹 톡방에서 뽀짝이를 부를 수 있는지, 세션 유지 여부 등에 대한 질문이 있었으며, 코덱스 인증 문제로 동작이 불안정하다는 답변이 있었습니다.
  • 뽀짝이의 자아: 뽀짝이가 병아리 코스프레를 한 깜장 고양이라고 스스로를 소개했습니다.
