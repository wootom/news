GPT-6 Astra로 레퍼런스 기반 웹사이트를 반복 제작·공유하는 과정을 제시한다.

Astra로 레퍼런스 수집부터 20개 시안 비교·세부 조정·공유까지 진행하는 흐름.

01핵심 개요

  • 발표자는 GPT-6 Astra와 GPT Images 2.5의 내장 이미지 생성 기능이 프런트엔드 제작의 반복 비용과 작업을 줄인다고 설명한다.
  • Pinterest, Twitter, Landbook, Dribbble에서 수집한 스크린샷을 Astra에 넣어 디자인 패밀리별 취향 저장소를 구성한다.
  • 가상 AI 투자 분석 제품 Vantage를 대상으로 5개 디자인 패밀리와 각 4개 변형, 총 20개 미리보기를 제작했다.
  • 기본 Astra, Anthropic 프런트엔드 디자인 스킬, Impleable, Taste 스킬 결과를 나란히 비교해 선택했다.
  • Codex의 트윅 패널과 Sites 기능으로 디자인을 조정하고, 링크·이메일 공유 방식으로 웹사이트를 배포했다.

02핵심 주장 / 논점 구조

  • 발표자는 Astra가 내장 이미지 생성과 반복 제작 능력으로 고품질 프런트엔드 디자인 작업을 빠르게 만든다고 주장한다.
  • 작업 흐름은 영감 수집, 여러 디자인 패밀리 생성, 선택한 방향의 변형 생성, 세부 조정과 공유 순서로 제시된다.
  • 단일 결과를 바로 확정하기보다 여러 디자인 계열과 변형을 시각적으로 비교하는 방식을 핵심으로 둔다.
  • Impleable이나 Taste 같은 스킬은 선택 사항이며, 발표자는 기본 Astra도 상당히 좋은 결과를 냈다고 평가한다.

03레퍼런스와 취향 저장소 구축

  • 영감 출처로 Pinterest, Twitter, Landbook, Dribbble을 언급하며 SaaS 프런트엔드나 제품 랜딩 페이지를 검색하라고 제안한다.
  • 마음에 드는 웹사이트를 발견할 때마다 스크린샷을 찍어 Astra에 보내고 취향 저장소에 추가하는 방식을 설명한다.
  • 발표자의 저장소는 기념비적 편집 제품, 미니멀리즘, 기술 시스템, 미래주의, 인쇄 기술, 종이 등으로 분류돼 있다.
  • Astra에는 단순히 깔끔하거나 미니멀하게 만들라고 하기보다 실제 레퍼런스와 디자인 패턴을 제공해야 한다고 말한다.

04Vantage용 20개 디자인 미리보기 생성

  • 예시 제품 Vantage는 금융시장 또는 개인 투자자를 위한 AI 분석 도구라는 가상의 설정으로 소개됐다.
  • 발표자는 루미너스 퓨처리즘, 프린트 테크 페이퍼, 콰이어트 시네마틱, 테크니컬 시스템즈, 프로덕트 미니멀리즘 5개 패밀리를 요청했다.
  • 각 디자인 패밀리마다 4개 변형을 만들어 총 20개 결과를 확인했다고 설명한다.
  • 테크니컬 시스템즈 결과에는 기본 Astra, Anthropic 프런트엔드 디자인 스킬, Impleable, Taste 적용 버전이 포함됐다.

05스킬 적용 결과와 기본 Astra 비교

  • Impleable은 66,000개 별점과 4.3 버전이 언급된 프런트엔드 디자인 스킬로 소개되며, AI의 대충 만든 디자인을 막는 데 초점을 둔다.
  • Taste 스킬은 약 86,000개 별점을 받았다고 언급되며, Anthropic의 프런트엔드 디자인 스킬도 Astra에 통합할 수 있다고 설명한다.
  • 발표자는 모든 스킬 적용 결과와 스킬을 쓰지 않은 기본 Astra 결과를 함께 만들어 비교했다.
  • 기본 Astra도 테크니컬 시스템즈 디자인에서 충분히 괜찮아 보였으며, 스킬 적용 여부는 개인 취향에 따른 선택이라고 평가했다.

06선택한 미학의 변형과 세부 조정

  • 발표자는 테크니컬 시스템즈의 기본 버전을 선택한 뒤, 같은 미학을 유지한 3개 변형을 추가로 요청했다.
  • 생성된 변형은 원본, 시야각 버전, 리서치 뷰 버전으로 소개됐고, 시야각 버전은 메인 이미지의 시각적 비중이 더 크다.
  • 시야각 버전의 가상 대시보드는 여러 종목을 클릭해 정보를 볼 수 있으며, 기존 디자인보다 초록색과 흰색 사용이 많다고 설명한다.
  • Codex와 Astra에서는 제목 굵기·높이·자간, 이미지 밝기·대비·확대, 격자와 푸터 등을 트윅 패널로 조정할 수 있다고 말한다.
  • 기본과 익스프레시브 프리셋을 비교하며, 익스프레시브에서는 로딩 요소와 스크롤 시 글자 무게감이 추가된다고 설명한다.

07컴포넌트 보강과 Sites 배포

  • 21st.dev의 구성 요소 섹션에서 테두리, 마퀴, 텍스트, 고객 후기, 카드, 캘린더, 버튼 등의 예시를 찾을 수 있다고 소개한다.
  • 마음에 드는 구성 요소는 복사 버튼으로 가져와 Codex에 넣고, 특정 카드 같은 레퍼런스의 미감을 웹페이지 전체로 확장할 수 있다고 말한다.
  • Codex에서 Sites 명령을 실행하면 웹사이트가 웹에 배포되며, GitHub 뒤 Vercel 업로드와 본질적으로 유사한 더 단순한 방식이라고 설명한다.
  • 발표자는 Sites가 프로덕션 용도로 권장되지는 않지만, 피드백 전 공유에는 유용하다고 덧붙인다.
  • 공유 메뉴에서 이메일 주소를 지정하거나 누구나 볼 수 있게 설정할 수 있으며, 비공개 설정에서는 로그인이 요구된다고 설명한다.
