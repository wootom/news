02왜 필요한가 — 리서치의 두 극단과 그 사이의 빈칸

Claude Code로 무언가를 조사할 때 사용자는 늘 두 가지 나쁜 선택지 사이에 놓인다.

  • 웹검색(web search): 사실상 '고급 구글 검색'. SEO 상위에 오른 기사와 헤드라인만 훑는다. 틀리지는 않지만 한 겹 더 들어가지 못해 표면적이다.
  • 딥리서치(deep research): 5·10·15·20분이 걸리고 수백 개의 서브에이전트, 잠재적으로 수백만 토큰을 소모한다. 무겁고 느리다.

'last 30 days'는 이 둘 사이의 완벽한 중간 지대를 제공한다. 여러 플랫폼을 빠르게 훑어 SEO 상위 기사가 아니라 실제 사용자들이 무슨 말을 하는지(user sentiment) 를 잡아낸다.

03무엇을 하는가 — 여론 스크래핑과 종합

  • Reddit, Hacker News, Polymarket, GitHub, YouTube, TikTok, Instagram 등 주요 소셜 플랫폼 전부를 훑어 필요한 정보를 찾는다.
  • 게시글 제목이 아니라 댓글·반응까지 파고들어 일반 웹검색으로는 얻을 수 없는 '풀뿌리(grassroots)' 여론을 확보한다.
  • 수집한 것을 종합해 랭킹된 브리프로 만들고, 원본(트랜스크립트·댓글 등 전부)을 JSON 파일로도 저장해 원자료를 직접 뒤질 수 있게 한다.

04실증 비교 — "Opus 5에 대한 여론" (last 30 days vs 웹검색)

발표자는 동일 질문 "What are people saying about Claude Opus 5?" 를 두 방식에 던져 결과를 나란히 비교했다.

  • 웹검색 쪽: 구글에서 나올 법한 주요 기사 요약 수준. 틀리진 않지만 트위터·레딧에서 사람들이 실제로 하는 말(풀뿌리)까지는 닿지 못한다.
  • last 30 days 쪽: 훨씬 넓은 그물. 실제 소스 규모가 그 차이를 보여준다(아래 표). 발견한 디테일도 구체적이다 — "Opus 5가 Fable 5의 절반 가격"이라는 프레이밍, 게시글이 아닌 '댓글'에서의 백래시, 전문 리뷰어들의 종합 여론까지.

05작동 원리 — 프롬프트 개선 → 병렬 검색 → 댓글 심층 → 랭킹 종합

  1. Claude Code 안에서 /last 30 days 또는 자연어("use the 30 day skill")로 스킬을 호출하고 주제를 준다.
  2. 사용자의 거친 프롬프트를 스킬이 스스로 더 낫게 다듬는다.
  3. 주제에 맞는 서브레딧·트위터 핸들 등을 알아서 판단해 여러 플랫폼을 병렬 검색한다(그래서 빠르다).
  4. 제목이 아니라 댓글까지 심층 확인한다.
  5. 실제 스크래핑은 결정적(deterministic) Python 스크립트가 실행한다.
  6. 교차 검증 랭킹 — 여러 플랫폼에서 반복 등장하는 신호를 상위로 올린다. 단일 레딧 댓글 하나가 결과를 왜곡하지 않는다.
  7. 스코핑 가능 — "레딧만"·"트위터만"·"유튜브만"처럼 플랫폼을 한정해 지시할 수 있다. 사용법을 모르면 Claude Code가 스킬 문서를 읽어 안내한다.

06설치·비용·API 키 — 진입장벽은 낮다

  • 설치: Claude Code에서 코드 한 줄. 설치하면 대부분의 소스가 자동 세팅되어 API 키가 필요 없다.
  • X(트위터): xAI(X AI) API 키 필요. 여기서 가장 비싼 소스지만 발표자 실측 기준 회당 평균 ~10센트.
  • TikTok·Instagram Reels: scrape creators API 키 필요. 다만 설치 시 보조 계정으로 수천 콜을 무료 제공해, 매일 써도 약 6개월은 공짜로 돌릴 수 있다.
  • 레포 자체가 소스별 필요 조건·비용을 문서화한다.
  • Claude Code 외에 Codex·Cursor·claude.ai 웹앱에서의 설정법도 안내한다.

07포지셔닝·전망 — 웹검색과 딥리서치 사이, 여론에선 딥리서치보다 나을 수 있다

  • 모든 질문에 쓸 도구는 아니다. 일상적인 잡다한 질문은 웹검색으로 충분하며, 발표자도 남용하지 말라고 권한다. '큰 건'에 쓰는 도구다.
  • 위치: 표면적인 웹검색과, 수천 서브에이전트를 돌리는 무거운 딥리서치 워크플로우의 딱 중간.
  • 강점: 특히 사용자 여론 파악에서는 딥리서치보다도 나을 수 있다는 게 발표자의 주장이다.
  • 유일한 걸림돌: 특정 소스(주로 X 키) 연결. 레포 링크를 Claude Code에 던지면 필요한 부분을 안내해 준다.
※ 영상 중반에는 발표자 본인 유료 강의(Chase AI Plus의 'Claude Code Masterclass') 홍보 구간이 포함되어 있어 본 분석에서는 제외했다.
