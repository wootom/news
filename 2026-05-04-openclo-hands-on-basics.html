Editor's Note

오픈클로(OpenCLO)란?

오픈클로는 AI를 실행하는 "운영 체제(OS)"입니다. 우리가 컴퓨터에서 Windows나 macOS를 쓰듯, AI 에이전트들이 돌아가는 플랫폼입니다. Claude Code, Codex 같은 코딩 AI들이 이 오픈클로 위에서 앱처럼 실행됩니다. 사람은 지시만 하고 AI가 알아서 작업하는 가장 높은 단계의 AI 활용 방식입니다.

AI 도구는 지금까지 4세대를 거쳐 발전했습니다. 각 세대가 어떻게 다른지 알아야 오픈클로가 어떤 위치에 있는지 이해할 수 있습니다.

오픈클로 = 에이전트 OS ▶ 02:51

오픈클로는 "AI들이 돌아가는 운영 체제"입니다. Windows 위에서 카카오톡·크롬 같은 앱들이 실행되듯, 오픈클로 위에서 Claude Code·Codex CLI가 앱처럼 실행됩니다. "오픈클로 vs Claude Code 뭘 써야 하나요?" 질문이 나오면 "오픈클로는 OS이고 Claude Code는 그 위에서 돌아가는 앱"이라고 이해하면 됩니다.

2LLM + Tool 구조 이해 ▶ 03:40

오픈클로가 어떻게 일을 하는지 이해하려면 "두뇌"와 "손발" 개념을 알아야 합니다. LLM(대규모 언어 모델)이 두뇌 역할을 하고, Tool(도구)이 손발 역할을 합니다. 두뇌만 있으면 생각만 하고 아무것도 실행 못 합니다. 손발(Tool)이 있어야 실제로 파일을 만들고, 검색하고, 코드를 실행할 수 있습니다.

4컨텍스트 이해 ▶ 08:32

컨텍스트(Context)는 AI가 한 번에 기억할 수 있는 정보의 양입니다. 사람으로 치면 "단기 기억 용량"입니다. 이 용량을 넘으면 앞에서 했던 내용을 잊어버려 오작동이 납니다.

모델컨텍스트 크기비고

실전 주의사항
Opus로 작업하다가 GPT로 모델을 바꾸면, GPT는 앞의 내용을 다 기억 못해 오작동이 날 수 있습니다. 작업 설계는 가장 작은 컨텍스트(200K) 기준으로 하는 것이 안전합니다.

5게이트웨이 관리 ▶ 09:42

게이트웨이(Gateway)는 오픈클로의 핵심 백그라운드 프로세스입니다. 컴퓨터를 켜면 자동으로 실행되어 항상 떠 있어야 합니다. 작업 중 갑자기 멈추거나 오류가 나면 대부분 게이트웨이 문제입니다. 즉시 게이트웨이 상태를 확인하세요.

6실습 — 파일 정리 ▶ 13:49

오픈클로의 강점은 내 컴퓨터 파일에 직접 접근한다는 점입니다. 코워크 같은 도구와 달리, 폴더를 일일이 첨부할 필요 없이 경로만 알려주면 됩니다. 파일 경로를 복사하는 단축키를 먼저 익혀두세요.

OS경로 복사 단축키
WindowsCtrl + Shift + C
macOSCmd + Option + C

중복 파일 정리 프롬프트 예시

"C:\Users\...\Downloads 폴더를 정리해 줘.
해시값이 같은 파일은 완벽한 중복이니
중복 파일을 별도 폴더에 따로 모아줘"
해시값이란?
파일 내용을 기반으로 만드는 고유 코드입니다. 파일 이름이 달라도 내용이 완전히 같으면 해시값이 같습니다. 반대로 내용이 1비트라도 다르면 해시값이 달라집니다. 해시값으로 비교하면 100% 정확한 중복 탐지가 가능합니다.
