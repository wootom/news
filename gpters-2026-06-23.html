02LLM(대규모 언어 모델) 사용 및 모델 관련 의견

  • 모델 전환 및 명령어 문제:

- 슬랙(Slack)에서 모델 전환이 어렵다는 의견이 있었고, @뽀짝이 /model 또는 !model과 같은 명령어로 시도 중인 경험이 공유되었습니다. - 슬랙 스레드에서는 슬래시(/) 대신 느낌표(!)로 명령어가 작동하도록 내부 파일에 세팅되어 있다는 정보와 함께, Hermes(허미스)에게 직접 요청하여 수정했다는 해결 방안이 제시되었습니다.

  • 모델 성능 및 속도:

- 클로드(Claude) 모델 사용 가능 여부에 대한 질문과 함께, 현재 안 된다는 답변과 코덱스(Codex) 모델로 넘어갔다는 언급이 있었습니다. - 로컬 모델 대신 클라우드 모델 사용을 권유하는 의견과 함께, 저사양 PC에서는 성능 문제(느림)가 발생한다는 의견도 있었습니다. - Hermes 모델 중 GPT-3.5 xhigh를 주로 사용한다는 의견과, Claude 5.3 spark로도 충분할 것 같아 모델을 내려볼까 고민 중이라는 의견이 있었습니다. - 5.5 xhigh와 같은 고성능 모델을 사용하는 이유로 "결과물의 품질 차이(95% vs 90%)"를 중요하게 생각하기 때문이라는 의견과 함께, '토큰 장사'라는 비판적인 시각도 있었습니다. - 모델 업데이트(5.6 버전)에 대한 기대감과 현재 코덱스 모델의 성능 저하("멍청해짐")에 대한 불만이 표명되었습니다. "Codex 초기화 느낌", "필살 소모 시켜야겠다" 등의 표현으로 불만을 나타냈습니다. - 일부 사용자들이 현재 모델들의 속도가 "겁나 느리다"고 느끼고 있음을 공유했습니다.
