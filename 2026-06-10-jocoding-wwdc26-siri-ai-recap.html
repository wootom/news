WWDC26 핵심 총정리 — 시리 AI와 애플 파운데이션 모델

조코딩이 WWDC26 키노트+개발자 세션을 총정리. 한 문장: 애플이 제미나이와 협력해 차세대 '애플 파운데이션 모델(20B MoE)'을 구축하고 이를 기반으로 시리 AI를 공개. 개인 맥락 이해가 강점이나 지원 기기는 아이폰 17 Pro·Air 이상으로 제한.

목차핵심 개요시스템 개선과 차세대 애플 인텔리전스시리 AI — 개인 맥락 비서의 부활앱 전반의 AI 내장개발자 업데이트 — Xcode의 바이브 코딩화모델 상세 — 20B MoE와 3계층 구조 (개발자 세션)총평 및 전망용어 사전핵심 타임스탬프

01핵심 개요

항목내용

모델 구조온디바이스 20B MoE(요청당 1~4B) + 프라이빗 클라우드 컴퓨트(프로) + 이미지 모델

02시스템 개선과 차세대 애플 인텔리전스

  • 성능 최적화: 앱 실행 30%↑, 사진 로딩 70%↑, 에어드롭 80%↑, 외장 전송 5배↑. 아동·청소년 보호 강화.
  • 차세대 애플 인텔리전스: 온디바이스 모델 + 프라이빗 클라우드 컴퓨트(구글 클라우드까지 확장), 멀티모달 강화, 개인 맥락 이해, 웹 지식 연결, 앱 액션·화면 인식.
  • 프라이버시 반복 강조: 제미나이 협력에도 데이터 유출 없음을 키노트 내내 강조.

03시리 AI — 개인 맥락 비서의 부활

  • 별도 시리 앱 등장. 애플 파운데이션 모델 기반으로 더 자연스러운 대화형 비서로 재탄생.
  • 월드 날리지: 웹 검색 연동(ChatGPT·제미나이처럼 후속 질문 가능).
  • 애플만의 강점: 앨범·문자 등 기기 내부 정보 기반 답변. 데모 — "엄마가 원했던 브랜드?" → 문자 내역에서 확인.
  • 멀티 진입점: 카메라/비주얼 인텔리전스, 맥 스팟라이트에서 바로 질의, 비전 프로는 시리 구슬을 '쳐다보며' 대화.
  • TTS 향상: 속도·표현력 조절 가능, 전반적으로 자연스러운 목소리.

04앱 전반의 AI 내장

  • 사파리: 탭 자동 그룹화, 페이지 변경 알림, AI로 커스텀 확장(익스텐션) 직접 생성("자동 번역 확장 만들어줘").
  • 메시지/메일/캘린더/전화: 메시지 맥락 기반 답장, 통화 중 예약번호·항공편 정보 자동 표시(AI 비서).
  • 쇼컷: 코딩 블록 조립 없이 말로 자동화 생성("바이브 쇼컷").
  • 이미지: 이미지 플레이그라운드(제미나이/나노바나 기반 추정), 부분 수정, 포토 보정.
  • 스페이셜 리프레이밍: 2D 사진을 온디바이스 3D 공간 모델로 변환해 구도 변경.

05개발자 업데이트 — Xcode의 바이브 코딩화

  • 앱 인텐트 강화, 파운데이션 모델 프레임워크(이미지 입력·커스텀·서버 모델 Swift API), 코어 AI(외부 모델 애플 실리콘 로컬 구동).
  • Xcode: 클로드 코드·코덱스·제미나이 3종 연결로 바이브 코딩 가능. 피그마·깃허브 연동.
  • 디바이스 허브: 시뮬레이터·실기기를 한 화면에서 통합 제어. 메시지는 "AI가 개발자 대체 아닌 향상".

06모델 상세 — 20B MoE와 3계층 구조 (개발자 세션)

  • 이전: 온디바이스 3B(성능 한계) → 신규 AFM 어드밴스드 20B 파라미터(MoE, 요청당 1~4B만 사용해 효율적).
  • 3계층: ① 애플 파운데이션 모델(온디바이스 20B) ② 클라우드 프로(프라이빗 클라우드, 거의 제미나이급) ③ 이미지(애플 디퓨전).
  • 라우팅: 저지연·최적 답을 주는 모델로 자동 라우팅(어려운 질문만 프로로).
  • 프라이빗 클라우드 컴퓨트 확장: 구글 클라우드 제휴로 엔비디아 GPU 기반 구동, 컨피덴셜 컴퓨트·인텔·구글 타이탄 결합, 실드 2개로 무결성 보호 — 데이터 미저장·미접근 유지.
  • 비하인드: 작년 시리 V1(기존 위에 도구 얹음)은 성능 미달로 폐기, 바닥부터 재구축.

07총평 및 전망

  • 성능 자체는 "어마어마한 혁신"은 아님 — 20B 압축 모델로 한계 존재.
  • 그러나 미래 유망: 개인 맥락(문자·캘린더·메일) 반영 답변은 애플·구글만 가능한 포지션 → 강력한 해자.
  • 미공개: AI 에이전트/오픈클로 데스크톱 통합은 업계 초기·불안정으로 보류(윈도우는 선제 통합, 맥은 관망).
  • 한도: 프라이빗 클라우드 사용 일부 기능(이미지 생성 등)은 1일 사용 한도, 상위 아이클라우드 플랜에서 상향.

용어한줄 설명비유/예시
