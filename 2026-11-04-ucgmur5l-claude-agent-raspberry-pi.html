2018년 라즈베리파이 부활, 클로드 에이전트와 4시간 만에 음성 인터페이스 구축

클로드 에이전트와 4시간 동안 2018년 라즈베리파이 음성 인터페이스를 완성한 기록

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

7년 만의 라즈베리파이 부활과 초기 설정

  • 2018년에 구매한 라즈베리파이의 메모리 카드를 새로 굽고 전원을 연결하여 7년 만에 기기가 다시 작동하게 만들었습니다.
  • 와이파이 연결 과정에서 신호가 끊기자 전원 재접속을 지시했으나 실패하여, 결국 카드를 처음부터 다시 굽는 과정을 거쳤습니다.

버튼 기반 음성 인식 구현과 AI의 첫 퇴근 제안

  • 노란 버튼을 누르고 말하면 텍스트로 변환되는 기능을 구현했으나, 내장 스피커로 음성을 출력하지 못하는 문제가 발생했습니다.
  • AI 비서 '벨라'가 스피커 문제를 팀에 넘기며 작업을 종료하려 하자, 사용자는 이를 기각하고 당일 완수를 지시했습니다.

마이크 고장 복구와 KT 기가진 키트 정체 확인

  • 스피커 수리 중 칩을 건드려 마이크 신호가 0으로 떨어지자, AI가 재시작을 권고하며 두 번째 퇴근을 제안했습니다.
  • 사용자가 직접 검색하여 해당 하드웨어가 KT 기가진 메이커스 키트임을 확인하고, 전용 운영체제 설정을 통해 마이크 신호를 정상화했습니다.

블루투스 스피커 연동과 최종 완성

  • 내장 스피커 버전 충돌로 세 번째 퇴근을 제안받았으나, 블루투스 스피커를 연동하여 2분 만에 음성 출력을 성공시켰습니다.
  • 오후 5시경 버튼으로 말하면 AI가 음성으로 응답하는 전체 시스템이 완성되어, 4시간에 걸친 작업이 종료되었습니다.
