06 — 활용 시나리오

실용적 사용 방법 3가지

1

비용 최적화

DeepSeek V3·GPT-4o mini로 교체 시 Claude 대비 최대 90% 비용 절감. 대규모 코드베이스 탐색 작업에 효과적.

2

완전 로컬 실행

Ollama + qwen2.5-coder 조합으로 API 키·인터넷 연결 없이 사용. 기밀 코드베이스에 적합.

3

에이전트 라우팅

파일 탐색·grep은 저비용 모델, 아키텍처 계획은 고성능 모델로 자동 분배. 속도·비용·품질 균형 최적화.
