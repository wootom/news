OpenAI Dots는 원격 작업과 여러 AI 작업의 조율을 겨냥한 상시형 비서다.

Dots의 강점은 GPT-6 Astra와 원격 작업·다중 에이전트 조율이다.

01핵심 개요

  • 영상은 Dots를 클라우드에서 상시 작동하는 AI 비서로 소개하고, Grokbot·Muse와 모델·가격·사용 방식을 비교한다.
  • 소개된 모델은 Dots의 GPT-6 Astra, Grokbot의 Grok 4.7, Muse의 Spark 1.3이며 진행자는 Astra가 더 강력하다고 평가한다.
  • Dots는 월 100·200·500달러 플랜 이용자 대상이며, Grokbot은 월 20달러, Muse는 무료 이용 단계가 있다고 설명한다.
  • 가상 컴퓨터와 실제 컴퓨터, 플러그인, 휴대전화 연결을 이용해 원격으로 작업을 맡기고 진행 상황을 확인할 수 있다.
  • 진행자는 다중 작업 조율과 원격 사용이 필요하면 Dots가 유용하지만, 단순한 이메일·날씨 확인에는 과할 수 있다고 본다.

02핵심 주장 / 논점 구조

  • Dots·Grokbot·Muse는 로컬 컴퓨터의 전원 여부와 관계없이 클라우드에서 작동하는 상시형 AI 비서로 소개된다.
  • 세 제품의 핵심 차이는 내부 모델, 비용, 사용 조건이며, 제공되는 기능과 접근 방식은 대체로 비슷하다고 설명한다.
  • 선택 기준은 사용 목적이다. 단순한 일상 업무인지, 개발·에이전트 조율·원격 작업인지에 따라 적합한 제품이 달라진다.

03모델 성능과 요금 비교

  • 영상에서 비교한 모델은 Dots의 GPT-6 Astra, Grokbot의 Grok 4.7, Muse의 Spark 1.3이다.
  • 진행자는 Astra가 세 선택지 중 성능이 가장 강력하다고 평가하며, 개발자와 복수 에이전트 조율 작업에 적합하다고 본다.
  • 설명된 요금은 Dots가 월 100·200·500달러 플랜, Grokbot이 월 20달러, Muse가 무료 단계다.
  • 진행자는 Dots 이용량이 당분간 사용 한도에 반영되지 않는다고 말하지만, 이후 요금제 적용 방식은 알 수 없다고 덧붙인다.

04설정 과정과 컴퓨터 연결

  • Codex 데스크톱의 새 채팅 메뉴에서 Dots를 설정하고, 필요한 플러그인을 추가한 뒤 외부 서비스의 권한을 승인한다.
  • 설정 중 Dots 전용 가상 컴퓨터와 실제 컴퓨터에 대한 접근을 선택하며, 진행자는 둘 다 허용할 것을 권한다.
  • 프로필 메뉴에서 이름과 색상·캐릭터를 설정하고, 연결된 두 컴퓨터와 Dots의 작업 상태를 확인할 수 있다.
  • 웹사이트 로그인처럼 API가 없는 서비스에 접근할 때는 비밀번호 입력이나 2단계 인증 등 사용자의 개입이 필요할 수 있다.

05음성 지시와 Codex 작업 조율

  • 진행자는 음성 통화로 Dots에 Codex의 dots 프로젝트 안에서 제품 비교 웹사이트를 만들도록 지시한다.
  • Dots는 작업을 Codex에 전달하고 별도 작업 흐름을 만들며, 사용자는 화면 오른쪽의 활동 내역에서 진행 상황을 확인한다.
  • 시연에서는 Dots가 작업을 수행하는 동안 사용자가 다른 작업을 맡겼고, YouTube Studio의 최근 긴 영상 10개 분석도 요청했다.
  • 웹사이트 미리보기는 생성됐지만 프로젝트 폴더에 들어가지 않는 문제가 있었고, 완료 안내가 충분히 명확하지 않았다고 진행자는 지적한다.

06상시 능동형 비서의 작동과 한계

  • Gmail을 연결하면 중요한 새 이메일이 왔을 때 사용자가 먼저 요청하지 않아도 알림을 보내는 사례를 소개한다.
  • 진행자는 알림 빈도 등 능동성 수준을 조정할 수 있다고 설명하며, Dots가 Drive·Slack·Gmail 등의 연결 정보를 활용한다고 말한다.
  • 실제 컴퓨터의 YouTube Studio에 로그인할 때는 계정 선택과 2단계 인증 과정에서 사용자가 직접 인증을 완료해야 했다.
  • 영상에서는 생성된 사이트의 프로젝트 배치 문제와 작업 완료 알림의 아쉬움도 확인돼, 시연 결과가 완벽하지만은 않았다.

07제품 선택과 활용 대상

  • 개발 작업, 여러 에이전트와 프로젝트의 조율, 휴대전화로 하는 원격 작업이 중요하면 Dots가 유용할 수 있다고 진행자는 판단한다.
  • 이메일 확인이나 날씨 문의처럼 간단한 비서 기능만 원한다면 Muse로 충분할 수 있다고 설명한다.
  • 진행자는 Cursor나 Grok을 선호하는 사용자에게는 Grokbot이 선택지가 될 수 있다고 말하며, Dots는 현재 EU에서 이용할 수 없다고 덧붙인다.
  • Codex 사용에 익숙한 사람에게는 추가 기능의 가치가 사용 상황에 달렸지만, 일반 이용자는 휴대전화에서 쉽게 시작할 수 있다고 평가한다.

08용어 사전

오케스트레이션한 곳에서 여러 프로젝트와 작업 흐름을 관리하고, Codex 등 다른 작업을 조율하는 기능을 가리킨다.
