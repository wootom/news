AI 세컨드 브레인 완전 가이드

Codex + Obsidian으로 나와 대화하는 지식 관리 시스템 만들기

▶ 영상 바로가기
기존 세컨드 브레인의 근본 문제
유튜브 자막·기사·팟캐스트를 저장해도 → "정보의 무덤"이 됨.
능동적으로 검색·복습하지 않으면 쓸모없는 저장소에 불과.
해결: AI가 자동으로 요약·연결·응답해주는 살아있는 지식 시스템
시스템 3대 기둥 ▶ 2:00
①

Wiki · 지식베이스

유튜브 자막·기사·팟캐스트를 Web Clipper로 저장 → AI가 자동 요약·개념 추출·상호 링크 생성. 모든 것의 중심.

②

CRM · 인맥 관리

이벤트·줌콜에서 만난 사람 정보를 자연어로 입력 → AI가 자동 CRM 파일 생성. "매튜를 어디서 만났지?" 즉시 답변.

③

Journal · 일기

일기 작성 시 AI가 Wiki + 과거 일기 + CRM을 참조해 맞춤 응답. ChatGPT가 아닌 내 지식으로 조언.

구축 단계별 가이드 ▶ 5:00
  1. Obsidian 설치 → 새 Vault(폴더) 생성 — "Second Brain" (무료)
  2. Obsidian Web Clipper 설치 → raw 폴더로 저장 설정 (유튜브 자막 자동 추출)
  3. Codeex에서 Karpathy LLM Wiki 구조 생성 → raw/·wiki/·agents.md·index.md·log.md
  4. agents.md 작성 → 인제스트·쿼리·저널·CRM 처리 규칙을 자연어로 정의
  5. Automations 설정 → 매시간 raw 폴더 자동 처리 (GPT-5.5, 높은 추론)
  6. GitHub Private Repo 연결 → 처리 완료마다 자동 커밋·백업
