Base44에 UI 레퍼런스와 프롬프트를 넣어 금융 앱을 구축·연결·게시하는 과정을 시연한다.

UI 레퍼런스 1만여 화면을 바탕으로 Base44 금융 앱을 만들고 결제·게시까지 시연한다.

01핵심 개요

  • AI가 훌륭한 기존 디자인 시스템을 보지 못하면 웹사이트와 앱이 좋지 않게 보인다는 문제의식에서 출발한다.
  • Stripe, Apple, Duolingo 등의 UI와 웹사이트 갤러리, UI 스니핑 자료를 디자인 영감과 참조 자원으로 제시한다.
  • Base44에서 이미지·링크·스크린샷을 넣고 Gorilla Finance라는 금융 앱의 디자인과 기본 기능을 생성한다.
  • Google 로그인과 예산 한도 변경 뒤 재로그인을 시연하며, 대시보드 정보가 업데이트되는 모습을 확인한다.
  • Stripe·Slack·Notion·Google Sheets·Zapier 연결, 월 10달러 멤버십, 게시·도메인·SEO 관리 흐름을 소개한다.

02핵심 주장 / 논점 구조

  • 영상은 AI 웹사이트·앱의 99%가 올바른 디자인 시스템을 사용하지 않아 형편없어 보인다고 주장한다.
  • 해결책은 성능이 검증된 기존 웹사이트·앱 UI 시스템을 AI에 보여주고, 원하는 결과를 설명하는 방식이다.
  • 전체 과정은 디자인·제작, 카피 검토, 기능 확인, 운영·출시의 네 단계로 제시된다.
  • 한 앱 안에서 프롬프트 입력부터 앱 생성, 연결, 게시까지 진행하는 것이 Base44 활용의 핵심으로 설명된다.

03UI 레퍼런스 수집과 금융 앱 무드보드

  • Stripe, Apple, Duolingo 등에서 만든 웹사이트를 둘러보며 AI에 제공할 디자인 참조 사례로 제시한다.
  • 웹사이트별·요소별 검색, 대시보드 탐색, UI 디자인 탐색을 통해 영감을 수집할 수 있다고 설명한다.
  • Canvas에 이미지를 업로드하고 금융 분야 디자인을 골라 맞춤형 무드보드를 만드는 흐름을 보여준다.
  • Orrus 웹사이트 디자인과 추가 참조 이미지·링크를 바탕으로 Gorilla Finance라는 금융 앱을 요청한다.

04Base44에서 디자인과 기본 기능 생성

  • 링크·이미지·스크린샷을 추가한 뒤 빌드 모드 또는 계획 모드를 선택하고 모델을 고를 수 있다고 소개한다.
  • Base44 기본 1 모델과 자동 모드를 언급하며, 자동 모드는 최적 모델 매칭과 크레딧 효율성에 유리하다고 설명한다.
  • 금융 앱에는 전문적 인상, 로그인, 로그인 화면 내 설정 기능, 예산 관리 기능을 넣고자 했다고 말한다.
  • 2단계 전에는 디자인 방향과 기본 기능이 원하는 수준에 가까운지만 확인하는 데 집중한다고 밝힌다.

05Google 로그인과 예산 대시보드 검증

  • 생성된 앱의 로그인 페이지에서 ‘Google로 계속하기’가 내장된 모습을 확인하고 계정 로그인 과정을 시연한다.
  • 로그인 후 이메일 주소를 인식하고, 대시보드의 데이터·정보를 수정할 수 있는지 확인한다.
  • 예산 한도를 25,000에서 500,000으로 변경한 뒤 로그아웃하고 다시 로그인해 업데이트 여부를 점검한다.
  • 재로그인 뒤 대시보드에 정보가 유지된 모습을 통해 기본 UI와 기능을 갖췄다고 평가한다.

06Slop Monster로 AI식 카피 수정과 UI 보강

  • AI가 쓴 것처럼 들리고 읽히는 카피는 구매로 이어지지 않는다는 문제를 해결하기 위해 Slop Monster를 사용한다.
  • Slop Monster는 고전적 AI 어휘, 문장 구조, 구두점 리듬, 3박자 규칙을 찾아내도록 구성됐다고 설명한다.
  • Horowitz, Daniel Priestley, Krug의 판매·마케팅 시스템과 사례를 바탕으로 구축했다고 소개한다.
  • 수정 후 ‘은행 업무·카드·재무를 하나의 플랫폼에서’라는 문구가 자금 위치·이동 속도·접근 권한을 묻는 표현으로 바뀐 사례를 비교한다.
  • 21st.dev와 Mobin에서 컴포넌트·아이콘·애니메이션을 찾아 프롬프트와 코드를 Base44에 추가하는 과정을 보인다.

07통합·결제·게시로 이어지는 운영 단계

  • 3단계는 계정, 데이터, 통합을 연결하는 단계이며 Stripe, Slack, Notion, 이메일, Google Sheets를 예시로 든다.
  • Zapier를 인증 계층으로 사용해 새 가입자 목록을 매일 이메일로 보내는 자동화 예시를 제시한다.
  • Stripe에 연결해 가입 시 월 10달러를 결제하는 기능을 요청하고, 테스트 결제 시스템과 멤버십 활성화 화면을 시연한다.
  • 4단계에서는 게시 버튼으로 일반 URL을 만들고, Google 로그인·대시보드·Stripe 결제 페이지 연결을 확인한다.
  • 대시보드에서 도메인 구매·관리와 SEO, 지역 최적화, 소셜 콘텐츠 관련 마케팅 기능을 살펴볼 수 있다고 설명한다.

08용어 사전

용어뜻
Base44프롬프트와 디자인 시스템을 입력해 앱을 만들고, 모델 선택·통합·게시·도메인 관리를 한곳에서 수행하는 도구로 소개된다.
Slop Monster영상 제작자가 만든 도구로, AI식 어휘와 문장 구조 등을 점검해 웹사이트 카피를 인간적으로 다듬는 데 사용된다.
UI 스니핑웹사이트와 앱의 UI 화면·컴포넌트·디자인을 찾아 저장하고 수집해 제작 참조 자료로 활용하는 방식이다.
21st.dev결제·축하·이벤트 같은 기능을 검색하고, 웹사이트에 넣을 컴포넌트와 애니메이션을 찾는 사이트로 언급된다.
Zapier이메일과 계정, 여러 앱·시스템을 연결하고 웹훅 URL 및 자동화에 쓰는 인증 계층으로 소개된다.
Stripe앱의 월 10달러 멤버십 결제 기능을 연결하고 테스트 결제 페이지를 추가하는 사례에 사용된다.
