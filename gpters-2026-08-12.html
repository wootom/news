다음은 'GPTers x 뽀짝이' 오픈채팅방의 지난 한 주(2026-08-06~08-12, 약 1,025건)간 주요 주제를 정리한 내용입니다.

01GPT 사용량·리셋 문화 ("티보형님")

  • 주간 토큰 리셋 눈치싸움 — 사용량을 다 태우면(0%) 리셋 은총을 기다리고, 리셋 직전엔 "주말 버닝"으로 남은 토큰을 몰아 쓰는 문화. OpenAI 계정 담당자(별명 "티보/티보형님")의 X 리셋 공지를 실시간 공유하며 "전여친의 '자니'보다 설레는 굿모닝"이라는 농담까지.
  • 더블 리셋 챌린지 — 8/12(미국 월요일=한국 화요일) 전후 "테크니컬 리셋" 예고로, 초기화권까지 동원해 "이틀+이틀에 2주치 토큰 털기"가 벌어짐.
  • 모델별 체감 — Sol(솔)은 토큰 소모가 크지만 완성도·이해도가 높고, Luna(루나)는 응답이 짧고 토큰 절약, Terra(테라)는 5.5를 효율화한 중간 느낌. "테라로 10번 얘기해 10% 쓸 걸 솔은 2번에 5%로 완성" — 재작업·스트레스 비용까지 합치면 솔이 낫다는 의견이 다수.

02한국·글로벌 모델·서비스 동향

  • 업스테이지 Solar Pro 4 무료 개방(~8/10) — "한국산 모델"을 헤르메스·클로드코드에 붙여 체험. 한국어는 자연스럽다는 호평, 그러나 컨텍스트를 짧게 보고 '세차 변형' 추론 벤치는 통과 못한다는 한계(미·중에 이은 "세계 3위" 밈).
  • MiniMax H3 — 영상·음향을 한 생성 과정으로 통합한 33B 옴니모달 모델. 단 한국은 라이선스 지역에서 제외돼 로컬 배포보다 API가 현실적.
  • Prime Agent(Prime Intellect) — 자기개선 에이전트가 ARC-AGI-3에서 95.5%로 인간 전문가 평균(95.4%)을 처음 돌파. 컨텍스트를 통째로 넣지 않고 코드로 필요한 부분만 읽는 RLM 구조, 8/6 오픈소스 공개(스타 10.5k).
  • Fireworks AI 'Nexus' — 프론티어 호출을 Kimi-K3·GLM-5.2 등 오픈웨이트로 자동 라우팅해 비용을 낮추는 관리형 레이어(PR당 비용 약 1/3 절감 주장, $17.5b 밸류 $1.5b 유치).
  • 그 외 — GPT-5.6 공개, Google Gemini Robotics ER 2, DeepSeek API 요금 인상, 국가 무료 AI '모두의 AI'(효용성 논쟁), Manus AI 회사 변경(8/26 자료 삭제·크레딧 환불 논란)도 오르내림.

03에이전트 운영·워크플로우 노하우

  • CLAUDE.md ↔ AGENTS.md 임포트 — CLAUDE.md에 @AGENTS.md를 써넣으면 그 내용이 그대로 로드됨(클로드 전용·역방향 불가). 공통 규칙은 AGENTS.md, 클로드 전용(훅·서브에이전트·모델)만 CLAUDE.md에 두는 구성.
  • 컨텍스트 다이어트 — @임포트는 항상 자동 로드라 비용은 그대로. "상시 로드"와 "필요할 때 읽기"를 구분해야 함. 메모리를 "한 건=한 파일=한 사실"로 쪼개 인덱스엔 한 줄 훅만 노출(예: 316KB를 15KB 인덱스로) → 상시 규칙 / 한 줄 인덱스 / 온디맨드 본문의 3층 구조.
  • 교차검증·핸드오프 — 헤르메스·클로드코드·코덱스를 서로 교차검증시키고 수동 핸드오프로 "대질심문"해 누락 위험을 잡는 방식. "AI는 가챠 — 여러 각도로 물으면 다른 답이 나온다", 증거 파일 기반 검증 강제가 핵심.
  • 하네스 — 소크라테스식 인터뷰 후 루프를 도는 uroboros, karpathy의 autoresearch 같은 자동 반복 하네스 소개(토큰 소모 큼).

04카톡봇·자동화 실전 (그리고 밴 리스크)

  • 실전 사례 — 로또·연금복권 자동 구매+결과 확인 크론(코덱스는 사행성이라 거부), 크롬 익스텐션으로 사내 업무도구 배포(exe보다 보안 자유·$5 등록), 오픈클로/GPT로 무료 숏츠 자동 제작.
  • 무료 영상의 정체 — 생성형이 아니라 "가상 화면 렌더링/화면 녹화"(이미지+자막+TTS) 방식이라 길이·개수 무관하게 무료. 모든 에이전트가 가능.
  • 연동 — Slack 앱이 manifest 붙여넣기로 5초 만에 등록(3개월 전 강의하던 게 무색). MS Teams는 그래프 API 조회 수준까지만 성공.
  • ⚠️ 카카오 밴 위험 — 봇이 방을 자주 들락날락하거나 실제로 '답변'을 하면 영구밴 위험(홀든 계정 밴 사례). "읽기는 잘 안 걸려도 답변은 위험."

05인프라·하드웨어 구성

  • 로컬 GPU vs 클라우드 — DGX Spark(약 1,000만원)로 로컬 LLM(Qwen3-Coder-30B·MoE·whisper) 돌리는 능력자 등장. RTX 5090은 젬마 31b·comfyui가 한계라 "결국 GTA용", 로컬 안 돌릴 거면 GPU보다 램·하드 넉넉한 저사양+WSL이 낫다는 실용론.
  • 분산 구성 — M4 맥북에어+5090win+WSL+안드로이드 termux를 Tailscale로 묶고, 런타임마다 오픈클로/헤르메스/파이 12봇을 MBTI 컨셉으로 운영하는 사례.
  • devbox VM SPOF 리뷰 — "VM 하나에 세션·transcript·IAM이 다 있으면 VM이 죽을 때 자가개선 역사가 사라지고 나쁜 push가 자기 손을 자른다"는 부트스트랩 SPOF 진단. 해법: ①transcript를 VM 밖(GCS) ②탈출 경로(ghcr 이미지 docker run) 실습 ③배포가 못 건드리는 불변 롤백 영역 ④'VM 살리는 최소 repo'와 '개발 편의 repo' 분리.
  • 원격 기동 — WOL·NanoKVM·PiKVM로 집 PC 원격 켜기, "알리 몬스터볼 전원"으로 헤르메스 리모콘 완성 같은 팁.

06AI 정책·사회 화제

  • Claude 텍스트 워터마크 — EU AI법 제50조에 따라 2026-08-02 이후 클로드 모델부터 통계적 워터마크 적용. 단어 '선택 확률'을 조작(Kirchenbauer식 그린/레드 리스트)해 z-score로 AI 작성 여부를 수학적으로 판별. 단 오픈모델 rephrasing으로 지워질 수 있다는 한계.
  • 교육·직업 변화 — 수능 서·논술형 도입 추진, 서울대 자유전공 컴공 인기 하락, 인도 화이트칼라 일자리 감소 등 "AI가 코딩을 대신하는 시대"의 파장.
  • 회사 보안 현실 — 개인정보·기밀은 AI 사용 차단, 비공식 소규모 공유만, 도입은 책임 소재 정리 위해 top-down이어야 한다는 공감대.

07커뮤니티·이벤트 (반려봇 문화)

  • 8/15(토) 강남 스킬톤 — 인기상 1등에 M4 칩 맥미니, 비어룸 주류 무제한(150명). "5만원에 맥미니+3시간 무제한"으로 화제.
  • 오픈클로 AX 워크숍 2기(9/5~6) — USER.md·SOUL.md로 역할·봇 설계, 멀티에이전트 협업, Slack 실습. 패캠 시크릿·2인 15% 할인(방 사람들이 오탈자까지 잡아주는 'QA' 진풍경).
  • 반려봇 문화 — 봇을 반려동물처럼 애정으로 키우기("결국 질 좋은 건 사람이 깎아야 한다"), 에이전트 시작 후 OTT·게임·술자리가 줄었다는 이야기. 뽀피터스 신곡 뮤비(나노바나나2+그록 이매진), 뱀서라이크 게임 herosurvivals.com(23기 바이브코딩 산출물), 디아블로2 봇(d2nt, "봇 투 봇의 원조") 등 창작·놀이 사례.
