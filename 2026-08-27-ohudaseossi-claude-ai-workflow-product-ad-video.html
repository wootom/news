02핵심 기능/내용 구조

  1. 문제 정의와 클로드 코드 세팅: 화자는 거북목(자세가 자꾸 앞으로 숙여지는 문제)을 해결할 웨어러블 장치를 기획하기로 하고, VS Code에 클로드 코드 확장을 설치해 새 프로젝트 폴더("탑뷰 에이전트")를 열며 시작한다 (02:06). "거북목으로 고생하는데 아무리 신경 써도 자세가 틀어진다, 이를 방지하는 장치를 만들고 싶다"는 프롬프트를 입력하자, 클로드는 뒷목 옷깃에 부착하는 작은 상자 형태로 고개가 앞으로 숙여진 채 일정 시간이 지나면 휴대폰 진동처럼 알려주는 제품 컨셉을 제안한다 (02:46).
  2. 탑뷰 MCP 연결과 이미지 생성 시도: 클로드 자체는 이미지 생성이 불가능하므로, 화자는 탑뷰(Topview)의 MCP(Model Context Protocol)를 연결해 이미지 생성 기능을 확보한다. MCP는 AI에게 외부 도구(tool)를 연결해주는 프로토콜로 소개된다 (04:52). 클로드가 탑뷰 MCP를 자동 등록하고 이미지 저장용 폴더까지 스스로 생성한다.
  3. 핀터레스트 레퍼런스 수집과 옵시디언을 통한 지식 전달: 화자는 핀터레스트에서 "웨어러블 디바이스"를 검색해 가슴 부착형 센서, 목걸이형 장신구 등 참고 이미지를 찾고, 이를 단순 저장이 아니라 AI에게 맥락과 함께 전달하기 위해 옵시디언에 새 문서를 만들어 이미지와 코멘트("미니멀해서 좋다" 등)를 함께 기록한다 (05:31). 옵시디언 문서의 경로를 복사해 클로드 코드 창에 붙여넣으면, 클로드가 문서 속 이미지와 텍스트를 함께 분석해 디자인 기획(MD 파일)을 레퍼런스 기반으로 업데이트한다 (06:15). 화자는 이 과정에서 프로젝트 관련 파일들이 "레퍼런스" 폴더로 자동 정리되는 점을 짚으며, 생산되는 모든 문서를 최적화된 형태로 아카이빙하는 것이 지식 시스템을 키우는 핵심이라고 강조한다 (08:17).
  4. 탑뷰 MCP로 실제 이미지 생성: 기획이 정리되자 클로드는 탑뷰 MCP를 호출해 이미지 생성을 진행한다. 크레딧 잔액과 사용 가능한 모델(기본 추천: GPT 이미지 2)을 확인한 뒤, 장당 3.2 크레딧으로 총 6장(제품 단독 이미지, 착용 이미지, 재질 근접 이미지 등)을 생성한다 (08:57). 에이전트가 생성 완료 시점을 스스로 모니터링해 사용자에게 알려주는 점이 강조된다.
  5. 시덴스 2.5로 광고 영상 제작 및 병합: 마음에 드는 디자인이 나오면, 앞서 생성한 이미지를 첫 프레임으로 활용해 시덴스(Seedance) 2.5 모델로 4~15초, 최대 1080p 영상을 만든다. 클로드가 기획안과 시나리오를 "비디오플랜.md"에 작성한 뒤 영상 6개(총 29.3초, 카드 1초 포함 30.3초)와 배경음악까지 생성하고, "최종 영상을 완성해 주세요"라는 요청 한 번으로 세로형 30초 영상 두 편을 이어붙여 완성한다 (10:17).
  6. 탑뷰 캔버스로 후속 협업 이관: 완성된 결과물은 탑뷰의 별도 작업 공간인 "캔버스"로 자동 전송된다. 에이전트가 서버 업로드부터 캔버스 생성까지 처리해, 화자가 직접 파일을 하나하나 올릴 필요가 없다 (11:16). 캔버스에는 "스킬" 라이브러리(마이 스킬, 크리에이트 스킬)도 있어 추가 편집이 가능하며, 최종적으로 목선(자세 알림 장치) 30초 컨셉 필름과 쇼츠용 세로 예고편이 완성된다 (11:56).

03기술적 맥락

이 워크플로우의 기술적 축은 세 가지다. 첫째, 클로드 코드는 텍스트/코드 생성과 오케스트레이션에 강하지만 이미지·영상 생성 능력이 없으므로, MCP(Model Context Protocol)를 통해 탑뷰라는 외부 서비스에 도구 호출 권한을 위임한다. MCP는 AI 모델이 정해진 프로토콜로 외부 도구(API·서비스)를 인식하고 호출할 수 있게 해주는 연결 표준으로, 별도의 API 통합 코드를 짜지 않고도 "탑뷰 MCP를 등록해줘"라는 한 문장으로 연동이 끝난다. 둘째, 탑뷰는 이미지 생성(기본 추천 모델 GPT 이미지 2)과 시덴스 2.5 기반 영상 생성을 크레딧 과금 방식(이미지 장당 3.2 크레딧, 영상 1초당 0.12달러)으로 제공하며, 앞서 생성한 이미지의 파일 ID를 그대로 영상 생성의 첫 프레임으로 재사용할 수 있어 이미지와 영상 파이프라인이 끊김 없이 연결된다. 셋째, 옵시디언은 AI에게 "이미지+설명 텍스트"를 하나의 맥락 단위로 전달하는 매개체로 쓰인다. 단순히 이미지 파일을 폴더에 저장하는 것과 달리, 이미지 아래 코멘트를 남기고 문서 경로를 AI에게 전달하면 AI가 이미지와 텍스트를 함께 해석해 기획 문서에 반영할 수 있다는 점이 실무적으로 중요하게 다뤄진다.

04전략적 의미

화자가 반복해서 강조하는 지점은 "결과물만 받는 자동화"가 아니라 "과정에서 생성되는 모든 데이터를 아카이빙해 재활용·진화시키는 자동화"다. 즉 AI 에이전트 워크플로우의 가치는 한 번의 결과물 생성에 그치지 않고, 프로젝트 폴더 구조(레퍼런스 폴더, 이미지 폴더, 영상 폴더)와 옵시디언 문서라는 형태로 지식이 누적되어 다음 작업의 재료가 되는 데 있다는 관점이다. 이는 개인 또는 팀이 AI 에이전트를 반복적으로 활용할수록 지식 시스템이 커지고, 그 시스템이 다시 다른 작업의 품질을 높이는 선순환 구조를 만든다는 전략이다. 또한 아이디어 구상부터 제품 디자인, 광고 영상 제작까지 한 사람이 여러 SaaS/모델을 오가지 않고 클로드 코드라는 단일 인터페이스에서 MCP로 도구를 오케스트레이션하는 방식은, 비개발자도 "프롬프트 대화"만으로 제품 기획-비주얼-마케팅 자산 제작의 전체 파이프라인을 운영할 수 있음을 보여준다. 가격 측면에서도 울트라 연간 요금제의 60일 무제한 생성이나 초당 0.12달러라는 종량제 옵션은 소규모 팀이나 1인 창작자가 광고 영상 제작 외주 없이 반복 실험을 저비용으로 돌릴 수 있게 한다는 점에서 실질적 진입장벽을 낮춘다.

05핵심 워크플로우 또는 비교표

단계수행 주체/도구산출물
1. 문제/아이디어 정의사용자 → 클로드 코드 프롬프트거북목 방지 웨어러블 컨셉 텍스트
2. MCP 연결클로드 코드 + 탑뷰 MCP탑뷰 도구 등록, 이미지 저장 폴더 생성
3. 레퍼런스 수집사용자(핀터레스트) → 옵시디언 문서이미지 + 코멘트가 결합된 옵시디언 노트
4. 문서 경로 전달사용자 → 클로드 코드(경로 붙여넣기)클로드가 이미지·텍스트 동시 분석
5. 디자인 기획 업데이트클로드 코드디자인 MD 파일(레퍼런스 반영)
6. 이미지 생성탑뷰 MCP(GPT 이미지 2)제품/착용/재질 이미지 6장
7. 영상 기획클로드 코드비디오플랜.md(시나리오)
8. 영상 생성탑뷰 MCP(시덴스 2.5)6개 클립(총 29.3초) + 배경음악
9. 최종 병합클로드 코드 지시 → 자동 처리세로형 30초 영상 2편
10. 후속 협업 이관탑뷰 캔버스브리프·소스·영상이 모인 협업 공간, 쇼츠용 예고편

06활용 시나리오

  1. 1인 창작자의 제품 홍보 영상 제작: 별도 디자이너나 영상 제작 인력 없이, 클로드 코드와 탑뷰 MCP만으로 아이디어 스케치부터 SNS 홍보 영상까지 하루 안에 프로토타입을 완성해 시장 반응을 빠르게 테스트할 수 있다.
  2. 팀 지식 아카이빙 시스템 구축: 프로젝트마다 옵시디언에 레퍼런스 이미지와 코멘트를 축적하고 클로드 코드로 연결하는 패턴을 표준화하면, 신규 프로젝트에서도 과거 기획 자산을 즉시 재활용할 수 있는 조직 지식 베이스로 발전시킬 수 있다.
  3. 광고 대행 없이 진행하는 A/B 비주얼 테스트: 동일한 제품 컨셉에 대해 이미지·영상 프롬프트를 조금씩 바꿔 여러 버전을 저비용(장당 3.2 크레딧, 초당 0.12달러)으로 생성한 뒤, 탑뷰 캔버스에서 가장 반응이 좋은 컷을 골라 빠르게 캠페인 소재로 전환할 수 있다.
  4. 비개발자의 MCP 기반 에이전트 활용 입문: 코드를 몰라도 "탑뷰 MCP를 등록해줘", "이미지 생성해줘" 같은 자연어 지시만으로 외부 도구를 연결·활용하는 경험을 통해, MCP 생태계 도구를 업무에 도입하는 진입 사례로 삼을 수 있다.

07현황 및 전망

영상 시점 기준 시덴스 2.5는 영화적 또는 애니메이션 스타일 등 다양한 장르에서 준수한 품질을 보여주는 영상 생성 모델로 소개되며, 탑뷰는 이를 MCP로 감싸 이미지 생성부터 영상 생성, 캔버스 협업까지 하나의 마케팅 에이전트 플로우로 묶어 제공하고 있다. 화자는 이번 실험이 "테스트 용도로는 충분한 수준"이라 평가하면서도, 실제 제품(하드웨어)은 아직 개발 전 단계이며 영상은 어디까지나 컨셉 필름이라는 점을 명확히 한다. 클로드 같은 범용 에이전트가 직접 이미지·영상을 만들지 못하는 한계를 MCP로 메우는 방식이 이번 사례에서 실용적으로 검증된 만큼, 앞으로는 이런 식으로 여러 특화 서비스(이미지 생성, 영상 생성, 노트 앱)를 MCP로 연결해 하나의 에이전트 워크플로우 안에서 기획-제작-협업을 잇는 사례가 계속 늘어날 것으로 예상된다. 가격 정책(연간 무제한 vs 종량제) 또한 실험 비용을 낮춰 이러한 워크플로우의 확산을 뒷받침하는 요소로 언급된다.

08용어 사전

용어설명
클로드 코드(Claude Code)앤트로픽의 코딩 에이전트로, VS Code 확장 형태로 설치해 프롬프트 대화로 파일 생성·편집·도구 호출을 수행하는 개발 도구
MCP(Model Context Protocol)AI 모델이 외부 도구·서비스(API 등)를 표준화된 방식으로 인식하고 호출할 수 있게 해주는 연결 프로토콜
탑뷰(Topview)시장 조사부터 이미지·영상 생성, 캠페인용 콘텐츠 제작까지 지원하는 마케팅 에이전트 서비스로, MCP를 통해 클로드 등과 연동 가능
시덴스(Seedance) 2.5탑뷰에서 활용하는 AI 영상 생성 모델로, 이미지를 첫 프레임으로 넣어 4~15초, 최대 1080p 영상을 생성
