01핵심 개요

항목내용
형식메이커 에반의 실사용 리뷰 영상. AI 브라우저 'Aside'에 세 가지 실제 작업을 시키고 화면을 그대로 보여준다.
화자메이커 에반(유튜버)
핵심 문제의식웹에서 반복되는 단순 작업(뉴스 수집, 글쓰기, 가격 비교)을 AI 브라우저에 맡겼을 때 실제로 얼마나 믿고 쓸 수 있는가를 하루 동안 직접 검증.
만든 회사유어사이드(Your Side), Y콤비네이터 출신 3인 스타트업. 브라우저는 2026년 6월 출시로 아직 2개월이 채 안 된 초기 제품. 현재 맥(Mac) 전용.
핵심 특징자체 AI 모델을 팔지 않고 사용자가 이미 구독 중인 클로드(하이쿠·소네트·오퍼스 역할 분담) 계정을 그대로 연결해 쓰는 구조. 크롬 기반이라 즐겨찾기·로그인 상태가 그대로 이전됨.
실증 결과네이버 뉴스 헤드라인 10개 표로 정리(24초), 네이버 카페 글쓰기 성공(54초, 중간 오류 스스로 수정), 4개 쇼핑몰 최저가 검색(깊이 설정에 따라 1분35초~6분, 결과값이 서로 다르게 나옴).

02핵심 기능/내용 구조

  1. 테스트 개요: 오늘 Aside에 세 가지 작업(네이버 뉴스 헤드라인 10개 수집, 자신이 운영하는 카페에 글 작성·등록, 여러 쇼핑몰에서 최저가 찾기)을 시켰고, 사람 손을 전혀 대지 않고 완료했다. 가장 빠른 작업은 24초 걸렸다.
  2. 제작사와 브라우저 개요: Aside는 Y콤비네이터 출신 3인 스타트업 '유어사이드'가 만들었으며 2026년 6월 출시로 아직 2개월이 안 된 신생 제품이다. 크롬과 같은 뿌리(엔진)를 쓰고 현재 맥에서만 작동한다. 일반 브라우저 화면에 채팅창이 붙어 있어, 여기에 지시하면 브라우저가 직접 클릭·타이핑을 수행한다. 비유하면 "컴퓨터 앞에 인턴을 앉혀둔 것"과 같다.
  3. 로그인·연동 방식: 별도의 아이디·비밀번호 입력 없이 사용자가 이미 로그인해 둔 세션을 그대로 활용한다. 설치 후 계정 생성(구글 계정 로그인)만 하면 되고, 이후 설정에서 AI 모델을 연결하는데, 자체 AI를 파는 대신 사용자의 클로드 구독을 그대로 붙이는 방식이 특징이다. 작업 난이도에 따라 빠른 일은 하이쿠, 평소 일은 소네트, 어려운 판단은 오퍼스로 역할이 자동 분담된다. 화면을 읽는 별도 모델도 있다. 이 방식 덕분에 하루 종일 사용해도 Aside 자체 크레딧은 거의 소모되지 않았다.
  4. 기존 브라우저 환경 이전: 설치 즉시 크롬에서 쓰던 즐겨찾기가 통째로 이전되고, 네이버 등 기존 로그인 상태도 그대로 유지됐다. 이는 아이디·비밀번호를 별도로 입력받는 기존 자동화 도구와 달리, 브라우저 자체이기 때문에 평소 쓰던 상태를 그대로 활용한다는 점에서 보안 우려가 적다.
  5. 작업 깊이 설정: 대화창 하단에서 모델과 함께 '생각하는 깊이'를 6단계(낮음·보통·높음·아주 높음·최대·울트라 브라우즈)로 선택할 수 있다. 마지막 단계(울트라 브라우즈)는 유료 요금제 전용이다. 빠르고 저렴하게 끝낼지, 느리지만 철저하게 파고들지를 매번 사용자가 직접 고르는 구조다.
  6. 첫 테스트(가벼운 작업): 요금제 페이지를 표로 정리해 달라고 요청하자 3초 만에 한글 표로 답이 나왔고, 묻지 않은 정보(연간 결제 20% 할인, 팀 요금제 별도 문의)까지 페이지에서 찾아 알려줬다. 다만 대화창 폭이 좁아 표가 잘려 보이는 UI 단점이 있었다.
  7. 뉴스 헤드라인 수집 테스트: 네이버 뉴스 IT 섹션에서 헤드라인 10개를 표로 요청하자, 브라우저는 사용자가 보던 탭을 건드리지 않고 별도 탭을 열어 작업했다. 24초 만에 완료됐으며, 헤드라인이 8개만 노출돼 나머지 2개는 '더보기'를 통해 최신 기사에서 채웠다고 출처를 명확히 밝혔다. 작업 과정(어느 페이지를 열었는지, 왜 그렇게 했는지)이 로그처럼 실시간으로 표시되어 오류 발생 시 원인 추적이 쉬웠다는 점이 가장 인상적이었다고 평가한다. 다만 작업이 늘어날수록 탭이 계속 생성돼(최대 9개) 정리 버튼을 활용해야 했다.
  8. 카페 글쓰기 테스트: 가입한 카페 12개 중 자신이 매니저인 카페 하나를 스스로 찾아 골라 글쓰기를 시도했다. 네이버 에디터가 포커스를 제대로 넘겨주지 않아 본문이 제목란에 통째로 들어가는 오류가 발생했으나, Aside가 스스로 이를 알아채고 제목을 지운 뒤 본문을 다시 넣어 54초 만에 등록을 완료했다. 이 자기 수정(self-correction) 능력이 특히 인상적이었다고 평가한다. 부가로 가입 카페 현황(가입 12개, 운영 1개, 탈퇴 150개)을 요청하자 근거(운영 카페만 탈퇴 버튼이 없다는 것)까지 함께 제시했고, "일반 회원인지 운영진인지는 화면만으로는 알 수 없다"며 모르는 부분을 명확히 인정하는 태도도 보였다.
  9. 최저가 검색 테스트(1차): 나이키 신발을 쿠팡·무신사·알리에서 검색해 최저가를 찾도록 요청하자 사이트별로 탭 3개를 동시에 열어 병렬로 작업, 1분 35초 만에 표를 완성했다. 쿠팡이 13만2,000원대로 최저가라고 안내했지만, 진행자는 이 가격이 '신규 쿠폰가'라 신뢰하기 어렵다고 판단했다.
  10. 최저가 검색 테스트(2차, 심화): 동일 작업을 다나와까지 포함한 4개 사이트로 확대하고 생각 깊이를 '최대'로 높이자 결과가 크게 달라졌다. 4개의 작업자(에이전트)가 각 사이트를 동시에 담당해 6분 만에 완료했으며(1차보다 약 4배 느림), 같은 쿠팡 상품에서도 사이즈별로 판매자가 다르다는 사실을 찾아내 7만3,000원짜리를 발견했다. 그러나 이 가격에 대해 정품 보장 문구 부재, 후기 14건뿐, 여성 패션 카테고리 오분류, "짝퉁 같다"는 후기 존재 등 위험 신호를 스스로 짚어내며 최종적으로는 무신사 공식 브랜드관의 11만9,000원을 추천했다. 즉 최저가를 찾아내되 무조건 추천하지 않고 신뢰도까지 함께 평가한 점이 핵심이다.
  11. 작업 중단 시 재개 기능: 작업이 도중에 멈추면 "어떻게 할까요?"라고 사용자에게 되묻고, "이어서 하라"는 지시를 받으면 처음부터 다시 하지 않고 멈춘 지점(에디터 상태 등)부터 이어서 진행했다.
  12. 메모리(기억) 기능: 하루 작업이 끝난 뒤 설정을 확인하니, Aside가 그날 배운 내용(네이버 뉴스는 더보기를 눌러도 8개가 한계라는 것, 카페 매니저 여부 확인 방법, 에디터 오류 원인 등)을 사람이 읽을 수 있는 평문으로 저장해 두었다. 기억은 날짜별 기록, 사용자 정보, 전체 정리본 세 파일로 나뉘며, 하루 일과가 끝나면 자동으로 정리하는 과정을 '드리밍(dreaming)'이라 부른다. 잘못 기억된 내용은 사용자가 직접 파일을 열어 수정·삭제할 수 있다는 점이 투명성 측면에서 긍정적으로 평가됐다.
  13. 루틴·채널·비밀번호 금고 기능: 반복 작업을 저장해두는 '루틴' 기능(무료 3개, 유료 시 무제한), 외출 중 휴대폰으로 작업을 지시하는 '채널' 기능(유료 전용), 로그인 정보를 저장해두면 자동 입력해주는 비밀번호 금고 기능이 있다. 금고는 값 자체를 AI에 넘기지 않고 페이지에만 직접 입력하는 구조이며 접근 기록도 남지만, 기본 자동 잠금 해제 시간이 일주일로 길어 짧게 줄이는 것을 권장한다. 자동 로그인 제출 기능도 기본 활성화돼 있어 편리하지만 위험할 수 있다고 지적한다.

03기술적 맥락

Aside는 별도의 자체 LLM을 개발하지 않고 사용자의 기존 클로드 구독(하이쿠·소네트·오퍼스)을 그대로 연결해 작업 난이도별로 자동 라우팅하는 구조를 취한다. 이는 최근 AI 에이전트 업계에서 논의되는 '스마트 라우팅'(쉬운 작업은 경량 모델, 어려운 작업은 고급 모델로 자동 분배)과 유사한 접근으로, 사용자 입장에서는 별도 API 비용 없이 기존 구독만으로 브라우저 자동화를 이용할 수 있다는 장점이 있다. 브라우저 자체가 에이전트의 실행 환경이 되는 방식(브라우저 네이티브 에이전트)은, 별도 인증 정보를 주고받아야 하는 API 기반 자동화 도구보다 보안 측면에서 유리하다 — 이미 로그인된 세션을 그대로 활용하기 때문에 아이디·비밀번호를 노출할 필요가 없다. 다만 이런 구조는 반대로 에이전트가 사용자의 모든 개인 계정에 접근 가능하다는 뜻이기도 해, 승인 없이 실행되는 작업(글 등록 등)에 대한 통제 장치 부재가 지적된다. '생각 깊이' 설정에 따라 결과가 달라지는 현상(1차 검색과 2차 심화 검색에서 가격이 다르게 나온 사례)은, 에이전트가 병렬로 띄우는 작업자(하위 에이전트) 수와 탐색 범위가 늘어날수록 더 정확하지만 느린 결과를 낸다는 트레이드오프를 보여준다.

04전략적 의미

첫째, AI 브라우저는 API 연동이나 별도 인증 없이 "이미 로그인된 상태"를 그대로 활용한다는 점에서, 일반 사용자가 가장 낮은 진입장벽으로 웹 자동화를 시작할 수 있는 형태로 주목된다. 둘째, 자체 모델 대신 사용자의 기존 AI 구독을 재사용하는 비즈니스 모델은, AI 브라우저 스타트업이 모델 개발비 없이 오케스트레이션(작업 조율)에만 집중할 수 있게 하는 전략으로, 향후 유사 서비스들의 표준 패턴이 될 가능성이 있다. 셋째, 동일 질문에 설정(생각 깊이)에 따라 서로 다른 답이 나온 사례는, AI 에이전트의 결과물을 무비판적으로 신뢰해서는 안 되며 특히 금전이 걸린 판단에는 근거 화면을 직접 확인하는 습관이 필요함을 보여준다. 넷째, 승인 절차 없이 글 등록·결제 등 되돌리기 어려운 작업까지 자동 실행된다는 한계는, 아직 이 카테고리 제품군 전반이 '읽기·정리' 작업에는 적합하지만 '쓰기·거래' 작업에는 신중한 접근이 필요한 초기 단계임을 시사한다.

  2. 다중 사이트 가격 비교가 필요한 쇼핑: 여러 쇼핑몰에서 동일 상품의 최저가를 찾을 때, 낮은 깊이로 빠르게 훑어본 뒤 중요한 구매 결정 시에는 깊이를 최대로 높여 신뢰도까지 검증하는 이원화 전략을 쓸 수 있다.
  3. 커뮤니티·카페 운영자의 콘텐츠 등록: 반복적으로 게시글을 작성·등록해야 하는 카페·블로그 운영자가 초안 작성부터 등록까지 위임하되, 결과를 반드시 확인하는 검증 단계를 두고 활용할 수 있다.
  4. AI 자동화 초심자의 안전한 도입: 처음 AI 브라우저를 써보는 사용자가 "되돌릴 수 있는 읽기·정리 작업부터 시작하고, 쓰기·결제 작업은 나중에" 라는 원칙을 따라 리스크를 최소화하며 익숙해질 수 있다.

07현황 및 전망

Aside는 출시 2개월이 채 안 된 초기 제품으로, 진행자는 좋은 점과 함께 버그, 결과 불일치, 승인 절차 부재, 맥 전용 한계, 보안 설정 미흡 등 다섯 가지 문제를 명확히 지적했다. 회사가 자체 발표한 웹 작업 벤치마크 점수(99점)는 외부 검증이 아닌 자체 평가이므로 참고만 하고 직접 사용해 판단해야 한다고 조언한다. 향후 프로젝트, 플러그인, 외부 도구 연동, 개발자 메뉴 등 아직 다루지 않은 기능이 남아 있어 추가 리뷰가 예상된다. 진행자는 앞으로 조사성 작업에는 이 브라우저를 계속 켜둘 것이라 밝히며, 시청자에게 어떤 작업을 맡기고 싶은지 의견을 구하는 것으로 마무리한다. 이 제품군(AI 네이티브 브라우저)은 초기 단계이지만, 클로드 등 기존 LLM 구독을 재사용하는 구조 덕분에 추가 비용 부담 없이 빠르게 확산될 잠재력이 있다.
