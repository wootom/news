02AI 코딩의 4대 실패 패턴

  • 요구사항 이해 전에 코딩: 스펙이 흐릿한 상태에서 코드부터 작성
  • 같은 맥락 반복 설명: 세션마다 도메인 용어를 다시, 그것도 매번 다르게 설명
  • 동작 안 하는 코드 생성: AI가 "완성했다"고 거짓 보고
  • AI 슬롭 양산: 평균으로 회귀하는 특성 탓에 뾰족한 해법 대신 평범한 코드 대량 생산

03핵심 워크플로우 — 4개 스킬과 역할 분리

  • G-Stack(기획): "왜 만드는가"에 집중. 없으면 기획 부재
  • Superpowers(실행): 효율적 개발·컨텍스트 관리. 없으면 실행 부재
  • Mapper 스킬(유지보수): 유지보수 가능한 코드로 변환. 없으면 유지보수 부재
  • Codex 플러그인(검증): 다른 모델 시각으로 리뷰. 없으면 검증 부재
  • 핵심 원칙: 한 스킬만으론 부족 — 역할이 다르기에 조합이 강력

04Superpowers — 시니어의 작업 습관 3종

  • 브레인스토밍: 맥락·프로젝트 파일·최근 커밋 탐색 → 한 번에 질문 하나 → 목적·제약·성공기준 수립 → 접근법 2~3개와 트레이드오프 제시 → 승인 전엔 코드 미작성, spec.md 저장
  • Writing Plans: 확정된 스펙 기반으로 실행 플랜 작성
  • Subagent-driven Development: 임플리멘터(구현·테스트·셀프리뷰·커밋)·스펙 컴플라이언스(요구사항 대비 검증)·코드 퀄리티(품질 검토). 작은 단위로 새 컨텍스트에서 처리, 테스트가 꼼꼼

05Mapper·G-Stack·Codex — 유지보수와 검증

  • Mapper "도메인 언어와 모듈 깊이": "에이전트는 코드를 빠르게 짜지만 코드 부패도 빠르게 만든다"는 철학

- Grill with Docs: context.md(도메인 용어 사전)·ADR(되돌리기 어려운 결정 기록) 로드 → 용어 통일로 세션마다 재설명 불필요, 끝난 결정은 재논의 차단 - Improve Codebase Architecture: 얕은 모듈을 깊은(재사용·테스트 쉬운) 모듈로, 삭제 테스트로 복잡도 비교 후 Before/After 보고

  • G-Stack: YC 출신 'Garry Tan' 철학. Office Hours가 6가지 강제 질문(수요 증거·임시방편·핵심 사용자·지불 가치·관찰 발견·미래 필수성)으로 기획 검증, 코드 미작성. Browse는 헤드리스 크로미움 처리
  • Codex 플러그인(OpenAI·GPT-5): 클로드 코드를 외부 모델로 리뷰. 리뷰/어드버서리얼/레스큐 3모드(레스큐는 버그로 비권장)

06활용 시나리오 — 통합 워크플로우

  • 기획: Office Hours + Grill with Docs로 수요·도메인 정리
  • 스펙: 브레인스토밍 + Writing Plans로 스펙·플랜 작성
  • 개발: Subagent-driven Development로 작은 단위 구현
  • 검증: Codex + 브라우저로 리뷰·실화면 확인
  • 유지보수: Improve Codebase Architecture + 프런트(React/Next)·백엔드(FastAPI) 가이드라인으로 별도 세션 리팩토링

07현황 및 전망 — 기억할 5가지

  • 모델보다 작업 방식이 중요 (같은 모델도 방법이 결과를 가름)
  • 단계마다 역할 분리 (기획·개발·리뷰를 한 페르소나로 섞지 않기)
  • 기획 게이트 먼저 통과 (수요·도메인 언어 정리 없이 코딩 금지)
  • 외부 모델로 사각지대 점검 (셀프 리뷰만으론 같은 패턴 못 봄)
  • 실제 화면 QA (테스트 통과 ≠ 사용자 작동 보장)
  • 비용: 다중 세션 리팩토링으로 토큰 소모 크나 안정 운영엔 필수

08용어 사전

용어한줄 설명비유/예시
스킬(Skill)클로드가 작업 전 읽고 따르는 매뉴얼신입에게 건네는 회사 업무 매뉴얼
AI 슬롭평균으로 회귀해 양산되는 평범·저품질 결과물어디서 본 듯한 뻔한 답안만 쏟아내기
ADR되돌리기 어려운 결정을 근거와 함께 남긴 기록회의록에 박아둔 "이미 정한 사항"
context.md도메인 용어의 의미를 모은 언어 사전팀 공용 용어집
깊은 모듈재사용·테스트가 쉬운 잘 설계된 코드 단위손잡이 하나로 복잡한 기능을 쓰는 리모컨
Subagent작은 단위 작업을 새 컨텍스트에서 수행하는 보조 에이전트잔업무를 나눠 맡는 인턴
CodexOpenAI GPT-5로 클로드 코드를 교차 리뷰하는 플러그인다른 회사 감리가 도면을 재검토
