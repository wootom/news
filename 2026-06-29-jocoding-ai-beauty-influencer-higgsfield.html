클로드 + Higgsfield MCP로 AI 뷰티 인플루언서 만들기

여러 이미지·영상·오디오 모델을 한 구독으로 묶은 Higgsfield를 MCP로 클로드에 연결, 자연어 프롬프트만으로 일관성 있는 AI 인플루언서 "유나"를 만들고 화장품 광고 콘텐츠까지 자동 생성하는 실습.

목차핵심 개요Higgsfield란MCP 연결 절차캐릭터 일관성 — Element 등록비포·애프터 영상 제작화장품 광고 — Marketing Studio전략적 의미용어 사전

01핵심 개요

항목내용
채널조코딩 JoCoding (Higgsfield 광고·협찬)
목표AI 뷰티 인플루언서 캐릭터 생성·운영 + 화장품 광고 제작
도구Higgsfield(이미지·영상·오디오 통합 플랫폼) + 클로드 MCP
결과물인스타그램·틱톡 계정 개설, 비포·애프터 바이럴 영상, 제품 광고 영상

02Higgsfield란

Nano Banana(이미지), Seedance(영상) 등 다양한 생성 모델을 개별 구독 없이 하나로 모아 쓰는 플랫폼. 기능·모델이 너무 많아 직접 고르기 어려운 문제를 MCP·CLI·스킬 공개로 해결 — AI 에이전트에게 목적만 말하면 알아서 최적 모델·기능을 조합한다.

03MCP 연결 절차

1
주소 접속Higgsfield.ai/MCP에서 연결 화면 진입, 연결 방식 MCP 선택.
2
URL 복사표시된 Higgsfield 원격 서버 URL 복사.
3
커넥터 추가클로드 설정 → 커넥터 → 커스텀 커넥터 추가에 URL 붙여넣고 이름 지정.
4
계정 연결연결 버튼 → 브라우저에서 구독 계정 인증(Allow) → 연결 완료.
5
채팅에서 활성화새 채팅의 플러스 → 커넥터에서 Higgsfield 켜고 프롬프트 작성.

04캐릭터 일관성 — Element 등록

클로드는 기본적으로 이미지·영상 생성이 없지만 MCP 연결 후 가능해진다. 여성 뷰티 인플루언서를 생성한 뒤 일관성 유지를 위해 캐릭터로 등록한다. (딥링크 5:14)

1
이미지 생성모델·비율 지정 프롬프트로 인플루언서 후보 4종 생성.
2
Element 등록이름(유나) 지정 후 Element로 즉시 등록(Soul 캐릭터는 별도).
3
다각도 보강정면·좌·우 컷을 추가 생성해 Element 강화(닮음도 향상).
4
Use 적용Element 탭의 Use로 프롬프트에 ID 자동 삽입 → 정확한 캐릭터 재현.

05비포·애프터 영상 제작

단계방식
비포 이미지유나 Element + 캐주얼 셀피 프롬프트, count 4로 다중 생성
애프터 이미지Image-to-Image로 화장 완료 컷 생성(유나 명시 + 레퍼런스 미디어)
영상 변환시작·엔드 프레임 지정 → Seedance 2.0으로 비포→애프터 전환 영상

추가로 Predict Virality 기능은 메타 연구 기반으로 숏폼의 뇌 반응을 점수화해 바이럴 가능성을 예측.

06화장품 광고 — Marketing Studio

뷰티 인플루언서 수익화를 위한 제품 소개(UGC) 콘텐츠 제작. 클로드 코드 + MCP로 자동화:

1
제품 등록화장품 사진(예: 메디테라피 콜라겐 펩타이드)을 Product로 등록, Product ID 획득.
2
광고 이미지유나 Element + Product ID로 제품을 자연스럽게 든 다양한 구도 생성(글씨 디테일 유지).
3
Animate생성 이미지를 Animate로 대사 포함 영상화("안녕하세요, 유나예요…").
4
자동 운영CLI(클로드 코드·Codex)를 맥미니 등에 띄워 주기적으로 사진·영상 생성 후 인스타·틱톡 자동 포스팅 → 계정 성장 실험.

07전략적 의미

사람이 메뉴를 직접 누르는 대신 에이전트에게 목적만 말하는 워크플로우로의 전환. Element·Product 등록을 통한 일관성 유지가 AI 인플루언서 운영의 핵심이며, MCP+CLI 조합으로 콘텐츠 생산을 무인 자동화할 수 있다. 실제 인스타·틱톡 계정을 개설해 광고 수주 가능성까지 실험. (딥링크 12:29)
