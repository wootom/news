구글 Antigravity 2.0 & Gemini 3.5 Flash — 부사장 Josh 인터뷰

조코딩 채널 요약. 구글 I/O에서 구글 부사장 Josh 인터뷰. Gemini 3.5 Flash·Antigravity 2.0·Code Men으로 Claude Code/Codex 대안 제시. 핵심 강점은 코드 품질뿐 아니라 비용 절감 및 Plan-Execute 모델 조합.

02Antigravity 2.0의 핵심 메시지

관련 구간

  • 3.5 Flash의 강점 — 원시(raw) 코딩 품질 + 압도적 비용 효율
  • Plan-Execute 조합 — 한 모델로 계획, 다른 모델로 실행 (Pro ↔ Flash 스위칭)
  • 사내 사용 사례 — 구글 내부 Gemini·AI Studio·Google Labs 팀이 Pro/Flash 번갈아 사용
  • 벤치마크 + 실사용 — 개발자가 진짜 신경 쓰는 건 코드 품질 + 비용

05한국 개발자 / 사용자에게 던지는 메시지

관련 구간

  • "프론티어로 가라" — 신모델·신기능을 가능한 한 많이 시도
  • 워크플로우에 어떻게 맞는지 직접 발견하는 것이 가장 중요
  • 작동·미작동 피드백은 구글팀이 즉시 반영
  • Gemini 3.5 Flash · Gemini Omni는 이전엔 불가능했던 것들을 가능하게 함

06핵심 워크플로우 — Plan→Execute 모델 스위칭

1
Pro 모델로 계획복잡한 멀티스텝 작업의 큰 그림 설계
2
Flash 모델로 실행빠르고 저렴한 실행 단위 처리
3
반복결과 검토 후 다시 Pro로 재계획, Flash로 재실행
4
CLI·SDK 활용Antigravity 2.0 CLI로 에이전트 워크플로우 자동화
5
Code Men 통합멀티 에이전트 코딩 협업

07활용 시나리오

  • 개발자 — Claude Code 사용 중 비용 압박 시 Flash로 부분 이관 실험
  • 기획자 — NotebookLM으로 자료 → Stitch로 UI → Antigravity로 코드 한 흐름
  • 콘텐츠 크리에이터 — Flow + Flow Music으로 영상·음악 동시 생성
  • 학습자 — Deep Research로 새 분야 빠르게 입문

08현황 및 전망

Gemini는 한국 시장에서 챗봇 앱 점유율 1위로 부상 — 한국어 품질과 빠른 채택 문화가 결합. Antigravity 2.0은 Claude Code·Codex가 장악한 코딩 에이전트 시장에 '비용 + 모델 조합'으로 도전. 한국팀이 로드맵 의사결정에 직접 참여하는 협력 모델 — 신기능 출시 시 한국이 우선 테스트 시장이 될 가능성.
