GrokBot이 외부 서비스 연결·음성 제어·작업 학습으로 업무 자동화를 확장했다고 소개한다.

GrokBot의 YouTube 분석, 음성 이메일 확인, Claude 제어, 작업 학습 사례를 시연한다.

01핵심 개요

  • 영상은 GrokBot 에이전트가 별도 API 설정 없이 설치되고, 에이전트끼리 상호작용할 수 있다고 설명한다.
  • YouTube Studio 로그인 후 GrokBot 관련 영상이 211명의 신규 구독자를 만들었다는 화면 결과를 제시한다.
  • 추천 동영상의 6만 조회수 기준 평균 CTR 4.8% 등 데이터를 바탕으로 다음 영상 방향을 제안받는 사례를 든다.
  • Helix·Atlas 등 음성을 선택해 대화하고, Atlas에게 이메일의 파트너십 관련 알림을 확인하도록 요청한다.
  • Claude Design 조작과 화면 녹화 기반 ‘teach task’를 통해 디자인 제작 및 반복 업무 학습을 시연한다.

02핵심 주장 / 논점 구조

  • 영상은 GrokBot을 개별 작업을 맡기고 서로 상호작용할 수 있는 ‘AI 직원’처럼 설명한다.
  • 발표자는 에이전트 비용이 70% 저렴해졌고 새 기능이 추가됐다고 말하며 5개 활용 사례를 시험한다.
  • 사례의 흐름은 외부 데이터 접속, 데이터 분석, 음성 대화, 타 앱 조작, 화면 녹화 기반 작업 학습으로 구성된다.
  • 발표자는 이 기능들이 시간을 절약하고 수익 창출 및 업무 성과에 도움이 되는지 검증하겠다고 밝힌다.

03YouTube Studio와 커뮤니티 데이터 연결

  • 발표자는 API가 준비되지 않은 YouTube 분석과 커뮤니티 데이터에도 GrokBot을 연결할 수 있는지 시험한다.
  • GrokBot은 YouTube Studio 접속에 Google 로그인과 비밀번호 확인이 필요하다고 안내한다.
  • 발표자는 채팅에서 자격 증명을 입력할 수 있으며, GrokBot도 이를 볼 수 없다고 설명한다.
  • 연결 후 GrokBot 영상이 211명의 신규 팔로워를 만들었다는 결과와 211명 구독자 수를 제시한다.

04성과 지표 분석과 다음 영상 제안

  • 발표자는 최신 GrokBot 영상 성과를 검토하고 다음 영상 시청자에게 도움이 될 아이디어를 요청하는 예시를 든다.
  • GrokBot이 여러 성과 지표를 정리하고, 이전에는 얻기 어려웠던 수준의 분석을 제공한다고 설명한다.
  • 제시된 데이터 포인트에서 추천 동영상은 6만 조회수 동안 평균 CTR 4.8%를 기록했다.
  • 발표자는 세 개 데이터 포인트와 결론을 요청하면 GrokBot이 다음 영상에서 할 일을 설명한다고 말한다.

05Atlas 음성 대화와 이메일 확인

  • 최신 업데이트는 상단의 Grokit 메뉴에서 ‘check for updates’를 눌러 확인할 수 있다고 안내한다.
  • 음성 기능에서 Helix와 Atlas를 포함한 목소리를 고르고, 재생 속도를 1.5X로 바꾸는 모습을 보인다.
  • Atlas는 자신을 파트너십 거래를 담당하는 역할로 소개하며 대화 내용을 듣고 있다고 답한다.
  • 발표자가 파트너십 알림을 확인해 달라고 요청하자 Atlas는 받은편지함에서 관련 내용을 찾겠다고 응답한다.

06Claude Design을 중앙 명령점으로 활용

  • 발표자는 Grok이 다른 프로그램과 시스템을 사용하게 해 중앙 명령점처럼 만들 수 있다고 설명한다.
  • Grok에게 Claude Design에 로그인해 스타트업 Glyder 발표용 그래픽을 만들라고 요청하는 사례를 제시한다.
  • 화면 제어를 허용하면 Grok이 앱을 독립적으로 사용할 수 있다고 말하며, 본인은 몇 번의 버튼만 눌렀다고 설명한다.
  • Claude에서 ‘Create a good presentation for investors’라는 질의가 실행되고 결과물이 열린 모습을 보여준다.
  • 발표자는 2027년 말까지 Grok이 세계 1위 모델이 될 것이라고 개인적 전망을 밝히며 Grok 5 로드맵을 언급한다.

07화면 녹화로 작업을 가르치는 Teach Task

  • 발표자는 화면 녹화로 작업을 보여주면 Grok이 이를 학습하고 이후 실행할 수 있는 기능을 ‘task-based learning’이라고 부른다.
  • Grok 패널의 컴퓨터 아이콘과 상단 ‘teach task’를 눌러 YouTube 댓글 답변 과정을 가르치는 예시를 시연한다.
  • 댓글 답변 외에도 정보·데이터 수집, YouTube 영상 탐색, 표에 추가하는 절차를 학습시킬 수 있다고 설명한다.
  • 녹화를 멈추면 작업을 학습하며, 이 녹화는 오디오가 아니라 사용자가 수행한 동작을 기록한다고 말한다.
  • 발표자는 학습 요소와 화면을 열어 특정 작업용 봇 훈련을 시작할 수 있다고 안내한다.
  • 에이전트 운영 방향과 영상의 고지: 발표자는 사용할수록 GrokBot이 더 좋아지고 팀들이 서로 소통하게 될 것이라고 말한다.
  • 에이전트 운영 방향과 영상의 고지: 핵심은 완료해야 할 작업을 생각한 뒤 이를 GrokBot에 할당하는 것이라고 조언한다.
  • 에이전트 운영 방향과 영상의 고지: 영상 말미에는 에이전트의 최적 구성 방식을 다음 영상에서 함께 살펴보겠다고 예고한다.
  • 에이전트 운영 방향과 영상의 고지: 영상 초반에는 xAI가 스폰서라고 밝히고, 말미에는 SpaceX에 스폰서 감사 인사를 전한다.
