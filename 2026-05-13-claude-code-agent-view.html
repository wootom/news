04
함께 출시된 /goal 명령
완료 조건 기반 자율 실행
Codex에서 먼저 검증된 패턴 — 완료 조건을 정의하면 그 조건이 충족될 때까지 제어권을 사용자에게 돌려주지 않고 에이전트가 스스로 반복·수정한다.

예시: /goal 현재 생성된 테스트가 모두 통과할 때까지 작업을 계속 진행해줘
05
활용 시나리오 4가지
시나리오 1 · 풀스택 동시 개발
세션 A: 백엔드 리팩토링
세션 B: 프론트엔드 컴포넌트
세션 C: 테스트 (/goal 모든 테스트 통과까지)
→ Space로 빠른 진행률 체크
시나리오 2 · 장시간 자율 + 모니터링
단순 반복(의존성 업데이트, 코드 마이그레이션)에 /goal 부여
사람은 다른 세션에서 신규 기능 설계
→ 두 흐름을 한 화면에 동시 추적
시나리오 3 · 멀티 레포 통합
A 레포 작업 중 @로 B 레포 선택 → 동일 화면에 B 세션 생성
기존: 터미널 여러 개 + cd 반복
→ 단일 화면으로 단순화
시나리오 4 · Agent View + /goal + deep-interview
deep-interview 스킬로 명확한 목표 정의
각 세션마다 /goal 완료 조건 자동화
Agent View로 에이전트 부대 한눈에 운영
