01핵심 개요

  • 영상은 Claude 작업 개선부터 웹사이트 제작·검색 노출·구직·학습까지 돕는 무료 오픈소스 저장소 9개를 다룬다.
  • Goldfish 하위 에이전트들은 Claude의 계획을 독립적으로 검토하고, 사례에서 서로 다른 문제점 네 가지를 찾아낸다.
  • Honcho는 여러 앱의 맥락을 공유하는 메모리 계층이며, OpenUI는 AI의 답변을 차트와 인터페이스로 바꾼다.
  • Bama로 만든 웹사이트는 SEO 점수가 48에서 78로 올랐고, 아홉 에이전트가 페이지를 확인해 개선점을 제시한다.
  • Mac 앱 제작, 실시간 웹 검색, 소셜 게시물 관리, 이력서 기반 채용 탐색, PDF 퀴즈 도구도 소개한다.

02핵심 주장 / 논점 구조

  • 영상은 지금 주목받는 무료 오픈소스 GitHub 저장소 9개를 직접 시험하고, 실제 활용 장면과 설치·사용 방식을 소개한다.
  • 소개 대상은 Claude 보완, 앱 제작, 검색과 SEO, 소셜 미디어 운영, 구직, 학습 등 여러 작업에 걸쳐 있다.
  • 일부 도구는 반복 작업을 자동화하고, 일부는 여러 앱이나 웹페이지의 정보를 더 잘 활용하도록 돕는 사례로 제시된다.

03Claude 계획 검토와 사전 질문

  • Goldfish는 기억이 없는 여러 하위 에이전트를 나눠 투입해, 계획의 특정 부분을 집중적으로 비판하게 한다.
  • 영상 속 예시에서는 Goldfish 검토가 계획의 서로 다른 장애물 네 가지를 찾아냈다.
  • 별도로 소개된 도구는 Google의 전문가 역할 7개를 활용해, 만들기 전에 질문을 제대로 설정하도록 돕는다.
  • 또 다른 도구는 사용자를 임의로 지어내기보다 일부 항목을 TBC로 남겨 나중에 채우도록 한다.

04Honcho의 맥락 공유와 OpenUI 시각화

  • Honcho는 Hermes Agent, Grokbot, Slack, Claude 등 여러 앱 위에서 작동하는 메모리 계층으로 소개된다.
  • 앱들을 하나의 메모리 시스템에 연결하면 작업 중 맥락을 잃는 일을 줄일 수 있다는 설명이다.
  • 영상의 예시에서는 서로 다른 앱에서 이어지는 Tidepool Mac 바 작업의 맥락을 Honcho가 유지한다.
  • OpenUI는 AI의 텍스트 답변을 실시간 차트와 인터페이스로 바꾸며, 집중 점수와 주간 방해 요인을 보여준다.

05Mac 앱 제작과 웹사이트 SEO 개선

  • Bama는 앱을 Mac 앱으로 복제하는 코드 스킬 묶음으로 소개되며, 프롬프트를 입력해 앱을 만들고 실행하는 흐름을 보여준다.
  • 영상에서는 만든 집중 앱이 인터넷 연결 없이 Mac에서 실행되는 사례를 제시한다.
  • 앱을 판매하려면 약 99달러의 Apple 라이선스가 필요하며, 그 외에는 압축해 다른 사람과 공유할 수 있다고 설명한다.
  • SEO 도구는 웹페이지를 아홉 에이전트가 점검하고 점수를 매긴 뒤 개선을 수행하며, 사례 점수는 48에서 78로 상승했다.

06실시간 웹 조사와 모션 중심 웹 제작

  • Oxylabs는 한 번의 호출로 실시간 웹을 검색하고 상위 페이지를 읽어 정리된 정보를 에이전트에 제공하는 방식으로 소개된다.
  • 영상은 일반 검색이 결과를 일부 스니펫으로 반환하거나 복잡한 페이지를 깔끔하게 처리하지 못할 수 있다고 비교한다.
  • Motion Sights는 한 번의 프롬프트로 시네마틱 웹사이트를 만드는 Claude 스킬로 설명된다.
  • Motion Sights는 실제 사례를 살펴 모션 클립을 고르고, 그 움직임을 중심으로 페이지를 만든 뒤 결과를 점검한다.

07소셜 운영·구직·PDF 학습 도구

  • Post-its는 Mac에서 로컬로 실행되는 무료 소셜 미디어 관리 도구로 소개되며, 설치에는 Docker가 필요하다고 설명한다.
  • 구직 도구는 이력서를 바탕으로 실시간 채용 공고를 찾고 지원서 내용을 해당 직무에 맞추도록 돕는다.
  • 시연에서는 이력서와 비교해 순위를 매긴 런던의 주니어 프로덕트 디자이너 공고 10개를 찾아 보여준다.
  • PDF 도구는 문서 내용을 바탕으로 질문을 만들고 사용자의 답을 채점해 학습을 돕는다.
