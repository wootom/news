02GPT-5.6 — Fable급 지능, 저비용

  • 3개 계열 Soul·Terra·Luna + Pro/Ultra/Light 티어
  • GDPval = Soul이 Claude Fable 제외 전부 앞섬(Fable과 격차도 근소)
  • 브라우저 컴퓨터 유즈 = 사실상 전부 제압, GPQA는 Mythos와 동률
  • BuyBench 상위 4위 독식(Soul Pro 1위), 최고 결과물 $0.77·4.5만 토큰·1분(GPT-5.5 Pro는 $4·6분)

03ChatGPT Work — 슈퍼앱 통합

  • Codex·ChatGPT·Atlas 브라우저를 단일 'ChatGPT 앱'으로 통합
  • Work 모드(비기술 비서) vs Codex 모드(개발) 전환
  • Sites 기능 = 프롬프트만으로 앱 생성·호스팅·공개(DB·CDN 신경 불필요)
  • Gmail·Drive·Slack·Granola 등 연결 → '데일리 컨트롤 타워' 개인 비서
  • Obsidian 세컨드 브레인(212 소스·426 위키 등) 시각화 데모

04그 밖의 발표

  • GPT Live = 상호 끼어들기 가능한 자연스러운 음성 모드 + 실시간 통역
  • Hyper Agent(Airtable 제작사) = AI 에이전트 팀 + 스킬 마켓플레이스(포크·공유)
  • Seeddream 5.0 Pro(바이트댄스) = 인포그래픽·레이어 분리·인터랙티브 편집·사실적 이미지

05Fable vs GPT-5.6 실사용 감

  • Fable = 아키텍처 결정·최적 경로 설계에 더 영리
  • GPT-5.6 = 대량 정보 투입 후 방치 → 완성도 높게 회수(원하는 결과에 더 근접)
  • 병용 효과 = Fable 산출물을 5.6이 검수해 API 키 노출 등 보안 취약점 발견
  • 저자 운용 = 5.6이 데일리 드라이버, Fable은 난제용 추가 사고력

06전략적 의미

  • 모델 격차 축소 = 최상위 근접 성능을 훨씬 낮은 비용으로 확보 가능
  • 앱 통합 = 코딩·업무·브라우징이 한 앱으로 수렴, 에이전트 비서화 가속
  • 병용 워크플로우 = 서로 다른 모델의 강점을 교차 검증에 활용

07활용 시나리오

  • 도구 스택 점검 → ChatGPT Work 통합앱으로 워크플로우 단순화 검토
  • 모델 조합 → 설계(Fable) + 실행·검수(GPT-5.6) 이중화
  • 콘텐츠 제작 → Hyper Agent·Seeddream 등 신규 생성 도구 실험
