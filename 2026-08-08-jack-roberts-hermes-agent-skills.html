100개 넘게 테스트한 에이전트 스킬 중 진짜 써야 할 13가지 (Jack Roberts)

01핵심 개요

항목내용
무엇을Jack Roberts가 "Hermes 에이전트"(AI 에이전트 플랫폼)용 스킬(skill) 100개 이상을 직접 테스트하고, 그중 반드시 써야 할 상위 13개를 선별해 소개하는 영상
누가AI 에이전트/자동화 유튜버 Jack Roberts. 촬영 당시 몬테네그로에서 AI 이벤트 진행 중이라고 언급
왜 중요한가발표자는 "테스트한 스킬 대부분이 쓰레기(garbage)"라며, 옳은 스킬을 골라 조합해야만 에이전트의 잠재력을 끌어낼 수 있고 시간·비용을 아낄 수 있다고 주장. 스킬이란 에이전트에게 특정 작업 절차를 규칙처럼 추가해 주는 확장 모듈이다
핵심 메시지에이전트를 "500 IQ 인턴"에 비유. 똑똑하지만 무엇을 어떻게 할지 정확히 알려줘야만 제 실력을 낸다. 스킬 설치는 "이 스킬 설치해줘"라고 말하고 저장소(repo) 링크만 붙여넣으면 끝
참고: 영상 자막상 제품명이 "Hermes agent"로 표기되나, 발표자는 Claude·Claude Code·Anthropic·Codex 등을 함께 언급한다. 여기서 스킬(skill) 개념은 클로드 계열 에이전트의 확장 방식과 동일한 맥락으로 다뤄진다.

02핵심 내용 구조

영상은 13개 스킬을 "뒤로 갈수록 더 강력하다"는 순서로 소개한다. 크게 (1) 입력 품질 개선(2·4번: 질문으로 요구사항 명확화), (2) 안전·관리(1·5·7번: 스킬 검증·생성·최적화), (3) 연속성·조사(3·8·9번: 인수인계·리서치·학습), (4) 인프라(6번: VPS 24/7 구동), (5) 산출물(10·12번: 디자인·이미지/영상), (6) 일상 자동화·의사결정(11·13번: 모닝 브리핑·전문가 혼합)으로 묶인다. 각 스킬 링크와 타임스탬프는 영상 설명란에 제공된다고 안내한다.

03기술적 맥락

발표자는 Anthropic 엔지니어들이 Claude Code 시스템 프롬프트의 80% 이상을 삭제했는데도 코딩 성능 손실이 0이었다는 점을 인용하며, 이 발상을 에이전트 최적화(7번 Context Doctor)에 적용했다고 설명한다. 스킬은 토큰 효율이 중요해 "설명 태그가 매 턴마다 실린다"는 점을 강조하고, 300자 넘는 장황한 설명·오래된 스킬·불필요한 도구 스키마를 정리해야 한다고 본다. 인프라 측면에서는 VPS(가상 사설 서버, 항상 켜져 있는 원격 컴퓨터) 위에 에이전트를 올려 노트북을 닫아도 24시간 구동하는 구성을 제시한다.

04전략적 의미

핵심 논지는 "많은 스킬"이 아니라 "옳은 스킬 조합"이 경쟁 우위라는 것이다. 스킬 관문 검증(1번 Bouncer)으로 악성 스킬·프롬프트 인젝션을 걸러 안전성을 확보하고, 시장을 먼저 조사해 더 나은 대안까지 찾아 항상 최고 품질의 스킬만 남긴다. 나아가 스킬을 만드는 메타 스킬(5번)과 스킬을 정리하는 최적화 스킬(7번)을 갖추면, 에이전트가 스스로 확장·정돈하는 자기개선 루프가 만들어진다. 발표자는 이를 통해 "남들보다 몇 광년 앞선다(light years ahead)"고 표현한다.

05핵심 워크플로우/방법론

  • 스킬 설치: 스킬을 에이전트로 가져와 "이 스킬 설치해줘"라고 말하고 repo 링크를 붙여넣는다.
  • 요구사항 명확화: "이 아이디어로 나를 그릴(grill)해줘"라고 하면 에이전트가 역질문으로 핵심(정확한 고객, 반복되는 통증 문제 등)을 파고든다.
  • 인수인계: "오늘 내용 정리해서 다른 에이전트에게 넘길 핸드오버 문서 써줘"라고 하면 상태·결정·다음 단계·추천 스킬·시크릿까지 담긴 문서를 생성한다.
  • 최적화 실행: Context Doctor에게 "가진 모든 것에 이 스킬을 돌려줘"라고 하면 6개 항목을 점검해 잘라내기(격리)·병합·이동·보류·다듬기 중 하나를 제안한다(하드 삭제는 하지 않음).
  • 의사결정: /moa로 여러 모델을 혼합(주 모델이 나머지 모델들에 같은 질문을 던지고 종합)한다.

06활용 시나리오 (3개 이상)

  1. 사업 아이디어 검증: "새 사업을 시작하려는데 좋은 아이디어인지 그릴해줘"라고 하면 에이전트가 고객·문제·수익 구조를 캐물어 맹점을 잡아준다(2번 Grill Me).
  2. 최근 30일 리서치: 8번 스킬이 X·YouTube·Reddit·해커뉴스·폴리마켓·GitHub 커밋 등을 훑고 업보트/좋아요 기준으로 최신 동향을 랭킹해 준다(단, Reddit·일반 웹은 쿠키 인증이나 Firecrawl 연동 필요).
  3. 웹사이트 디자인: 10번 Art Director(Power Design)로 황금비(부제:제목 = 1:1.61 등) 등 20개 보편 디자인 원칙과 21st.dev의 인터랙티브 컴포넌트를 결합해 가볍고 아름다운 사이트를 만든다.
  4. 매일 아침 자동 브리핑: 11번 Morning Brief로 캘린더·이메일·최근 7일 대화를 종합해 오전 7시에 "오늘 집중할 일 한 가지"를 폰으로 받는다(Zapier로 Gmail·Outlook 연결).
  5. 이미지/영상 제작: 12번 The Studio에서 Higgsfield CLI와 Nano Banana를 에이전트에 연결해 썸네일 텍스트 수정·영상 생성 등을 대화로 처리한다.

07현황 및 전망

발표자는 13개 중 11번 Morning Brief를 "가장 가치 있는 스킬"로, 7·8·13번을 뒤로 갈수록 강력한 축으로 꼽는다. 6번 VPS 구동은 Hostinger 협찬 파트로, KVM2 플랜을 추천하고 연간·격년 결제 시 코드 "Jack Roberts"로 10% 추가 할인을 안내한다(설정 시 에이전트 자동 배포, OpenAI/ChatGPT 구독 연동, Telegram 연결 가능). 다수 스킬이 Matt Poclls(Matt PCO Skills) 저작물이며, 마지막에는 "가장 수익성 높은 스킬"로 웹사이트 제작 강의를 예고한다. 전반적으로 스킬 생태계가 빠르게 발전 중이며 "옳은 스킬을 골라 조합하는 큐레이션 능력"이 핵심 역량이 될 것이라는 전망을 담는다.
