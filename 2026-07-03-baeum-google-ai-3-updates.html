02① Google Vids — 커스텀 AI 아바타

Google Docs 계열 Vids에서 "Start new video → AI 아바타" 진입. 기존 프리셋 외 Create custom avatar로 자기 아바타 생성 가능. 실습: 아시아인 아바타가 없어 성별·연령·인종(동아시아)·복장(캐주얼) 지정해 동양인 남성 아바타 생성 → 자기 썸네일 이미지를 업로드하고 "이 이미지의 모델과 배경 모두 사용해줘"로 리파인 → 본인 얼굴 반영. 다소 불안정하나 "이미지 그대로 사용하게 해줘"가 가장 간단한 리파인 프롬프트. 음성(티처 보이스) 선택 → 한글 대본 입력 → 프리뷰 → Generate 시 립싱크까지 수행.

03② NotebookLM — 비디오 오버뷰 '쇼츠'

NotebookLM 비디오 오버뷰에 쇼츠(Shorts) 기능 신설. 선택 후 생성 시 5분 이상 소요, 약 90초(1분 20초) 세로 쇼츠 영상 산출. 현재 한계: 한글 자막(폰트) 미지원(깨짐), 영어만 정상. 단 더빙 음성은 한국어 정상 출력 → 자막 불필요한 용도면 활용 가치 있음. 영어 콘텐츠는 고퀄리티 산출 → 영어 교육·콘텐츠 제작자에게 추천. 한국어 지원은 시간 문제로 전망.

04③ Gemini 캔버스 × NotebookLM — 인터랙티브 학습 페이지

Gemini 시작 화면 개편(구버전 선호 의견도). Multi-upload(＋)에 Notebooks 항목 추가 → 내 NotebookLM 노트 직접 호출. 실습: '고환율 시대 한국 경제 지표·투자 전략 분석' 노트 선택 → ＋ → 캔버스 → "이 노트를 학습할 수 있는 인터랙티브 HTML 페이지 생성, 완전 학습 가능해야 한다" 프롬프트 → 클릭 반응형 개념 학습 + 플래시카드 + 실전 퀴즈(오답 체크) HTML 산출. 다운로드·공유(링크) 가능 → 공유자가 Gemini 로그인 시 함께 사용. 교사·직원 교육 자료로 활용 가능.

05종합 — 구글의 위치

2025년만큼의 충격·센세이션은 없으나, 구글만의 사용성·생태계(Docs·Gemini·NotebookLM 연동)는 무시 불가. 업무·학습에 적절히 활용 시 실질 도움.
