코덱스 최신 업데이트 총정리 - ChatGPT 통합·Sites·Quick Chat 워크플로우

01핵심 개요

항목내용
형식코덱스 앰버서더 한서우 x 평범한 사업가 AI 팟캐스트 #92
최대 변화ChatGPT와 Codex 통합 → 하나의 워크플로우/OS로 수렴
핵심 기능Quick Chat, Work(로컬/클라우드), Sites, Pet 알림
사용자 급증클로드 코드에서 대거 이동, 사용자 1,000만 돌파

02ChatGPT + Codex 통합

  • 좌상단에서 ChatGPT(일상)와 Codex(코딩) 구분, 궁극적으로 단일 서비스로 수렴(과도기)
  • Quick Chat = 웹 ChatGPT 지능을 앱 안에서, 코덱스 토큰과 별개 차감
  • 워크플로우 = 기획·리서치·코드리뷰는 Quick Chat → 결과를 'Add to chat'으로 코덱스에 임베딩(토큰 절약)
  • GPT-5.6 Sol 프로 모드 = 코덱스 내에서 유일하게 사용 가능(플랜 수립·코드 리뷰에 강력)

03핵심 기능 상세

기능내용
Quick Chat자료조사·기획·리서치용, 웹 검색 결과를 코덱스로 이어붙임
Work(로컬)코덱스와 동일, 코드는 뒤로 숨고 결과물만 표시
Work(클라우드)PC 닫아도 ChatGPT 웹/모바일에서 작업 지속(장비 의존 탈피)
Pet다른 창에서도 작업 진행·완료를 알려주는 알림(맥 노치 이동 오픈소스 존재)

04전략적 의미 — Sites 기능

  • Sites = 리서치 결과를 웹페이지로 즉시 퍼블리시(원래 비즈니스·엔터프라이즈 전용 → 전 계정 개방, 프리뷰)
  • 특징 = 로컬 사진 폴더 지정 시 자동 DB화(192장 업로드), 애널리틱스(7일·30일 방문자) 기본 제공
  • 어노테이션 편집·커스텀 도메인 연결 지원
  • 홍보 부족 = ChatGPT.site 도메인이 피싱으로 오해받을 만큼 알려지지 않음

05핵심 방법론 — 모델 선택 전략

  • 테라(Terra) = 업무용, GPT-5.5보다 상위(오픈AI 직원 평가)
  • Sol = 복잡한 코딩 문제 해결
  • 루나(Luna) = 반복적·간단한 업무
  • 페이블(클로드) 지휘 + Sol 실행 조합도 여전히 활용

06활용 시나리오

  1. 리서치→Sites 퍼블리시 = 업데이트 내용을 이미지젠 스킬로 시각화한 홈페이지 + 신청 폼
  2. 슬라이드·대시보드 = 리서치를 발표자료/엑셀 데이터 대시보드로 즉시 변환
  3. 클라우드 Work = PC 없이 모바일로 장시간 작업 지속(비개발자 친화)

07현황 및 전망

  • 오픈AI = X/트위터로 유저 피드백 초고속 반영(코덱스 명칭 삭제→반발→복원, 밋업·크레딧 이벤트)
  • 토큰 리셋 = 사용자 급증·버그 보상성 리셋 빈번, 단 '당연시'는 경계 권고
  • 빌드위크 = GPT-5.6 기반 해커톤, 아틀라스(브라우저) 축소·컴퓨터 유즈 성능 강화
  • 함의 = 고사양 모델 개방 기간에 다각도 실험(울트라·포크)로 AI 사용성 극대화 권장, GPT-5.6은 미 정부 이슈로 릴리즈 지연
