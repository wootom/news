01
Manus 특가 대란 HOT
특가 발견 — 안드로이드 전용
연간 32,000원 또는 월 23만 크레딧 파격가. 웹·iOS에서는 노출 안 됨. 안드로이드 모바일에서만 확인 가능.
결제 방법 — 페이스북 계정 성공률 높음
구글·이메일 계정은 정지 사례 多. 페이스북 계정 결제 성공 후기가 가장 많았음.
배경 — Meta 인수 불발
중국 정부 반대로 Meta의 Manus 인수가 좌절. 급하게 자금 확보를 위한 가격 오류 특가일 가능성 제기.
환불 주의 — 일부 이미 환불 처리
가격 오류로 환불될 가능성 높음. 커뮤니티 반응: "최대한 빨리 크레딧 소모해서 뽕 뽑자"
Manus란? 자체 AI 모델이 아닌 Anthropic·OpenAI API를 활용하는 고급 에이전트 래퍼. 중국 Butterfly Effect 팀 개발, 현재 싱가포르 기반. API 연동 지원 (BASE: api.manus.im)

Hermes / OpenClaw 트러블슈팅
Hermes Rate Limit (HTTP 429)
  • GPT-5.4 mini 모델 연결 상태 재확인
  • hermes setup 또는 hermes auth로 프로바이더 재연결
  • 메모리 부족 시 Mem0 / Honcho 벡터DB 연동 검토
  • MD 파일 2,200자 → 5만자 제한으로 확장 가능
OpenClaw 웹서치 실패 대처
  • settings.json에서 WebSearch 비활성화 (가장 빠름)
  • Codex 백엔드, web_fetch, chrome relay 스킬로 우회
  • Q&A 자료: bbojjak-library.gpters.org/qna-30
  • Hermes·OpenClaw 칸반 기능 활용으로 작업 추적 개선

챗봇 설이 & 뽀짝이 운영 현황
설이 (LLM 챗봇)
모델 비공개 ("모델은 아직 비밀"). 프롬프트 지시문이 출력에 노출되는 오류 발생. 특정 대화 흐름에서 반복 반응 "맛이 갔다" 현상 보고.
뽀짝이 (자동 반응 봇)
"뽀짝" 키워드 트리거 방식. Stable Diffusion 등 기술 영역 지원 불가. GPTers 운영 관련 Q&A에 특화.
디스코드 봇 2개 협업
메시지 전송·읽기 권한 확인 → MessageContent Intent ON → MongoDB 등 공유 DB로 스레드 정보 공유. 채널 ID 하드코딩 금지.
