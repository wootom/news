DeepSeek 하네스 — 클로드 코드급 에이전트를 무료 오픈소스로 구동하는 법

02핵심 기능/내용 구조

  1. 모델(brain) vs 하네스(body) 개념 구분: 저자는 "모델은 두뇌, 하네스는 몸"이라는 비유로 설명하며, 클로드라는 모델에 클로드 코드라는 하네스가 붙듯, DeepSeek 모델(V4 flash)에도 이번에 무료 하네스가 새로 공개됐다고 소개한다. 하네스가 UI, 플러그인, 채팅 툴을 모두 교체 가능하게 만드는 껍데기 역할을 한다는 점이 핵심이다.
  2. 폭발적 성장과 라이선스: 공개된 지 얼마 되지 않아 약 17만(170,000) 개의 깃허브 스타를 받아 "역대 가장 빠르게 성장한 레포"로 소개되며, MIT 라이선스로 배포돼 사용자가 자유롭게 수정·재배포할 수 있다.
  3. 설치 방법: 공식 웹사이트에서 "View on GitHub"를 클릭해 레포 링크를 복사한 뒤, 클로드(또는 유사 코딩 어시스턴트)의 새 채팅창에 "이 깃허브 레포를 다운로드해서 로컬호스트에 열어달라"고 요청하면 클로드가 설치를 대행해준다. 설치 후 열리는 로컬 페이지에서 모델 선택, effort(추론 강도) 설정 등을 조정할 수 있다.
  4. 완전한 모델 애그노스틱 구조: 하네스 내에서 DeepSeek뿐 아니라 클로드 코드 모델, OpenRouter의 무료 모델까지 자유롭게 전환하며 사용할 수 있다. 시연에서는 "메모리 도구를 직접 만들어달라"는 요청을 하네스에 실행시켜, 작업 단계별 세부 로그(토큰 수, 소요 시간 등)를 확인하는 과정을 보여준다.
  5. 네 가지 작업 모드: Standard 모드(음성 코딩 에이전트, 파일 편집 등 기본 기능), PTC 모드(Standard 기능에 Code Mode SDK로 다단계 작업을 하나의 TypeScript 프로그램으로 결합하는 기능 추가), Minimal 모드, Creative 모드(런타임 인스펙션을 포함한 커스텀 에이전트 프리셋 제작용)로 구성되며, 저자는 실제로는 대부분 Standard 모드만으로 충분했다고 언급한다.
  6. Zapier를 통한 외부 서비스 연동 시연: 하네스에 Zapier를 인증 레이어로 연동해 Gmail 초안 작성을 지시하는 실제 시연을 진행한다. Zapier를 선택한 이유로 Outlook 등 다른 플랫폼과의 연동이 School(저자의 커뮤니티 플랫폼)에서는 불가능했던 것과 달리 손쉽게 가능하다는 점을 든다. 실제로 "Gmail에 가서 부다페스트가 얼마나 아름다운 도시인지 설명하는 이메일 초안을 나에게 써달라"는 요청을 실행해 스킬 카탈로그·툴 콜 실행 과정을 보여준다.
  7. 가격 구조와 벤치마크: DeepSeek 모델은 Opus·GPT-5.6 대비 성능이 "한 단계 아래"지만 "비용 대비 90~95%의 성능"이라는 위치로 소개되며, OpenRouter 기준 누적 사용량이 11조(11 trillion) 토큰을 넘어 OpenRouter 내 최대 트래픽 모델이라는 수치가 제시된다.
  8. 클로드 코드 사용 vs DeepSeek 하네스 사용 기준: 클라이언트에게 보여줄 완성도 높은 결과물(예: 채널에서 만드는 웹사이트)이 필요하거나 디자인 감각이 중요할 때는 클로드 코드를 권장하고, 대량 작업이라 비용이 중요하거나 신모델을 빠르게 테스트하고 싶을 때는 DeepSeek 하네스를 "워크호스(workhorse)"로 쓰라고 구분한다.

03기술적 맥락

이 영상이 다루는 핵심 기술 구조는 "모델(brain)"과 "하네스(body, 에이전틱 오케스트레이션 레이어)"의 분리이며, DeepSeek 하네스는 이 하네스 레이어 자체를 MIT 라이선스 오픈소스로 공개함으로써 클로드 코드·Codex처럼 특정 벤더에 종속된 폐쇄형 하네스와 대비되는 완전 커스터마이징 가능한 대안을 제공한다. 하네스는 로컬 머신에서 구동되며(클라우드 아님), 텔레메트리가 기본 꺼짐 상태이고 API 키 기반으로만 인증되므로 클로드 코드/Codex 구독을 그대로 재사용할 수는 없다. Standard/PTC/Minimal/Creative 네 가지 모드 구분과 Code Mode SDK를 통한 다단계 TypeScript 프로그램 결합 기능은, 단순 챗봇을 넘어 실제 에이전틱 자동화(멀티스텝 툴 호출, 외부 서비스 인증 연동)를 지원하는 구조임을 보여주며, Zapier 같은 인증 레이어를 매개로 Gmail·Outlook 등 실제 생산성 도구와 연결되는 점이 이번 시연의 기술적 핵심이다.

04전략적 의미

DeepSeek 하네스의 오픈소스·무료 공개는 에이전틱 코딩 도구 시장에서 "모델 종속형 하네스"에서 "모델 애그노스틱 하네스"로 무게중심이 이동할 수 있음을 시사한다. 사용자가 브랜드에 상관없이 최신 모델(DeepSeek, 클로드, ChatGPT, 로컬 Ollama 모델까지)을 하나의 하네스 안에서 자유롭게 교체할 수 있게 되면서, 특정 랩(Anthropic, OpenAI)의 폐쇄형 워크플로우 락인 효과가 약화될 가능성이 있다. 동시에 저자가 제시하는 "프론티어 모델(클로드, GPT) vs 워크호스 모델(DeepSeek)"이라는 이분법은, 고품질·고비용 결과물과 대량·저비용 반복 작업을 서로 다른 모델에 분리해 배정하는 하이브리드 운영 전략이 실무에 자리잡고 있음을 보여준다. 다만 하네스가 아직 초기 단계라 불안정할 수 있다는 저자의 경고, 그리고 클로드 코드 특유의 "내장된 디자인 감각"이 하네스만으로는 완전히 대체되지 않는다는 관찰은, 오픈소스 하네스가 범용성은 확보했지만 완성도 면에서는 아직 벤더 통합형 도구를 완전히 대체하지 못했다는 한계도 동시에 드러낸다.

06활용 시나리오

  1. 비용에 민감한 개발자/1인 창업자: 대량의 반복적 코딩·문서 작업을 처리할 때 클로드 코드 대신 DeepSeek 하네스를 "워크호스"로 배정해, 토큰 비용만 지불하며 90~95% 수준의 결과물을 확보하는 방식으로 운영 비용을 절감할 수 있다.
  2. 여러 모델을 비교 테스트하려는 실험적 사용자: 신모델이 출시될 때마다 별도 구독 없이 DeepSeek 하네스에 API 키만 꽂아 즉시 성능을 체험해보고, 자신의 워크플로우에 맞는 모델을 선택하는 용도로 활용할 수 있다.
  3. 자동화 워크플로우 구축자: Zapier 같은 인증 레이어를 하네스에 연동해 Gmail 초안 작성, Outlook 연동 등 반복적인 이메일·커뮤니케이션 업무를 에이전트에게 위임하는 자동화 파이프라인을 구축할 수 있다.
  4. 자체 에이전트 프리셋을 만들고 싶은 파워유저: Creative 모드나 PTC 모드(Code Mode SDK)를 활용해 표준 UI에 얽매이지 않는 커스텀 에이전트를 직접 설계하고, 이를 플러그인·스킬 형태로 재배포할 수 있다.

07현황 및 전망

DeepSeek 하네스는 공개 직후 약 17만 스타를 확보하며 "역대 가장 빠르게 성장한 레포"라는 초기 흥행을 보이고 있으나, 저자는 "아직 초기 단계이므로 완벽함을 기대하지 말라"고 명시하며 안정성 면에서는 검증이 더 필요하다고 밝힌다. OpenRouter 기준 DeepSeek V4 flash가 누적 11조 토큰으로 최대 트래픽 모델 자리를 차지하고 있어 실제 채택률은 이미 상당한 수준이며, 향후 하네스 생태계(플러그인 스토어 포함)가 성숙할수록 모델 애그노스틱 에이전틱 워크플로우가 클로드 코드·Codex와 나란히 표준 옵션으로 자리잡을 가능성이 있다. 저자는 후속 영상에서 에이전틱 시스템을 제대로 구축하는 법을 더 다루겠다고 예고했다.
