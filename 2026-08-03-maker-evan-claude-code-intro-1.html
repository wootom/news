클로드 코드 입문 1강

01핵심 개요

  • 강사 '메이커 에반'의 "비개발자를 위한 AI 비서 활용 가이드" 세션. 비개발자도 클로드 코드로 자기만의 앱·프로그램을 만들 수 있게 하는 것이 목표.
  • 시대 변화: 2023년에는 코드를 모르면 개발 불가였으나, 2026년은 말로만 시키면 AI가 처리. 랜딩 제작 비용이 과거 100만~1천만 원에서 도메인 월 3만 원 + 호스팅 월 1만 원 수준으로 하락. 팀도 기획·디자인·개발·PM 3~4명에서 혼자 풀스택 가능으로, 출시 기간도 3개월에서 12시간 강의 후 첫 사이트 완성 수준으로 단축.
  • 역설적으로 비개발자가 유리: (1) 빈 머리가 무기 — 개발자는 코드 흐름(플로)으로, 비개발자는 비즈니스 문제로 사고하며 AI 시대엔 후자가 승리. (2) 사용자 감각 우위 — 화면 직관성 판단이 곧 제품 품질. (3) 본업 결합 — 마케터·디자이너가 본업과 AI 코딩을 결합할 때 가장 강력한 차별화.
  • 마음가짐 3원칙: 실수해도 OK(깃으로 어제로 되돌림, 많이 망친 사람이 빨리 배움) / 모르는 걸 부끄러워 말 것(즉시 질문, 30분 헤매기보다 묻고 30초에 푸는 게 100배 가치) / 모방→변형→창조 3단계로 발전.

02클로드 코드란 무엇인가

  • 클로드 코드는 '터미널에서 만나는 AI 비서'. 옆자리에 앉은 만능 비서처럼 보고서 작성, 데이터 정리, 자료 조사, 브레인스토밍을 도움.
  • 개발자가 아니어도 사용 가능. 터미널은 그저 AI와 대화하는 창구일 뿐.
  • 할 수 있는 일: 코딩 외에 자료 조사(인터넷 검색→보고서화), 문서 작성(보고서·이메일·기획서), 브레인스토밍(다관점 아이디어), 데이터 정리(고객 데이터 분류·평균 계산). 그 외 PPT 제작, 영어 문맥 분석, 긴 문서 요약, 엑셀 처리.
  • 작동 방식 3단계: (1) 자연어로 요청("경쟁사 분석 보고서 만들어 줘") → (2) 클로드 코드가 알아서 파일 분석·명령 실행·인터넷 검색 → (3) 결과물 승인/리젝트.
  • 실제 활용 예시: 강의 PPT 자체가 클로드 코드로 제작. 배너 이미지 자동화, 유튜브 영상 자동화(강사 영상 조회수 약 20만), 인스타 카드뉴스 제작, 랜딩 페이지 제작 모두 가능.

03프롬프팅 — 잘 시키는 법

  • 프롬프팅은 지시사항을 주면 AI가 이해하고 결과를 내놓는 과정. AI에 내리는 명령이 곧 프롬프트.
  • 명확한 지시를 위한 4항목: 지시(무엇을 할지) / 맥락(환경·전체 상황, 예: 윈도우·크롬·디버그 모드·로그인) / 작업(구체 단계, 예: 주문 페이지→어제 필터→CSV 다운로드) / 출력(산출물 형식, 예: 보고서 MD).
  • 프롬프트 4원칙: 구체적 지시·상황·형태·예시 — 하나라도 빠지면 품질 급락. "정리해줘"(X)→"결정사항·담당자 표로"(O), "보고서"(X)→"마케팅팀·월간·KPI"(O), "요약해줘"(X)→"임원 3줄 발표용"(O), 모호한 예시(X)→"매출 15% 이상, 방문자 20% 이상"(O).
  • 5번째 보조 원칙: CLAUDE.md 같은 파일을 참조(@CLAUDE.md에 따라)로 함께 전달하면 프로젝트 규칙이 반영돼 결과가 더 정확.
  • 마인드셋: 신입에게 일 시키듯 맥락을 줄 것. 처음에 5분 더 써서 맥락을 주면 다음 5번의 작업이 10배 정확해짐.

04필수 도구·환경 개념

  • CLAUDE.md: AI에게 주는 '인수인계서'. 권장 원칙 — 200단어 이하(길면 컨텍스트가 터져 AI가 끝까지 안 봄, 초과 시 모듈로 분할) / /init로 자동 초안 생성 후 본인 룰 추가 / 프로젝트 루트 최상위에 두면 자동으로 읽음 / 팀 공유 권장, 개인 메모는 CLAUDE.local.md / 한 달에 한 번 검토·업데이트.
  • 터미널: 마우스 없이 키보드로 명령을 내리는 검은 창. 맥은 터미널 앱, 윈도우는 파워셸. 평소 쓰는 명령은 안전하고 망가져도 깃이 되돌림.
  • IDE: Integrated Development Environment 약자, 코드 전용 메모장. 자동완성·문법 색칠·에러 빨간 줄·파일 탐색기 제공(메모장 vs 워드 비유). 추천은 마이크로소프트의 무료 VS Code(code.visualstudio.com에서 다운로드).
  • Node.js: 자바스크립트를 노트북/서버에서 실행시키는 엔진. 원래 브라우저에서만 돌던 JS를 노드가 서버에서도 실행 가능케 함. 강의 메인 프레임워크 Next.js가 노드 기반이라 먼저 설치 필요. LTS(Long Term Support) 버전 설치, 강의는 V20 이상 권장.
  • Git: '코드의 시간 여행 도구'. 변경 이력을 기록하는 무료 도구로 모든 개발자가 사용. 어제 코드로 되돌리기, 망가진 지점 추적, 협업 가능. AI가 망쳐도 한 줄로 1초 만에 복구, git diff로 무엇이 바뀌었는지 확인. 일상 명령 4개(add·commit·push·pull)는 외울 필요 없이 클로드 코드에게 "커밋 해 줘"처럼 말로 시키면 됨.
  • GitHub: 코드를 인터넷에 올리는 클라우드(구글 드라이브가 문서라면 깃허브는 코드). 백업·공유·포트폴리오 가능, 무료. 깃(내 노트북의 시간여행)과 깃허브(인터넷 저장소)는 커밋→푸시로 이어지는 한 세트. 노트북이 망가져도 코드 생존, 버셀 배포와 깃허브 연결 자동화, 깃허브 자체가 포트폴리오.

05핵심 명령어와 첫 실행

  • 외울 명령어 5개면 평생 사용: claude(어디서나 입력해 클로드 코드 실행·입력창 띄움) / /clear(현재 대화 비우기, 주제 전환 시 사용) / /init(프로젝트 안내서 자동 생성, 새 프로젝트 첫 회) / /exit(종료) / @파일명(파일 첨부·특정 파일 분석). 나머지는 한국어 자연어로 처리.
  • 첫 대화 5단계: (1) 터미널에서 claude 입력→브라우저 로그인 (2) "이 폴더에 뭐가 있어?" 자연어로 시작(한국어 OK) (3) 후속 질문 "이 파일 열어봐", "이 함수 설명해 줘" (4) @ 입력 후 파일명 자동완성으로 파일 첨부 (5) /exit로 종료.

06스킬(Skills)과 서브 에이전트

  • 스킬즈: '전문가 모드를 켜는 버튼'. 감기엔 내과, 치아엔 치과 가듯, 스킬은 클로드 코드에 전문의 자격증(도메인 지식)을 주입. 없으면 팀 규칙·회사 형식을 몰라 매번 반복 설명 필요, 있으면 회사 문서 형식 자동 적용·팀 규칙 준수·한 번 작성으로 자동 반영.
  • 스킬을 만들 때: 같은 설명을 반복할 때, 팀만의 규칙(문서 형식·보고서 구조·브랜드 가이드)이 있을 때, 자주 하는 작업(주간 보고서·회의록·데이터 분석)이 있을 때.
  • 스킬 파일 구조: 프론트매터(name·description, 특히 description으로 클로드 코드가 언제 이 스킬을 쓸지 판단) + 바디(규칙·예시·주의사항 자유 작성). 팁 — SKILL.md는 500단어 넘지 않기(앤트로픽 권장, 너무 길면 역효과), 초과분은 다른 파일로 분리해 점진적 로딩, 구체적 예시 포함, 나쁜 패턴도 명시.
  • 서브 에이전트: 전문 분야별 AI 비서를 여러 명 두고 메인 AI가 상황에 맞게 위임하는 시스템(사장이 코드리뷰 담당·디버거·데이터 분석가에게 분업). 이점 — 메인 대화가 깔끔(1만 줄 로그도 실패 3개만 요약 보고, AI의 단기 용량 한계 극복), 권한 제한 가능(읽기만 허용해 파일 삭제 사고 방지), 저렴한 모델 사용 가능(단순 검색은 싼 모델, 복잡 판단만 똑똑한 모델로 비용 절감).
  • 스킬 vs 에이전트: 스킬은 요리 레시피 책(지식 제공·참고하며 작업·개입 가능), 에이전트는 전문 요리사(작업 수행·전체 위임·독립 수행 후 보고).
  • 에이전트 예시 3종: 플랜 리뷰어(계획을 실행 전 검토, 빠진·위험·개선점 분석 보고서), 다큐멘테이션 아키텍트(배경·목적·주의사항·다음 단계 포함 종합 문서), 웹 리서치 스페셜리스트(인터넷 검색으로 뉴스·연구·블로그 핵심 정리). 호출 방법 3가지 중 강사는 @에이전트로 빠르게 호출하는 3번을 선호(나머지는 트리거가 잘 안 될 때가 있어서).

07활용 시나리오

  • PPT·배너 이미지·유튜브 영상·인스타 카드뉴스·랜딩 페이지 등 콘텐츠 제작 자동화.
  • 자주 하는 실수와 해결: (1) 모호한 요청 → 목적·대상 독자·분량·톤을 구체화("좋은 걸 써 줘" X → "20대 직장인을 위한 저축팁을 친근한 톤으로 500자 내외로"). (2) 한 번에 과다 요청 → 단계적 접근으로 각 결과물 확인 후 진행. (3) 결과 미검토 → AI도 실수하니 숫자·날짜·이름 반드시 검증. (4) 컨텍스트 미제공 → 배경 상황 설명("납기 연장 요청 이메일이야, 일주일까지 가능해, 정중히 수락하는 답장 써 줘").
  • 실전 팁: 대화가 길어지면 /clear로 새 세션 시작(앞부분 망각 방지), CLAUDE.md로 프로젝트 전체 규칙 설정, 복잡 작업은 중간 결과물 확인, 같은 설명 3회 이상이면 스킬화 신호, 실패 시 무엇이 잘못됐는지 분석해 더 구체적 요청, 개인 스킬을 팀 규칙 스킬로 발전시켜 팀 생산성 향상.

08현황 및 전망

  • 학습 순서 4단계: (1) 첫 대화 — 설치·파일 참조·간단 요약 요청 (2) 스킬 활용 — 기본 제공 스킬 사용·팀 규칙 스킬 제작 (3) 에이전트 활용 — 웹 리서치 실전·여러 에이전트 조합 (4) 나만의 에이전트 제작·팀 도입·워크플로우 최적화.
  • FAQ: 코딩 몰라도 사용 가능(자연어 소통, 문서·자료조사·데이터 정리에 활용) / 결과물이 틀릴 수 있음(숫자·날짜·고유명사 반드시 확인) / 민감한 개인정보는 입력 금지, 회사 보안 정책 우선 확인 / 반복 규칙·지식은 스킬, 특정 결과물을 만드는 복잡 작업은 에이전트.
  • 본 강의는 이론 파트 마무리이며, 이후 실습으로 이어짐을 시사.
