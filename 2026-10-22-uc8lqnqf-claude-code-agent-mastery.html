01핵심 개요

  • 클로드 코드는 AGI 시대에 맞춰 사용자의 일을 대신할 에이전트를 생성하는 핵심 도구로 정의된다.
  • 클로드 MD는 지침 컨텍스트일 뿐 강제 설정이 아니므로, 권한 설정과 훅을 병행해 안정성을 확보해야 한다.
  • 에이전트 MD는 클로드 전용이 아닌 여러 AI 코딩 도구를 아우르는 범용 지침서로 기능한다.
  • 슬래시 컴팩트 명령어는 컨텍스트 사용률을 12%에서 0%로 낮추어 토큰 부담을 즉각적으로 해소한다.
  • 서브 에이전트는 별도 작업 공간에 위임하여 세션 컨텍스트 오염을 방지하고 결과만 전달하는 구조다.

02핵심 주장 / 논점 구조

  • 클로드 코드를 배우는 이유는 GPT 아스트라와 클루드 페이블 5.1 등 AGI의 시작을 대비하기 위해서다.
  • 클로드 코드의 본질은 사용자의 업무를 대신 수행하는 에이전트를 만드는 도구이다.
  • 2027년 이전까지 클로드 코드 기능의 80%를 마스터하는 것이 본 강의의 최종 목표다.
  • 단순 코드 작성 도구를 넘어, 자율적 판단과 실행을 위한 에이전트 설계 역량이 핵심이다.

03지침 파일의 한계와 범용성

  • 클로드 MD는 지침 컨텍스트이지 강제 설정이 아니므로 100% 실행 보장이 없다.
  • 모호하거나 충돌하는 지시는 지켜지지 않을 수 있어 권한 설정과 훅으로 보완해야 한다.
  • 에이전트 MD는 클로드 전용이 아닌 구글 드라이버, 슬랙 등 여러 AI 코딩 도구와 통합된다.
  • 도구를 가리지 않는 범용 지침서로서 에이전트 MD의 개념이 새롭게 부각되고 있다.

04컨텍스트 압축과 MCP 허브

  • 슬래시 컴팩트 명령어는 컨텍스트 사용률을 12%에서 0%까지 즉시 낮추는 압축 기능이다.
  • 압축된 컨텍스트에서도 이전 대화 내용을 유지하며 질문 응답이 가능하다.
  • MCP는 허브 역할을 하여 구글 드라이버, 슬랙, 기타버 API를 일일이 연결하지 않고 통합한다.
  • 허브 포트 하나만 연결하면 HD, C타입 등 다양한 외부 도구와 API를 유연하게 사용할 수 있다.

05스킬과 권한 모드 설계

  • 스킬은 반복 업무 절차서이자 에이전트에게 주는 작은 지시서로 기능한다.
  • 플랫 모드는 기획과 계획 수립에 특화된 권한 모드이다.
  • 바이패스 모드는 제한 없이 자유롭게 실행을 허용하는 권한 모드이다.
  • 오토 모드와 함께 다양한 권한 수준을 설정하여 에이전트의 행동 범위를 제어한다.

06서브 에이전트와 훅 메커니즘

  • 서브 에이전트는 별도 작업 공간에 위임하여 세션 컨텍스트 오염을 방지한다.
  • 장시간 세션으로 인한 토큰 오염을 막고 작업 완료 후 결과만 메인 세션에 전달한다.
  • 훅은 특정 행동 전후에 100% 실행되는 장치로, 낚시 미끼에 물고기 낚인 원리와 유사하다.
  • 프리훅과 포스트훅을 통해 A 종료 시 B 실행, B 종료 시 C 실행 등 자동화 체인을 구축한다.

07워크플로와 에이전트의 차이

  • 워크플로는 반복된 절차로 진행되며 현재 세션 내에서 작업을 수행한다.
  • 에이전트는 백그라운드에서 작업을 수행하고 결과를 사용자에게 전달한다.
  • 워크플로는 절차 준수에 중점을 두고, 에이전트는 그때그때 판단하여 최적의 행동을 취한다.
  • 두 방식의 차이는 세션 내 진행 여부 및 자율적 판단 능력의 유무로 구분된다.
