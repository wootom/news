그록봇을 유튜브·인스타그램·쓰레드 운영에 연결하고 사람의 승인과 검수로 관리한다

그록봇에 콘텐츠 제작·업로드를 맡기고 승인과 검수로 운영하는 방법

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

클라우드에서 일하는 AI 직원으로 소개한 그록봇

  • 영상에서는 그록봇을 각자 클라우드 컴퓨터를 가진 AI 직원으로 설명한다. 사용 중인 앱에 로그인해 작업하고, 노트북을 꺼도 계속 일한다고 소개한다.
  • 메시지로 업무를 맡기고 대화하며, 직원들이 작업을 기억하고 서로 협업하는 방식으로 사용할 수 있다고 말한다.

플랫폼별 담당 봇과 그룹 채팅으로 업무를 나누다

  • 플러스 버튼으로 봇을 만들거나 그룹 채팅을 구성해 협업시킬 수 있다. 유튜브 총괄은 기획과 스토리보드, 인스타그램 총괄은 게시물 구성 등을 맡긴다고 설명한다.
  • 쓰레드 총괄은 유튜브나 인스타그램 콘텐츠를 쓰레드용으로 변환하고 업로드하도록 구성했다. 별도로 카드뉴스 제작 봇도 콘텐츠 작업에 활용한다.
  • 운영 계정은 유튜브 약 1만 1천 명, 인스타그램 약 2만 명, 쓰레드 약 7천 명이라고 밝힌다. 콘텐츠 업무를 맡기되 승인과 검수를 거치는 방식으로 운영한다.

Composio MCP와 Canva로 카드뉴스 초안을 만들다

  • 그록봇에 기본 제공되는 앱 연결만으로 부족하다고 보고, Composio를 통해 여러 앱을 연결하는 MCP를 그록봇에 제공했다고 설명한다.
  • 연결한 앱 가운데 Canva를 이용해 인스타그램 카드뉴스 초안을 만든다. 제작된 초안을 직접 검수한 뒤 인스타그램에 올리는 흐름을 보여준다.

Zernio API로 인스타그램·쓰레드·유튜브 게시물을 예약하다

  • 업로드에는 Zernio를 사용한다고 설명한다. 인스타그램·쓰레드·유튜브를 연결하고, Composio의 MCP를 그록봇에 전달해 게시와 예약 업로드를 설정했다.
  • 영상에서는 브라우저를 통한 자동 업로드 중 계정 정지가 발생할 수 있다고 우려하며, API를 활용하는 도구를 선택했다고 말한다. Zernio는 기본적으로 두 건까지 무료라고 소개한다.

Claude와 Codex를 쓰는 작업자 봇과 CMO를 구성하다

  • 그록 모델만으로 영상 편집이나 아티팩트·카드뉴스 제작을 처리하는 방식이 불안정할 수 있다고 보고, Claude와 Codex 구독을 연결한 작업자 봇도 만들었다고 설명한다.
  • Claude와 Codex를 활용하는 팀원들을 만든 뒤, 이들을 총괄하는 CMO 봇을 구성했다. 그룹 채팅에 메시지를 보내거나 팀장에게 업무를 맡기고 보고받는 방식으로 활용한다.

세컨드 브레인의 MCP로 개인 작업 기준을 연결하다

  • 개인 작업 프레임워크를 반영하기 위해 세컨드 브레인과 그록봇을 연결했다고 말한다. 보관 공간의 설정에서 MCP를 가져와 그록봇에 제공하는 방식이다.
  • 그록봇이 해당 MCP를 참고해 작업별 기준을 파악하도록 구성하고, Composio로 앱 간 연결을 더해 유튜브와 인스타그램 등의 업무에 활용한다고 설명한다.

월 30달러 플랜을 사용 중이며 더 높은 요금제로 옮길 계획

  • 무료 체험 기간은 있지만 이용에는 유료 플랜이 필요하고, 프리미엄 플랜은 월 30달러라고 소개한다. 해당 플랜에 Cursor도 포함돼 있다고 설명한다.
  • 본인은 현재 30달러 플랜을 사용 중이며 200달러 플랜으로 옮길 생각이라고 말한다. 앞으로 세일즈와 영업 업무, Claude와 Codex가 협업하는 개발팀 등으로 활용을 넓힐 계획도 언급한다.
