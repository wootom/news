100시간 테스트: 딥시크 하니스 vs. 클로드 코드

유튜버 Nate Herk가 딥시크(DeepSeek)가 새로 공개한 오픈소스 AI 에이전트 실행기 "Deepseek Harness"를 일주일간 실사용하고, 클로드 코드(Claude Code)와 정면 비교한 리뷰 영상. "하니스(harness)"란 AI 모델을 실제로 파일을 읽고 쓰고 명령을 실행하게 만드는 "운전석·틀" 같은 실행 환경을 뜻하며, 이 영상은 그 틀 자체를 오픈소스로 완전히 뜯어고칠 수 있게 만든 신제품의 장단점을 다룬다.

02핵심 기능/내용 구조

영상은 크게 5부로 구성된다.

  1. 딥시크 하니스란 무엇인가 (60초 요약, 0:00)
  2. UI·설정 둘러보기: 챗봇형 UI, 세션 관리, 오픈라우터(OpenRouter) API 키 연동 (2:35)
  3. 4가지 모드 비교: 표준(Standard)·PTC·미니멀(Minimal)·크리에이터(Creator) 모드 (4:17)
  4. 비용·신뢰성·커스터마이징 평가
  5. 실전 비교 테스트 4종: 검색 속도, 유튜브 데이터 분석(엑셀 산출), 리서치 스킬(설탕이 신체에 미치는 영향 리포트), 결과물 신뢰도 비교 (12:05)

03기술적 맥락

  • 딥시크 모델군: 지난해 화제였던 DeepSeek R1 이후, 현재는 DeepSeek V4 Flash(저렴·빠름)와 V4 Pro(고성능) 두 계열이 주력. 단, 두 모델 모두 이미지를 "볼" 수 없는(비전 미지원) 한계가 있음.
  • 하니스 3파전 구도: Codex(모델: GPT-5.x Sol/Luna 등), Claude Code(모델: Opus, Fable 등), 그리고 이번에 등장한 Deepseek Harness. 하니스는 그 자체로는 AI 모델이 아니라 모델을 감싸는 실행 틀이며, 딥시크 모델뿐 아니라 Opus, GPT, Kimi(Kimmy) 등 원하는 모델을 자유롭게 꽂아 쓸 수 있음.
  • 완전 오픈소스 구조: 공식 사이트에 "everything is a plugin(모든 것이 플러그인)"이라고 명시. 도구(tools), 스킬(skills), 세션(sessions), 샌드박스(sandbox), 저장소(storage), 에이전트 루프(loop), UI까지 전부 교체 가능한 플러그인 단위로 설계됨. 반면 클로드 코드·코덱스는 폐쇄형이라 "엔진(모델)만 바꿔 끼울 수 있는 자동차"에 비유됨.
  • 로컬 실행: GitHub 링크를 코덱스에 주고 "이거 설치해줘"라고 요청하는 것만으로 로컬호스트에 셋업 가능. 설정에서 오픈라우터 등 API 키를 등록하면 다양한 모델 선택 가능. 단, 클로드/코덱스 구독을 그대로 재사용하는 기본 기능은 없고 토큰 단위 API 과금이 기본(일부 플러그인으로 우회 가능하다는 언급은 있으나 미검증).

04전략적 의미

  • "모델 대 하니스"의 분리가 명확해짐: 같은 모델(Opus)을 넣어도 하니스에 따라 응답 속도·품질이 크게 달라진다는 것을 실증 테스트로 보여줌. 즉 AI 도구 선택 시 "어떤 모델이냐"뿐 아니라 "어떤 실행 틀에 태우느냐"가 성능을 좌우하는 별개의 변수임을 시사.
  • 커스터마이징의 대중화: 지금까지 하드코어 개발자만 건드릴 수 있던 "에이전트 루프 자체의 개조"가 크리에이터 모드를 통해 대화형으로("하니스에 이런 기능 만들어줘") 가능해짐. 발표자는 "우리 모두가 자신만의 커스텀 하니스를 가지는 시대"의 신호탄으로 평가.
  • 보안 유의사항: 오픈소스 플러그인 생태계 특성상 출처 불명 플러그인 설치 시 위험이 있으므로, 설치 전 클로드 코드나 코덱스로 코드 리뷰를 먼저 해볼 것을 권고.
  • 현재는 대체재가 아닌 보완재: 딥시크 하니스가 클로드 코드를 대체하기보다, 한도(limit)에 걸렸을 때나 가벼운 리서치·지식노동용 "저렴한 보조 도구"로 자리매김할 가능성이 큼.

05핵심 워크플로우·방법론

  1. 표준(Standard) 모드: 파일 편집·셸·웹 검색이 모두 포함된 풀(full) 코딩 에이전트. 평상시 기본으로 쓰는 모드.
  2. PTC 모드: 여러 작업을 병렬로, 다중 체인(multi-chain)으로 처리할 때 사용. 클로드 코드의 "다이내믹 워크플로우"와 유사한 느낌이지만 동일하지는 않음.
  3. 미니멀(Minimal) 모드: "2-tool 코딩 에이전트 + 영속 배시(persistent bash)". 컨텍스트를 덜어내고 더 빠르게 실행. 다만 시작 시 AGENTS.md·CLAUDE.md·시스템 프롬프트·스킬 카탈로그를 자동으로 읽어들이는 "컨텍스트 주입"이 표준 모드와 달리 일어나지 않아, 매번 새로 시작하는 "1회성 채팅"에 가까움.
  4. 크리에이터(Creator) 모드: 커스텀 에이전트 프리셋 제작, 플러그인 빌드, UI 변경 등 하니스 자체를 개조하는 모드. (단, 영상 시연 중 이 모드로 전환이 안 되고 되돌아가는 버그가 실제로 발생함)

06활용 시나리오

  1. 대규모 지식베이스(위키) 검색: "지난주에 이야기했던 그 프로젝트 찾아줘" 같은 모호한 검색 질의를 자신의 "AI 운영체제(AIOS, 개인 위키)"에 던졌을 때, 딥시크 하니스는 약 50초 만에 답을 찾은 반면 클로드 코드는 5분 이상 소요됨 (12:05).
  2. 유튜브 애널리틱스 → 엑셀 리포트 자동 생성: 동일한 Opus 5 모델로 같은 작업(최근 데이터 분석 후 엑셀 시트 작성)을 시켰을 때, 딥시크 하니스는 약 3분, 클로드 코드는 약 17분 소요. 다만 품질 면에서는 클로드 코드 결과물이 전체 467개 영상 데이터까지 다루는 등 더 풍부하고 상세했음(14:47).
  3. 커스텀 리서치 스킬 실행(설탕이 신체에 미치는 영향 리포트): 동일한 "스톰 리서치 스킬"을 두 하니스에서 실행. 클로드 코드는 약 5,000단어·26개 출처, 딥시크 하니스는 약 4,400단어·최소 14개(총 약 22개) 근거 출처. 클로드 코드가 더 학술적·보수적이었고, 딥시크 하니스는 더 실용적이지만 때로 과신하는 경향을 보임.
  4. UI/디자인 작업: 딥시크 V4 Flash로 브랜드 가이드라인을 반영한 웹사이트를 제작한 사례는 준수했으나, 딥시크 모델이 스크린샷을 보고 반복 검증(iterate)하는 기능이 없어 클로드 코드·코덱스 대비 디자인 정교함에서는 한계가 있음.
  5. 한도 초과 시 보조 워크플로우: 클로드 코드 사용량 한도에 근접했을 때, 저렴한 모델을 딥시크 하니스에 꽂아 지식노동·리서치성 작업을 대신 처리하는 용도로 활용 예정이라고 언급.

07현황 및 전망

  • 현재 상태: 공식적으로 "개발자 프리뷰(developer preview)" 단계임을 명시하고 있으며, 실제로도 그에 걸맞게 버그가 다수 관찰됨. 장시간 세션에서의 압축(compaction) 오류, 컨텍스트가 이전 대화를 잊어버리는 컨텍스트 회귀(context regression) 현상, 마우스가 특정 영역에 갇히는 등의 기이한 버그, 크리에이터 모드 전환 실패 버그 등이 실사용 중 확인됨.
  • 강점: 속도(같은 모델 기준 압도적으로 빠른 응답), 완전한 커스터마이징 자유도(하니스 자체가 플러그인 구조), 무료 오픈소스(하니스 자체는 무료, 추론 비용만 모델별로 발생), 트래젝토리(trajectory) 뷰를 통한 세션 단위의 세밀한 중간 단계 로그 확인 및 다운로드 기능.
  • 약점: 신뢰성 부족(프리뷰 단계 버그), 결과물의 깊이·보수성 면에서 클로드 코드에 못 미침, 딥시크 모델 자체의 비전(이미지 인식) 미지원, 클로드/코덱스 구독을 그대로 활용하는 기본 지원 부재로 토큰 과금 필요.
  • 전망: 발표자는 하드코어 개발자나 "하니스 자체를 뜯어고치고 싶다"는 니즈가 있는 사용자에게는 강력 추천하지만, 자신처럼 영상 편집·리서치·지식노동·문서 작성이 주업무인 경우 클로드 코드·코덱스에서 아쉬움을 느낀 적이 없어 당장의 대체 필요성은 낮다고 평가. 다만 "누구나 자신만의 커스텀 하니스를 가지는 방향"으로 업계가 흘러갈 조짐이라는 점에서 의미 있는 이정표로 봄 (19:00 부근, 딥시크 전용 스킬을 새로 만들면 훨씬 빠르고 정확해질 것이라는 결론).

08용어 사전

용어한줄설명비유·예시
하니스(Harness)AI 모델이 파일·명령을 실제로 실행하게 하는 틀자동차의 차체·운전석(모델=엔진)
DeepSeek Harness딥시크가 낸 오픈소스 무료 에이전트 실행기완전 분해 가능한 조립식 자동차
Claude Code앤스로픽의 폐쇄형 코딩 에이전트 하니스엔진만 바꿀 수 있는 완성차
PTC 모드여러 작업을 병렬·다중 체인으로 처리하는 모드여러 줄 계산대를 동시에 여는 것
미니멀(Minimal) 모드컨텍스트 주입 없이 빠르게 실행하는 경량 모드짐 없이 홀가분하게 뛰는 단거리 달리기
크리에이터(Creator) 모드하니스 자체(플러그인·UI)를 개조하는 모드자동차 정비소에서 직접 개조하기
컨텍스트 주입(Context injection)세션 시작 시 관련 설정·기억 파일을 자동으로 불러오는 것회의 시작 전 참고자료를 미리 깔아두는 것
트래젝토리(Trajectory)프롬프트 처리 과정의 중간 단계를 시각화한 로그배달 앱의 실시간 이동 경로 표시
컴팩션(Compaction)긴 대화 내용을 요약·압축해 용량을 줄이는 처리옷장 정리하며 부피를 줄이는 것
오픈라우터(OpenRouter)여러 AI 모델을 한 API로 골라 쓸 수 있게 해주는 중개 서비스여러 통신사를 한 앱에서 비교·가입하는 것
