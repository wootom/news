02핵심 기능 구조

  • 셀프호스팅 인터페이스: 채팅·자율 에이전트·툴·모델 서빙·이메일·리서치를 한 서버에 통합
  • 구성 요소: Chat, Agents, Tools & MCP, Cookbook, Deep Research, Email Assistant, Memory, Skills
  • 모델 연결: 로컬(Ollama) 또는 클라우드 호스팅 모델 중 선택, 챗에 API 엔드포인트 붙여넣어 등록
  • 오픈소스: GitHub repo 클론 후 디렉터리 진입해 즉시 실행, VPS 구성도 가능

03기술적 맥락 — Docker 컨테이너 구조

  • ODCS·Ollama·Traefik(라우팅) 등이 각각 별도 Docker 컨테이너로 동작
  • 두 컨테이너(ODCS·Ollama)를 docker network connect로 연결해 내부 통신
  • Ollama 컨테이너 터미널에서 모델 pull·run, 다운로드 후 ODCS 설정에 로컬 엔드포인트 등록
  • 테스트 모델: Qwen 3 8B(약 5.2GB), GPT-OSS 20B(약 13GB) — VPS에서 1~2분 내 다운로드

04전략적 의미

  • "워크스페이스 콘텐츠 전부를 내가 소유" — 대화가 서버 밖으로 안 나가 AI사 학습에 미사용
  • 프라이버시·데이터 주권을 핵심 가치로 내세운 PewDiePie의 오픈소스 운동
  • 고사양 PC 없는 사용자도 VPS+원클릭 템플릿으로 진입장벽 대폭 완화

05핵심 워크플로우 — VPS 원클릭 + 로컬 모델 연결

단계내용
VPS 배포Hostinger "Deploy Odysseus in one click" 템플릿 선택(KVM2: 2코어·8GB·100GB)
접속Docker Manager에서 ODCS 컨테이너 Open → admin 계정 로그인
Ollama 추가Docker Compose 원클릭 deploy로 Ollama 컨테이너 구성
모델 받기Ollama 터미널에서 ollama pull qwen3:8b 등 모델 다운로드·실행
컨테이너 연결docker network connect로 ODCS↔Ollama 연결(컨테이너 접미사 치환)
모델 등록ODCS 설정 → Add Models → Local → 엔드포인트 URL 입력 → Test → Add
사용드롭다운에서 모델 선택해 채팅, 추가 모델(GPT-OSS 등)도 동일 방식

06활용 시나리오

  1. 프라이버시 챗봇: 민감 대화를 클라우드 없이 내 VPS 로컬 모델로만 처리
  2. 멀티모델 스위칭: Qwen·GPT-OSS 등 여러 오픈웨이트 모델을 받아 드롭다운으로 즉시 교체
  3. 통합 AI 워크스페이스: 리서치·이메일·에이전트·메모리를 한 서버에서 자체 운영

07현황 및 전망

  • 한 번의 클릭으로 VPS+모델 구축 가능할 만큼 셀프호스팅 진입장벽 낮아짐
  • 후속 영상에서 ODCS 다양한 활용 사례 예고
