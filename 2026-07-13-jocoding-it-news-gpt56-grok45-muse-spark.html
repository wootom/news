01핵심 개요

채널소재핵심결론
조코딩 JoCodingOpenAI GPT-5.6 출시 및 동시 다발 신제품 러시GPT-5.6(Sol/Terra/Luna), ChatGPT Work, GPT Live 동시 공개 — 비용 대비 성능 강조종합 성능은 Fable 5가 근소 1위지만 비용 효율은 GPT-5.6이 압도적 우위
조코딩 JoCoding경쟁사 대응 및 신모델 러시Anthropic 액세스 연장·Opus 5 소문, Meta 뮤즈 스파크 1.1 클로즈드 전환, xAI Grok 4.5 저가 공개OpenAI·Anthropic·Meta·xAI 4강 체제 고착, 구글은 후발
조코딩 JoCoding로봇·정책·배포 도구 잡다 소식1X NEO 25자유도 손, KDI 일자리 자동화 포럼, 구글 커스텀 URL, Cloudflare Drop, Lingbot-World-2물리 AI·노동시장·배포 인프라 전방위로 발전 가속

02GPT-5.6 (OpenAI) 출시

  • 크기별 3종 체계 도입: Sol(대형)·Terra(중형)·Luna(소형) — 태양·지구·달 비유 명명
  • 슬로건은 "토큰당 더 많은 인텔리전스" — 가성비 전면 강조, Claude 대비 저렴·고성능 포지셔닝
  • 추론 강도 조절 옵션(Max/Ultra) 존재하나, Ultra는 성능 상향이 아닌 서브 에이전트 다중 활용 모드(토큰 소모 증가)
  • 빠름 모드: Cerebras 칩 협업으로 초고속 추론 지원
  • 객관 벤치마크(Artificial Analysis 종합점수): Fable 5가 60점으로 1위, GPT-5.6 Sol Max는 59점으로 근소 2위
  • 비용 효율(코스트-인텔리전스 지수)은 GPT-5.6 Sol이 Fable 5 대비 약 2.7배 우위
  • 에이전트 라스트 이그젬(Agent Last Exam) 벤치마크에서는 Fable을 상회하는 결과 확인
  • 디자인·프론트엔드 UI 생성 능력 대폭 향상 — 세일링 게임, 3D 게임, PPT, 인터랙티브 웹사이트 제작 사례 다수
  • 지식업무 강점: 문서·Slack·Notion·Microsoft 365·Google Drive의 뒤섞인 컨텍스트를 정리해 전문가 수준 산출물로 반환
  • 화제 사례: GPT-5.6 Sol이 CUA(컴퓨터 유즈 에이전트)로 Blender를 마우스 조작해 3D 오브젝트 직접 제작(가속 영상 아님), 복셀 기반 맨해튼 재현, 구글 어스 클론, 10분 만에 플라이트 시뮬레이터 제작 등
  • 출시 첫날 데스크톱 앱 성장률이 직전 2주 합산치를 상회

03ChatGPT Work (OpenAI) 신규 공개

  • 코덱스(Codex) 기술을 기반으로 한 일반 사무직용 에이전트 제품 — Anthropic Cowork에 대응하는 포지션
  • 단순 질문·답변을 넘어 앱·파일·브라우저를 오가며 에이전틱 업무(자료 조사, PPT 작성, 문서 취합) 수행
  • Slack, Microsoft Teams, Google Drive, SharePoint, 이메일, 캘린더 등 업무 컨텍스트 연동 지원
  • 웹·모바일·데스크톱 앱에서 모두 사용 가능하며 무료 플랜 포함 전 플랜에 제공
  • ChatGPT 내 '챗 모드'와 '워크 모드'를 전환하며 사용하는 구조

04GPT Live 음성 모델

  • 계단식(STT→LLM→TTS) 및 턴 기반 음성 시스템의 한계를 넘어 백그라운드 사고 + 동시 발화(끊임없는 상호작용) 구현
  • 사람처럼 자연스러운 추임새 삽입, 대화 중 복잡한 작업을 서브 에이전트에 위임하고 결과를 이어받아 응답 가능
  • GPT Live 1(고지능)·GPT Live mini(경량·고속) 2종 모델 공개, 무료 버전에도 개방
  • 라이브 데모에서 한↔영 동시통역 수행 사례 확인(현장 시연 중 일부 접속 오류 발생)

05코덱스 AMA(Ask Me Anything) 요약

  • 코덱스 주간 사용자 500만 명 이상, 3개월 만에 2배 성장
  • 데스크톱용 GUI 앱 개발 진행 중(출시 시점 미정)
  • 자동 모델 라우팅 기능은 현재 부재(모델 수동 지정 방식)
  • GPT-5.6은 UI·프론트엔드 작업에 특화 훈련됨을 공식 확인
  • 일반 대화는 에이전트 사용 허용량을 소모하지 않음
  • 벤치마크 치팅을 실제 문제로 인정하고 평가 시 페널티 부여, 독립 벤더로 검증 중이라고 설명

06Anthropic 대응 동향

  • GPT-5.6 출시에 맞서 Claude Fable 5 접근권을 7월 12일까지 연장(이용자 이탈 방지 전략으로 추정)
  • 폴리마켓 기준 Opus 5가 이번 달 내 출시될 확률 78%로 형성된 소문 확산
  • 클로드 데스크톱 앱에 인앱 브라우저 기능 추가 — 코덱스와 유사한 방향으로 수렴 진화
  • 루프 엔지니어링(Loop Engineering) 개념 관련 블로그 공개 — 턴 기반·목표 기반·시간 기반·사전 예방적 루프 등 네 가지 설계 방식 소개

07Grok 4.5 (xAI)

  • 스페이스X 코딩 에이전트·지식 업무를 겨냥해 xAI 최상위 모델로 공개, GB300 GPU 수만 개로 훈련
  • 소프트웨어 엔지니어 마라톤 벤치마크에서 Fable을 상회하는 1위 기록
  • 초당 약 80토큰(TPS)의 높은 처리 속도, 출력 토큰 6달러 수준의 저렴한 가격 강조
  • 태양계 시뮬레이터, PPT 등 제작 사례 시연
  • 일론 머스크가 한국 식당 간판(모호한 필기체)을 인식해 상호를 추론한 사례를 직접 홍보
  • Artificial Analysis 지능 지표에서 구글을 앞서는 위치까지 상승

08메타 뮤즈 스파크 1.1

  • 벤치마크에서 제미나이 3.1 Pro, 오퍼스 4.8, GPT-5.5와 견주거나 상회하는 성능 확인
  • 오픈소스 정책 폐기, 클로즈드 소스 전환 — Llama 계열과 달리 API·자사 툴에서만 접근 가능
  • 100만 토큰 컨텍스트 창 지원, 컴퓨터 유즈·코딩 등 에이전틱 작업에서 강점
  • 동시에 뮤즈 이미지(이미지 아레나 2위)·뮤즈 비디오(시덴스 대비 근소 열세, 옴니 플래시와 유사 수준) 모델도 공개
  • Artificial Analysis 기준 OpenAI·Anthropic·xAI와 함께 프론티어 4강 구도 형성(구글은 아직 후발)

09AI 기업 간 신경전

  • 애플이 오픈AI를 고소 — 전 애플 직원이 이직 과정에서 애플 내부 기밀 자료를 요청받았다는 의혹
  • 일론 머스크와 샘 알트만이 SNS에서 상호 비방("스캠 알트만" 등) — 우주 데이터센터, 애플 기술 유용 의혹 등 공방
  • 결론적으로 경쟁 심화가 GPU 수요 증가로 귀결되어 엔비디아 젠슨 황이 수혜를 본다는 풍자 밈 확산

101X NEO 로봇 손 데모

  • 25 자유도(DOF) 손 신규 공개, "휴머노이드 컴퓨터 API 핸드"로 소개
  • 전구 교체, 포도 수확, 레고 조립, 게임 컨트롤러 조작, 20kg급 물체 들기, 스스로 충전 등 정교한 동작 시연
  • 사람 손 수준에 근접한 물리적 조작 능력 확보, 두뇌(제어 지능) 영역이 다음 과제로 평가됨

11Google 배포 도구 소식

  • AI Studio 커스텀 URL: 바이브 코딩 결과물을 퍼블리시하면 기억하기 쉬운 고유 도메인 부여, 손쉬운 공유 가능
  • Cloudflare Drop: 로그인 없이 폴더/파일을 드롭하면 즉시 배포, 1시간 한시적 유지(로그인 시 클레임해 영구 연결 가능) — 피싱 등 악용 우려 지적
  • Cloudflare 정책 변화: Workers도 정적 콘텐츠 무료 제공으로 확대되어 Pages 대신 Workers 사용 권장 추세

12기타 소식

  • Lingbot-World-2: 중국발 오픈소스 월드 모델, 키보드 입력으로 실시간 프레임 생성 탐험 가능(파도타기, 유성우, 석양 등 인터랙티브 씬 구현), 허깅페이스 공개
  • 완스트리머 0.2: 실시간 상호작용 영상 생성 모델 업그레이드, 해상도 향상에도 약 0.2초 레이턴시 유지
  • TTS-Bench: 여러 오픈소스 TTS 모델(키, 코코로, 슈퍼톤 등) 성능을 비교 평가할 수 있는 레포 공개
  • KDI '일의 미래' 포럼(7월 9일): 2030년까지 일자리의 90%에서 업무 90%가 기술적 자동화 가능하다는 전망 발표. 청년·신규 진입자의 경력 사다리 약화 우려, 사회안전망·평생학습·AX(AI 전환) 논의 필요성 제기, AI를 인력 감축용 자동화가 아닌 역량 증강 도구로 설계할지가 쟁점

13활용 시나리오

  1. 디자인·프론트엔드 제작 업무: PPT, 웹사이트, 인터랙티브 UI 제작 시 GPT-5.6을 활용해 품질과 속도를 동시에 높인다.
  2. 비개발자 사무 자동화 도입: 코딩 지식 없는 사무직이 ChatGPT Work로 문서 취합·자료조사·일정 연동 등 에이전틱 업무를 위임한다.
  3. 저비용 대량 코딩/에이전트 운용: 예산이 민감한 반복 코딩·다중 에이전트 작업에는 Grok 4.5의 가격·속도 이점을 활용한다.
