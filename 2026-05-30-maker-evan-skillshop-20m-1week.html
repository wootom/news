01핵심 개요

항목내용
채널메이커 에반
서비스스킬샵 (AI 에이전트용 스킬 마켓플레이스)

핵심 도구클로드 코드 + 바이브 코딩

02핵심 내용 구조

  • 서비스 정체 — Claude Code·Cursor용 스킬을 사고파는 마켓플레이스
  • 7일 개발 — 1일 기획(노코드 대화) + 6일 화면·결제·대시보드 구현
  • 2천만 원 매출 — 오픈 7일간 정산 결제 합계
  • 비용 거의 0 — 클로드 맥스 구독 + 배포(Vercel·Railway) 합산 약 10만원
  • 핵심 도구 — Claude Code + 바이브 코딩 워크플로우
  • 확산 메시지 — "작게 빠르게 던지고 시장 반응 확인" 사이클이 핵심

03기술적 맥락

  • 스킬(Skill) 개념 — AI 에이전트에 끼우는 외부 능력 패키지
  • 마켓플레이스 구조 — 판매자(스킬 업로드·정산) + 구매자(검색·결제)
  • 자동 부가가치 — 한국어 소개·썸네일 자동 생성 (LLM 활용)
  • 결제 연동 — 결제 모듈 디버깅을 AI에게 에러 메시지 통째로 던지는 방식
  • 풀스택 단독 개발 — 디자인·기획·DB·결제 전부 1인 + AI 페어 프로그래밍

04전략적 의미

  • 3대 장벽 동시 붕괴 — 기술·시간·비용이 한꺼번에 1/10 수준으로 감소
  • MVP 검증 사이클 단축 — 몇 달 → 며칠 → 시장 반응 즉시 측정
  • 인디 해커 르네상스 — 1인 창업·소호 비즈니스 진입 장벽 급감
  • 스킬 생태계 부재 — 90%가 비동작 쓰레기 → 큐레이션 마켓 수요
  • 노트 속 아이디어 실현 — 미실행 아이디어를 빠르게 검증 가능

05핵심 워크플로우

단계내용
Day 1코파운더와 AI 대화로 기획 (화면 수·결제·기능)
Day 2~6화면별 구현 (목록·상세·결제·판매자 대시보드)
Day 6결제 연동 디버깅 (에러 → AI에 그대로 질문 → 수정)
Day 7오픈
Day 8~14매출 누적 2천만 원, 판매자·구매자 동시 유입

06활용 시나리오

  • 개인 불편 해결 도구 — 일상 귀찮은 작업 자동화하는 작은 페이지부터 시작
  • 가계부 정리 페이지 — 영수증·카드 내역 자동 정리 도구
  • 친구 모임 계산기 — n빵 정산·환율 계산 페이지
  • MVP 시장 검증 — 아이디어 1주일 안에 시장에 던지고 반응 측정
  • 스타터 키트 판매 — 바이브 코딩 보일러플레이트(Next·Tailwind·Supabase) 자체 판매

07현황 및 전망

  • 개발자 배경 인정 — 화자도 기존 개발 경험 있음, 단 AI로 1주일 단축
  • 진입 장벽 변화 — 10년 개발 경험 필요 → 기초만 있어도 가능
  • 바이브 코딩 학습 곡선 — 며칠~몇 주면 감각 확보
  • 강의·콘텐츠 확장 — 스타터 키트 + 후속 강의 오픈 예정
  • 다음 단계 전망 — 작게 빠르게 → 반응 보고 키우는 사이클이 표준

084단계 실행 가이드 (시청자용)

단계행동
1. 만들 것 정하기거창하지 말고 내 불편 하나, 한 문장으로 정의
2. AI에 던지기Claude·Cursor에 "어떻게 시작해?" 단계 분해 요청
3. 막힘 대처에러 메시지 통째로 복사 → AI에 "왜 이래?" 질문
4. 빨리 내놓기완벽 추구 금지 → 출시 후 사용자 반응으로 학습
