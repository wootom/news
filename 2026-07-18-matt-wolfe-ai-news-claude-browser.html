02주요 뉴스 정리

Claude Code, 데스크톱에 인앱 브라우저 추가

Anthropic이 Claude Code 데스크톱 앱에 인앱 브라우저를 추가했다. ChatGPT 앱이 브라우저 기능을 내장한 지 며칠 만에 나온 업데이트다. 일반 채팅이 아닌 Claude Code 프로젝트 화면에서만 사용 가능하며, Cmd+Shift+B 단축키나 우측 상단 브라우저 아이콘으로 열 수 있다. 화면 요소를 클릭해 선택하면 좌측 코드에서 해당 요소가 하이라이트되고, "버튼 텍스트를 바꿔줘" 같은 지시로 실제 코드 수정까지 이어진다. 또한 브라우저 접근 권한이 있으면 X(트위터)처럼 API 비용이 비싼 사이트도 API 없이 직접 스크롤하며 정보를 수집할 수 있다.

Google, 검색·Vids에 AI 기능 확장

  • AI 모드 앱 연결: Google Gemini에 이미 연결된 여러 앱을, 이제 검색의 AI 모드에서도 프롬프트 기반으로 자동 연결할 수 있다. 예: "장보기 목록을 만들어서 장바구니에 담아줘"라고 하면 Instacart 앱을 찾아 연결을 제안한다.
  • Google Vids + Gemini Omni: 슬라이드 프레젠테이션형 영상 제작 도구인 Google Vids에 Gemini Omni가 결합돼, 슬라이드를 실제로 애니메이션화할 수 있게 됐다. 대화로 영상을 수정하는 기능도 추가됐고, 사용자의 아바타를 영상에 삽입하는 기능(예: 생일 축하 영상)도 새로 생겼다.
  • Google 이미지 검색 25주년 리뉴얼: Pinterest처럼 저장 이력을 학습해 이미지를 추천하는 기능과, google.com에서 바로 이미지를 생성하는 기능이 "곧" 출시 예정이다.
  • Notebook LM → Gemini Notebook으로 리브랜딩: 제품은 동일하지만 이름이 바뀐다.

Spotify, 대화형 AI 베타 출시

Spotify 프리미엄 사용자 대상으로 홈 화면과 재생 화면에서 텍스트/음성으로 대화하며 음악을 탐색하는 기능이 베타로 출시됐다. 시연에서 "2년 전에 뭘 들었는지 알려주고 그 스타일의 플레이리스트를 만들어줘"라고 요청하자 청취 기록을 분석해 로파이 계열 플레이리스트를 생성했다. 아티스트 스타일 설명(예: Tosho — 로파이 힙합/코지 인스트루멘탈)도 대화로 제공한다.

ByteDance Seedream 5.0 Pro (지난주 소식 후속, Art List 스폰서 구간)

참조 이미지 최대 5장으로 캐릭터·제품·색감·구도·스타일을 제어할 수 있는 멀티모달 이미지 생성기. 추론 능력이 강화돼 인포그래픽, UI 목업, 광고, 읽을 수 있는 텍스트가 포함된 이미지 생성이 가능하다. Art List 플랫폼에서 바로 사용 가능.

신규 오픈웨이트 LLM 3종

모델개발사특징
InklingThinking Machines Labs (Mira Murati 창업)첫 공개 모델, 952B 파라미터, 약 2TB 파일 크기, 오픈웨이트지만 벤치마크상 최상위권은 아님. GLM 5.2에 추론·에이전틱 코딩 전 항목에서 밀림
Bonsai 27BPrism ML1비트 초압축 모델, 약 4GB, 27B 파라미터로 폰에서 구동 가능한 최대급. 코드 생성은 사실상 불가, Hugging Face 데모에서 94 tokens/sec
Kimi K3Moonshot AI이번 달 중 오픈웨이트 예정, 2.8조(2.8T) 파라미터로 최초의 오픈모델. 코딩 벤치마크(deepu)에서 5.6 Sonnet·Fable 바로 다음 순위, GPT-5.5·Opus 4.8·GLM 5.2보다 우위. Terminal Bench에서는 Fable 5도 능가

라피드 파이어 (짧은 소식 모음)

  • Grok Build 오픈소스화: xAI의 코딩 에이전트 겸 터미널 UI가 GitHub에 공개됨
  • Grok에 자동화(Automations) 추가: Claude·ChatGPT Codex처럼 일정 기반 반복 작업("루프") 설정 가능. 매일 트리거, 이메일 수신 트리거 등 지원
  • ChatGPT 검색 기능 개선: 웹/iOS/Android에서 채팅·프로젝트·이미지·문서를 한 곳에서 검색 가능, 필터 지원
  • Claude, 1Password 연동: 로그인이 필요한 작업을 자격 증명 노출 없이 대신 수행. 비밀번호는 Claude로 전송되거나 학습에 사용되지 않음
  • DoorDash CLI 출시: OpenClaw·Hermes·Codex 등 AI 에이전트가 DoorDash로 주문 가능(매장 검색, 최저가 비교, 결제). 미국·캐나다 대기자 명단 운영 중
  • Meta, Instagram 인물 태그 이미지 생성 기능 롤백: 지난주 소개된 기능이 배우·크리에이터들의 반발로 1주일도 안 돼 철회됨
  • 새 Siri 롤아웃 시작: 애플워치에도 AI 기능이 적용되며 초기 반응은 긍정적
  • Anthropic, Claude for Teachers 출시: 미국 K-12 인증 교사 대상 프리미엄 Claude 무료 제공, 교육 스킬 라이브러리와 근거 기반 커리큘럼 연동 포함
  • OpenAI 첫 하드웨어 출시: Work Louder와 협업한 Codex 전용 키패드 "Codex Creator Micro", openai.com/supply에서 230달러에 판매. 스크린 없는 스마트 스피커형 기기도 소문 단계로 개발 중이라는 보도(미확정)
  • OpenAI vs Apple 소송: Apple이 전직원의 이직 및 영업비밀 유출을 주장하며 OpenAI를 제소, OpenAI는 근거 없다고 반박
  • 뉴욕주, 데이터센터 모라토리엄 시행: 50메가와트 이상 하이퍼스케일 데이터센터에 대한 신규 환경 허가를 최대 1년간 중단, 에너지 가격·환경영향 규제 마련 시간 확보 목적
  • Sunrun, 가정용 분산 AI 컴퓨트 파일럿: 태양광·배터리 시스템에 미니 컴퓨트 노드를 결합해 가정에 배치하고, AI 기업이 이를 활용하는 대가로 가입자에게 보상 지급

03기술적 맥락

  • 에이전트의 "눈" 확장: Claude Code의 인앱 브라우저와 Claude-1Password 연동은 모두 에이전트가 웹 UI를 직접 조작·인증하는 방향으로, API 의존도를 낮추고 실제 화면 기반 자동화(computer use류)를 강화하는 흐름과 맞닿아 있다.
  • 오픈웨이트 모델 스펙트럼 확대: 952B(Inkling)부터 27B 1비트 압축(Bonsai, 온디바이스용)까지, 그리고 2.8T(Kimi K3, 클라우드 전용)까지 오픈웨이트 모델의 크기·타깃 디바이스가 양극화되고 있다.
  • 분산 컴퓨트 실험: Sunrun의 가정용 컴퓨트 노드 파일럿은 대형 데이터센터 중앙집중형 인프라의 대안으로, 크라우드소싱형 컴퓨트 공급 모델을 시사한다.

04전략적 의미

  • Anthropic은 Claude Code에 브라우저를 통합해 개발자 워크플로우 내 "웹 조작 에이전트"로서의 입지를 강화하고 있으며, 이는 OpenAI의 ChatGPT 앱 브라우저 기능에 대한 즉각적 대응 성격이 강하다.
  • Spotify·Google Vids·Google 검색 등 소비자 서비스 전반에 대화형 AI 인터페이스가 확산되며, "프롬프트로 조작하는 앱"이 표준 UX로 자리잡는 중이다.
  • 오픈웨이트 모델 경쟁(Kimi K3, GLM 5.2, Inkling)은 폐쇄형 최상위 모델(Sonnet 5.6, Fable 5, Opus 4.8, GPT-5.5)과의 격차를 빠르게 좁히고 있으며, 특히 코딩·에이전틱 벤치마크에서 오픈모델의 상위권 진입이 가시화되고 있다.
  • 뉴욕주 데이터센터 모라토리엄은 AI 인프라 확장에 대한 규제 리스크가 현실화되는 신호로, 다른 주의 후속 조치 여부가 인프라 투자 지형을 바꿀 수 있다.

06활용 시나리오

  1. 개발자: Claude Code 인앱 브라우저로 실제 배포 사이트를 열어 UI 요소를 클릭해 바로 텍스트/스타일 수정을 요청하고, X 같은 API 비용이 높은 사이트에서 리서치 자동화에 활용
  2. 콘텐츠 크리에이터: Seedream 5.0 Pro로 참조 이미지 기반 인포그래픽·광고 이미지·읽을 수 있는 텍스트 포함 이미지를 Art List에서 제작
  3. 교사: Claude for Teachers로 K-12 커리큘럼 연계 수업 자료를 무료로 제작
  4. 바쁜 직장인: Spotify 대화형 AI로 "2년 전 듣던 스타일 플레이리스트 만들어줘" 같은 자연어 요청으로 음악 큐레이션
  5. 에이전트 사용자: 1Password 연동 Claude나 DoorDash CLI를 통해 로그인이 필요한 작업이나 음식 주문을 에이전트에 위임(단, 대기자 명단 상태 확인 필요)

07현황 및 전망

지난주(새 앱들, 음성 모드, 신모델, Fable 사용시간 연장 등)에 비해 이번 주는 비교적 조용한 한 주였다고 진행자는 평가한다. 다만 Kimi K3는 아직 오픈웨이트가 공개되지 않아 다음 주 이후 실제 벤치마크(BeautyBench 등) 검증이 예상되며, OpenAI의 스크린리스 스마트 스피커는 아직 루머 단계로 Apple과의 소송전과 맞물려 주목할 필요가 있다. 뉴욕주의 데이터센터 규제가 다른 주로 확산될지, Sunrun의 분산 컴퓨트 파일럿이 실제 채택으로 이어질지도 지켜볼 지점이다.
