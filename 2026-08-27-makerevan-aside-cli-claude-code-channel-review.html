02핵심 기능/내용 구조

  1. 클로드 코드의 웹 탐색 한계 진단 (00:00) — 화자는 유튜브 채널 8개를 찾는 작업(사람이 하면 30분 걸리는, 채널에서 채널로 계속 넘어가야 하는 작업)을 클로드 코드에 시켰으나 결과가 "처참"했다고 밝힌다. 엉뚱한 데이터가 섞여 나온 것이 문제였다.
  1. 왜 안 되는지 3가지 구조적 원인 (00:51) — 첫째, 클로드 코드는 페이지를 텍스트로 변환해서 가져오는데 유튜브처럼 화면이 자바스크립트로 그려지는 사이트는 텍스트 변환 시 껍데기만 남아 구독자 수·관련 채널 목록이 안 보인다. 둘째, 클로드 코드가 가져오는 페이지는 로그아웃 상태라서 로그인 상태에서만 노출되는 관련 채널 추천 정보를 애초에 볼 수 없다. 셋째, 한 페이지씩 개별적으로 가져올 뿐 "여기서 저기로 넘어간다"는 개념 자체가 없어서, 검색 결과를 거르지 않고 그대로 덮어써 버린다. 그 결과 10년 전 영상, 구독자 100명짜리 채널, 코딩과 무관한 채널, 심지어 같은 채널 중복까지 섞여 나왔다.
  1. Aside 브라우저와 Aside CLI 소개 (01:41) — Aside는 Y콤비네이터 출신 회사가 만든, 크롬과 같은 뿌리(크로미움 기반)를 쓰는 브라우저로 현재 맥에서만 동작한다. 외형은 일반 브라우저와 같지만 옆에 채팅창이 붙어 있어 그곳에 지시하면 브라우저가 직접 클릭·타이핑을 수행한다. 이미 로그인해 둔 세션을 그대로 재사용하기 때문에 별도 연동 절차가 없다. 공식 활용 예시로는 로그인이 걸린 대시보드 확인, 실패한 빌드 로그 열람, 스테이징 화면 스크린샷 촬영 등이 제시된다. 설치는 스크립트 한 줄 또는 설정 화면 버튼으로 가능하며, 설치 후 명령어는 aside(A사이드)로 큰따옴표 안에 한국어로 지시문을 작성해 실행한다.
  1. 핵심 옵션 3가지와 울트라브라우즈 모드 (02:57) — 모델 선택 옵션(클로드 또는 다른 모델), 생각의 깊이 옵션(꺼짐부터 최대 단계까지 있으며 맨 끝이 울트라브라우즈), 세션 이어붙이기 옵션(터미널을 껐다 켜도 조사를 이어감, 계정별로도 골라 쓸 수 있음)이 핵심이다. 울트라브라우즈는 자료가 여러 페이지에 흩어져 있을 때 쓰는 모드로, 공식 설명상 "근거가 많이 필요한 조사, 페이지 사이의 비교"에 해당하며 이 영상에서 다루는 "파도타기" 작업이 바로 이 모드의 용례다.
  1. 실전 시연: 70개 수집 후 8개로 압축 (04:34) — 실제로 "AI 코딩 다루는 한국 채널에서 시작해 관련 채널로 계속 옮겨가며 구독자 1만 명 넘는 채널 8곳을 표로 정리하라"고 지시하자, 방문 기록에서 시작 채널을 찾고 유튜브 검색·채널 페이지 구조 확인·인기 영상 열람·관련 채널 진입을 반복했다. 1차로 40여 채널, 2차까지 총 70개를 모은 뒤 그대로 주지 않고 구독자 수와 대표 영상을 하나씩 실제로 확인해 8개로 걸러냈다. 클로드 코드는 이런 "거르는 단계" 없이 모은 것을 그대로 주는 것과 대비된다. 진행 중에는 한국어로 "파도타기 1차에서 40여개 수집" 같은 실시간 보고가 이뤄져 화자가 중간에 개입할 수 있었다.
  1. 결과물과 스스로 만든 판단·증빙 (05:26) — 최종적으로 채널명·구독자 수·대표 영상 주소가 담긴 표 8행이 나왔고(11만·9만·최소 18,000명 등), 그중 한 곳을 별도로 추천했다. 추천 근거는 "구독자는 적지만 대표 영상 조회수가 20만으로 구독자 대비 배율이 약 10배로 가장 높아 협업 제안하기에 적합하다"는, 시키지 않은 자체 판단이었다. 나아가 채널 페이지를 직접 열어 구독자 수 스크린샷을 증빙으로 남기고 나머지 캡처는 폴더에 저장했다. 전체 과정은 6분 50초가 걸렸다.

03기술적 맥락

클로드 코드의 웹 접근 방식은 "페이지를 텍스트로 변환해서 읽는" 구조다. 이는 정적 텍스트 위주 페이지에서는 문제가 없지만, 유튜브처럼 콘텐츠가 자바스크립트 렌더링으로 그려지는 사이트에서는 변환 시점에 실제 데이터(구독자 수, 관련 채널 목록)가 비어 있는 "껍데기"만 남는다. 또한 클로드 코드가 페이지를 가져오는 방식은 비로그인 상태로 동작하므로, 유튜브의 관련 채널 추천처럼 로그인 세션에 종속된 개인화 정보는 원천적으로 접근 불가능하다. 마지막으로 클로드 코드는 "한 페이지 단위 요청"만 처리할 뿐 페이지 간 이동(내비게이션)이라는 개념이 없어, 여러 페이지를 넘나들며 판단해야 하는 작업에서는 검색 결과를 필터링 없이 그대로 반환하는 한계를 보인다.

Aside는 이 세 가지 문제를 "실제 브라우저를 대신 조작한다"는 접근으로 해결한다. 크로미움 기반 브라우저이므로 자바스크립트 렌더링을 그대로 처리하고, 사용자가 이미 로그인해 둔 세션을 재사용하므로 로그인 전용 정보에도 접근하며, 브라우저가 페이지 간 클릭·이동을 직접 수행하므로 "여기서 저기로 넘어가는" 탐색이 가능하다. 다만 이는 검색 API가 아니라 실제 브라우저 조작이라는 점이 강조되는데, 이 때문에 방문 기록을 참조하거나(설정에서 끌 수 있음) 운영 환경(로그인 계정) 설정을 건드리지 않는다는 공식 문서상 제약도 함께 따른다. 속도 면에서는 브라우저가 실제로 페이지를 열고 읽는 방식이라 느리며, 이번 시연도 6분 50초가 소요됐다.

04전략적 의미

이 영상이 시사하는 핵심은 "클로드 코드와 Aside는 경쟁 관계가 아니라 분업 관계"라는 점이다. 클로드 코드는 코드를 고치는 데 강하고, Aside는 로그인된 웹을 여러 페이지에 걸쳐 돌아다니며 자료를 모으는 데 강하다. 화자는 이를 "둘 다 잘하는 도구가 아니라 각자 잘하는 게 다른 도구"라고 명확히 구분하며, 코드 작업을 Aside에 시키는 것은 권장하지 않는다고 못 박는다.

더 나아가 이 조합은 "사람이 브라우저를 열어 자료를 긁어다 코드 도구에 붙여넣는 단계"를 완전히 없앤다는 점에서 워크플로우 자동화의 의미가 크다. MCP로 Aside를 클로드 코드에 도구로 등록하면, 클로드 코드가 필요할 때 자동으로 Aside를 호출해 웹 자료를 파일로 받아 그대로 활용할 수 있다. 이는 AI 에이전트가 "브라우저 조작"이라는, 기존에는 사람만 할 수 있었던 영역까지 위임받는 흐름을 보여주는 사례다. 동시에 화자는 결과를 맹신하지 말고 원본을 직접 확인하라는 경고, 자체 성능 발표에 대한 유보적 태도 등 과신을 경계하는 균형 잡힌 시각도 함께 제시한다.

06활용 시나리오

  1. 경쟁·협업 채널 리서치: 특정 주제(예: AI 코딩) 한국 채널을 시작점으로 관련 채널을 연쇄적으로 탐색해 구독자 조건에 맞는 후보를 표로 정리하고, 구독자 대비 조회수 배율 등 자체 기준으로 협업 제안 우선순위까지 추천받는다.
  2. 로그인 필요 대시보드/빌드 로그 확인: 공식 활용 예시로 제시된 것처럼, 로그인이 걸린 내부 대시보드 확인이나 실패한 빌드 로그 열람, 스테이징 화면 스크린샷 촬영처럼 개발자가 편집기 밖에서 반복 수행하던 잡무를 자동화한다.
  3. 클로드 코드 파이프라인 내 자료수집 단계: MCP로 Aside를 등록해, 코드 작업 도중 외부 웹 자료가 필요할 때 클로드 코드가 자동으로 Aside를 호출해 파일로 받아오게 함으로써 사람의 개입 없이 자료수집→코드반영 흐름을 완성한다.
  4. 정해진 절차의 반복 작업(리플): 탭 열기, 요소 클릭, 스크린샷 등 순서가 고정된 작업은 리플 방식으로 자바스크립트 직접 조작을 활용해 플레이라이트처럼 정확하게 반복 수행한다.

07현황 및 전망

현재 Aside는 맥 전용으로만 동작해 윈도우 사용자는 이용할 수 없으며, 핵심 기능인 울트라브라우즈 모드는 유료 요금제에서만 제공된다(무료 요금제는 안내 화면만 노출). 속도 면에서도 브라우저가 실제로 페이지를 열람하는 방식 특성상 느리고, 이번 시연도 6분 50초가 소요돼 빠른 답이 필요한 상황에는 맞지 않는다. 화자는 "아직 어린 물건"이라 버전이 계속 바뀌며 오늘 되던 동작이 내일 달라질 수 있다는 불안정성도 언급했다.

신뢰성 측면에서는 두 가지 유보 사항이 강조된다. 하나는 결과를 그대로 믿지 말라는 것으로, 브라우저가 화면을 읽어 옮긴 숫자이므로 표만 보면 다 맞아 보이지만 원본 채널을 직접 열어 확인해야 한다. 다른 하나는 "성능 1위" 같은 자체 발표 수치는 회사 자체 발표일 뿐이라는 점이다. 또한 시킨 것보다 많은 결과를 주는 경향(8곳 요청에 11곳 추가 제공)과 증빙 이미지 생성 중 세 번 연속 실패했다가 스스로 다른 방법으로 복구한 사례도 실사용상 유의점으로 제시됐다. 전망 측면에서 화자는 "자료는 Aside가, 코드는 클로드 코드가" 나누는 조합이 현재로서는 가장 편한 방식이라 결론짓고, 처음 쓸 때는 작은 요약부터 시작하고 깊이를 목적에 맞게 조절하며 숫자가 나오면 항상 원본을 재확인하라는 3가지 팁을 제시하며 마무리한다.

울트라브라우즈(UltraBrowse)Aside의 생각 깊이 옵션 중 최상위 모드. 여러 페이지에 흩어진 자료를 근거 삼아 조사하거나 페이지 간 비교가 필요할 때 쓰며, 유료 요금제 전용 기능
MCP(Model Context Protocol)클로드 코드 같은 AI 도구가 외부 도구(여기서는 Aside)를 표준화된 방식으로 호출해 쓸 수 있게 하는 연동 프로토콜. 설정 파일에 몇 줄 추가하면 클로드 코드가 Aside를 도구로 부를 수 있다
리플(Repl)Aside 브라우저를 자바스크립트 코드로 직접 조종하는 방식. 탭 열기·요소 클릭·스크린샷 촬영 등을 정해진 순서대로 정확히 수행할 때 사용하며, 공식 문서는 이를 플레이라이트(Playwright, 웹 자동화 테스트 도구)에 비유한다
파도타기이 영상에서 화자가 사용한 표현으로, 한 채널의 관련 채널로 계속 넘어가며 새로운 후보를 발굴해가는 탐색 방식을 뜻한다
클로드 코드(Claude Code)앤트로픽의 터미널 기반 AI 코딩 에이전트. 코드 작성·수정에는 강하지만 텍스트 변환 방식의 웹 접근과 로그아웃 상태 접근, 페이지 간 이동 불가라는 한계로 인해 로그인 기반의 다단계 웹 조사에는 취약하다
