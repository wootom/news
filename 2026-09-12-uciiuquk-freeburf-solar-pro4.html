프리버프는 광고와 데이터 활용을 조건으로 AI 모델을 무료 제공한다.

프리버프 무료 AI 사용법과 프롬프트 광고 활용·GitHub 연결 주의점.

01핵심 개요

  • 프리버프는 매일 100프리버스를 제공하며, 잔여량은 24시간마다 한 번 리셋된다고 소개된다.
  • 업스테이지 Solar Pro 4는 시간당 0프리버스로 표시돼 일일 100프리버스 차감 없이 사용할 수 있다.
  • GLM 5.3은 시간당 5프리버스, GPT 루나는 시간당 20프리버스를 사용하는 모델로 제시된다.
  • 무료 사용의 대가로 입력 프롬프트가 광고 활용 재료가 되며, 작업 중 스폰서 광고가 표시된다.
  • GitHub 저장소를 클라우드에 연결하면 코드와 파일을 볼 수 있어 연결을 피하라고 권고한다.

02핵심 주장 / 논점 구조

  • 영상은 토큰 부족을 겪는 사용자를 위한 대안으로 프리버프 데스크톱·CLI·웹 서비스를 소개한다.
  • 프리버프는 Solar Pro 4, GLM 5.3 등 모델을 무료 또는 프리버스 방식으로 제공한다고 설명한다.
  • 다만 무료 사용은 프롬프트의 광고 활용과 광고 노출을 전제로 하며, 민감한 작업에는 주의가 필요하다.
  • 발표자는 간단한 문서 작업에 활용하되 GitHub 클라우드 연결과 중요한 문서 작업은 피하라고 권한다.

03일일 프리버스와 모델별 사용량

  • 프리버프에서는 매일 100개의 프리버스가 제공되고, 사용량은 24시간에 한 번 리셋된다고 안내한다.
  • 업스테이지 Solar Pro 4는 시간당 0프리버스로 표시돼 프리버스가 차감되지 않는 모델로 소개된다.
  • GLM 5.3은 시간당 5프리버스를 사용하며, 일일 100프리버스 기준으로 계산 가능한 모델로 언급된다.
  • GPT 루나는 시간당 20프리버스여서 100프리버스로 5시간 사용할 수 있다고 설명한다.
  • 영상에서는 Deep V4 Flash와 Meta의 MuseSpark도 프리버프에서 선택 가능한 모델로 언급한다.

04설치 방식과 작업 인터페이스

  • 프리버프는 데스크톱 앱, CLI 명령어 입력, 웹 사용 방식을 제공하는 것으로 소개된다.
  • 발표자는 Mac 데스크톱 앱을 설치했으며, Windows 사용자는 Windows 데스크톱을 사용할 수 있다고 말한다.
  • 프로젝트 폴더를 열어 코딩 작업을 진행할 수 있고, 빌드와 플랜 모드 두 가지가 보인다고 설명한다.
  • 파일과 이미지 첨부가 가능하며, 모델 선택 화면에서 남은 프리버스와 리셋까지의 시간이 표시된다.

05광고 기반 무료 사용 방식

  • 프리버프에서는 작업 화면에 Supabase, Magic Patterns 등 광고와 스폰서 메시지가 표시되는 사례가 제시된다.
  • 발표자는 사용자가 작성한 프롬프트가 광고에 활용되며, 프롬프트 내용에 맞춘 광고가 노출된다고 설명한다.
  • 강의안 노트를 인터랙티브 HTML PPT 파일로 만들어 달라고 입력하자 디자인 사이트인 Magic Patterns 광고가 표시됐다.
  • 프롬프트 진행 중마다 새 광고가 뜰 수 있으며, 파일 업로드 과정에서도 Supabase로 연결하는 광고 메시지가 나온다.

06Solar Pro 4 문서 작업 테스트

  • 발표자는 옵시디언의 강의학교용 DX 우선 노트를 넣고 인터랙티브 HTML PPT 파일 생성을 요청했다.
  • 테스트 중 Solar Pro 4는 필요한 사항을 계속 질문하며 진행하는 방식으로 동작했다고 평가됐다.
  • 작업 화면 하단에는 Solar Pro 4 사용 표시와 시간이 나타났고, 이 모델은 프리버스가 차감되지 않는다고 설명한다.
  • 결과물에 대해서는 업스테이지가 디자인을 잘하는 것 같지는 않다고 개인적 평가를 덧붙였다.

07개인정보 처리 방침과 GitHub 연결 위험

  • 발표자는 9월 2일 업데이트된 프리버프 개인정보 처리 방침을 반드시 읽어 보라고 강조한다.
  • 프롬프트는 광고 재료가 될 수 있으며, 중요 문서나 민감한 문서 작업은 이 서비스에서 하지 말라고 권한다.
  • 프리버프 클라우드에 GitHub 저장소를 연결하면 저장소 코드와 파일을 볼 수 있다고 설명한다.
  • GitHub 연결 후 프리버프를 삭제하더라도 연결 과정에서 수집된 데이터가 지워지지 않을 수 있다고 언급한다.
  • 기본값은 제3자나 모델 학습을 하지 않는 것이지만, 'May use data for AI training' 문구가 있으면 학습될 수 있다고 안내한다.
  • 권장 활용 범위와 최종 주의사항: 발표자는 프리버프가 완전히 무료처럼 보이지만 프롬프트와 데이터가 학습·광고에 활용될 수 있어 절대 무료만은 아니라고 말한다.
  • 권장 활용 범위와 최종 주의사항: 토큰을 아끼기 위한 간단한 문서 작업이라면 광고를 보는 조건으로 활용할 수 있다고 제안한다.
  • 권장 활용 범위와 최종 주의사항: 사용 전에는 학습 관련 라벨을 확인하고, 원하지 않는 경우 해당 사용을 피하라고 권고한다.
  • 권장 활용 범위와 최종 주의사항: 핵심 주의사항으로 프롬프트의 광고 활용, GitHub 클라우드 미연결, 학습 라벨 확인의 세 가지를 제시한다.

08용어 사전

용어뜻
프리버프광고 노출과 프롬프트 활용을 조건으로 여러 AI 모델을 무료 또는 프리버스 방식으로 제공한다고 소개된 서비스다.
프리버스프리버프에서 모델 사용량을 계산하는 단위로, 매일 100개가 제공되고 24시간마다 리셋된다고 설명된다.
Solar Pro 4업스테이지의 모델로 소개되며 프리버프에서는 시간당 0프리버스로 사용할 수 있다고 제시된다.
GLM 5.3최근 각광받는 모델로 언급됐으며 프리버프에서 시간당 5프리버스를 사용하는 것으로 설명된다.
GitHub 클라우드 연결프리버프 클라우드에 저장소를 연결하는 기능으로, 코드와 파일 열람 및 수집 데이터 문제 때문에 피하라고 권고된다.
