AI 에이전트가 쓸수록 똑똑해지는 성과 기반 학습 루프와 지시문 구조 설계

성과 점수화와 레시피 검증으로 AI 에이전트의 학습 루프를 설계하는 방법

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

모델 역할 분담과 지시문 층위 구조

  • 에이전트는 입력 문자를 딥시크 플래시로 분류하고, 세일 등 실행이 필요한 경우에만 비싼 모델을 호출해 계획을 세운 뒤 빠른 모델로 도구를 실행하는 역할 분담 구조를 사용한다.
  • 지시문은 고정 규칙, 사장님 선호, 잘된/안 된 게시물, 검증된 레시피, 최근 대화 순으로 층을 쌓아 위쪽 고정 내용을 프롬프트 캐시로 적중시켜 비용을 절감한다.
  • 대화가 8만 토큰 또는 30턴을 넘으면 앞부분을 요약으로 압축하고 최근 6턴만 유지하며, 선호와 포맷은 최대 50개, 일반 기억은 100개로 상한을 설정해 지시문 팽창을 방지한다.

성과 점수 계산과 레시피 검증 기준

  • 게시물 공개 24시간 후 좋아요, 댓글, 공유, 저장, 도달 데이터를 수집해 (좋아요 + 댓글*2 + 공유*3 + 저장*3) / 도달 공식으로 점수를 계산한다.
  • 계산된 점수를 해당 계정 최근 30개 게시물 점수의 중간값으로 나누어 평소 대비 배수를 구하며, 1.5배 이상이면 잘된 게시물로, 0.6배 이하면 안 된 게시물로 분류한다.
  • 잘된 게시물의 구조를 레시피로 저장하되 최대 12개만 유지하고, 세 번 이상 사용해도 평균 성적이 낮으면 은퇴시키며 지시문에는 상위 5개만 포함한다.

브랜드 추정과 경쟁사 분석 자동화

  • 브랜드 정보가 비어 있으면 계정 연결 시 최근 글 20개를 분석해 회사, 제품, 타깃, 말투 등을 추정하고 7일마다 재분석하며, 사용자가 직접 정한 값은 절대 덮어쓰지 않는다.
  • 사용자가 경쟁사 릴스 링크를 보내면 프레임 8장과 오디오를 추출해 훅, 장면 순서, 속도로 구성된 블루프린트를 생성하고, 이 구조를 기반으로 우리 제품 대본을 작성한다.
  • 매일 아침 7시 경쟁사 게시물을 훑어 구조를 빌려 영상을 생성하고 9시에 미리보기를 보내며, 영상 생성 실패 시 카드 뉴스로 대체해 사용자에게 항상 결과물을 전달한다.

현재 코드 한계와 데이터 삭제 정책

  • 광고형 및 모션형 영상에는 레시피 번호가 부여되지 않아 성과 학습 루프에서 제외되며, 참고 영상 기반 대본은 사용자 선호와 포맷 기억을 받지 못하는 한계가 있다.
  • 대화 원문은 1년, 진행 기록은 90일, 경쟁사 게시물은 30일 후 자동 삭제되며, 잘된 초안은 구조만 레시피로 전환 후 원본을 지운다.
  • 사용자 탈퇴 시 암호화 열쇠를 파쇄하는 단계를 포함해 8단계로 데이터를 삭제하여 백업 내 데이터도 복호화 불가능하게 만든다.
