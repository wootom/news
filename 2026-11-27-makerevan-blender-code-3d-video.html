블렌더 GUI 없이 코드로 3D 데모 영상을 자동 생성하는 워크플로우

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

코드로만 블렌더 3D 영상 제작 과정

  • 클로드 데스크톱 앱에 말로 지시하여 블렌더 파이썬 스크립트를 작성하고 렌더링을 수행했으며, GUI 화면은 열지 않았다.
  • 블렌더, 하이퍼프레임즈, 일로, FFM 팩 네 가지 도구를 사용해 3D 렌더링, 자막 합성, 오디오 생성 및 믹싱을 처리했다.
  • 대본과 나레이션을 먼저 확정하고 단어 타이밍에 맞춰 3D 장면의 애니메이션과 카메라 전환 시점을 설정했다.

SVG 기반 마스코트 캐릭터 모델링

  • 스쿼드 사이트의 SVG 아이콘 윤곽선을 가져와 블렌더 커브로 변환하고 복셀 리메시를 적용해 입체적인 젤리 형태를 만들었다.
  • 반투명 재질과 코팅층을 적용해 빛이 22% 정도 통과하도록 설정하고, 눈꺼풀 회전만으로 표정을 표현했다.
  • 사람 캐릭터는 비율 어색함으로 인해 제외하고, 회색 마스코트를 지친 사장 역할로 대체해 화면 톤을 통일했다.

물리 엔진 활용 카드 낙하 시뮬레이션

  • 리즈드 바디 물리 엔진을 사용해 릴스, 상세 페이지, 스레드 화면이 담긴 카드 350장을 떨어뜨리는 장면을 구현했다.
  • 바람을 키프레임으로 제어해도 물리 사전 계산 단계에서 무시되는 문제를 해결하기 위해 바람 위치를 순간 이동시키는 방식을 적용했다.
  • 투명한 벽 제거와 대기 위치 조정으로 카드가 허공에 멈추거나 이상하게 쌓이는 버그를 수정했다.

애니메이션 및 렌더링 최적화

  • 키프레임 기준을 초에서 프레임으로 변환할 때 파이썬 반올림 오류로 인한 겹침을 방지하기 위해 수동 계산 방식을 사용했다.
  • 착지 시 찌그러짐과 늘어남을 적용해 무게감을 표현하고, 1080p 한 장당 5~7초가 걸리는 렌더링 시간을 스틸 이미지 테스트로 단축했다.
  • 카메라는 샷 단위로 위치와 렌즈 길이를 설정하고, 나레이션 문장 전환 시점에 맞춰 컷을 이어 붙였다.

하이퍼프레임즈 합성 및 오디오 믹싱

  • 블렌더 렌더링 영상을 배경으로 하이퍼프레임즈에서 HTML 기반 자막과 실제 앱 화면 캡처를 합성했다.
  • 나레이션은 전체 대본을 한 번에 생성해 톤을 통일하고, 11레븐 랩스로 생성한 배경 음악의 드롭 지점을 착지 순간에 맞추었다. 전체 음량을 유튜브 및 인스타그램 기준인 -14dBFS로 맞춘 후 최종 영상을 완성했다.
