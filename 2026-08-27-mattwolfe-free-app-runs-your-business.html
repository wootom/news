코딩 에이전트로 SaaS 없이 만든 '올인원 비즈니스 컨트롤타워' 무료 대시보드

01핵심 개요 (표)

항목내용
채널Matt Wolfe (구독자 약 100만 명 돌파 시점 공개 영상)
핵심 주제코딩 에이전트(ChatGPT Codex)로 유료 SaaS 없이 개인용 '올인원 비즈니스 대시보드'를 직접 만드는 방법
앱/도구명Wolf Control Tower(원본, 저자 개인용) → 이 영상에서 새로 만드는 버전은 "Control Center"
핵심 기능업계 뉴스 큐레이션, 브랜드/개인명 언급 추적(구글 알리미 대체), 뉴스레터 자동 요약, 소셜 오디언스 성장 추적, 할 일 목록, 다크모드
사용 도구ChatGPT 앱의 Codex(코딩 에이전트), GPT-5.6 계열 모델(고성능/저성능 혼용), Google OAuth(Gmail 연동), GitHub(배포)
화자 배경AI 뉴스 큐레이션 유튜버(매주 금요일 AI 뉴스 총정리 영상 제작), futuretools.io 운영자
배포 방식GitHub 공개 저장소(github.com/MrEFlow/control-center), 로컬 실행 또는 ChatGPT Pro 서버 호스팅
비용무료(단, AI 요약 고도화를 위해 선택적으로 OpenAI/Anthropic/Gemini/Grok API 키 또는 로컬 모델 연결 가능)

02핵심 기능/내용 구조

  1. 업계 뉴스(Industry) 탭 — 우선순위 기반 뉴스 큐레이션: OpenAI, Anthropic, DeepMind 같은 특정 소스와 "AI", "머신러닝", "뉴럴 네트워크" 같은 키워드를 설정해두면, 관련 기사를 자동으로 긁어와 중요도순으로 정렬해 보여준다(242초). 최신순, 오래된순, 관심 사이트 우선순 정렬도 가능하며, 읽은 기사는 리마인더로 저장하거나 보관(archive) 처리할 수 있다. 초기 버전은 22개 기사를 노출했다.
  1. 멘션(Mentions) 탭 — 구글 알리미보다 똑똑한 브랜드/개인명 추적: 자신의 이름이나 브랜드명이 언급된 글을 찾아주되, 동명이인(예: 골프선수 Matt Wolf, 부동산 중개인 Matt Wolf)이나 무관한 콘텐츠(넷플릭스 드라마 속 'Matt Wolf'라는 캐릭터)는 필터링하는 '아이덴티티 인지형 필터링'을 갖췄다(576초). 실제로 팟캐스트 출연분을 정확히 자신에 관한 콘텐츠로 식별해 고신뢰도로 표시하는 장면이 나온다.
  1. 뉴스레터(Newsletters) 탭 — 이메일 뉴스레터 자동 리딩 & 중복 제거: Google OAuth로 전용 Gmail 계정(뉴스레터 전용으로 만든 별도 계정)을 연결하면, 구독 중인 모든 AI 뉴스레터(The Rundown, TLDR, Superhuman, AI Pulse 등)를 읽어 기사 단위로 취합하고 중복 보도를 하나로 합쳐준다(732초, 설정 방법은 815초 부근). 초기엔 단순히 이메일만 감지했지만, 41분짜리 추가 프롬프트 이후 이메일 본문까지 읽어 뉴스로 재구성하도록 개선됐다(898초). 시연 시점 기준 뉴스레터 48건에서 156개의 유효 스토리를 중복 제거해 추출했다.
  1. 오디언스(Audience) 탭 — 소셜미디어 성장 통합 추적: YouTube, X, Instagram, Facebook, LinkedIn, Threads, TikTok 등 여러 플랫폼의 프로필(다중 계정 등록 가능)을 연결하면 각 채널의 팔로워 수와 전일 대비 성장률, 합산 구독자 수를 보여준다(654초). 후속 업데이트에서는 파이 차트(플랫폼별 비중), 채널별 성장 추세 미니 그래프 등 시각화가 추가됐다.
  1. 할 일 목록(Tasks) 탭 — 반복/단발 작업 관리: 매일 반복되는 작업(예: "업계 뉴스 검토")은 완료 시 자동으로 다음 날짜의 새 작업으로 재생성되고, 단발성 작업(예: "Dave가 보낸 계약서 검토")은 체크 시 완료 목록으로 이동한다. 오늘 처리해야 할 작업 대비 완료율(%)도 표시된다.
  1. 투데이(Today) 탭 — 데일리 브리핑 요약 화면: 대시보드 진입 시 첫 화면으로, 업계 뉴스·멘션·뉴스레터 각각에서 가장 중요한 5건씩을 자동으로 뽑아 한 곳에 모아 보여주도록 후속 업데이트됐다(1308초).

03기술적 맥락

이 대시보드는 전통적인 개발 프로세스 없이 ChatGPT 앱의 코딩 에이전트인 Codex를 사용해 처음부터 끝까지 대화형 프롬프트만으로 제작됐다. 저자는 초기 뼈대(bones)를 잡을 때는 가장 성능이 좋은 모델(영상 내 "5.6 소울 하이"로 언급, GPT-5.6 계열의 고성능 추론 모델을 지칭하는 것으로 보임)을 쓰고, 이후 세부 기능을 다듬을 때는 더 가벼운 모델로 전환하는 전략을 권장한다. 실제 빌드는 초기 15분짜리 뼈대 작업 이후, 20분·23분·31분·2시간 37분짜리 후속 프롬프트가 이어지는 등 총 몇 시간에 걸친 반복 수정으로 완성됐다.

뉴스레터 연동에는 Google Cloud Console에서 발급하는 OAuth 클라이언트 ID/시크릿이 필요하며, 이를 로컬 앱(control center)의 리디렉션 URI에 등록해 Gmail API 접근 권한을 부여하는 구조다. 저장은 저자 컴퓨터의 로컬 폴더에 프로젝트로 생성되며, 실행은 로컬호스트(localhost) 기반이다. 코드는 GitHub(github.com/MrEFlow/control-center)에 공개되어 있어, 저장소 URL만 있으면 Codex(또는 Claude Code 등 다른 코딩 에이전트)에 "이 저장소를 클론해줘"라고 지시하는 것만으로 동일한 앱을 자신의 컴퓨터에 설치할 수 있다. 클론에는 약 7초, 의존성 설치와 로컬 실행에는 약 2분 30초가 걸렸다고 시연됐다.

AI 기반 요약·중요도 판단은 기본값으로는 비활성화되어 있으며(AI 없이도 전체 기능 동작), 사용자가 OpenAI·Anthropic·Google Gemini·xAI(Grok) 중 하나의 API 키를 직접 발급해 연결하면 활성화된다. 완전 오프라인 운용을 원하는 사용자를 위해 LM Studio나 Ollama 같은 로컬 모델 연동 옵션도 추가됐다. OpenAI 연결 시 기본 모델은 비용 대비 성능 균형을 이유로 GPT-5 Mini가 채택되어 있으나, 더 강력한 모델(GPT-5.6 Soul 등)로 교체할 수도 있다.

04전략적 의미

저자는 영상 서두에서 "이미지·영상 생성 모델이나 최신 LLM들이 이제는 그저 점진적 개선처럼 느껴져 지루하다"고 말하며, 대신 AI로 실질적인 도구·워크플로우·맞춤형 앱을 직접 만드는 데서 흥분을 느낀다고 밝힌다. 동시에 "SaaS 비즈니스는 AI 시대에 위기에 처할 수 있다"는 진단을 내린다. 이는 코딩 에이전트가 충분히 발전하면, 개인이나 소규모 팀이 자신에게 딱 맞는 도구를 몇 시간 만에 직접 만들어 구독료 없이 쓸 수 있게 된다는 시사점을 담고 있다. 실제로 이 영상에서 소개된 대시보드는 뉴스 큐레이션 SaaS, 소셜 리스닝/브랜드 모니터링 SaaS(구글 알리미의 유료 대체재), 뉴스레터 요약 SaaS, 소셜 오디언스 분석 SaaS, 할 일 관리 앱 등 여러 카테고리의 유료 서비스 기능을 한 무료 오픈소스 앱에 통합한 사례로 제시된다.

또한 이 사례는 "바이브 코딩(vibe coding)"이 단발성 데모를 넘어 실사용 가능한 개인 생산성 인프라로 확장되고 있음을 보여준다. 저자는 이 대시보드를 실제로 자신의 업무에서 "하루 종일 켜두는 단일 탭"으로 쓰고 있다고 밝혀, 단순한 기술 시연이 아니라 실전 운영 도구임을 강조한다. 코드를 GitHub에 무료 공개함으로써, 시청자가 처음부터 다시 만들 필요 없이 즉시 복제해 자신의 산업/관심사에 맞게 커스터마이징할 수 있다는 점도 확산성을 높이는 요소다.

05핵심 워크플로우 또는 비교표

단계내용
1. 프로젝트 생성ChatGPT 앱에서 Codex 진입 → 새 로컬 프로젝트 생성 → 소스 폴더 지정(예: code/control-center)
2. 초기 프롬프트"업계 뉴스 대시보드, 리마인더 섹션, 소셜 오디언스 트래커, 뉴스레터 페이지, 할 일 목록을 각각 별도 탭으로 만들어줘. Granola/Gmail/Google Calendar/Slack 등 연결된 플러그인에 접근 가능하게 해줘"라는 취지로 뼈대를 요청(고성능 모델 사용)
3. 반복 수정동작하지 않는 부분(링크, 뉴스레터 설정 등)을 발견할 때마다 추가 프롬프트로 수정 지시 → 수 시간에 걸쳐 세부 기능 완성, 다크모드 등 누락 기능도 추가
4. 설정(Settings) 페이지 튜닝업계 관심사(트래킹 소스, 키워드, 목표 기사 수, 제외 주제) / 멘션 대상(이름, 브랜드, 공식 사이트, 제외 대상) / 오디언스 SNS 계정 / (선택) AI API 키 입력
5. 뉴스레터 연동Google Cloud Console에서 OAuth 클라이언트 생성 → 리디렉션 URI 등록 → 클라이언트 ID/시크릿을 앱에 입력 → 뉴스레터 전용 Gmail 계정 선택
6. 배포/재사용GitHub 저장소 URL을 코딩 에이전트에 전달해 "clone" 지시 → 의존성 설치 및 로컬 실행 지시 → (선택) ChatGPT Pro 계정으로 ChatGPT 서버에 배포해 어디서든 접속 가능한 URL 확보

06활용 시나리오

  1. 1인 크리에이터/인플루언서의 브랜드 모니터링: 자신의 이름·채널명·소셜 핸들이 언급된 콘텐츠를 동명이인 없이 정확히 걸러내는 개인용 구글 알리미 대체 도구로 활용. 유료 소셜 리스닝 툴 구독을 대체할 수 있다.
  2. 업종별 뉴스 큐레이터 구축: 특정 산업(예: 핀테크, 헬스케어, 게임)에 특화된 소스와 키워드를 설정해, 매일 아침 가장 중요한 뉴스만 우선순위순으로 훑어보는 개인 뉴스룸을 만들 수 있다.
  3. 뉴스레터 다이어트: 수십 개의 업계 뉴스레터를 구독하지만 다 읽을 시간이 없는 사람이, 전용 Gmail 계정으로 뉴스레터만 모아 받고 이 도구가 자동으로 중복 제거·요약해주는 용도로 사용.
  4. 팀/에이전시의 클라이언트별 소셜 오디언스 리포팅: 여러 SNS 계정(다중 클라이언트 포함)을 한 화면에서 성장률과 함께 추적해 별도 유료 애널리틱스 툴 없이 리포트를 만들 수 있다.
  5. 비개발자의 맞춤형 내부 도구 제작 학습 사례: 코딩 경험이 없어도 자연어 프롬프트만으로 실사용 가능한 웹앱을 처음부터 만들 수 있음을 보여주는 실습 템플릿으로, 다른 종류의 개인화 대시보드(예: 재무 관리, 독서 트래커) 제작에도 응용 가능하다.

07현황 및 전망

영상 공개 시점 기준으로 이 대시보드는 이미 저자가 실제 업무에서 매일 사용하는 도구로 자리 잡았으며, 영상 녹화 이후에도 계속 기능이 추가되고 있다고 밝힌다(투데이 탭 자동 요약, 멘션 페이지 AI 요약·우선순위 정렬, 오디언스 페이지 차트 시각화, Grok·로컬 모델(LM Studio/Ollama) 지원 추가 등). 저자는 "GitHub에서 다운로드하는 시점의 버전이 영상에서 보여준 것보다 더 나을 수도 있다"고 언급할 정도로 지속적인 업데이트를 예고한다.

또한 로컬 실행의 한계(한 대의 컴퓨터에서만 접근 가능, 매번 로컬호스트를 켜야 함)를 보완하기 위해, ChatGPT Pro/유료 플랜 사용자는 별도 비용 없이 ChatGPT 서버에 앱 전체를 배포해 어디서든(모바일, 다른 컴퓨터) 접속 가능한 URL을 받을 수 있는 방법도 함께 소개된다(배포에 약 21분 소요, ChatGPT 로그인으로 접근 제한). 이는 개인 프로젝트 수준의 바이브 코딩 결과물이 별도의 클라우드 인프라 구축 없이도 실서비스처럼 배포될 수 있음을 보여주는 사례로, 향후 코딩 에이전트와 호스팅 플랫폼의 결합이 개인 SaaS 대체 흐름을 더 가속할 가능성을 시사한다.

08용어 사전

용어설명
CodexChatGPT 앱 내에 통합된 코딩 에이전트로, 자연어 프롬프트를 받아 실제 코드를 작성·수정·실행하는 도구
바이브 코딩(vibe coding)개발자가 코드를 직접 작성하지 않고 AI에게 원하는 결과를 자연어로 설명해 앱을 만들어가는 개발 방식
