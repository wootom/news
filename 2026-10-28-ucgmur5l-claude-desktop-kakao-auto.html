클로드 데스크탑 프로젝트로 AI가 카톡을 직접 작성하고 보내기 직전까지 자동화하는 방법

클로드 데스크탑 프로젝트로 AI가 카톡을 작성하고 전송 직전까지 자동화하는 방법

영상 발화자의 견해·경험을 원문에 근거해 정리한 요약입니다.

01핵심 개요

  • 클로드 데스크탑의 새 프로젝트 기능은 목표를 저장해 반복 작업 시 매번 설명할 필요 없이 규칙을 기억한다.
  • 에이전트 구조에서 팀장 AI가 일을 나누고 팀원 AI가 폴더 파일과 화면 제어를 동시에 수행한다.
  • 카톡 PC 앱은 API가 없어 화면을 보고 마우스·키보드로 조작하며, 보내기 버튼은 사람이 누른다.
  • 컴퓨터 사용 기능은 유료 요금제와 설정 활성화, 그리고 손쉬운 사용·화면 기록 허락이 필요하다.
  • 보안상 한 번만 허락과 멈춤 단추를 활용하며, 화면에 민감한 정보가 있는지 사전에 확인해야 한다.

02핵심 주장 / 논점 구조

  • 클로드 데스크탑 앱은 클로드 코드의 힘을 결합해 폴더 파일 읽기와 화면 제어를 동시에 수행한다.
  • 새 프로젝트 기능은 대화 하나를 방으로 만들어 목표와 자료를 저장하고 규칙을 기억하게 한다.
  • 에이전트 구조에서 팀장 AI가 큰 일을 여러 갈래로 나누고 팀원 AI가 동시에 처리한다.
  • 카카오톡은 AI와 직접 연결되는 기능이 없어 사람처럼 화면을 보고 마우스·키보드로 조작해야 한다.
  • 최종 전송 버튼은 사람이 누르도록 설계되어 AI의 오동작 위험을 줄이는 안전장치를 제공한다.

03클로드 프로젝트 기능 변화와 에이전트 구조

  • 기존 화면 제어는 대화마다 폴더와 규칙을 매번 설명해야 했지만, 프로젝트는 이를 저장한다.
  • 프로젝트는 목표, 지침, 지난 일을 공유하는 단일 대화 공간으로 기능한다.
  • 팀장 AI는 일을 나누는 역할을 하며, 팀원 AI는 폴더 접근과 화면 조작을 담당한다.
  • 노트북을 닫아도 클라우드에서 작업이 계속되며, 필요 시 로컬 폴더에서도 일할 수 있다.
  • 이 구조는 늘 같은 규칙으로 반복되는 업무, 예를 들어 카톡 보내기에 적합하다.

04데스크탑 앱 필수 조건과 설정 절차

  • 클로드 데스크탑 앱에 유료 요금제로 로그인해야 프로젝트 기능을 사용할 수 있다.
  • 설정에서 '컴퓨터 사용' 스위치를 켜야 화면 제어 기능이 활성화된다.
  • 맥에서는 처음 실행 시 손쉬운 사용과 화면 기록에 대한 시스템 허락을 받아야 한다.
  • 카카오톡 PC 앱이 설치되어 있고 로그인된 상태여야 AI가 창을 열 수 있다.
  • 보낼 글을 저장할 로컬 폴더를 미리 준비하고 프로젝트에 컨텍스트로 연결해야 한다.

05카톡 자동화 시연 과정과 허락 관리

  • 사용자는 '내 맥에서 준비해 둔 내일 할 일을 나와의 채팅에 넣어 줘'라고 지시한다.
  • 클로드는 데모 폴더에서 글을 읽고, 카카오톡 앱과 클립보드 사용 허락을 요청한다.
  • 동시에 두 갈래가 생성될 수 있어, 한쪽만 선택해 진행하도록 지시해야 중복 입력을 방지한다.
  • 허락 창은 메인 화면이 아닌 개별 스레드 내부에 뜨므로, 멈춘 것처럼 보이면 스레드를 눌러 확인한다.
  • AI는 카톡 입력창에 글을 넣고 '보내기' 버튼 클릭 직전에 멈춰 사용자에게 확인을 요청한다.

06보안 주의사항과 안전 장치 활용

  • 화면을 AI에 맡기기 전, 채팅창에 비밀번호나 민감한 정보가 있는지 먼저 확인해야 한다.
  • 클로드는 채팅창에 적힌 메일 ID와 비밀번호를 감지하고 방송 노출 위험을 경고했다.
  • 처음 사용 시에는 '한 번만 허락'을 눌러 동작을 확인한 후, 신뢰가 생기면 '늘 허락'으로 변경한다.
  • 화면 조작 중 빨간 띠가 뜨며, 옆의 '멈춤' 단추로 즉시 AI의 화면 제어를 중단할 수 있다.
  • AI가 대상을 잘못 선택하거나 이상한 동작을 할 경우, 멈춤 단추를 눌러 즉시 제어권을 회수한다.

07확장 가능성과 향후 전망

  • 터미널용 클로드 코드에도 컴퓨터 사용 시험 기능이 있어, 데스크탑 외 환경에서도 활용 가능하다.
  • 카톡 외에도 매주 반복되는 다른 업무에 프로젝트를 적용해 자동화 범위를 넓힐 수 있다.
  • AI가 채팅 내용을 읽고 답을 지어 보내는 기능도 가능하지만, 오보 위험이 있어 주의가 필요하다.
  • 로컬 파일 분석과 화면 조작 결합으로, 단순 입력을 넘어 데이터 기반 의사결정 보조가 가능하다.
  • 다음 영상에서는 터미널 환경에서의 클로드 코드 화면 제어 시험 기능을 다룰 예정이다.
