Codex를 비기술자의 AI 운영체제와 고객용 제작 도구로 활용하는 방법을 설명한다.

비기술자도 Codex로 AI 운영체제·자동화·고객용 납품물을 만드는 18개 핵심 개념.

01핵심 개요

  • Nate Herk는 기술 배경 없이 AI를 활용해 월 10만 달러 이상의 컨설팅 사업을 확장했고, 현재 사업 단위 평균 월 40만 달러 이상을 만든다고 말한다.
  • 강의는 ChatGPT 데스크톱 앱의 Codex 설치부터 프로젝트, agents.md, 에이전트 루프, 목표 설정 등 18개 핵심 개념을 다룬다.
  • 프로젝트는 폴더와 파일의 집합이며, Herk 2 프로젝트에는 규칙·자격 증명·유튜브 자료·활성 작업 관련 지식이 담겨 있다고 설명한다.
  • agents.md는 프로젝트별 규칙과 라우팅 맵을 담는 마크다운 파일로, Codex가 사용자 메시지보다 먼저 읽는다고 소개한다.
  • Codex는 로컬 파일 편집, localhost 결과물 생성, 휴대폰 원격 대화, 작업 트리 실험 및 모델 선택을 지원한다고 설명한다.

02핵심 주장 / 논점 구조

  • 발표자는 Codex가 자연어만으로도 비기술자가 활용할 수 있는 강력한 도구이며, ChatGPT Work보다 확장 기능이 많다고 주장한다.
  • 강의의 목표는 Codex 설치와 핵심 원리 이해를 넘어, AI 운영체제·세컨드 브레인·자동화 제작 체계를 만드는 것이다.
  • 이미지, 웹사이트 디자인, 영상 편집, 자동화, 브랜드화된 납품물 제작과 이를 고객에게 판매하는 방법까지 다룬다고 예고한다.
  • Claude Code 사용자도 기존 프로젝트 파일을 Codex 형식에 맞춰 복제·정리하면 전환할 수 있다고 설명한다.

03설치와 구독 요금 운영

  • Google에서 ChatGPT 또는 Codex를 검색해 운영체제용 앱을 설치하며, 강의에서는 ChatGPT 데스크톱 앱의 Codex를 사용한다.
  • 기존 ChatGPT 구독자는 같은 계정을 사용할 수 있고, 무료 계정 사용자는 월 20달러 요금제부터 시작하라고 권한다.
  • 발표자는 월 200달러 요금제를 사용하며, 주간 한도를 소진하면 초기화까지 기다리거나 API 사용량 과금을 선택할 수 있다고 말한다.
  • 그는 200달러 구독으로 전체 사용 시 약 1만4,000달러의 추론 사용량을 얻는다고 설명하며, 이를 생산성 비용으로 본다.

04프로젝트와 agents.md로 만드는 AI 운영체제

  • 프로젝트는 폴더와 파일의 집합으로, 새 대화마다 사업·업무 맥락을 다시 설명하는 문제를 줄이는 구조로 제시된다.
  • Herk 2에는 규칙, 자격 증명, 프로젝트, 유튜브 영상 등이 있으며, Codex는 이전 대화와 프로젝트 자료를 찾아 최근 업무를 요약한다.
  • agents.md의 MD는 마크다운을 뜻하며, 파일에는 프로젝트 역할, 작업 방식, 데스크톱 안전 규칙 등을 기록할 수 있다.
  • 라우팅 맵은 사업 정보는 위키, 기업 구조는 위키의 해당 섹션, 목소리·강의 지식·활성 프로젝트는 각각의 위치로 연결한다.

05에이전트 루프와 목표 기반 실행

  • Codex·Claude Code·Hermes Agent 같은 에이전트 하니스는 생각하고 추론한 뒤 도구를 사용하고 응답하는 에이전트 루프를 가진다고 설명한다.
  • Codex는 최근 작업을 찾는 요청에서 memory.md와 다른 대화를 읽고 명령을 실행하는 과정을 화면에서 보여준다.
  • 최근 유튜브 영상의 재미있는 댓글 3개를 찾는 예시에서는 YouTube 데이터에 접근할 명령을 실행해 결과를 가져온다고 설명한다.
  • slash goal은 목표 달성까지 계속 실행하게 하는 기능으로, ‘257개 출처를 모아 보고서 작성’처럼 객관적인 목표가 더 효과적이라고 말한다.
  • Hyperframes에서 인트로 장면 1개와 카드 18개를 요청한 사례에서는 완성 뒤 스크린샷으로 시각 검토까지 했다고 소개한다.

06로컬·클라우드 환경과 원격 작업

  • 로컬은 현재 사용 중인 컴퓨터에서만 접근 가능한 파일·결과물을 뜻하며, OneDrive 동기화 시에는 클라우드로 전송될 수 있다고 설명한다.
  • 127.0.0.1과 포트 8008의 localhost 주소는 해당 로컬 장치에서만 동작하므로 다른 사람에게 보내도 동일한 사이트가 열리지 않는다고 설명한다.
  • 로컬 대화에서는 Codex가 파일 생성·삭제·수정·이동과 다운로드·데스크톱 접근 등 컴퓨터 작업을 수행할 수 있다고 말한다.
  • 휴대폰 ChatGPT 앱의 Remote 기능으로, 데스크톱이 켜져 있으면 외출 중에도 로컬 Codex 대화를 보고 메시지를 보낼 수 있다고 시연한다.

07작업 트리·설정 범위·모델 선택

  • 작업 트리는 Herk 2의 복제본을 만들어 병렬로 실험하고, 나중에 메인 브랜치에 병합하는 방식으로 설명된다.
  • 발표자는 지식 업무에서는 작업 트리를 거의 쓰지 않지만, 소프트웨어 작업 중 Codex가 새 작업 트리 사용을 제안할 수 있다고 말한다.
  • 프로젝트 내부의 .codex에는 agents, workflows, config.yaml 같은 설정이 있고, 사용자 전역 .codex에는 메모리·세션·자동화 같은 전역 설정이 있다고 설명한다.
  • 새 대화와 메시지 사이에서 모델을 바꿀 수 있으며, GBD6 Astra는 가장 강력하지만 주간 사용량을 더 빨리 소모한다고 소개한다.
  • API 가격은 토큰 기준이며, Astra는 입력 100만 토큰당 10달러, 출력 100만 토큰당 50달러라고 설명한다.

08용어 사전

용어뜻
CodexOpenAI와 ChatGPT의 제품으로 소개되며, 데스크톱 앱에서 프로젝트 파일과 자연어 요청을 바탕으로 작업하는 도구다.
agents.md프로젝트 역할·작업 규칙·안전 규칙·자료 위치의 라우팅 맵을 기록하는 마크다운 파일이다.
에이전트 루프에이전트가 요청을 받은 뒤 추론하고 도구를 사용해 행동한 후 응답하는 반복 과정이다.
slash goal에이전트가 설정된 목표를 달성할 때까지 재시도하며 작업하도록 하는 목표 기반 요청 방식이다.
작업 트리메인 작업을 방해하지 않고 변경을 시험하기 위해 프로젝트 복제본에서 병렬 작업하는 환경이다.
